# 회로 실험실

**전기회로의 구성·측정·시각화를 지원하는 수업용 웹앱**

[**앱 열기 ↗**](https://cho-wh.github.io/circuit/)　·　[사용 설명서](docs/ux/quick-start.md)　·　[개발자 안내](docs/development/README.md)

</div>

<br>

**전기회로 수업과 탐구 활동을 고민하는 교사의 입장에서 만들었습니다.**

* **복잡하지 않은 조작**으로 회로를 구성할 수 있습니다.
* 쉽게 **측정하고 직관적으로 시각화**하여 회로를 이해할 수 있습니다.
* 위험한 회로에서 **소자의 과부화와 파손**을 확인할 수 있습니다.
* **문제지용 회로도**를 쉽게 편집하고 출력할 수 있습니다.

## 수업 활용 예시

예제 회로의 값과 표시를 조절해 다음 활동에 활용할 수 있습니다.

| 주제                 | 예제 회로                         | 활동 방법                                          |
| :------------------- | :-------------------------------- | :------------------------------------------------- |
| 직렬·병렬 연결       | 직렬 · 병렬 · 12 V 직병렬 혼합    | 전위 숫자 숨기기 → 값 예상 → 측정값과 비교         |
| 저항값과 전류의 관계 | 가변저항 (직렬) · 가변저항 (병렬) | 저항값 조절 → 각 전류와 전위차 변화 실시간 비교 |
| 다이오드의 정류 작용 | 브릿지 정류 회로                  | 전원 방향 전환 → 가운데 저항의 전류 방향 비교      |
| 전위차와 전류        | 휘트스톤 브릿지                   | 저항값 조절 → 가운데에 전류가 흐르지 않는 저항값 찾기     |

## 시작하기

1. **회로 열기** — [앱](https://cho-wh.github.io/circuit/)에서 **예제 회로 → 직렬**을 선택합니다.
2. **관찰하기** — **분석하기 → 3D**에서 전위를 높이로 확인합니다.
3. **측정하기** — **전압 탐침**을 선택하고 2D에서 저항 양끝을 누릅니다.

휴대폰에서는 **+ 부품 → 예제 회로**로 시작합니다.

**사용 설명서** · [회로 편집](docs/ux/quick-start.md#components) · [측정](docs/ux/quick-start.md#measurement) · [출력](docs/ux/quick-start.md#worksheet) · [터치·단축키](docs/ux/quick-start.md#controls)

## 추가 기능

### 유연한 인터페이스
- **마우스·터치** 모두 지원. 기본적으로 태블릿 이상의 화면을 권장하나, 휴대폰에서도 좁은 화면에 맞는 UI를 제공합니다.
- **출력 글자 배치·주석 편집** 등 모든 기능은 태블릿 이상의 넓은 화면에서 제공합니다.

### 데이터 저장
- **회로**는 현재 브라우저에 자동 저장됩니다. 별도 보관·기기 이동은 **파일 → 회로 파일 저장**을 이용합니다.
- **측정 기록**은 회로 파일에 포함되지 않습니다. 표나 CSV로 내보냅니다.

### 회로의 손상
- 기본적으로는 이상적인 소자(내부저항이 없는 등)를 시뮬레이션하지만, **고전류 등 위험한 회로** 조건에서는 적절한 현실 값을 적용하여 손상을 시뮬레이션합니다.

## 앞으로의 개발 방향

| 개발 방향                          | 목표                                                                                     |
| :--------------------------------- | :--------------------------------------------------------------------------------------- |
| **학생과 함께 탐구하는 활동 모드** | 교사가 회로·탐구 과제를 준비하고, 학생이 예측 → 조작 → 측정 → 비교를 이어 가는 활동 지원 |
| **다양한 소자와 세부 특성 지원**   | 소자 종류 확대, 수업 목적에 맞는 특성·설정·표현의 세분화                                 |

위 항목은 **향후 계획**입니다. 구체적인 범위와 일정은 수업에서의 필요와 검증 결과에 따라 정합니다.
