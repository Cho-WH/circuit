# 회로 실험실 · 1차 MVP 0.1

같은 회로 데이터에서 편집·직류 해석·전위 시각화·측정·문제 출력을 연결하는 한국어 교육용 웹앱이다. 이상적인 선형 직류 저항 회로를 지원한다.

## 실행

```bash
npm ci
npm run dev
```

Node.js 20.19 이상이 필요하다. 기본 주소는 http://localhost:5173 이다. 이 Windows 작업 환경에서는 `powershell -ExecutionPolicy Bypass -File tools/run-dev.ps1`로 번들 Node와 설치된 의존성을 사용해 실행할 수도 있다.

`npm run build`로 `dist/`를 생성한다. 회로 기능은 외부 서버·로그인·API 키 없이 동작한다.

## 사용 흐름

1. **회로 만들기**: 예제를 열거나 부품을 배치하고 단자에서 배선을 시작한다. 선택 도선의 분기 힌트와 교차점 클릭으로 연결을 편집한다. 이름·값을 함께 수정하며 분수와 아래첨자를 지원한다.
2. **분석하기**: 전위 숫자·색상·3D 높이와 전류 흐름을 살펴본다. 기본 색상은 전체 스펙트럼이며 색상바를 눌러 세 팔레트 중 선택한다. 넓은 화면에서는 경로 그래프도 비교한다.
3. **측정 도구**: 분석하기에서 빨강·검정 탐침으로 전압을, 비접촉 센서로 전류를 측정한다. 탐침 옆 숫자는 각 지점의 전위다. 등가저항 측정에서는 모든 직류 전원을 분리한다. 측정 기록·메모를 표 복사·CSV로 내보낼 수 있다.
4. **회로도 출력**: 이름·값의 표시·빈칸·위치를 조절하고 점·전류 화살표·글자를 배치한다. 수학 글꼴을 포함한 SVG·PNG를 저장하거나 그림을 복사한다.

모바일은 **+ 부품**에서 부품·예제를 고르고, 분석의 **측정** 버튼으로 같은 도구 바를 전환한다. **전위**는 색상만 켜고 끄며 숫자는 유지한다. 보기 바의 **⋯**에서 현재 색상바를 누르면 팔레트 목록이 펼쳐진다. **회로도 출력**은 상단 **⋯**에서 열어 복사·저장하며 정밀 표기·주석 편집은 넓은 화면에서 제공한다. 도움말과 피드백은 상단 물음표·말풍선 아이콘으로 연다.

자동 저장은 현재 브라우저에 남으며 JSON으로 별도 보관할 수 있다. 측정 기록·메모는 회로와 별도로 저장되어 새로고침 후 복원되지만 실행 취소 이력은 초기화된다. 회로 JSON에는 측정 기록이 포함되지 않는다. 파일 형식은 `edu-circuit` v5이며 이전 형식은 지원하지 않는다. 계산은 정확 유리수를 기본으로 하고 연산 예산을 초과하면 명시적인 근사 경로를 사용한다. ‘한마디’ 게시판은 Firebase에 연결되어 공개·비공개 글을 처리한다.

터치는 부품 탭 후 배치를 지원하며, 넓은 화면의 부품 목록에서는 길게 눌러 끌어올 수도 있다. 빈 공간에는 바로 놓고 도선에는 미리보기 후 **삽입**으로 확정한다. 회로의 선택 부품은 바로 끌거나 **이동 → 목적지 탭 → 놓기**를 사용한다. 두 손가락은 화면 이동·확대이며 진행 중 편집을 취소한다. 넓은 화면의 출력 표기는 방향 버튼으로도 조절한다. 실제 휴대전화·OS 키보드 검증은 남아 있으며 [남은 작업과 검증](docs/implementation/follow-up.md)에 범위를 기록했다.

## 개발과 배포

로컬과 CI의 공통 검증 명령은 `npm run verify`다. 변경에 맞는 개별 검증 명령과 GitHub Pages 운영 절차는 [개발 운영](docs/operations/development-workflow.md)에 모았다. 게시 주소는 https://cho-wh.github.io/circuit/ 이며, `codex/mvp`에 푸시하면 Actions가 검증 후 정적 빌드를 게시한다. 작업 트리의 변경은 푸시·배포 전까지 공개 사이트에 반영되지 않는다.
