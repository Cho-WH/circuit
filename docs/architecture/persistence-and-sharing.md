# 저장·복구·공유

## 현재 저장 계약

회로 편집·계산·출력은 로그인이나 서버 없이 작동한다. 저장·공유되는 회로 구조의 원본은 `CircuitDocument`이며 계산 결과와 일시적인 UI 상태는 포함하지 않는다.

- 자동 저장은 브라우저 `localStorage`에 마지막 변경 후 450 ms 지연해 기록한다. 이전의 유효한 자동 저장본은 별도 백업 키에 둔다.
- 파일 메뉴의 현재 회로 보관은 자동 저장과 별도 키에 사본을 남긴다. 회로 파일 저장·열기는 JSON 파일만 다루며 보관본을 갱신하지 않는다. 보관한 회로 불러오기는 ReplaceDocument 명령으로 적용되어 실행 취소할 수 있다.
- 자동 저장본이 손상되면 유효한 이전 자동 저장본을 불러온다. 수동 복원 지점은 사용자가 명시적으로 복원한다.
- 브라우저 데이터 삭제나 다른 기기·사이트 주소로의 이동은 로컬 저장본을 옮기지 않는다. 중요한 회로는 JSON 파일로 보관해야 한다.

## 파일 열기와 버전

현재 파일 형식은 `edu-circuit` v4다. v1·v2·v3 파일은 해당 버전의 보존된 스키마로 검증한 뒤 `v1 → v2 → v3 → v4` 순서로 새 문서에 변환한다. 현재 v4 스키마와 ID 참조 무결성을 검사한 결과만 적용한다. 잘못된 JSON·지원하지 않는 버전·깨진 참조는 구조화된 진단으로 거부하며 현재 문서를 바꾸지 않는다. 이전 버전 fixture와 JSON 왕복 검사를 유지한다. 출력 표기와 화살표 저장 계약은 [ADR-012](../../decisions/ADR-012-worksheet-presentation.md)를 따른다.

## 후속 공유 범위

공유 링크와 학생 활동 배포는 단계 6의 미구현 범위다. 링크가 도입되면 보기·제한된 조작·측정·자유 편집 권한을 명시하고, 학생 식별 정보·비밀 키·장기 인증 토큰·교사 원본 수정 권한을 URL에 싣지 않는다. URL 직접 내장과 서버 ID 방식의 선택은 [ADR-005](../../decisions/ADR-005-share-link.md)를 따른다.

회로·활동 기본 스키마에는 개인 식별 필드를 두지 않는다. 상세 행동 로그는 별도 동의를 전제로 한다. 후기 게시판의 Firebase 저장은 회로 문서 저장과 별도이며 [게시판 구조](feedback.md)를 따른다.
