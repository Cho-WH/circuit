# 저장·복구·공유

## 현재 저장 계약

회로 편집·계산·출력은 로그인이나 서버 없이 작동한다. 저장·공유되는 회로 구조의 원본은 `CircuitDocument`이며 계산 결과와 일시적인 UI 상태는 포함하지 않는다.

- 자동 저장은 브라우저 `localStorage`에 마지막 변경 후 450 ms 지연해 기록한다. 이전의 유효한 자동 저장본은 별도 백업 키에 둔다.
- 파일 메뉴의 현재 회로 보관은 자동 저장과 별도 키에 사본을 남긴다. 회로 파일 저장·열기는 JSON 파일만 다루며 보관본을 갱신하지 않는다. 보관한 회로 불러오기는 ReplaceDocument 명령으로 적용되어 실행 취소할 수 있다.
- 자동 저장본을 읽지 못하면 자동 저장을 멈추고 새 회로·복원·백업을 제공한다. 복원 실패 후에는 새 회로·백업만 남긴다. 유효한 이전 자동 저장본도 복원 버튼을 누른 뒤 적용한다. 새 회로·복원 결과를 저장하기 전에 원문을 별도 보관하며 파일 메뉴에서 다시 내려받을 수 있다. 보관·저장 실패 시 기존 원본을 덮어쓰지 않는다. [ADR-039](../../decisions/ADR-039-circuit-recovery.md).
- 브라우저 데이터 삭제나 다른 기기·사이트 주소로의 이동은 로컬 저장본을 옮기지 않는다. 중요한 회로는 JSON 파일로 보관해야 한다.

## 안정판·개발판 저장 공간

[ADR-027](../../decisions/ADR-027-release-channels.md)에 따라 빌드 채널 main/dev를 모든 브라우저 저장 키 앞에 붙인다. 자동·수동 회로, 측정 기록, 각각의 백업, 첫 안내, 로컬 후기 미리보기가 분리된다. 예: `main:edu-circuit:auto:v1`, `dev:edu-circuit:auto:v1`. 경로나 문서 안에 채널을 기록하지 않고 `release` 공개 모듈을 공유한다.

기존 접두사 없는 저장본은 해당 채널 키가 없고 검증을 통과할 때만 복사한다. 측정 기록 v5는 아래의 검증 변환을 거쳐 v6 키로 복사한다. 원본은 삭제하지 않고, 한 번 생성된 채널 키를 기존 공용 데이터로 덮어쓰지 않는다. 다른 채널 키는 복구 후보로도 읽지 않는다. 지원 밖 형식은 변환 없이 남겨 둔다. 파일 가져오기와 Firebase 운영 후기·인증은 기존 계약을 유지한다.

## 파일 열기와 버전

현재 파일 형식은 `edu-circuit` v7다. 정상 읽기는 현재 스키마·정규형 물리값·ID 참조 무결성을 검사한 결과만 적용한다. 복원 버튼에서는 고정된 v5 또는 v6 스키마를 통과한 문서를 v7로 변환하고 다시 검증한다. 원문 보관에 성공한 뒤 저장하며 v1~4·미래 버전·깨진 연결·구버전으로 위장한 축전기는 추측해서 고치지 않는다. 파일 열기·수동 보관본의 실패도 같은 복원 안내를 사용한다. 버전 전환은 [ADR-042](../../decisions/ADR-042-rc-contracts-storage.md), 정확값 저장은 [ADR-024](../../decisions/ADR-024-exact-dc-arithmetic.md), 출력 표기는 [ADR-012](../../decisions/ADR-012-worksheet-presentation.md)를 따른다.

## 측정표

측정표는 회로 파일과 별도의 브라우저 기록이다. `<channel>:edu-circuit:measurement-notebook:v6`에 버전 6 목록을 저장하고 유효한 이전 사본을 백업한다. 문서 스냅샷·측정값·방향·전원 분리 조건·메모와 정확한 탐침/센서 위치를 검증해 복원한다. 값은 정규형 정수 문자열 쌍이며 record.quality와 근사값의 approximation(reason/policy/absoluteError)을 함께 검증한다. 누락·불일치는 거부하며 스냅샷은 회로 v7다.

v6 키가 없을 때에만 검증된 기록 v5와 내부 회로 v6를 변환해 새 키에 복사한다. 원래 v5 키·백업은 그대로 둔다. DC 기록에 RC 시간 출처를 만들어 넣지 않는다. 현재 v6 키가 있으면 구버전으로 되돌리지 않으며, 손상된 현재 기록은 같은 버전 백업으로만 복구한다. 복구한 기록을 수정·삭제하여 저장할 때 손상 원문을 `<channel>:edu-circuit:measurement-notebook:originals:v1`에 먼저 보관한다. 백업 회전 시 손상 백업도 보관한다. 원문 보관 실패 시 덮어쓰지 않는다. 읽기 실패를 빈 기록으로 취급하지 않고, 일반 쓰기 실패 시 메모리 기록과 표 복사/CSV 저장을 유지한다. 다중 탭 병합은 지원하지 않는다. [ADR-022](../../decisions/ADR-022-measurement-notebook.md), [ADR-042](../../decisions/ADR-042-rc-contracts-storage.md).

RC 기록은 `transient`에 회로 리비전·조작 번호·frame ID·물리/연산/안정화 정책과 finite/equilibrium 시간을 남긴다. equilibrium에는 유한 seconds를 넣지 않는다. RC 출처와 근사값은 함께 검증하며 DC 출처와 혼합하지 않는다. 실제 RC 측정 UI 연결은 C4다.

## 후속 공유 범위

측정 기록의 선택적 `provenance`는 `physicalModel`, `profileRevision`, `arithmeticQuality`를 함께 보존한다. 분석 결과에서 만든 기록은 이 출처를 전달하고, 외부 측정이나 기존 선형 공개 API처럼 출처가 없는 기록은 실제로 제공된 조건만 저장한다. 물리 모델의 교육용 근사와 수치 연산 품질을 하나의 quality로 합치지 않는다.

공유 링크와 학생 활동 배포는 단계 6의 미구현 범위다. 링크가 도입되면 보기·제한된 조작·측정·자유 편집 권한을 명시하고, 학생 식별 정보·비밀 키·장기 인증 토큰·교사 원본 수정 권한을 URL에 싣지 않는다. URL 직접 내장과 서버 ID 방식의 선택은 [ADR-005](../../decisions/ADR-005-share-link.md)를 따른다.

회로·활동 기본 스키마에는 개인 식별 필드를 두지 않는다. 상세 행동 로그는 별도 동의를 전제로 한다. 후기 게시판의 Firebase 저장은 회로 문서 저장과 별도이며 [게시판 구조](feedback.md)를 따른다.

다이오드 종류 확장은 당시 회로 v6·측정 기록 v5 안에서 두 프로필 ID를 추가했다. C1 변환에서도 기존 프로필 및 참조 생략 의미를 보존한다. 모르는 ID/revision과 지원 밖 문서 버전은 거부한다. 종류 선택 당시 ID는 회로 복사·기록 스냅샷·출처에 함께 남는다. [ADR-028](../../decisions/ADR-028-diode-kinds.md).
