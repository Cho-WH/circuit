# 저장·복구·공유

## 로컬 우선

핵심 편집, 시뮬레이션, 출력은 로그인과 서버 없이 작동한다.

- 자동 저장: IndexedDB 또는 동등한 로컬 저장소
- 명시 저장: 버전이 포함된 JSON 파일
- 열기: 스키마 검증 후 현재 버전으로 마이그레이션
- 공유: 작은 문서는 URL 또는 압축 코드, 큰 문서는 후속 서버 ID 방식 검토

## 자동 저장

- 매 동작마다 디스크에 쓰지 않고 짧은 지연 후 마지막 안정 문서를 저장한다.
- 현재 작업, 마지막 정상 저장본, 활동 원본 스냅샷을 분리한다.
- 스키마 검증을 통과한 문서만 정상 저장본으로 승격한다.
- 비정상 종료 흔적이 있으면 자동 복구본과 마지막 명시 저장본을 비교해 선택하게 한다.

## 파일 열기

1. `format`과 `version`을 확인한다.
2. JSON Schema로 구조를 검증한다.
3. 오래된 버전이면 순차 마이그레이션을 적용한다.
4. 도메인 불변식을 검사한다.
5. 실패하면 현재 문서를 변경하지 않고 원인과 복구 방법을 안내한다.

## 버전과 마이그레이션

- 현재 저장 형식은 `edu-circuit` version 2이다. v1은 이전 스키마 검증 후 출력 주석의 가시성을 변환한다. 상세 계약은 ADR-012를 따른다.
- 변환은 `v1 → v2 → v3`처럼 한 단계씩 적용한다.
- 변환 전 원본을 보존한다.
- 마이그레이션 함수는 새 객체를 반환한다.
- 이전 fixture에 대한 왕복 테스트를 유지한다.

## 공유 링크

공유 링크에는 다음을 포함하지 않는다.

- 학생 이름, 학번, 이메일
- 비밀 키
- 장기 인증 토큰
- 교사 원본을 수정할 수 있는 암묵적 권한

링크는 다음 권한을 명시한다.

- 보기만 가능
- 스위치·지정 값만 변경
- 측정 가능
- 자유 편집

URL 직접 내장 크기와 서버 ID 방식의 경계는 `ADR-005`에서 확정한다.

## 개인정보

- 회로·활동 기본 스키마에 개인 식별 필드를 두지 않는다.
- 상세 행동 로그는 별도 동의를 전제로 한다.
- 오류 보고에는 앱 버전, 진단 코드, 사용자가 선택한 익명화된 회로 구조만 포함한다.
