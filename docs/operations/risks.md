# 위험과 완화책

| ID | 위험 | 영향 | 완화 |
|---|---|---:|---|
| R-01 | 배선 UX가 예상보다 복잡함 | 높음 | 자동 추측을 줄이고 명시적 연결, 경로 미리보기, 실행 취소를 우선한다. |
| R-02 | 전위 색·3D가 오개념을 만들 수 있음 | 높음 | PV 규약과 교사·학생 이해도 테스트를 출시 게이트로 둔다. |
| R-03 | 기능 추가로 모듈 경계가 무너짐 | 중간 | import 규칙, 공개 API, ADR, PR 검토를 적용한다. |
| R-04 | 저장 형식 변경으로 이전 파일이 손상됨 | 높음 | 스키마 버전, 순차 마이그레이션, 원본 보존, fixture를 유지한다. |
| R-05 | 3D가 저사양 기기에서 느림 | 중간 | 자동 품질 저하, 2D 대체 표현, 지오메트리 재사용을 적용한다. |
| R-06 | 화면과 인쇄 출력이 다름 | 중간 | 같은 `SymbolDefinition`을 공유하고 인쇄 렌더러를 별도 테스트한다. |
| R-07 | 초기부터 과도한 플러그인 구조를 만듦 | 중간 | 실제 두 번째 구현 전에는 공개 인터페이스만 둔다. |
| R-08 | 교실에서 원본 활동을 실수로 변경함 | 높음 | 원본, 학생 작업본, 초기화 스냅샷을 분리하고 읽기 전용 링크를 제공한다. |

## 현재 기준

- 기본 기호는 한국 고등학교 교과서에서 익숙한 한 세트를 먼저 완성한다.
- 접지가 없으면 전지 음극 0 V를 제안하되 항상 표시하고 변경 가능하게 한다.
- 전구는 MVP에서 제외하거나 고정 저항성 부하로 명시한다.
- 초기 저장소는 단일 저장소·단일 앱·모듈 폴더 구조다.
- 계산 범위는 선형 직류 해석에 집중한다.
- 계정, 성적, 개인 식별 정보는 MVP에 포함하지 않는다.
