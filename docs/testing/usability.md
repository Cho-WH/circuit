# 사용성 검증

## 첫 사용자 과제

| 번호 | 과제 | 관찰할 점 |
|---:|---|---|
| 1 | 9 V 전지와 10 Ω 저항 두 개를 직렬로 연결한다. | 부품 찾기, 배치, 단자 인식, 배선 오류 |
| 2 | 두 번째 저항 양단의 전압을 측정한다. | 탐침 방향, 전압계 의미, 부호 해석 |
| 3 | 가장 높은 전위의 지점을 찾고 같은 전위 영역을 표시한다. | 전위와 전위차 구분, 등전위 이해 |
| 4 | 전위 높이 보기로 바꾸고 저항별 전압 강하를 설명한다. | 2D↔3D 대응, 높이 과장 이해 |
| 5 | 저항값 하나를 숨긴 문제지 그림을 복사한다. | 모드 전환, 값 숨기기, 출력 발견성 |

## 관찰 원칙

- 사용자가 막혔을 때 바로 해결 방법을 알려 주지 않는다.
- 먼저 어떤 버튼과 표현을 기대했는지 묻는다.
- 기능 성공 여부와 함께 물리적 오해를 기록한다.
- 도움말을 읽지 않은 상태의 행동을 관찰한다.
- 마우스, 터치, 키보드 환경을 나누어 시험한다.

## 초기 목표

- 첫 부품 배치: 10초 이내
- 직렬 회로 완성: 1분 이내
- 전압 측정: 추가 설명 없이 성공
- 문제지 그림 복사: 2분 이내
- 같은 도선이 같은 전위라는 설명: 시각화 후 구두로 표현 가능

## 이해도 확인 질문

- 왜 이 도선 전체가 같은 색인가?
- 전압계 탐침을 바꾸면 부호가 왜 바뀌는가?
- 병렬 가지가 같은 높이에서 시작하고 끝나는 이유는 무엇인가?
- 열린 스위치에서 전류가 0인데 양단 전위차가 생길 수 있는가?
- 기준점을 바꾸어도 바뀌지 않는 물리량은 무엇인가?
