# 테스트 전략

## 테스트 층

| 층 | 대상 | 예 |
|---|---|---|
| 단위 테스트 | 작은 순수 함수와 규칙 | 단위 파서, ID, net 병합, 행렬 stamp, 색상 범위 |
| 모듈 통합 테스트 | 문서→컴파일→계산→진단 | 직렬 회로 fixture의 전체 결과 비교 |
| 상호작용 테스트 | 편집 명령과 실행 취소 | 부품 이동 후 배선 유지, 연결 취소 |
| 시각 회귀 | SVG·PNG·주요 화면 | 기호 위치, 선 굵기, 문제지 출력 |
| 브라우저 E2E | 실제 사용자 흐름 | 회로 만들기→측정→전위→그림 복사 |
| 사용성 테스트 | 학생·교사의 이해와 조작 | 설명 없이 지정 과제를 수행하는지 관찰 |

## 물리 불변식

- 각 분기점에서 유입 전류의 합과 유출 전류의 합이 허용 오차 내에서 같다.
- 각 폐회로 경로에서 전위 변화의 합이 0에 가깝다.
- 같은 `net`의 모든 단자는 같은 절점 전위를 참조한다.
- 기준점을 바꾸어도 부품 전압, 가지 전류, 전력은 변하지 않는다.
- 수동 부호 규약에서 저항 소비 전력은 음수가 되지 않는다.
- 탐침 순서를 바꾸면 전위차의 크기는 같고 부호만 반전된다.

## 수치 허용 오차

초기 기본값:

- 절대 오차: `1e-9`
- 상대 오차: `1e-9`
- 화면 표시 비교는 사용하지 않는다.

특이 행렬, 0 Ω, 매우 큰 저항의 정책은 ADR-003과 ADR-004에서 조정할 수 있다.

## 편집·실행 취소

| 행동 | 검증 |
|---|---|
| 부품 이동 | 연결된 도선 끝이 단자에 유지되고 자동 경로 변경이 한 번에 취소된다. |
| 분기 생성·삭제 | `net` 수와 시각 분기점이 일치한다. |
| 복사·붙여넣기 | 새 ID를 사용하고 원본과 연결을 공유하지 않는다. |
| 값 수정 | 파싱 실패 시 이전 값을 유지하고 설명한다. |
| 활동 제한 | 버튼, 키보드, 명령 API를 통한 금지 동작을 모두 거부한다. |

## 성능 목표

| 상황 | 초기 목표 |
|---|---|
| 일반 수업 회로 | 부품 1~30개에서 편집과 계산이 체감상 즉시 반응 |
| 복잡한 예시 | 부품 100개까지 기능 유지, 지연 시 진행 상태 표시 |
| 2D 상호작용 | 목표 60 fps, 최소 30 fps 이상 지향 |
| 3D 전위 | 중급 태블릿에서 30 fps 이상, 자동 품질 저하 |
| 내보내기 | SVG 즉시, 고해상도 PNG는 완료 상태 표시 |

성능 예산은 실제 저장소의 자동 테스트에서 구체적인 시간 기준으로 고정한다.
