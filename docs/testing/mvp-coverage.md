# 단계 0–5 MVP 검증 범위

검증일: 2026-09-23  
대상 버전: `0.1.0`  
범위: `requirements/requirements.yaml`에서 단계 0–5와 `all`로 지정된 요구사항

요구사항 표와 초기 게이트는 단계 0~5를 처음 완료한 시점의 근거다. 자동 검사·당시 검증 Sol의 기능 브라우저 확인·메인 Astra의 최종 시각 판정·미검증 범위를 구분한다. 이후 변경의 실행 범위는 아래 후속 검증과 [작업 추적](../implementation/mvp-tracker.md)에 기록하며, 초기 228개 통과를 현재 전체 스위트의 결과로 해석하지 않는다.

## 초기 MVP 완료 시점의 자동 게이트

| 검사 | 결과 |
|---|---|
| `npm test -- --run` | 7개 파일, 228개 테스트 통과 |
| `npm run typecheck` | 통과 |

빌드는 Three.js 지연 청크가 502.30 kB로 Vite의 500 kB 안내 기준을 2.30 kB 초과한다는 비차단 경고를 남긴다. 기능·타입·명세 실패는 없다.

| 요구사항 | 상태 | 검증 근거 |

| TCH-003 | 자동+기능 브라우저 검증 | 결정론적 독립 SVG, XML escape·제어문자 대체, 흑백·투명·여백·숫자 형식, 빈 회로·회전·긴 텍스트 bounds, PNG 배율과 클립보드 성공/거부 대체를 확인했다. |

단계 5 기능 브라우저 확인에서 흑백·투명·여백 64·4× 옵션으로 실제 PNG를 생성했다. 정답지는 2,876×1,812 px, 문제지는 주석을 포함해 2,876×1,908 px로 디코딩되었다. 투명 checkerboard, 흑백 기호, 문제용 `R_A`·`?`·전압 빈칸·화살표와 정답용 실제 값·설명을 확인했다. SVG·PNG 저장 완료 안내와 PNG 클립보드 성공 안내도 확인했다. 390×844에서 작업 모드, 실제 PNG 모달, 수업 화면 패널 숨김, 가로 넘침 없음도 확인했다. 이 기능 브라우저 근거는 검증 Sol이 수행했다.

메인 Astra는 최종 시각 판정에서 데스크톱의 회로 만들기, 2D·3D 전위, 6 V 탐침 측정, 문제지 PNG를 확인했다. 390×844 모바일에서는 2D·3D와 PNG 전체 폭을 확인했고, 페이지 폭은 `374/374`로 가로 넘침이 없었다. 최종 기본 출력 PNG는 2,061×1,335 px로 디코딩되었으며 오른쪽 잘림 없이 표시되었다.

Chrome 자동화 확장의 비동기 message channel 종료 오류가 1건 기록되었으나 앱 stack이 없고 사용자 흐름 실패도 없었다. 앱 자체 오류로 분류하지 않았다.

## 도구 제약으로 남긴 항목

| 항목 | 현재 근거 | 남은 확인 |
|---|---|---|
| 브라우저 JSON 파일 열기 | 파서·스키마·저장 불변성은 자동 테스트 통과 | 파일 선택 broker가 없어 실제 file chooser 왕복은 확인하지 못했다. |
| 저장한 파일 다시 읽기 | SVG 문자열·PNG Blob·CSV 내용은 자동 테스트, PNG는 앱 미리보기에서 실제 디코딩 | 브라우저가 내려받은 JSON/SVG/PNG/CSV 파일을 자동화 도구로 다시 열어 byte 단위 비교하지 않았다. |
| 클립보드 거부 시 UI 다운로드 | `copyPng`의 API 부재와 권한 거부가 같은 PNG Blob을 반환함을 자동 테스트 | 사용한 Chrome에서는 클립보드 쓰기가 성공했으므로 실제 브라우저 거부 안내와 다운로드 파일은 재현하지 않았다. |

도구 제약 항목은 관련 순수 모듈의 실패 경로를 자동 테스트했지만 실제 운영체제 파일 선택기·다운로드함·클립보드 거부 UI를 대체한다고 주장하지 않는다.

## 사람 대상 미수행 항목

- 실제 교사가 회로 문제지 그림을 2분 안에 만드는지 관찰하지 않았다.
- 실제 학생이 전위·전위차·전류 방향·3D 높이의 의미를 설명할 수 있는지 연구하지 않았다.
- 터치 기기, 실제 프린터, 다른 워드프로세서에 PNG 붙여넣기를 시험하지 않았다.
- 교실 환경의 수업 진행, 장시간 사용, 접근성 보조기술 사용자 검증은 단계 6–7 후속 범위다.

따라서 이 문서는 단계 0–5 기능 계약과 자동·기능 브라우저 게이트 통과를 기록하며, 교사·학생 사용성이나 교육 효과를 입증하지 않는다.


## 후속 VIS-004: 3D 기준면과 전압 안내

`tests/potential-3d.test.ts`에 음수/미소 전압 눈금, 0 V 기준면을 포함하는 범위, net별 전위 표지와 미정 전위 제외, 선택 단자의 부호 있는 전압 차이/높이 일치 4개 검증을 추가했다. 기존 물리 불변식 테스트와 함께 232개가 통과했다. 메인 직접 브라우저 검증 범위와 한계는 [작업 추적](../implementation/mvp-tracker.md)의 후속 항목에 기록했다.
