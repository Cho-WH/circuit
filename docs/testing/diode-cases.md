# 다이오드 확장 수용 사례

상태: [ADR-026](../../decisions/ADR-026-diode-boundary-analysis.md)의 구현 전 검증 설계. 아래 ID와 수치는 향후 테스트의 기준이며, 현재 앱에 다이오드 테스트가 구현·통과했다는 뜻이 아니다.

정본은 [전기 모델](../physics/diode-dc-model.md), [작동 경계](../physics/circuit-operating-boundaries.md), [UX](../ux/diode-analysis.md)다. 유리수 결과는 반올림 전 값으로 비교한다.

## 1. 교과서 엔진

다이오드는 별도 언급이 없으면 A→K 방향이고 도통 강하는 정확히 7/10 V다. 아래의 전원은 이 절에서 이상 전압원이다.

| ID | 회로·조작 | 수용 결과 |
|---|---|---|
| DIO-E01 | 기존 저항 회로 fixture 전체 | 기존 정확값·품질·진단 보존. 균형 브리지의 0 A와 실제 작은 전류를 구별 |
| DIO-E02 | 5 V, 1 kΩ, 순방향 다이오드 직렬 | 다이오드 0.7 V, 전류 43/10000 A = 4.3 mA |
| DIO-E03 | E02의 다이오드 반전 | 전류 정확히 0 A. 역전압을 순방향 강하 0.7 V로 고정하지 않음 |
| DIO-E04 | 0.7 V 전원에 다이오드 직결 | 전압은 고정되지만 이상 전류는 하나로 정해지지 않음. 계산 실패·파손으로 곧바로 치환하지 않음 |
| DIO-E05 | 1 V 전원, 순방향 다이오드 두 개 직렬, 외부 저항 없음 | 전류 0 A. 아래 단자 0 V·위 단자 1 V일 때 중간 전위는 [0.3, 0.7] V. 임의 대표값을 실제 측정값으로 표시하지 않음 |
| DIO-E06 | E05의 전원을 1.5 V로 변경 | 고정 강하 교과서 모델에는 해가 없음. 전압 제약 검사가 모순을 찾고 관련 요소를 반환. 부품 모델의 위험 평가는 별도 |
| DIO-E07 | 5 V → 공통 1 kΩ → 동일 다이오드 두 병렬 가지 | 총전류는 4.3 mA, 각 전류는 음수가 아니며 합만 고정. 임의 반반 분배를 교과서의 유일해로 반환하지 않음 |
| DIO-E08 | 서로 같은 전압의 이상 전원 병렬 / 서로 다른 전압의 이상 전원 병렬 | 전자는 전원별 전류 비유일, 후자는 모순. 계수 부족과 모순을 구별 |
| DIO-E09 | 기준 없는 연결 회로의 두 점 전압차 | 각 절대 전위의 가용성과 별개로 차이가 유일하면 측정 가능. 서로 독립적으로 떠 있는 회로 사이에는 임의 기준을 붙이지 않음 |
| DIO-E10 | 이상 도선 루프·분기에서 센서 위치 변경 | 특정 구간 전류가 비유일해도 유일한 KCL 결합량을 직접 질의. 센서가 계산 모델을 바꾸지 않음 |
| DIO-E11 | 같은 문서·옵션, 부품 배열·실행 이력 변경 | 안정된 ID 순서에 따라 결과·진단·예산 판정 재현. ON/OFF 문턱 중복은 물리적으로 같은 상태로 취급 |
| DIO-E12 | 상태·부등식·정확 연산 예산 초과 또는 근사 검증 실패 | 제한된 비용 안에 미확인 결과. NaN·무한 전류·거짓 0 A·파손 사건을 만들지 않음 |
| DIO-E13 | 다이오드가 있는 측정 대상에 Ω 측정 / 별도 저항 회로에서 Ω 측정 | 다이오드를 누락하거나 도통 상태를 저항으로 고정하지 않음. 지원 밖 대상은 명확히 구별하고 독립적인 저항 회로의 기존 측정은 보존 |

작은 회로에서는 모든 ON/OFF 후보의 허용 해 집합을 기준으로 사용한다. 해 집합 최적화와 전압 제약 사전 검사는 이 기준과 대조한 뒤 도입한다. 제약 그래프가 통과했다는 사실을 유일해·안전 판정으로 사용하지 않는다.

## 2. 시험 전용 부품 프로필

다음 값은 산술과 경계 포함 관계를 쉽게 검증하기 위한 **시험 전용 값**이다. 제품의 기본 전지·실제 다이오드 정격이 아니다. 제품 프로필은 [구현 D0](../implementation/diode-mvp.md)에서 근거와 함께 별도로 고정한다.

| 항목 | 시험값 |
|---|---|
| 전원 | E = 3 V, 내부저항 R_s = 10 Ω |
| 다이오드 | V_0 = 0.7 V, R_on = 10 Ω, 역방향 누설 0 |
| 다이오드 전류 경계 | continuousMax = 50 mA, damageAt = 100 mA |
| 다른 평가량 | 해당 시험에서는 경계를 등록하지 않음. 아래 전력값은 산술 검증용 |

외부 직렬 저항 R일 때 `I = 2.3 / (R + 20)` A다. 이 회로는 부품 모델을 명시적으로 적용한다. 개별 경계 검사와 모델 선택 정책 검사는 별도 사례로 구별한다.

| ID | 조건 | 정확 결과 | 경계 결과 |
|---|---|---|---|
| DIO-B01 | R = 100 Ω | I = 23/1200 A ≈ 19.1667 mA | 정상 |
| DIO-B02 | R = 26 Ω | I = 1/20 A = 50 mA | 정상 상한과 같으므로 정상 |
| DIO-B03 | R = 10 Ω | I = 23/300 A ≈ 76.6667 mA | 노랑 |
| DIO-B04 | R = 3 Ω | I = 1/10 A = 100 mA | 파손 경계와 같으므로 빨강 |
| DIO-B05 | 외부 저항 없이 직결 | I = 23/200 A = 115 mA, V_D = 37/20 V, P_D = 851/4000 W, P_source-loss = 529/4000 W | 빨강. 표시값과 판정값이 같은 부품 모델에서 나옴 |
| DIO-B06 | 외부 저항 없이 동일 다이오드 두 개 병렬 | 각 I = 23/300 A, 총 I = 23/150 A, 각 V_D = 22/15 V | 각 다이오드 노랑. 총전류만 표시하고 가지 현상을 생략하지 않음 |
| DIO-B07 | B06에서 두 V_0를 0.65 V, 0.75 V로 고정 | 공통 V_D = 22/15 V, 각 I = 49/600 A·43/600 A | 반복 실행해도 같은 분배 차이. 무작위 편차 재추첨 없음 |
| DIO-B08 | 직결, R_s만 100 Ω로 변경 | I = 23/1100 A ≈ 20.9091 mA | 정상. 외부 저항의 유무 자체를 위험 조건으로 삼지 않음 |
| DIO-B09 | 직결, E를 정확히 0.7 V로 변경 | I = 0 A | 정상. 이상 전류 비유일과 물리적 위험을 구별 |

경계 직전·동일·초과 값도 유리수로 생성한다. 예를 들어 B04의 R을 3 Ω보다 조금 크게 하면 노랑, 같거나 작게 하면 빨강이다. 소수 표시가 모두 100 mA로 반올림되어도 판정에는 원래 값을 쓴다.

## 3. 가변저항과 비선형 표시 범위

다이오드 회로에서 슬라이더 양 끝의 값만 검사하여 전체 전위·전류의 최대/최소를 확정하지 않는다. 다음은 전위가 내부에서 최대가 되는 회귀 회로다.

- 기준 g = 0 V, 이상 전원으로 p = 5 V와 c = 2.3 V를 고정한다.
- p–a 1 kΩ, b–g 1 kΩ, a–y 1 kΩ, y–b 3 kΩ, a–b 가변저항 R.
- 다이오드 A = a, K = c, 고정 강하 0.7 V. R 범위는 100 Ω~10 kΩ.
- y 전위는 R = 100 Ω에서 약 2.55814 V, R = 4000/7 Ω에서 2.75 V, R = 10 kΩ에서 약 2.44444 V다.

이 사례는 교과서 모델의 **전위 범위** 시험이다. 양 끝으로 만든 축이 내부의 실제 2.75 V를 잘라서는 안 된다. 이 결과만으로 모든 위험량이 같은 위치에서 극값을 가진다고 추론하지 않는다.

위험 사건은 확인한 현재 입력 상태에서 발생한다. 자동 조절은 논리적 이산 위치를 순서대로 확인하고 첫 위험에서 멈춘다. 표시 프레임이 생략되어도 미검증 구간을 안전하게 통과했다고 처리하지 않는다. 전체 연속 실수 구간의 위험을 증명했다는 주장도 하지 않는다.

| DIO-U17 | 열린 입력 초안·진행 중 배선·비동기 이전 결과 | 확정 리비전과 현재값만 위험 평가. 계산 미확인을 위험이나 안전으로 꾸미지 않음 |

U01~U17은 상태·컴포넌트 테스트와 실제 화면 점검을 구분한다. 교사·학생의 원인 이해, 프로젝터 가독성, 실제 휴대전화·보조기술 검증은 별도 수용 활동이며 자동 테스트만으로 완료 처리하지 않는다.

## 5. 회귀 실행 원칙

구현 단계마다 바뀐 계산·측정·세션 경계에 해당하는 사례와 기존 회귀를 실행한다. 코드 변경 없이 이 문서를 추가한 시점에는 링크·수치·설계 일관성을 확인한다. 전체 앱 테스트나 실제 다이오드 기능이 검증되었다고 기록하지 않는다.
