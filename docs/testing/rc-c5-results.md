# C5 RC 제품 흐름과 계산 비용 확인

2026-10-22, dev. C4 구현·검토 후 같은 브랜치에서 C5 기술 확인을 진행했다. **기술 확인은 완료했고, 실제 기기·보조기술·수업 사용자 수용은 남아 있다.** C5 검증 당시에는 미배포였으며, 이후 2026-10-22 사용자가 2D 판 색상 개선을 포함한 dev 커밋·배포를 승인했다. 공개 상태는 [개발판 release.json](https://cho-wh.github.io/circuit/dev/release.json)과 [Pages 실행 기록](https://github.com/Cho-WH/circuit/actions/workflows/deploy-pages.yml)을 따른다.

## 실제 브라우저 확인

Windows Chrome, 별도 로컬 테스트 주소 `http://127.0.0.1:5181/`에서 새 예제를 사용했다. 사용자 기존 실행 주소의 저장 자료는 수정하지 않았다.

| 흐름 | 관찰 근거 |
|---|---|
| 충전·키보드 측정 | 분석→Enter로 일시정지→C₁ 위/아래 단자에 Enter로 탐침 배치. 0.1852 s에서 약 1.69 V 표시·기록 |
| 같은 시각의 3D | 정지 상태에서 3D로 전환해 같은 측정값 유지. SVG와 3D 영역의 `data-rc-frame` 일치, 두 판의 전위 높이 분리 |
| 넘기기·평형 기록 | 넘기기 뒤 정확한 10 V와 ‘충분한 시간이 지난 상태’, 두 번째 기록 확인 |

브라우저 연결에서 비동기 메시지 채널 오류 한 건을 확인했으나 앱 오류 스택은 제공되지 않았다. 파일 다운로드 대기 중 연결이 멈춰 CSV의 최종 파일 전달은 확인하지 못했다. CSV 원본 값·출처 생성과 저장 왕복은 자동 검사로 확인했다. 브라우저 연결 문제를 CSV 제품 오류로 단정하거나 파일 전달까지 통과한 것으로 기록하지 않는다.

## C5에서 반영한 수정과 자동 검사

- 축전기 값 클릭은 C·초기 전압을 함께 편집하는 폼으로 연다.
- RC 저항·전압 값 클릭은 단발 **적용** 경로를 사용한다. 초안 변경·blur가 즉시 회로를 바꾸지 않는지 검사했다.
- 초기 전압의 분수 표시와 빈칸을 유지하고 중복 `U =`를 제거했다.
- 측정표의 초 표시에서 부동소수점 꼬리를 줄였다. CSV의 원래 물리 시각은 보존한다.
- 모바일 배속 메뉴를 화면 안으로 배치했다. 키보드로 배속을 선택해 실제 반영을 확인했다.
- 터치 포인터로 축전기 배치·값 편집을 검사했다. 실제 손가락/태블릿 사용성 검사를 대신하지 않는다.

수정 후 관련 6개 파일 **111개 검사**를 통과했다. 새 터치 검사의 이벤트 대상 오류를 바로잡은 뒤 해당 파일 45개를 다시 실행했다. C4의 217개와 겹치는 검사이므로 합산하지 않는다.

```powershell
$env:TEMP = Join-Path (Get-Location) '.tools/rc-c0-tmp'
$env:TMP = $env:TEMP
npx vitest run tests/rc-observation.test.ts tests/rc-session-ui.test.ts tests/current-overlay.test.ts tests/worksheet-export.test.ts tests/touch-interactions.test.ts tests/measurement-workspace.test.ts
```

요구사항·스키마 검사 56개, 타입을 포함한 프로덕션 빌드, 173개 소스 파일 모듈 경계 검사를 통과했다. 기존 500kB 초과 번들 경고는 남아 있다. 전체 테스트·전체 verify는 실행하지 않았다.

## 후속 확인: 초기 전압과 2D 판 색

예제 원본은 C=100 µF·초기 전압 0 V·S₁ A 연결이다. 검증에 사용한 C=200 µF·초기 전압 −2/3 V·B 연결을 브라우저가 저장하면 전원을 분리해도 방전한다. 실제 엔진에서 이 설정은 6초에 저항 전압 33.19 mV, 7.064초에 19.50 mV였다. 동일 B 회로의 초기 전압을 0 V로 두면 전압·전류가 처음부터 정확히 0이며 안정화 시간도 0이다. 저장된 초기 조건과 계산 오차를 구분한다.

사용자 요청으로 2D 판·리드에도 기존 단자 색을 연결했다. 네 방향·단자 배열 역순·색상 토글·흑백 출력을 포함한 관련 46개 검사와 타입 검사를 통과했다. 실제 Chrome에서 10 V/0 V 판의 빨강/남색, 선택 시 색 유지와 굵기 강조, 색상 해제 시 기본 기호색 복귀를 확인했다. 계산·저장·3D 구조는 변경하지 않았다.

## 배포 준비 검증

배포 준비 CI에서는 기존 이름·네이티브 드롭 검사가 축전기 없는 9종 목록을 가정하고, 센서 검사가 모든 예제를 DC 엔진으로 풀던 문제를 발견했다. 목록을 10종으로 갱신하고 RC 예제의 비접촉 센서 검사를 실제 prepare/sample 관찰에 연결했다. 관련 3개 파일 30개 검사가 통과했으며 최종 전체 검사·게시 결과는 Pages 실행 기록을 따른다.

후속 정리에서는 10종으로 바꾼 목록 고정도 제거했다. 이름 생성은 접두어를 공유하는 전원·스위치의 번호 충돌과 축전기 별칭 예약을 직접 검사하고, 네이티브 드롭은 등록 종류별 추가·원본 보존·이름 중복 방지와 알 수 없는 종류의 문서 불변을 검사한다. RC 측정 검사는 유지했으며 관련 3개 파일 30개가 다시 통과했다. 첫 실패 뒤 [수정 실행 39705730712](https://github.com/Cho-WH/circuit/actions/runs/39705730712)는 전체 1160개 검사·Firestore 27개·빌드와 dev 게시에 성공했다. 테스트 정리는 이 성공 이후의 유지보수 변경이다.

## 계산 비용

Node 24.18.0, AMD Ryzen 5 5600X, 회로당 5회 준비와 회당 60개의 유한 프레임을 측정했다. 준비는 컴파일을 포함하고, 프레임은 sample·관찰 변환·전류/전위 모델 생성을 포함한다. **React·WebGL 렌더 시간과 브라우저 FPS는 포함하지 않는다.**

## 남은 수용 범위

- 실제 태블릿·터치 하드웨어, Safari/다른 브라우저, 스크린리더, 수업 중 사용자 수용.
- 브라우저 CSV 파일 전달과 외부 스프레드시트에서 열기.
- 좁은 화면에서 큰 표기가 전체 보기 경계에 걸릴 수 있음. 이번 예제의 C 값도 일부 잘려 축소/이동이 필요했다. 재생 제어는 사용할 수 있으며, 표기까지 고려하는 전체 맞춤 개선은 후속이다.
- 큰 회로 준비의 워커 분리/취소 응답과 크기 제한 UX. 32개 전체 지원으로 안내하지 않는다.
- 실제 수업에서의 사용자 수용. dev 배포 승인은 받았지만 안정판 승격·실기기 수용을 대신하지 않는다.
