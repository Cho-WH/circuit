# C0 선형 RC 계산 시제품 검증 결과

후속 상태: C1 공개 계약·저장 형식도 구현했다. 최신 결과는 [C1 검증](rc-c1-results.md)을 따른다. 아래 수치와 미착수 표기는 C0 완료 당시의 범위다.

기준일: 2026-10-22, dev 브랜치. 사용자가 승인한 C0 계산 시제품을 구현했다. 다중 RC 축약·보존 전하·초기 조건 검사·시간 응답·안정화 상한의 타당성을 아래 범위에서 확인했다. **제품 연결 전의 시제품이며, 32개 축전기의 모든 회로를 지원한다는 결과는 아니다.** C1 이후 공개 계약·저장·UI 구현은 별도 단계다.

상위 기준은 [물리 규약](../physics/linear-rc-transient.md), 구현 경계는 [설계](../architecture/rc-transient.md), 전체 수용 계획은 [RC 사례](rc-transient-cases.md)다. ADR-041과 요구사항은 제품 계약 확정 전까지 proposed로 유지한다.

## 계산 방식과 오차 상한

전압원·닫힌 스위치·0 Ω 저항과 초기 축전기 전압의 양립 여부를 정확 유리수로 확인한다. 연결 기준 자유도와 대수 변수를 제거하고 `M x' + G x = f`를 만든다. `ker(G)`에서 보존 전하를 추출해 최종 평형을 구한 뒤, 실제 감쇠 부분만 수치 계산한다. 구조적인 0과 작은 양의 감쇠율을 구분하는 단계에 부동소수점 rank 임계값을 쓰지 않는다.

감쇠 부분 `M z' + G z = 0`의 수치 후보를 `ẑ(t)=Σ d_k exp(-λ_k t)`로 둔다. λ와 d는 binary64 값 자체를 정확 유리수로 다시 해석한다. 초기 불일치와 회로식 잔차를 정확 계산한다.

```text
δ₀ = z(0) - Σ d_k
r_k = G d_k - λ_k M d_k
E = ||δ₀||_M + Σ ||r_k||_(M⁻¹) / λ_k
||z(t) - ẑ(t)||_M ≤ E, 모든 t ≥ 0
```

수동 회로의 `M>0, G≥0`에서 동차 전달은 M 에너지 노름을 늘리지 않는다. 잔차 구동의 Duhamel 적분을 적용하고 `∫₀ᵗ exp(-λs)ds ≤ 1/λ`로 덮으면 위 식을 얻는다. 따라서 고유값 오차를 작은 상수로 추측하거나 모드 간 충분한 간격을 가정할 필요가 없다. 이 증명은 정확 축약으로 얻은 수동 회로와 양의 후보 λ에 한정된다.

관측량 `y=y∞+h z`의 오차 상한은 `E_y = sqrt(h M⁻¹ hᵀ) E`이며, 남은 변화는 다음으로 덮는다.

```text
B̂_y(t) = Σ upper(|h d_k| exp(-λ_k t)) + E_y
모든 s ≥ t에서 |y(s) - y∞| ≤ B̂_y(t)
```

노름의 제곱은 유리수로 계산하고 제곱근 상한은 정확한 제곱 비교로 확인한다. 사칙연산을 바깥쪽으로 반올림하며, 지수함수는 양의 Taylor 급수·잔여항·반복 제곱으로 포함 구간을 만든다. Math.exp의 플랫폼별 반올림을 오차 보증으로 가정하지 않는다. 같은 후보 감쇠율은 정확 합산하고, 비슷할 뿐인 감쇠율은 병합하지 않는다.

이는 초기 설계의 ‘각 고유값·계수의 오차 구간 추정’을 **회로식 잔차의 에너지 상한**으로 구체화한 것이다. 반복 고유값도 처리할 수 있지만, 조건이 나쁘면 상한이 보수적으로 커져 해석을 거부할 수 있다. 잔차만 작다는 이유로 정확하다고 간주하지 않는다.

정책 `rc-c0-envelope-1`은 상대 0.001, 전압 1 µV, 전류 1 pA, 계산 오차 예산은 허용량의 1%다. 변화 규모 S는 인증한 수치 후보의 모드 진폭 절댓값 합으로 정의한다. 정확한 고유분해의 진폭 합과 같다고 주장하지 않는다. 이 S로 고정한 허용량에 대해 **실제 응답**의 남은 변화 상한을 검사한다. 모든 같은 그룹 노드 쌍 전압차·유일한 부품 전압/전류를 판정하고, 화면에 보이는 계기만 검사하지 않는다.

prepare에서는 E_y 예산을 검사한다. sample에서는 추가 지수 평가·출력 반올림까지 합한 오차를 검사하며 예산 초과 시 실패한다. 보고의 maxNumericalBudgetRatio는 **E_y / 계산 오차 예산**의 최댓값으로, sample 전체 오차 비율이나 회로 조건수가 아니다. 절대 전위가 매우 크고 변화가 아주 작으면 prepare 성공 후에도 sample이 실패할 수 있으므로 제품에서는 프레임 실패를 보존해야 한다.

## 검증 결과와 범위

직접 관련된 자동 테스트 25개가 통과했다. 문서 링크·요구사항/스키마 검사까지 함께 실행한 결과는 3개 파일, 81개 통과다. 프로젝트 및 시제품 타입 검사와 코드 형식 검사도 통과했다. 전체 테스트·제품 빌드·브라우저 UI 검사는 이번 변경 범위에 포함하지 않았다.

독립 기준 5개 회로의 35개 시각에서 노드 전압·가지 전류의 기준값이 반환 오차 구간 안에 있는지 확인하고, 남은 변화 상한도 기준값과 비교한다. 기준 생성기는 고유분해를 재사용하지 않고 직접 절점식 `C⁻¹G`의 행렬 지수를 90자리 Decimal Taylor scaling/squaring으로 계산한다. 독립 고정밀 기준값과 수학적 상한 증명은 서로 다른 검증 근거이며, 기준 생성기 자체를 형식 검증한 구간 연산기로 주장하지 않는다.

| 계획 사례 | C0 확인 내용 | 남은 제품 검증 |
|---|---|---|
| RC-01~04 | 단일 충전/방전, 2·3·6상태 다중 RC, 비대각 C, 부유 도체 전하, 고립 축전기, 저항 재분배와 순간 전력 수지 | 제품 netlist·표현 연결 |
| RC-05~08 | 초기 모순·충격 거부, 무저항 일관 연결, 평형 후 R/전압 변경·연속 초기 전압 | 명령 원자성·스위치 UX |
| RC-09~11 | 10⁸ 시간 규모 기준값, 중복 감쇠율, λ=10⁻²⁰, 상쇄, 미세한 비영 변화, 수치 미확인·예산 실패 | 더 넓은 제품 입력·회로 규모 검증 |
| RC-12 | 호출 순서·요소 순서 독립, 기준점 변경 후 V차/I 동일 | 실제 FPS·배속·모든 화면 프레임 일치 |
| RC-14·16·17 | finite/equilibrium 구별, 다음 초기 상태 재사용, 미정 전류, 단자 반전 부호 | 전환 연출·기록·공통 기호 |
| RC-21 | 다이오드 입력 거부, 기존 src·스키마 변경 없음 | 제품 경로 분기 후 DC 회귀 |

RC-11의 유한 평형 없음은 방어 진단만 둔다. 현재 허용하는 수동 R/C와 일정한 이상적 전압원에서 일관된 초기 조건을 갖는 반례는 구성하지 않았으며, 해당 분기를 실물 회로 사례로 검증했다고 표시하지 않는다. RC-13·15·18~20의 UI·세션·저장 수용은 미착수다.

## 규모와 계산 예산

Node 24.18.0 / Windows에서 한 번 실행한 참고 측정이다. 워밍업·CPU·브라우저에 따라 달라지며 지연시간 보장이 아니다. 성공 회로마다 0부터 T까지 101개 시각의 sample도 성공했다.

|---|---:|---:|---|
| 독립 기준 5개(2~6상태) | 약 4.6~26.1 ms | 약 1.8~4.9 ms | 기준 비교 통과 |
| 8단 사다리 | 약 49.8 ms | 약 6.6 ms | 성공, GCD 나머지 연산 448,665회 |
| 16단 사다리 | 약 320.9 ms | 약 14.7 ms | 성공, GCD 나머지 연산 3,369,263회 |
| 32단 사다리 | 약 573.4 ms | 해당 없음 | GCD 예산 초과 진단 |
| 33단 사다리 | 약 0.2 ms | 해당 없음 | 크기 예산 초과 진단 |
| 2단 저항비 10¹²·10¹⁶·10²⁰ | 약 3.3~3.8 ms | 약 1.0~1.6 ms | 준비·평가 성공. 독립 90자리 기준 비교 범위와 구분 |

C0 기본 상한은 축전기 32개, 노드+이상적 제약 가지 256개, 정수 4096 bit, GCD 나머지 5,000,000회, Jacobi 80 sweep, 시간 상한 확장 256회, 이분 탐색 80회로 고정했다. **개수 상한은 계산 성공 보장이 아니다.** 예산 소진은 안정화가 아니라 RC_BUDGET_EXCEEDED다. 16개보다 적어도 복잡한 유리수·나쁜 조건에서 실패할 수 있다.

상대 모드 크기가 매우 다른 경우와 수치적으로 나쁜 행렬은 구별한다. 저항비 10²⁰의 특정 사다리는 계산되지만, `C=[[10²⁰+1,-10²⁰],[-10²⁰,10²⁰+1]]`처럼 binary64에서 작은 에너지 방향을 잃는 입력은 RC_NUMERICAL_UNVERIFIED로 거부했다.

## C0 결론과 다음 경계

작은 교육용 선형 RC 회로에서 정확 제약 축약 + 대칭 모드 후보 + 잔차 에너지 인증을 사용할 타당성을 확보했다. C0에는 외부 수치 라이브러리를 추가하거나 외부 소스 코드를 복사하지 않았다. 기존 rational 공개 API와 자체 구현을 사용하며, 보고 실행에만 기존 Vite 도구 체인의 esbuild를 사용한다.

C1은 타입·품질·진단·새 저장 버전 계약을 확정하는 단계다. C2에서 제품 netlist와 도선 센서 전류 복원, 예산 정책, 큰 회로에서의 비용 개선을 다룬다. 32개 일반 회로의 보장·브라우저 Worker·근사 초기 상태·전력 오차 전파는 이번 결과에 포함하지 않는다. UI·새 스키마·배포는 이번 C0에 포함하지 않았다.
