# 제품 범위

## MVP 포함 범위

### 회로 요소

- 이상적인 직류 전압원
- 선형 저항
- 열린·닫힌 스위치
- 이상적인 도선과 분기점
- 기준점
- 이상적인 전압계와 전류계

### 회로 해석

- 직렬·병렬·직병렬 혼합 저항 회로
- 절점 전위와 가지 전류
- 부품 양단 전압과 전력
- 두 점 사이 등가저항
- KCL·KVL 기본 확인
- 부유 회로, 전원 단락, 충돌 전원, 미연결 단자 진단

### 시각화와 측정

- 전위 숫자와 색상
- 등전위 영역 강조
- 3D 전위 높이 지도
- 선택 경로 전위 그래프
- 두 탐침 전압 측정
- 비접촉 센서로 부품·도선 구간 전류 측정

### 교사 작업

- 이름·값 편집, 표시 토글, 사각 빈칸, 글자 배율
- 지점 라벨, 전류 화살표, 미지수, 설명 주석
- SVG, 고해상도 PNG, 클립보드 출력
- 투명 배경과 고해상도 출력 토글

### 저장과 활동

- 브라우저 자동 저장
- 버전이 포함된 JSON 저장·열기
- 제한된 URL 또는 공유 코드
- 예측 후 공개
- 학생 조작 권한의 기초
- 활동 시작 상태 초기화

## MVP 비목표

- 교류 위상·주파수 해석
- 콘덴서·코일의 과도 현상
- 다이오드, 트랜지스터, 연산증폭기
- 마이크로컨트롤러 코드 실행과 브레드보드 시뮬레이션
- 실제 전자 이동의 미시적 시뮬레이션
- 실시간 공동 편집
- 학생 계정, 성적 관리, LMS 연동
- 대규모 클라우드 문서 저장
- AI 자동 채점과 AI 문제 자동 생성
- 외부 플러그인 설치 체계

## 범위 통제

MVP 이후 사용자 요청으로 후기·피드백 게시판(DAT-005)을 추가했다. 공개·비공개, 자유 닉네임, Firebase 익명 인증에 따른 본인 글 수정·삭제, 하루 작성 제한과 관리자 삭제 기록 보관을 포함한다. 비밀번호는 사용하지 않는다. Firebase Spark의 Firestore 규칙과 Google 관리자 접근을 운영에 연결했으며, 이 게시판은 회로 공유·학생 계정 기능과 별개다.

새 부품이나 분석 방식을 추가하기 전에 다음을 확인한다.

1. 현재 단계의 핵심 사용자 흐름에 필수적인가?
2. 기존 이상적 직류 모델로 설명 가능한가?
3. 새 기능이 요구사항과 fixture를 갖는가?
4. 기존 모듈 경계를 유지할 수 있는가?
5. 후속 확장 지점만 검증해도 충분하지 않은가?
