# 제품 범위

## MVP 포함 범위

### 회로 요소

- 이상적인 직류 전압원
- 선형 저항
- 일반 다이오드의 A/K 단자와 정확한 0.7 V 교과서 모델
- 열린·닫힌 스위치
- 이상적인 도선과 분기점
- 기준점
- 이상적인 전압계와 전류계

### 회로 해석

- 직렬·병렬·직병렬 혼합 저항 회로
- 다이오드 상태 해석과 전원 내부저항·양의 도통저항을 사용하는 구간선형 부품 모델
- 절점 전위와 가지 전류
- 부품 양단 전압과 전력
- 다이오드가 없는 측정 부분의 두 점 사이 등가저항
- KCL·KVL 기본 확인
- 부유 회로, 전원 단락, 충돌 전원, 미연결 단자 진단

### 시각화와 측정

- 전위 숫자와 색상
- 등전위 영역 강조
- 3D 전위 높이 지도
- 선택 경로 전위 그래프
- 두 탐침 전압 측정
- 비접촉 센서로 부품·도선 구간 전류 측정
- 만들기의 현재값 사전 경고, 분석의 과부하·파손 사건과 회로 수정 복귀

### 교사 작업

- 이름·값 편집, 표시 토글, 사각 빈칸, 글자 배율
- 지점 라벨, 전류 화살표, 미지수, 설명 주석
- SVG, 고해상도 PNG, 클립보드 출력
- 투명 배경과 고해상도 출력 토글

### 저장과 활동

- 브라우저 자동 저장
- 회로 v6·측정 기록 v5 저장·열기, 이전 형식은 변환 없이 거부
- 제한된 URL 또는 공유 코드, 예측 후 공개, 활동 시작 상태 초기화는 단계 6의 미구현 범위
- 학생 조작 권한의 기초

## MVP 비목표

- 교류 위상·주파수 해석
- 콘덴서·코일의 과도 현상
- LED, 트랜지스터, 연산증폭기
- 열 축적·냉각·실제 파손 시각과 파손 후 연쇄 고장
- 마이크로컨트롤러 코드 실행과 브레드보드 시뮬레이션
- 실제 전자 이동의 미시적 시뮬레이션
- 실시간 공동 편집
- 학생 계정, 성적 관리, LMS 연동
- 대규모 클라우드 문서 저장
- AI 자동 채점과 AI 문제 자동 생성
- 외부 플러그인 설치 체계

## 1차 MVP 이후 구현한 다이오드 확장

2026-10-05 사용자 요청으로 [다이오드 확장 D0~D4](../implementation/diode-mvp.md)와 [ADR-026](../../decisions/ADR-026-diode-boundary-analysis.md)을 구현했다. 내장 부품 프로필은 고정된 교육용 가정이며 실물 부품의 정격이나 실제 파손 예측이 아니다.

확장 범위는 정확한 0.7 V 모델, 필요한 경우의 유한 부품 특성, 부품별 작동 경계, 만들기 경고와 분석 진입·가변저항에 따른 과부하/파손 표현이다. 열 축적·냉각·실제 파손 시각과 파손 후 회로 해석은 포함하지 않는다. LED는 이 경계·밝기 분리 구조를 사용하는 후속 소자로 남긴다.

현재 변경은 로컬 구현이며 푸시·배포하지 않았다. 실제 교실·실기기·보조기술의 수용 검증은 미완료다.

## 범위 통제

MVP 이후 사용자 요청으로 후기·피드백 게시판(DAT-005)을 추가했다. 공개·비공개, 자유 닉네임, Firebase 익명 인증에 따른 본인 글 수정·삭제, 하루 작성 제한과 관리자 삭제 기록 보관을 포함한다. 비밀번호는 사용하지 않는다. Firebase Spark의 Firestore 규칙과 Google 관리자 접근을 운영에 연결했으며, 이 게시판은 회로 공유·학생 계정 기능과 별개다.

새 부품이나 분석 방식을 추가하기 전에 다음을 확인한다.

1. 현재 단계의 핵심 사용자 흐름에 필수적인가?
2. 현재 선형·구간선형 직류 모델로 설명 가능한가?
3. 새 기능이 요구사항과 fixture를 갖는가?
4. 기존 모듈 경계를 유지할 수 있는가?
5. 후속 확장 지점만 검증해도 충분하지 않은가?
