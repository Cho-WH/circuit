# 제품 개요

## 제품 정의

회로를 한 번 그리면 표준 2D 회로도, 시뮬레이션, 측정, 전위 색상·숫자·3D 높이, 문제지와 정답지를 같은 데이터에서 만드는 교육용 회로 작업대다.

## 해결하려는 문제

기존 회로 도구는 전문 전자공학 소프트웨어처럼 복잡하거나, 어린 학습자를 위한 장난감 같은 외형에 치우치는 경우가 많다. 고등학교 수업에는 다음 네 가지가 한 흐름 안에서 필요하다.

- 표준 회로 기호와 정확한 물리 표현
- 설명서 없이 시작할 수 있는 직접 조작
- 전위·전류를 구조적으로 이해하는 시각화
- 시험지·수업 자료로 바로 사용할 수 있는 출력

## 대상 사용자

| 사용자 | 주요 목적 | 필요한 경험 |
|---|---|---|
| 고등학교 과학·물리 교사 | 회로도 제작, 수업 시연, 활동 배포, 문제·정답 출력 | 짧은 시간 안에 결과를 만들고 수업 중 실수 없이 조작한다. |
| 고등학생 | 회로 구성, 측정, 예측과 확인, 전위·전류 해석 | 숨은 기능을 찾지 않아도 기본 활동을 끝내고 결과의 이유를 확인한다. |
| 중학교·기초 대학 과정 사용자 | 기초 회로 탐구와 복습 | 어린이용 표현이나 전문 설정에 의존하지 않는다. |
| 콘텐츠 제작자·교사 연구회 | 예제와 활동 템플릿 제작 | 회로와 활동 조건을 재사용하고 버전 관리한다. |

## 제품 원칙

| ID | 원칙 | 적용 |
|---|---|---|
| P-01 | 교과서처럼 익숙하다 | 표준 회로 기호와 교과 용어를 기본으로 사용한다. |
| P-02 | 프레젠테이션 앱처럼 직접 조작한다 | 부품을 놓고 선을 잇고 값을 화면에서 바로 수정한다. |
| P-03 | 실험 장치처럼 즉시 반응한다 | 회로가 바뀌면 별도 해석 설정 없이 결과를 갱신한다. |
| P-04 | 정보를 한꺼번에 쏟지 않는다 | 기본 회로도 위에 필요한 정보 레이어만 켠다. |
| P-05 | 교육적 정확성을 시각 효과보다 우선한다 | 이상적 도선은 같은 전위로 표시하고 애니메이션의 의미를 명시한다. |
| P-06 | 오류를 학습 기회로 바꾼다 | 원인, 물리적 의미, 수정 행동을 회로 언어로 설명한다. |
| P-07 | 로그인 없이 핵심 기능을 쓴다 | 편집·시뮬레이션·출력에 계정을 요구하지 않는다. |
| P-08 | 확장은 경계를 통해 한다 | 새 기능이 기존 계산·편집 코드를 직접 침범하지 않게 한다. |

정본은 [`requirements/product-principles.yaml`](../../requirements/product-principles.yaml)이다.

## 초기 성공 지표

- 첫 부품을 설명서 없이 10초 안에 배치한다.
- 직렬 회로를 1분 안에 완성한다.
- 교사가 기존 회로를 문제지용 흑백 그림으로 2분 안에 복사한다.
- 학생이 전위 색상과 3D 높이에서 같은 도선이 같은 전위임을 설명한다.
- 기준 회로 모음의 계산 결과가 허용 오차 안에서 일치한다.
- 새 저항성 부품 한 종류를 기존 모듈의 대규모 수정 없이 추가한다.
- 잘못된 회로에서도 앱이 멈추지 않고 원인과 영향을 설명한다.
