# 회로 실험실 빠른 시작

## 앱의 빠른 시작 안내창

상단 물음표에서 연다. 기본 편집·측정·예제는 짧게 소개하고, 도선의 곧은 구간에 저항을 끼워 넣는 조작 하나를 공통 기호 그림으로 안내한다. 중심 내용은 **전위 보기 → 3D**와 **회로도 출력 → 그림 복사**다. 전위 높이의 의미, 값 숨기기·빈칸·화살표·설명을 활용한 문제 그림 제작을 예시와 함께 보여준다. 자동 저장의 범위와 별도 회로 파일 저장은 하단에 짧게 안내한다.

안내창에서 회로·작업 모드를 바꾸지 않는다. 닫기·직접 해보기·바깥 클릭·Escape로 현재 작업에 돌아가며 키보드 초점은 물음표로 복귀한다. 열린 동안 편집 단축키를 차단하고, Tab으로 안내 본문에 초점을 옮겨 키보드로 스크롤할 수 있다. 작은 화면은 기능 소개를 세로로 배치하며 제목·닫기·하단 버튼을 유지하고 본문만 스크롤한다. 아래 내용은 상세 사용 설명이다.

## 실행과 첫 회로

Node.js 20.19 이상에서 저장소 루트의 `npm ci`, `npm run dev`를 실행한다. 이 작업 환경의 Windows에서는 `powershell -ExecutionPolicy Bypass -File tools/run-dev.ps1`로 설치된 Vite를 시작할 수 있다.

왼쪽 예제 목록에서 단일·직렬·병렬 회로를 선택한다. 새 회로를 만들려면 **빈 회로 만들기**를 누르고 부품을 고른 뒤 캔버스에 놓는다. 첫 단자와 두 번째 단자를 차례로 누르면 도선이 생긴다. 전원을 처음 놓을 때 음극을 0 V 기준으로 제안한다.

도선이 교차하는 것만으로는 전기적으로 연결되지 않는다. 도선을 선택하고 원하는 위치의 반투명 가지 표시를 눌러 새 배선을 시작한다. 기준을 바꾸려면 **접지(0V)** 도구로 단자나 분기점을 선택한다.

배선 중 빈 곳을 차례로 눌러 원하는 경로를 만든다. 방향 전환 버튼(`/`)은 마지막 구간의 가로·세로 순서를 바꾸며, 되돌리기 버튼(Backspace)은 마지막 경유점만 지운다. 단자·도선에서 완료하고 Esc로 전체 취소한다. 선택한 도선의 사각 손잡이를 끌거나 방향키로 선분을 옮길 수 있다. 부품 이동 시 가까운 코너만 따라 움직이고 가운데 경로는 유지된다.

가변저항은 지그재그 저항에 대각선 화살표로 표시한다. 값 편집으로 저항값을 바꾸며 일반 저항과 같은 두 단자 저항 모델로 계산한다.

연결된 부품을 **삭제**하면 기존 배선을 남기고 부품 자리를 도선으로 잇는다. 전압계·열린 스위치도 같은 방식으로 연결된다. 배선도 지우려면 해당 도선을 함께 선택해 삭제한다. 실행 취소로 부품과 배선을 모두 복원할 수 있다.

단순 직렬 구간은 하나의 도선으로 합쳐 부품 양쪽에 불필요한 점을 남기지 않는다. 실제 분기점과 열린 도선 끝, 기준점·주석이 붙은 점은 유지한다.

가지를 지우면 해당 분기점도 연결 수에 맞춰 정리된다. 남은 도선이 두 개면 굴곡을 보존해 합치고, 연결이 없으면 점을 지운다. 끝단과 일반 분기점은 누르면 바로 배선을 시작한다. 노드는 수동으로 삭제하지 않는다. 불필요한 중간 노드 위에도 직렬 삽입할 수 있으며, 배치할 수 없는 위치는 짧은 X 표시만 보여 주고 배치 상태를 유지한다.

## 값과 전위

부품 옆 이름이나 값을 누르면 이름·값을 함께 바꾸는 입력창이 열린다. `1k`, `1.5 kΩ`, `3/4 kΩ`처럼 입력하고 Enter 또는 **적용**을 누른다. 입력한 분수는 저장·재편집·표시에서 유지하며 자동 계산 결과는 필요한 경우에만 소수점 최대 두 자리로 표시한다. 이름에 `R_1` 또는 `R_{eq}`를 쓰면 아래첨자로 보인다. 값의 단위와 잘못된 입력 안내를 확인한다. 스위치를 두 번 누르면 열린/닫힌 상태를 전환한다.

**전위 보기**에서 숫자·색상·전류 화살표를 켜거나 끈다. 같은 절점의 도선과 단자는 같은 전위를 가진다. 단자나 도선을 누르면 그 절점 전체를 강조한다. 색상바를 누르면 **파랑 → 노랑**, **전체 스펙트럼**(기본), **검붉은색 → 노랑** 중에서 고를 수 있다. 2D와 3D에 함께 적용된다. 비교 실험에서는 같은 색상표와 같은 고정 범위를 사용해야 같은 색이 같은 전위를 뜻한다.

**3D 높이**의 높이는 전위이며 실제 공간 높이나 전자의 에너지를 직접 측정한 그림이 아니다. 전류 화살표는 관습적 전류 방향을 보여 준다. 열린 스위치는 높이 지도에서 연결하지 않는다. 전위가 정해지지 않은 회로에는 임의의 높이를 만들지 않는다.

**경로 그래프 보기**를 열고 경로 목록에서 한 바퀴 경로를 고르거나 **경로 직접 선택**으로 연결된 부품을 순서대로 선택한다. 전위 그래프의 부품에 마우스를 올리면 회로의 해당 부품이 강조된다.

## 측정과 실험

**측정하기 → 전압**에서 빨강·검정 탐침을 단자나 도선에 놓는다. 표시값은 빨강 전위에서 검정 전위를 뺀 값이다. **두 탐침 맞바꾸기**로 부호를 비교한다.

**전류**를 고르고 부품이나 도선을 누르면 작은 비접촉 센서가 놓인다. 전류의 크기는 상단에, 방향은 센서 옆 화살표로 표시한다. 센서를 끌어 다른 곳으로 옮길 수 있다. 회로 모양과 연결은 그대로 유지된다.

**등가저항**을 고르면 전원이 흐려지고 양쪽 연결이 끊어진다. 두 탐침을 놓아 그 사이의 저항을 잰다. 전원 분리 아이콘을 누르면 실제 저항계가 작은 시험 신호로 저항을 재는 원리를 볼 수 있다. 3 Ω·6 Ω 직렬 회로는 각 저항에서 3 Ω·6 Ω, 전체에서 9 Ω이다.

예측과 조건을 쓰고 **측정값 기록**을 누른다. CSV는 당시 회로 JSON, 조건, 시간, 값과 단위를 포함한다. 회로를 바꿔도 이전 기록은 그대로다. 기록은 실행 중 메모리에 있으므로 페이지를 닫기 전에 CSV로 보관한다.

**전류·전압의 합 확인**은 항별 부호와 합을, **값 바꿔 보기**은 원본을 바꾸지 않은 21개 조건의 그래프와 수치 표를 보여 준다.

## 회로도 출력

**회로도 출력**에서 요소를 선택하고 이름·값을 각각 수정한다. 표시 토글로 숨기고 **빈칸 □**로 사각 답란을 표시한다. 이름과 값은 각각 드래그해 위치를 조절한다. 실제 부품값과 계산은 그대로다.

이름·값·주석에 분수를 쓸 수 있다. 접지는 기본으로 숨기며 **접지 표시**를 켜면 0 V 숫자 없이 기호만 표시한다. 기호·숫자·단위는 Libertinus Math로 표시하고 SVG·PNG에도 반영한다. 기호는 이탤릭체, 숫자·단위는 정자다.

상단 **점·전류 화살표·직각 전류 화살표·글자** 도구를 선택하고 원하는 위치를 누른다. 드래그로 이동하며 선택한 화살표 양 끝의 작은 원을 드래그해 길이를 조절한다. 끝점은 선 방향으로만 움직여 각도를 유지하고 직각 화살표의 두 변은 각각 조절된다. 회전 각도는 상단 도구에서 정한다. 회전 아이콘은 90°씩 돌리고 반전 아이콘은 경로를 유지한 채 화살촉 방향을 뒤집는다. 화살표도 부품과 같은 기호·값 입력, 표시 토글·빈칸 설정을 사용한다. 기호와 값 글자를 각각 드래그하면 화살표는 그대로 두고 글자만 이동한다. 각 위치 초기화로 기본 배치로 돌아온다. 다른 주석의 문구도 수정하거나 삭제할 수 있다. 장식은 출력 탭에만 나타난다. 노드와 접속점은 생략하며 비연결 교차는 아치로 표시한다.

**글자 크기 배율**은 50~200%로 조절한다. Tab으로 표기를 선택하고 방향키로 미세 이동할 수 있다. 도구 선택 후 캔버스에서 Enter로 중앙에 추가할 수도 있다. 빈 공간 드래그는 화면 이동이다.

숫자는 소수점 최대 두 자리, 여백은 좁게 자동 적용한다. **투명 배경**과 **고해상도 출력**을 켤 수 있다. PNG는 기본 1배이며 고해상도는 가로·세로 각각 2배다. 상단 **미리보기**로 실제 이미지를 확인한다.

상단 **그림 복사** 후 문서에 붙여넣는다. 브라우저가 그림 복사를 허용하지 않으면 같은 PNG가 파일로 저장된다. **SVG 저장**은 확대 가능한 선과 텍스트를 유지한다. 출력에는 편집 테두리와 캔버스 배율이 섞이지 않는다.

**수업 화면**은 양쪽 패널을 숨기고 회로 글자를 키운다. **편집 화면**으로 돌아올 수 있다.

## 저장과 단축키

자동 저장은 현재 브라우저에만 남는다. **파일 → 회로 파일 저장 / 회로 파일 열기**로 JSON 파일을 보관하고 다시 연다. **현재 회로 보관 / 보관한 회로 불러오기**는 이 브라우저의 별도 사본을 사용한다. 파일 저장은 보관본을 덮어쓰지 않는다. 보관본을 불러온 뒤 실행 취소하면 직전 편집으로 돌아갈 수 있다.

| 행동 | 회로 | 측정 기록 |
|---|---|---|
| 새로고침·앱 다시 열기 | 마지막 자동 저장 문서 복원 | 사라짐, CSV로 보관 필요 |
| 실행 중 다른 예제·빈 회로 열기 | 선택한 새 회로로 교체 | 기존 기록과 당시 조건 유지 |
| 실행 중 JSON 다시 열기 | 파일의 회로로 교체 | 현재 세션 기록 유지, 파일에서 기록을 가져오지는 않음 |
| 새 세션에서 JSON 열기 | 파일의 회로 복원 | 기록 없음 |

## 회로 위에서 편집하기

회로 만들기·전위 보기·측정·출력 화면에서 마우스 휠로 확대·축소할 수 있다. 2D에서는 마우스가 가리키는 위치를 기준으로 확대되며 Ctrl/⌘를 누를 필요가 없다.

이름·값 편집은 Enter로 함께 적용하고 Escape 또는 취소로 함께 취소한다. 한 번의 실행 취소로 두 항목을 복원한다. 잘못된 입력은 적용하지 않는다. 회전·복사·삭제는 선택 부품 근처에서 사용할 수 있다.

새 부품을 도선 위에 놓으면 충분한 직선 구간에 직렬로 삽입한다. 실제 기호·방향·양쪽 도선이 미리 보이고 기존 우회 도선은 제거된다. 전압계는 빈 공간에 놓고 병렬 연결한다. 배선은 시작 단자 → 끝 단자 또는 도선을 차례로 눌러 완성한다. 진행 중 취소 버튼도 제공한다.

비연결 교차점을 누르면 연결한다. 네 갈래 직교 교차는 다시 누르면 비연결로 전환한다. 비연결은 아치, 연결은 채운 점이며 작은 버블은 현재 상태만 표시한다. 이미 배선 중이면 연결점은 도착점으로 사용한다. T자·겹침·앵커가 있는 점은 분리하지 않고 일반 배선 시작 처리를 따른다.

모바일에서는 단자를 탭해 시작하고 끝 단자를 탭해 완료한다. 끝이 도선이면 탭으로 후보 위치를 고른 뒤 체크 아이콘 또는 같은 후보를 다시 탭해 확정한다. 분기는 도선 탭 → 반투명 가지 표시 재탭 또는 체크 아이콘 → 끝 단자 또는 도선 순서다. 완료 전 닫기 아이콘을 누르면 임시 분기점도 사라진다.

부품 목록은 옆으로 밀어 넘긴다. 부품을 탭한 뒤 놓을 곳을 누르거나, 부품을 길게 눌러 회로로 끌어온다. 빈 공간에는 바로 놓이고 도선 위에서는 미리보기 후 **삽입**을 누른다. 미선택 부품 위를 짧게 밀면 화면이 움직이고, 길게 누르면 그 부품을 집는다. 이미 선택된 부품은 바로 끌 수 있다. 드래그가 어려우면 **이동 → 목적지 탭 → 놓기**를 사용한다. 두 손가락을 대면 진행 중 이동을 취소하고 확대·화면 이동으로 바뀐다. 별도의 화면 이동 버튼 없이 조작하며, 마우스는 선택 도구에서 빈 공간을 끌고 캔버스에 초점을 둔 상태에서는 방향키로 이동한다.

출력의 이름·값·주석도 길게 눌러 옮기며, 선택 후 방향 버튼으로 미세 조절할 수 있다. 겹친 대상은 이름 목록에서 고른다. 모바일 표시 설정은 상단 버튼으로 연다. 두 손가락 화면 조작은 회로·표기 위치를 바꾸지 않는다.

전위·출력 모드에서는 편집 패널을 접어 회로 공간을 넓힌다. 전위 그래프는 **경로 그래프 보기**로 열고 높이 강조는 3D 상세 설정에서 바꾼다. 출력 도구, 글자 배율, **미리보기**, **그림 복사**는 항상 회로 상단에 있다. SVG·PNG 파일은 **파일 저장**, 투명 배경과 고해상도는 표시 설정의 토글에서 고른다.

| 조작 | 단축키 |
|---|---|
| 실행 취소 / 다시 실행 | Ctrl+Z / Ctrl+Shift+Z 또는 Ctrl+Y |
| 복사 / 붙여넣기 | Ctrl+C / Ctrl+V |
| 복수 선택 | Shift+클릭 |
| 이동 / 크게 이동 | 방향키 / Shift+방향키 |
| 회전 / 배선 | R / W |
| 삭제 / 도구 취소 | Delete / Esc |
| 키보드 부품 배치 | 부품 선택 후 캔버스에 포커스, 방향키로 위치 이동, Enter로 확정 |

계산 오류는 회로 아래 안내에서 원인과 수정 행동을 확인하고 **회로에서 위치 보기**로 대상을 찾는다. 미연결 단자는 묶은 조립 안내로 표시한다. 이상적인 직류 저항 회로 모델을 사용하므로 실제 계기의 내부저항이나 전원의 한계 전류는 포함하지 않는다.

## 후기와 피드백 남기기

상단 **한마디**(말풍선)를 열고 **한마디 남기기**를 누른다. 후기·개선 제안·오류 제보 중 하나를 고르고 내용과 자유 닉네임을 입력한다. 비공개로 남긴 글은 **내가 쓴 글**에서 확인한다. 작성한 기기의 같은 브라우저에서 본인 글의 **수정**·**삭제**를 사용할 수 있다. 수정에서는 닉네임·내용·종류·공개 범위를 바꿀 수 있고, 삭제 후에도 관리자 보관함에는 삭제 표시와 마지막 내용이 남는다.

한 줄 안내 옆 물음표를 누르거나 키보드 초점을 옮기면 자세한 설명이 열린다. 사이트 데이터를 지우거나 시크릿 모드를 종료하면 작성자 확인 정보가 사라질 수 있다. 직접 삭제하기 어려우면 삭제할 글의 닉네임·작성일·내용을 적어 비공개 글 등으로 관리자에게 별도로 요청한다.

글은 Firebase에 저장된다. 공개 글은 다른 사용자에게 보이고 비공개 글은 작성자와 허용된 관리자만 볼 수 있다. 로컬 개발 주소와 공개 사이트는 같은 게시판을 사용하지만 주소별 익명 인증 정보가 달라 한쪽에서 쓴 글을 다른 주소의 **내가 쓴 글**로 관리할 수는 없다. 이전 로컬 미리보기 글은 자동 이전되지 않는다. 관리자 보관함은 별도 `/admin/feedback/` 경로에서 연다(GitHub Pages에서는 `/circuit/admin/feedback/`). 등록된 Google 관리자만 조회할 수 있으며 일반 게시판에는 관리자 이동 버튼이 없다.
