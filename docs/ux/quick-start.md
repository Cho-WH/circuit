# 회로 실험실 빠른 시작

## 앱의 빠른 시작 안내창

상단 물음표에서 연다. 예제·부품 선택과 단자 두 곳 연결을 소개한 뒤, **3D로 회로를 분석하세요**와 **문제지에 넣을 그림을 만드세요** 두 카드로 안내한다. 분석 카드에서는 전위 높이·전류 흐름·탐침과 센서 측정을 짧게 소개하고, **3D 보기**와 **측정하기**의 진입 경로를 나눠 보여준다. 보조 문구는 “회로를 살펴보는 시선을 한 차원 높여보세요!”이며 자세한 조작 설명을 덧붙이지 않는다.

분석 그림은 실제 앱의 바닥 회로도·전압 눈금·전류 띠·탐침을 반영한 정적 SVG다. 부품 기호·기본 전위 색상·탐침 아이콘은 앱과 공유한다. 출력 카드에서는 데스크톱의 빈칸·주석·글자 크기·이름과 값 위치 조절을 소개하고, 모바일은 그림 복사·저장과 넓은 화면의 편집 기능을 구분한다. 시작·측정·출력·파일 저장 경로와 피드백 이름은 현재 화면 배치에 맞게 표시한다. 브라우저 저장 범위와 피드백 안내는 하단에 짧게 둔다.

안내창에서 회로·작업 모드를 바꾸지 않는다. 닫기·직접 해보기·바깥 클릭·Escape로 현재 작업에 돌아가며 키보드 초점은 물음표로 복귀한다. 열린 동안 편집 단축키를 차단하고, Tab으로 안내 본문에 초점을 옮겨 키보드로 스크롤할 수 있다. 좁은 화면은 기능 소개를 세로로 배치한다. 짧은 가로 화면을 포함해 제목·닫기·하단 버튼은 유지하고 본문만 스크롤한다. 아래 내용은 상세 사용 설명이다.

## 실행과 첫 회로

Node.js 20.19 이상에서 저장소 루트의 `npm ci`, `npm run dev`를 실행한다. 이 작업 환경의 Windows에서는 `powershell -ExecutionPolicy Bypass -File tools/run-dev.ps1`로 설치된 Vite를 시작할 수 있다.

**예제 회로** 버튼의 목록에서 단일·직렬·병렬 회로를 선택한다. 새 회로를 만들려면 **빈 회로 만들기**를 누르고 부품을 고른 뒤 캔버스에 놓는다. 모바일은 **+ 부품**을 눌러 목록을 열고 부품을 탭해 고른다. 예제는 같은 팝업의 **예제 회로**에서, 새 빈 회로는 상단 **⋯ → 새 회로**에서 연다. 첫 단자와 두 번째 단자를 차례로 누르면 도선이 생긴다. 전원을 처음 놓을 때 음극을 0 V 기준으로 제안한다.

도선이 교차하는 것만으로는 전기적으로 연결되지 않는다. 도선을 선택하고 원하는 위치의 반투명 가지 표시를 눌러 새 배선을 시작한다. 기준을 바꾸려면 **접지(0V)** 도구로 단자나 분기점을 선택한다. 모바일에서는 편집 도구 바의 **⋯ → 접지(0V) 지정**으로 연다.

배선 중 빈 곳을 차례로 눌러 원하는 경로를 만든다. 방향 전환 버튼(`/`)은 마지막 구간의 가로·세로 순서를 바꾸며, 되돌리기 버튼(Backspace)은 마지막 경유점만 지운다. 단자·도선에서 완료하고 Esc로 전체 취소한다. 선택한 도선의 사각 손잡이를 끌거나 방향키로 선분을 옮길 수 있다. 부품 이동 시 가까운 코너만 따라 움직이고 가운데 경로는 유지된다.

가변저항은 지그재그 저항에 대각선 화살표로 표시한다. 값 편집으로 저항값을 바꾸며 일반 저항과 같은 두 단자 저항 모델로 계산한다.

연결된 부품을 **삭제**하면 기존 배선을 남기고 부품 자리를 도선으로 잇는다. 전압계·열린 스위치도 같은 방식으로 연결된다. 배선도 지우려면 해당 도선을 함께 선택해 삭제한다. 실행 취소로 부품과 배선을 모두 복원할 수 있다.

단순 직렬 구간은 하나의 도선으로 합쳐 부품 양쪽에 불필요한 점을 남기지 않는다. 실제 분기점과 열린 도선 끝, 기준점·주석이 붙은 점은 유지한다.

가지를 지우면 해당 분기점도 연결 수에 맞춰 정리된다. 남은 도선이 두 개면 굴곡을 보존해 합치고, 연결이 없으면 점을 지운다. 끝단과 일반 분기점은 누르면 바로 배선을 시작한다. 노드는 수동으로 삭제하지 않는다. 불필요한 중간 노드 위에도 직렬 삽입할 수 있으며, 배치할 수 없는 위치는 짧은 X 표시만 보여 주고 배치 상태를 유지한다.

## 값과 전위

부품 옆 이름이나 값을 누르면 이름·값을 함께 바꾸는 입력창이 열린다. `1k`, `1.5 kΩ`, `3/4 kΩ`처럼 입력하고 Enter 또는 **적용**을 누른다. 입력한 분수는 저장·재편집과 기본 자동 단위 표시에서 유지하며, 숫자는 부품별로 선택한 방식으로 표시한다. 이름에 `R_1` 또는 `R_{eq}`를 쓰면 아래첨자로 보인다. 값의 단위와 잘못된 입력 안내를 확인한다. 스위치를 두 번 누르면 열린/닫힌 상태를 전환한다.

데스크톱의 **분석하기**에서 **숫자·색상·전류 흐름**을 각각 켜거나 끈다. 모바일의 **전위·전류**는 색상과 흐름을 전환하며 숫자 표시를 바꾸지 않는다. 같은 절점의 도선과 단자는 같은 전위를 가진다. 단자나 도선을 누르면 그 절점 전체를 강조한다. 색상바를 누르면 **파랑 → 노랑**, **전체 스펙트럼**(기본), **검붉은색 → 노랑** 중에서 고를 수 있다. 모바일에서는 보기 바의 **⋯** 안에 색상바가 있다. 선택은 2D와 3D에 함께 적용된다. 비교 실험에서는 같은 색상표와 같은 고정 범위를 사용해야 같은 색이 같은 전위를 뜻한다.

**전류 흐름**에서는 기존 도선이 전위 색상을 유지한 전류 띠로 바뀐다. 전류가 클수록 띠가 두껍고 무늬 간격이 좁으며, 이동 속도는 일정하다. 회로에 맞춰 자동으로 축척을 조절한다. **상세 설정 → 전류 두께**에서 배율을 조절하고 선택 구간의 수치를 확인한다. 화면 안 왼쪽 위 버튼으로 흐름을 일시 정지하거나 재생한다. 분기·합류 접점에서는 무늬가 짧게 나타나거나 사라지며, 각 가지의 간격은 일정하게 유지된다. 3D의 바닥 회로도는 도선까지 그대로 표시된다.

**3D**에서 높이는 전위이며 실제 공간 높이나 전자의 에너지를 직접 측정한 그림이 아니다. 흐름 무늬는 저항의 경사에서도 같은 화면 속도로 이동한다. 열린 스위치는 높이 지도에서 연결하지 않는다. 전위가 정해지지 않은 회로에는 임의의 높이를 만들지 않는다.

3D 기본 높이는 표시 영역과 전압 범위에 자동으로 맞춘다. **높이 ×배율**로 강조 정도를 조절하며, 창 크기를 바꾼 뒤에는 **보기 초기화**로 현재 영역에 다시 맞출 수 있다. 실제 전압은 축 눈금과 수치로 확인한다.

넓은 화면에서는 **경로 그래프**를 열고 경로 목록에서 한 바퀴 경로를 고르거나 **경로 직접 선택**으로 연결된 부품을 순서대로 선택한다. 전위 그래프의 부품에 마우스를 올리면 회로의 해당 부품이 강조된다.

## 모바일의 공용 도구 바

휴대전화와 짧은 가로 화면에서는 상단에 제목·회로 만들기·분석하기·파일 메뉴(⋯)와 도움말·피드백 아이콘을 배치한다. 분석하기의 한 줄 바에서 **2D/3D·전위·전류**를 고르고 **측정**을 누르면 같은 자리가 **뒤로·측정 종류·측정값·탐침**으로 바뀐다. 전압 측정에서 탐침 아이콘 옆은 해당 지점의 전위, 큰 숫자는 두 지점의 전위차다. 긴 값은 측정값을 눌러 전체를 확인한다.

**뒤로**를 눌러도 탐침 위치·기록·보기 설정은 남는다. 전압 탐침을 놓고 뒤로 → 3D로 이동하면 높이 차를 볼 수 있다. 측정 종류 버튼에서 전류 센서·등가저항을 고른다. 등가저항 측정에서 뒤로 돌아가면 전원과 이전 보기도 복원한다.

기록·탐침 맞바꾸기·위치 지우기는 측정 바의 **⋯**에 있다. 보기 바의 **⋯**에는 전위 색상표·측정 기록 보기·상세 설정을 둔다. 색상표는 현재 그라데이션 버튼만 보이며 누르면 다른 색상표가 펼쳐진다. 2D/3D는 선택된 쪽이 밝게, 켜진 전위·전류 버튼은 진한 색으로 표시된다. 기록과 가변저항 조절창은 회로 아래쪽에 겹쳐 떠서 회로 영역을 줄이지 않는다. 경로 그래프·수업 화면·정밀 출력 편집은 넓은 화면에서 사용한다.

## 측정과 실험

데스크톱은 **분석하기**의 왼쪽 측정 도구에서, 모바일은 **측정**을 누른 뒤 측정 종류 메뉴에서 도구를 고른다. 도구를 켜도 숫자·색상·전류 보기 설정은 유지된다. 데스크톱의 전원 아이콘(**도구 종료**)·Escape로 측정을 해제하며 모바일은 **뒤로**로 보기 바에 돌아간다. 탐침 위치와 기록은 남으며, 측정 중 부품 값은 **상세 설정 → 값을 바꿀 부품**에서 수정한다.

3D에서 측정 도구를 고르면 2D로 전환한다. 전압 탐침을 놓은 뒤 **3D**를 누르면 두 점의 높이 차와 측정값을 함께 볼 수 있다. 모바일은 먼저 **뒤로**로 보기 바에 돌아간다. 데스크톱에서는 **두 탐침 맞바꾸기**·기록을 3D에서도 사용하고, 빨강·검정 탐침 버튼을 누르면 해당 탐침을 선택한 채 2D로 돌아가 위치를 바꿀 수 있다. 전류 센서·등가저항은 3D로 전환하면 종료되며 위치와 기록은 유지된다.

**분석하기 → 전압 탐침**에서 빨강·검정 탐침을 단자나 도선에 놓는다. 표시값은 빨강 전위에서 검정 전위를 뺀 값이다. **두 탐침 맞바꾸기**로 부호를 비교한다.

데스크톱 전압 디스플레이 윗줄과 모바일 측정 바의 작은 빨강·검정 탐침 옆 숫자는 각 지점의 전위다. 현재 접지(0 V)를 기준으로 표시하며, 미연결·계산 불가인 지점은 `—`로 표시한다.

**전류 센서**를 고르고 부품이나 도선을 누르면 작은 비접촉 센서가 놓인다. 전류의 크기는 측정 도구 영역에, 방향은 센서 옆 화살표로 표시한다. 센서를 끌어 다른 곳으로 옮길 수 있다. 회로 모양과 연결은 그대로 유지된다.

**등가저항**을 고르고 **전지 분리하고 측정**을 누르면 전원이 흐려지고 양쪽 연결이 끊어진다. 전원이 없는 회로는 바로 시작한다. 두 탐침을 놓아 그 사이의 저항을 잰다. 분리 중에는 전위·전류 표시를 잠시 숨기고, **도구 종료**·Escape 또는 모바일의 **뒤로**로 이전 보기를 복원한다. 원본 배선은 유지된다. 3 Ω·6 Ω 직렬 회로는 각 저항에서 3 Ω·6 Ω, 전체에서 9 Ω이다.

데스크톱은 측정값 아래 **기록 · + 추가**로 값을 담고 **보기**로 하단 측정표를 연다. 도구를 종료한 뒤에는 왼쪽 **기록 보기**를 사용한다. 모바일은 측정 바의 **⋯ → 측정값 기록 / 기록 보기**, 보기 바의 **⋯ → 측정 기록 보기**를 사용한다. 같은 회로 조건의 위치·값을 비교하고 행별 메모를 수정하거나 삭제할 수 있다. 위치 이름을 누르면 **기록 당시 회로**가 열린다. 기록은 이 브라우저에 남으며 활동지에는 **표 복사**, 파일로는 **CSV 저장**을 사용한다.

## 회로도 출력

모바일은 **상단 ⋯ → 회로도 출력**에서 완성된 회로를 확인하고 복사·저장한다. 확대·화면 이동·그림 설정은 가능하며 아래의 이름·값 배치와 주석 편집은 넓은 화면에서 사용한다.

**회로도 출력**에서 부품 이름을 바꾸면 회로 전체의 실제 이름도 바뀐다. 값은 실제 부품값을 읽기 전용으로 표시하며 **회로 만들기**에서 수정한다. 표시 토글로 숨기고 **빈칸 □**로 사각 답란을 표시한다. 이름과 값은 각각 드래그해 위치를 조절한다.

부품값은 회로 만들기에서 입력한 분수 표기를 사용하며, 이름·화살표 문구·주석에도 분수를 쓸 수 있다. 접지는 기본으로 숨기며 **접지 표시**를 켜면 0 V 숫자 없이 기호만 표시한다. 기호·숫자·단위는 Libertinus Math로 표시하고 SVG·PNG에도 반영한다. 기호는 이탤릭체, 숫자·단위는 정자다.

데스크톱에서 표기를 클릭하면 표시 설정이 열린다. 드래그할 때는 설정을 자동으로 열지 않아 회로 위치가 유지된다. 설정이 닫혀 있어도 첫 드래그부터 이동할 수 있으며 필요할 때 상단 **표시 설정**을 누른다.

상단 **점·전류 화살표·직각 전류 화살표·글자** 도구를 선택하고 원하는 위치를 누른다. 드래그로 이동하며 선택한 화살표 양 끝의 작은 원을 드래그해 길이를 조절한다. 끝점은 선 방향으로만 움직여 각도를 유지하고 직각 화살표의 두 변은 각각 조절된다. 회전 각도는 상단 도구에서 정한다. 회전 아이콘은 90°씩 돌리고 반전 아이콘은 경로를 유지한 채 화살촉 방향을 뒤집는다. 화살표는 출력용 주석으로 기호·값 문구를 자유롭게 편집하며 표시 토글·빈칸을 설정한다. 기호와 값 글자를 각각 드래그하면 화살표는 그대로 두고 글자만 이동한다. 각 위치 초기화로 기본 배치로 돌아온다. 다른 주석의 문구도 수정하거나 삭제할 수 있다. 장식은 출력 탭에만 나타난다. 노드와 접속점은 생략하며 비연결 교차는 아치로 표시한다.

**글자 크기 배율**은 50~200%로 조절한다. Tab으로 표기를 선택하고 방향키로 미세 이동할 수 있다. 도구 선택 후 캔버스에서 Enter로 중앙에 추가할 수도 있다. 빈 공간 드래그는 화면 이동이다.

숫자는 부품별로 선택한 공통 표시 방식으로 보여주며, 여백은 좁게 자동 적용한다. **표시 설정 → 그림 설정**에서 **투명 배경**과 **고해상도 출력**을 켤 수 있다. PNG는 기본 1배이며 고해상도는 가로·세로 각각 2배다. 데스크톱에서는 상단 **미리보기**로 실제 이미지를 확인한다.

상단 **그림 복사** 후 문서에 붙여넣는다. 브라우저가 그림 복사를 허용하지 않으면 같은 PNG가 파일로 저장된다. **파일 저장 → SVG 저장 / PNG 저장**으로 파일을 내려받는다. SVG는 확대 가능한 선과 텍스트를 유지한다. 출력에는 편집 테두리와 캔버스 배율이 섞이지 않는다.

데스크톱의 **수업 화면**은 양쪽 패널을 숨기고 회로 글자를 키운다. **편집 화면**으로 돌아올 수 있다.

## 저장과 단축키

자동 저장은 현재 브라우저에만 남는다. **파일 → 회로 파일 저장 / 회로 파일 열기**로 JSON 파일을 보관하고 다시 연다. 모바일의 파일 메뉴는 상단 **⋯**다. **현재 회로 보관 / 보관한 회로 불러오기**는 이 브라우저의 별도 사본을 사용한다. 파일 저장은 보관본을 덮어쓰지 않는다. 보관본을 불러온 뒤 실행 취소하면 직전 편집으로 돌아갈 수 있다.

상단 저장 상태의 **이 브라우저에 저장됨**은 현재 회로의 자동 저장 상태다. 측정표에 추가한 기록과 메모는 회로와 별도로 이 브라우저에 저장된다. 사이트 데이터를 지우거나 다른 브라우저·기기를 사용하면 함께 옮겨지지 않는다. 측정 기록을 옮길 때는 **표 복사 / CSV 저장**을 사용한다.

| 행동 | 회로 | 측정 기록·메모 | 실행 취소·다시 실행 이력 |
|---|---|---|---|
| 같은 브라우저에서 새로고침·앱 다시 열기 | 마지막 자동 저장 문서 복원 | 저장된 기록과 당시 조건·메모 복원 | 초기화 |
| 실행 중 다른 예제·빈 회로 열기 | 선택한 새 회로로 교체 | 기존 기록 유지 | 문서 교체를 실행 취소 가능 |
| 실행 중 JSON 열기 | 파일의 회로로 교체 | 기존 기록 유지, 파일에서 기록을 가져오지는 않음 | 문서 교체를 실행 취소 가능 |
| 다른 브라우저·기기에서 JSON 열기 | 파일의 회로 복원 | 파일에는 기록·메모가 포함되지 않음 | 원래 브라우저의 이력은 옮겨지지 않음 |

**파일 → 새 회로**와 **빈 회로 만들기**는 회로 만들기 화면에서 시작한다. 데스크톱에는 부품 목록이 보이고 모바일은 **+ 부품**으로 목록을 연다. 수업 화면이었다면 편집 화면으로 돌아온다. 기존 회로 파일 열기와 보관본 불러오기는 현재 작업 모드를 유지한다.

## 회로 위에서 편집하기

회로 만들기·분석하기·출력 화면에서 마우스 휠로 확대·축소할 수 있다. 2D에서는 마우스가 가리키는 위치를 기준으로 확대되며 Ctrl/⌘를 누를 필요가 없다.

이름·값 편집은 Enter로 함께 적용하고 Escape 또는 취소로 함께 취소한다. 한 번의 실행 취소로 두 항목을 복원한다. 잘못된 입력은 적용하지 않는다. 회전·복사·삭제는 선택 부품 근처에서 사용할 수 있다.

새 부품을 도선 위에 놓으면 충분한 직선 구간에 직렬로 삽입한다. 실제 기호·방향·양쪽 도선이 미리 보이고 기존 우회 도선은 제거된다. 전압계는 빈 공간에 놓고 병렬 연결한다. 배선은 시작 단자 → 끝 단자 또는 도선을 차례로 눌러 완성한다. 진행 중 취소 버튼도 제공한다.

비연결 교차점을 누르면 연결한다. 네 갈래 직교 교차는 다시 누르면 비연결로 전환한다. 비연결은 아치, 연결은 채운 점이며 작은 버블은 현재 상태만 표시한다. 이미 배선 중이면 연결점은 도착점으로 사용한다. T자·겹침·앵커가 있는 점은 분리하지 않고 일반 배선 시작 처리를 따른다.

모바일에서는 단자를 탭해 시작하고 끝 단자를 탭해 완료한다. 끝이 도선이면 탭으로 후보 위치를 고른 뒤 체크 아이콘 또는 같은 후보를 다시 탭해 확정한다. 분기는 도선 탭 → 반투명 가지 표시 재탭 또는 체크 아이콘 → 끝 단자 또는 도선 순서다. 완료 전 닫기 아이콘을 누르면 임시 분기점도 사라진다.

모바일에서는 **+ 부품**의 타일을 탭하면 목록이 닫힌다. 이어 놓을 곳을 누른다. 넓은 터치 화면의 부품 목록에서는 길게 눌러 끌어올 수도 있다. 빈 공간에는 바로 놓이고 도선 위에서는 미리보기 후 **삽입**을 누른다.

회로에 놓인 미선택 부품 위를 짧게 밀면 화면이 움직이고, 길게 누르면 그 부품을 집는다. 이미 선택된 부품은 바로 끌 수 있다. 드래그가 어려우면 **이동 → 목적지 탭 → 놓기**를 사용한다. 두 손가락을 대면 진행 중 이동을 취소하고 확대·화면 이동으로 바뀐다. 별도의 화면 이동 버튼 없이 조작하며, 마우스는 선택 도구에서 빈 공간을 끌고 캔버스에 초점을 둔 상태에서는 방향키로 이동한다.

넓은 터치 화면에서는 출력의 이름·값·주석도 길게 눌러 옮기며, 선택 후 방향 버튼으로 미세 조절할 수 있다. 겹친 대상은 이름 목록에서 고른다. 모바일 출력 캔버스에서는 화면 이동·확대만 지원하고 표기 편집은 제공하지 않는다. 두 손가락 화면 조작은 회로·표기 위치를 바꾸지 않는다.

| 조작 | 단축키 |
|---|---|
| 실행 취소 / 다시 실행 | Ctrl+Z / Ctrl+Shift+Z 또는 Ctrl+Y |
| 복사 / 붙여넣기 | Ctrl+C / Ctrl+V |
| 복수 선택 | Shift+클릭 |
| 이동 / 크게 이동 | 방향키 / Shift+방향키 |
| 회전 / 배선 | R / W |
| 삭제 / 도구 취소 | Delete / Esc |
| 키보드 부품 배치 | 부품 선택 후 캔버스에 포커스, 방향키로 위치 이동, Enter로 확정 |

회로 화면 왼쪽 위의 정보·경고 아이콘을 누르면 원인과 수정 방법을 설명하는 말풍선이 열린다. 미연결 단자는 묶은 조립 안내로 표시하며, **회로에서 위치 보기**로 대상을 찾는다. 말풍선은 닫기 버튼·바깥 클릭·Esc로 닫는다. 안내가 나타나거나 사라져도 회로 화면은 움직이지 않는다. 이상적인 직류 저항 회로 모델을 사용하므로 실제 계기의 내부저항이나 전원의 한계 전류는 포함하지 않는다.

## 후기와 피드백 남기기

상단 **한마디**(모바일은 말풍선 아이콘)를 열고 **한마디 남기기**를 누른다. 후기·개선 제안·오류 제보 중 하나를 고르고 내용과 자유 닉네임을 입력한다. 비공개로 남긴 글은 **내가 쓴 글**에서 확인한다. 작성한 기기의 같은 브라우저에서 본인 글의 **수정**·**삭제**를 사용할 수 있다. 수정에서는 닉네임·내용·종류·공개 범위를 바꿀 수 있고, 삭제 후에도 관리자 보관함에는 삭제 표시와 마지막 내용이 남는다.

한 줄 안내 옆 물음표를 누르거나 키보드 초점을 옮기면 자세한 설명이 열린다. 사이트 데이터를 지우거나 시크릿 모드를 종료하면 작성자 확인 정보가 사라질 수 있다. 직접 삭제하기 어려우면 삭제할 글의 닉네임·작성일·내용을 적어 비공개 글 등으로 관리자에게 별도로 요청한다.

글은 Firebase에 저장된다. 공개 글은 다른 사용자에게 보이고 비공개 글은 작성자와 허용된 관리자만 볼 수 있다. 로컬 개발 주소와 공개 사이트는 같은 게시판을 사용하지만 주소별 익명 인증 정보가 달라 한쪽에서 쓴 글을 다른 주소의 **내가 쓴 글**로 관리할 수는 없다. 이전 로컬 미리보기 글은 자동 이전되지 않는다. 관리자 보관함은 별도 `/admin/feedback/` 경로에서 연다(GitHub Pages에서는 `/circuit/admin/feedback/`). 등록된 Google 관리자만 조회할 수 있으며 일반 게시판에는 관리자 이동 버튼이 없다.

## 숫자 표시와 입력

부품을 선택하고 **상세 설정**의 값 입력 아래에서 **표시: 자동 단위 / 유효 숫자 / 원래 숫자**를 선택합니다. 유효 숫자는 4자리 지수 표기입니다. 선택은 그 부품에 저장되고 편집·빠른 값·출력에 함께 적용됩니다. 옆의 **전체 적용**은 현재 선택한 방식을 모든 부품에 적용하며 한 번의 실행 취소로 되돌릴 수 있습니다. 실제 회로값은 바뀌지 않습니다. 원래 숫자는 접두어 없이 기본 단위의 숫자를 보여줍니다. 예: 10 μΩ → 1.000 × 10⁻⁵ Ω → 0.00001 Ω.

상세 설정의 입력은 별도 적용 버튼 없이 Enter 또는 다른 곳으로 이동하면 확정되고 Escape는 초안을 취소합니다. 입력에는 10u, 10n, 10p, 1/3 mV 같은 형식을 사용할 수 있습니다. 분수는 재편집할 때 원문을 유지합니다. 부품 이름도 같은 방식으로 확정·취소하며 공백만 있는 이름은 적용되지 않습니다. 회로 위 이름·값 편집창에서는 Enter 또는 **적용**으로 두 항목을 함께 확정합니다.
