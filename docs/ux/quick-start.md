# 회로 실험실 빠른 시작

## 실행과 첫 회로

Node.js 20.19 이상에서 저장소 루트의 `npm ci`, `npm run dev`를 실행한다. 이 작업 환경의 Windows에서는 `powershell -ExecutionPolicy Bypass -File tools/run-dev.ps1`로 설치된 Vite를 시작할 수 있다.

왼쪽 예제 목록에서 단일·직렬·병렬 회로를 선택한다. 새 회로를 만들려면 **빈 회로 만들기**를 누르고 부품을 고른 뒤 캔버스에 놓는다. 첫 단자와 두 번째 단자를 차례로 누르면 도선이 생긴다. 전원을 처음 놓을 때 음극을 0 V 기준으로 제안한다.

도선이 교차하는 것만으로는 전기적으로 연결되지 않는다. 도선을 선택하고 원하는 위치의 반투명 가지 표시를 눌러 새 배선을 시작한다. 기준을 바꾸려면 **접지(0V)** 도구로 단자나 분기점을 선택한다.

## 값과 전위

부품 옆 값을 누르면 회로 위 입력창이 열린다. `1k`, `1.5 kΩ`처럼 입력하고 Enter 또는 **적용**을 누른다. 값의 단위와 잘못된 입력 안내를 확인한다. 스위치를 두 번 누르면 열린/닫힌 상태를 전환한다.

**전위 보기**에서 숫자·색상·전류 화살표를 켜거나 끈다. 같은 절점의 도선과 단자는 같은 전위를 가진다. 단자나 도선을 누르면 그 절점 전체를 강조한다. 비교 실험에서는 색상 범위를 고정하면 같은 색이 같은 전위를 뜻한다.

**3D 높이**의 높이는 전위이며 실제 공간 높이나 전자의 에너지를 직접 측정한 그림이 아니다. 전류 화살표는 관습적 전류 방향을 보여 준다. 열린 스위치는 높이 지도에서 연결하지 않는다. 전위가 정해지지 않은 회로에는 임의의 높이를 만들지 않는다.

**경로 그래프 보기**를 열고 경로 목록에서 한 바퀴 경로를 고르거나 **경로 직접 선택**으로 연결된 부품을 순서대로 선택한다. 전위 그래프의 부품에 마우스를 올리면 회로의 해당 부품이 강조된다.

## 측정과 실험

**측정하기 → 전압**에서 빨강·검정 탐침을 단자에 놓는다. 표시값은 빨강 전위에서 검정 전위를 뺀 값이다. **탐침 순서 바꾸기**로 부호를 비교한다.

**전류**에서 가지를 선택하면 임시 전류계를 직렬 삽입한 연결을 볼 수 있다. **원본 연결 / 전류계 삽입 후**로 비교한다. 원본 회로 파일은 바뀌지 않는다.

**등가저항**은 선택한 두 탐침 사이를 측정한다. **부하**는 그 포트에 걸린 외부 전원을 분리하고 나머지 전압원을 0 V로 치환한다. **전체 회로**는 외부 전원도 0 V로 치환하므로 전원 양단이 0 Ω으로 나올 수 있다. 화면에 분리한 전원 ID가 표시된다.

예측과 조건을 쓰고 **측정값 기록**을 누른다. CSV는 당시 회로 JSON, 조건, 시간, 값과 단위를 포함한다. 회로를 바꿔도 이전 기록은 그대로다. 기록은 실행 중 메모리에 있으므로 페이지를 닫기 전에 CSV로 보관한다.

**KCL·KVL 확인**은 항별 부호와 합을, **값 변화 실험**은 원본을 바꾸지 않은 21개 조건의 그래프와 수치 표를 보여 준다.

## 문제지와 정답지 출력

**문제 만들기**에서 부품을 선택한다. 부품값·이름·전압·전류에 실제 값, 숨김, 물음표, 빈칸, 문자를 설정한다. 전압·전류는 표시 체크박스를 켜야 나타난다. **문제지 / 정답지**로 같은 회로를 전환한다.

주석 영역에서 단자·분기점을 고르고 점 이름, 오른쪽 전류 화살표, 미지수, 설명을 추가한다. 주석을 선택해 내용을 수정하거나 삭제한다. 실행 취소로 복원할 수 있다.

**숫자·인쇄 옵션**에서 유효숫자/SI 접두어, 소수 자리수 또는 정수를 고른다. 소수·정수 형식은 기본 단위 V/A/Ω를 사용한다. 흑백·투명 배경·여백·PNG 배율을 설정하고 상단 **미리보기**로 실제 이미지를 확인한다.

상단 **그림 복사** 후 문서에 붙여넣는다. 브라우저가 그림 복사를 허용하지 않으면 같은 PNG가 파일로 저장된다. **SVG 저장**은 확대 가능한 선과 텍스트를 유지한다. 출력에는 편집 테두리와 캔버스 배율이 섞이지 않는다.

**수업 화면**은 양쪽 패널을 숨기고 회로 글자를 키운다. **편집 화면**으로 돌아올 수 있다.

## 저장과 단축키

자동 저장은 현재 브라우저에만 남는다. **JSON 저장**으로 파일을 보관하고 **열기**로 다시 연다. **복원 지점 저장**은 이 브라우저에 회로 사본을 남기며 상세 설정의 **회로 복원 지점으로 돌아가기**로 되돌릴 수 있다. JSON 저장도 같은 복원 지점을 갱신한다.

| 행동 | 회로 | 측정 기록 |
|---|---|---|
| 새로고침·앱 다시 열기 | 마지막 자동 저장 문서 복원 | 사라짐, CSV로 보관 필요 |
| 실행 중 다른 예제·빈 회로 열기 | 선택한 새 회로로 교체 | 기존 기록과 당시 조건 유지 |
| 실행 중 JSON 다시 열기 | 파일의 회로로 교체 | 현재 세션 기록 유지, 파일에서 기록을 가져오지는 않음 |
| 새 세션에서 JSON 열기 | 파일의 회로 복원 | 기록 없음 |

## 회로 위에서 편집하기

값을 누르면 가까운 입력창이 열린다. `1k`처럼 입력하고 Enter로 적용한다. Escape 또는 취소로 원래 값을 유지하며, 잘못된 입력의 이유는 입력창 옆에 표시된다. 회전·복사·삭제는 선택 부품 근처에서 사용할 수 있다. 이름 등 상세 편집은 **상세 설정**을 연다.

새 부품을 도선 위에 놓으면 충분한 직선 구간에 직렬로 삽입한다. 실제 기호·방향·양쪽 도선이 미리 보이고 기존 우회 도선은 제거된다. 전압계는 빈 공간에 놓고 병렬 연결한다. 배선은 시작 단자 → 끝 단자 또는 도선을 차례로 눌러 완성한다. 진행 중 취소 버튼도 제공한다.

교차점을 직접 누르면 **연결 / 비연결**이 전환된다. 비연결은 아치, 연결은 채운 점이며 작은 버블은 현재 상태만 표시한다. 이미 배선 중이면 연결점은 도착점으로 사용한다. 네 갈래 직교 교차만 자동 분리하며 주석·기준점이 달린 점은 재지정 후 분리한다.

모바일에서는 단자를 탭해 시작하고 끝 단자를 탭해 완료한다. 끝이 도선이면 탭으로 후보 위치를 고른 뒤 체크 아이콘 또는 같은 후보를 다시 탭해 확정한다. 분기는 도선 탭 → 반투명 가지 표시 재탭 또는 체크 아이콘 → 끝 단자 또는 도선 순서다. 완료 전 닫기 아이콘을 누르면 임시 분기점도 사라진다. 한 손가락으로 화면을 이동하고 두 손가락으로 확대한다. 부품 이동은 먼저 부품을 선택한 뒤 드래그한다.

전위·문제 모드에서는 편집 패널을 접어 회로 공간을 넓힌다. 전위 그래프는 **경로 그래프 보기**로 열고 높이 강조는 3D 상세 설정에서 바꾼다. 문제·정답 전환, **미리보기**, **그림 복사**는 항상 회로 상단에 있다. SVG·PNG 파일은 **파일 저장**, 배율·여백은 표시 설정의 **숫자·인쇄 옵션**에서 고른다.

| 조작 | 단축키 |
|---|---|
| 실행 취소 / 다시 실행 | Ctrl+Z / Ctrl+Shift+Z 또는 Ctrl+Y |
| 복사 / 붙여넣기 | Ctrl+C / Ctrl+V |
| 복수 선택 | Shift+클릭 |
| 이동 / 크게 이동 | 방향키 / Shift+방향키 |
| 회전 / 배선 | R / W |
| 삭제 / 도구 취소 | Delete / Esc |
| 키보드 부품 배치 | 부품 선택 후 캔버스에 포커스, 방향키로 위치 이동, Enter로 확정 |

계산 오류는 회로 아래 안내에서 원인과 수정 행동을 확인하고 **회로에서 위치 보기**로 대상을 찾는다. 미연결 단자는 묶은 조립 안내로 표시한다. 이상적인 직류 저항 회로 모델을 사용하므로 실제 계기의 내부저항이나 전원의 한계 전류는 포함하지 않는다.

## 후기와 피드백 남기기

상단 **한마디**(말풍선)를 열고 **한마디 남기기**를 누른다. 후기·개선 제안·오류 제보 중 하나를 고르고 내용, 자유 닉네임, 글 관리 비밀번호를 입력한다. 비공개로 남긴 글은 **내가 쓴 글**에서 확인한다. **글 삭제**는 작성 시 비밀번호가 필요하며 관리자 보관함에는 삭제 표시와 원문이 남는다.

현재는 이 브라우저에만 저장되는 미리보기다. 다른 사용자나 운영자에게 실제로 전달되지 않으며, Firebase 연결은 후속 작업이다. 개발 환경에서는 하단 **관리자 미리보기**에서 비공개·삭제 글을 확인할 수 있다.
