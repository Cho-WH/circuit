# 사용자 경험 구조

## 작업 모드

역할별로 서로 다른 앱을 만들지 않는다. 같은 `CircuitDocument`에서 사용 목적에 따라 도구를 전환한다.

| 모드 | 주요 행동 | 기본적으로 감추는 것 |
|---|---|---|
| 회로 만들기 | 부품 배치, 배선, 값·이름 수정, 정렬, 실행 취소 | 측정값, 정답, 고급 해석 옵션 |
| 측정·탐구 | 탐침 연결, 스위치·값 변경, 기록표, 그래프 | 모든 값의 자동 공개 |
| 전위 보기 | 기준점, 숫자·색상·높이, 등전위, 경로 그래프 | 편집 도구의 대부분 |
| 문제 만들기 | 값 숨기기, 점·화살표·빈칸, 문제·정답 전환, 출력 | 시뮬레이션 세부 정보 |
| 수업 화면 | 회로 확대, 단계별 공개, 값 슬라이더, 강조 펜 | 편집 패널과 관리 메뉴 |

## 시작 화면

첫 화면에는 세 가지 시작점을 제공한다.

1. **빠르게 회로도 그리기** — 흰 캔버스와 기본 부품으로 시작한다.
2. **회로 탐구하기** — 간단한 예제 회로와 측정·전위 도구를 연다.
3. **예제에서 시작하기** — 직렬·병렬·혼합·열린 스위치 예제를 선택한다.

처음 방문한 사용자에게만 짧은 선택형 체험을 제안한다. 전지와 저항을 직접 놓고 연결하게 하며 언제든 건너뛸 수 있어야 한다.

## 레이어 원칙

2D 회로도가 모든 모드의 기준이다. 다음 정보는 필요할 때 켜는 레이어다.

- 전위 숫자
- 전위 색상
- 등전위 강조
- 전류 방향과 크기
- 측정 결과
- 문제·정답 표시
- 3D 전위 높이

한 화면에서 주 레이어 하나와 보조 레이어 하나를 우선하고, 모든 값을 기본으로 공개하지 않는다.

## 반응형 화면

| 환경 | 우선 경험 |
|---|---|
| 데스크톱·크롬북 | 좌측 부품, 중앙 캔버스, 우측 속성, 하단 레이어. 캔버스가 화면 대부분을 차지한다. |
| 태블릿 | 부품과 속성을 하단 패널로 제공하고 두 손가락 확대·이동을 지원한다. |
| 스마트폰 세로 | 복잡한 편집보다 활동 열람, 스위치·값 변경, 측정, 전위 보기를 우선한다. |
| 키보드 | 선택·이동·회전·삭제·연결 탐색을 키보드만으로 수행한다. |

## 시각 디자인

- 캔버스는 흰색 또는 옅은 회백색을 사용한다.
- 회로 기호는 검정 또는 짙은 중성색을 사용한다.
- UI 장식 색은 제한하고 물리량 색상의 의미를 보존한다.
- 표준 회로 기호와 이름을 함께 표시한다.
- 만화적 부품, 폭죽·점수 보상, 네온 중심의 EDA 외형을 기본값으로 사용하지 않는다.
