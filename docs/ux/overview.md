# 사용자 경험 구조

## 작업 모드

역할별로 서로 다른 앱을 만들지 않는다. 같은 `CircuitDocument`에서 사용 목적에 따라 도구를 전환한다.

| 모드 | 주요 행동 | 기본적으로 감추는 것 |
|---|---|---|
| 회로 만들기 | 부품 배치, 배선, 값·이름 수정, 실행 취소 | 측정값, 정답, 고급 해석 옵션 |
| 측정하기 | 탐침 연결, 임시 계기, 법칙 확인, 기록표, 값 변화 실험 | 구조·값 편집 도구 |
| 전위 보기 | 기준점, 숫자·색상·높이, 등전위, 경로 그래프 | 편집 도구의 대부분 |
| 회로도 출력 | 값 숨기기, 점·화살표·빈칸, 자유 배치, 출력 | 시뮬레이션 세부 정보 |

수업 화면은 별도 작업 모드가 아니라 패널을 감추고 회로를 넓게 보는 표시 전환이다. 단계별 공개·값 슬라이더·강조 펜은 현재 구현 범위에 포함하지 않는다.

## 시작과 조작

현재 앱은 회로 작업 화면에서 시작한다. 자동 저장을 복원하거나 ‘빈 회로 만들기’와 예제를 선택한다. 예제는 단일 저항·직렬·병렬·혼합·열린 스위치·균형 브리지·기준점 이동의 7개 탐구 회로를 제공한다. 병렬은 같은 폭의 가지와 중앙 전원, 브리지는 좌우 대칭 저항 쌍으로 표시한다. 별도의 세 갈래 시작 화면과 최초 방문 체험은 후속 UX 구상이다.

선택은 사각 테두리 대신 윤곽·그림자·작은 상승과 확대로 표시한다. 기호보다 넓은 클릭 영역을 사용하고, 단자 강조·분기 원과 희미한 가지·교차점 직접 토글로 배선 행동을 드러낸다. 일반 호버·클릭의 설명 버블이나 하단 안내를 사용하지 않는다. 교차 상태만 ‘연결’/‘비연결’로 짧게 표시한다. 세부 규칙은 [상호작용](interactions.md)을 따른다.

## 레이어 원칙

2D 회로도가 모든 모드의 기준이다. 다음 정보는 필요할 때 켜는 레이어다.

- 전위 숫자
- 전위 색상
- 등전위 강조
- 전류 방향과 크기
- 측정 결과
- 출력 표기
- 3D 전위 높이

한 화면에서 주 레이어 하나와 보조 레이어 하나를 우선하고, 모든 값을 기본으로 공개하지 않는다.

## 반응형 화면

| 환경 | 우선 경험 |
|---|---|
| 데스크톱·크롬북 | 모드에 필요한 도구만 보이고 상세·그래프는 접어 둔다. 편집 모드의 부품 라이브러리와 회로 위 값 입력을 사용한다. |
| 터치 화면 | 한 손가락 화면 이동, 선택 부품 드래그, 두 손가락 확대, 후보 확인·취소와 겹친 단자 선택 아이콘을 제공한다. |
| 스마트폰 세로 | 가로 도구 목록과 모드별 배치로 편집·전위·측정·출력을 제공한다. 실제 기기 사용성 검증은 남아 있다. |
| 키보드 | 선택·이동·회전·삭제·연결 탐색을 키보드만으로 수행한다. |

390×844 CSS 뷰포트의 브라우저 확인과 포인터 이벤트 테스트를 수행했다. 실제 태블릿·휴대전화 손가락 조작 검증을 대신하지 않는다.

## 시각 디자인

- 캔버스는 흰색 또는 옅은 회백색을 사용한다.
- 회로 기호는 검정 또는 짙은 중성색을 사용한다.
- UI 장식 색은 제한하고 물리량 색상의 의미를 보존한다.
- 한국 교과서·수업 자료에서 익숙한 회로 기호와 이름을 함께 표시한다.
- 저항은 지그재그 기호, 가변저항은 지그재그를 가로지르는 대각선 화살표로 표시한다. 가변저항도 입력한 저항값으로 동일하게 계산하는 두 단자 요소다.
- 이후 추가할 요소도 대상 학년의 한국 교과서 또는 공공 교육 자료에서 주로 쓰이는 표기를 확인해 선택하고 출처·선택 이유를 남긴다. 표기가 여러 가지라면 학습자에게 익숙한 표기를 기본으로 하며, 한 종류만 유일한 표준이라고 설명하지 않는다.
- 부품 라이브러리, 편집 화면, 출력 SVG/PNG는 같은 공통 기호를 사용한다.
- 만화적 부품, 폭죽·점수 보상, 네온 중심의 EDA 외형을 기본값으로 사용하지 않는다.
