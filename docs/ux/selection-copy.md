# 영역 선택과 위치 지정 복사

상태: accepted, 2026-10-08 사용자 승인. EDT-001/002/005, ADR-032.

## 학생의 조작

- 선택 도구에서 빈 공간을 끌면 즉시 선택 상자가 나타난다. 마우스·터치 모두 같은 방식이며 길게 누르기를 기다리지 않는다. 상자 안의 부품 중심·연결점과 경로 전체가 들어간 도선을 선택한다. Shift는 기존 선택에 더한다. 한 요소 클릭도 유지한다.
- 상단 도구막대의 복사 버튼은 선택한 요소가 하나 이상일 때만 나타난다. 모바일도 선택·복사 아이콘을 상단에 둔다. 요소 옆의 이동·복사와 상세 설정의 복사·붙여넣기는 제거한다.
- 마우스에서 복사하면 반투명 회로가 포인터를 따라다니며 클릭으로 배치한다. 터치는 다음 탭 위치에 미리보기를 고정하고 그 옆의 ‘붙여넣기’ 버블 버튼으로 확정한다. 다른 곳을 탭하면 미리보기 위치만 바뀐다.
- 안내는 ‘복사했어요. 놓을 곳을 클릭하세요.’ 또는 ‘복사했어요. 놓을 곳을 터치하세요.’로 짧게 표시한다. 취소·Esc·다른 도구/모드 선택·문서 변경으로 미확정 복사를 끝낸다. Ctrl+C는 같은 복사 시작, Ctrl+A는 회로 전체 선택이며 Ctrl+V는 배치하지 않는다.
- 배치 후 복사 모드를 끝내고 새 묶음을 선택한다. 단일 부품은 원래 특성을 유지한 채 기존 부품 배치·도선 삽입 판정을 공유한다. 도선 후보가 겹치면 기존 후보 선택을 사용한다. 터치에서는 빈 곳·도선 모두 확정 버튼을 거친다.
- 여러 요소는 상대 위치·연결을 유지한다. 기존 부품과 겹치면 ‘빈 공간에 놓아 주세요.’로 안내하고 미리보기를 유지한다. 기존 도선/연결점과 겹쳐도 자동으로 전기 연결하지 않는다.

## 입력과 책임

복사본의 이름은 [ADR-034](../../decisions/ADR-034-component-names.md)의 공통 생성기로 새 배치와 동일하게 부여한다. 원본의 사용자 지정 이름은 유지하고 복사본은 종류에 맞는 새 번호를 받는다. ID 재발급·속성 보존과 별개로 처리한다.

영역 선택은 포인터 캡처와 requestAnimationFrame으로 최신 좌표를 그린다. 매 이동마다 문서 명령이나 해석을 실행하지 않고 놓을 때 선택을 한 번 전달한다. 두 번째 손가락은 선택 상자를 취소하고 기존 핀치·화면 이동을 이어간다. pointercancel·캡처 손실·창 초점 이탈·크기 변경도 원본을 보존한다. 마우스 화면 이동은 가운데 버튼, 터치는 두 손가락을 사용한다. 분석 화면의 기존 이동은 유지한다.

복사 데이터 생성·ID 재발급은 editor.copySelection, 선택 영역·배치 위치/겹침은 app의 작은 순수 함수, 포인터 수명은 전용 hook, 문서 확정·권한·Undo는 기존 useCircuitSession/editor가 담당한다. 단일 부품 삽입은 InsertComponentOnWire를 재사용한다. 확정 전 문서는 변하지 않으며 확정은 한 번의 Undo 단위다. 회로 v6·기록 v5와 계산 계약은 바꾸지 않는다.

선택 도선의 외부 단자는 복사본의 독립 연결점으로 끝낸다. 원본 ID를 참조하지 않는다. 두 선택 부품/연결점 사이의 도선은 함께 복사하며 회로 전체 선택에는 모든 연결점을 포함한다. 화면 미리보기는 공통 기호·도선 경로를 사용한다.

## 검증

마우스/터치 즉시 영역 선택, 양방향 드래그, 핀치·취소·놓은 좌표 처리, 클릭 선택, 모바일 아이콘 표시, 선택 없는 복사 버튼 부재, 단축키 우회 없음, 터치 위치 재지정/확정, 단일 부품 특성 보존과 도선 삽입, 묶음 겹침 거부·연결 분리·Undo·권한·현재 저장 형식 왕복을 확인한다.

입력 근거: [Pointer capture](https://developer.mozilla.org/en-US/docs/Web/API/Element/setPointerCapture), [touch-action](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/touch-action), [requestAnimationFrame](https://developer.mozilla.org/en-US/docs/Web/API/Window/requestAnimationFrame). 기존 useTouchNavigation의 다중 포인터·후속 클릭 억제 계약을 유지한다.
