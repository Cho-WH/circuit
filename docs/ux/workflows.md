# 주요 사용자 흐름

## 교사: 시험지용 회로도 만들기

1. `회로 만들기`에서 `빈 회로 만들기` 또는 예제를 선택한다.
2. 전지, 저항, 스위치를 배치하고 도선을 연결한다.
3. 회로 위에서 값을 수정하고 선택 부품의 속성에서 이름을 수정한다.
4. 회로도 출력에서 요소를 선택해 이름·값의 문자, 표시 여부, 사각 빈칸을 정한다.
5. 이름·값을 드래그하고 점·전류 화살표·글자를 배치한 뒤 글자 배율과 미리보기를 확인한다.
6. 기본 `그림 복사`로 PNG를 복사하거나 세부 메뉴에서 SVG·고해상도 PNG를 저장한다.

완료 상태:

- 선택 테두리와 편집 UI가 출력에 포함되지 않는다.
- 흑백 출력에서도 부품, 라벨, 미지수를 구분할 수 있다.
- 출력 장식은 다른 작업 탭이나 물리 계산에 영향을 주지 않는다.
- 노드·접속점은 생략하고 비연결 교차는 아치로 구분한다.

## 후속 계획: 교사의 탐구 활동 제작·배포

아래는 단계 6의 목표 흐름이며 현재 앱의 사용 절차가 아니다. 활동 정책 데이터와 명령 제한의 기본 계약은 있으나 제작·링크·QR·단계별 공개 UI는 아직 구현하지 않았다.

1. 회로와 초기 스위치 상태, 부품값을 설정한다.
2. 학생에게 허용할 행동을 선택한다.
3. 예측 질문과 결과 공개 순서를 설정한다.
4. 활동 시작 상태를 저장한다.
5. 읽기·조작 권한이 포함된 링크나 QR로 배포한다.
6. 수업 화면에서 단계별 공개를 진행한다.

### 활동 유형

| 유형 | 핵심 흐름 |
|---|---|
| 관찰 | 값이나 스위치를 바꾸고 결과 변화를 관찰한다. |
| 예측 | 전류 방향·전위 순서·측정값을 기록한 뒤 결과를 공개한다. |
| 측정 | 빠른 값 보기를 막고 전압계·전류계로 값을 찾는다. |
| 문제 해결 | 단선, 단락, 값 변화 같은 고장을 측정 결과로 진단한다. |

## 학생: 만들기·측정·설명

1. 예제 또는 빈 회로에서 전지와 저항을 연결한다.
2. 회로 상태와 계산 가능 여부를 확인한다.
3. 두 탐침으로 전위차를 측정하고 부호를 해석한다.
4. 전위 색상 또는 등전위 강조를 켜 같은 도선의 전위를 확인한다.
5. 전위 높이 지도에서 전원의 상승과 저항의 하강을 설명한다.
6. 경로 전위 그래프에서 폐회로를 따라 전위 변화의 합이 0인지 확인한다.

## 빠른 값 보기와 측정기 모드

| 기능 | 목적 | 교육적 의미 |
|---|---|---|
| 빠른 값 보기 | 회로 상태를 빠르게 검토한다. | 부품의 전압·전류·전력을 카드로 확인한다. |
| 두 점 전위차 도구 | 두 점과 방향의 관계를 확인한다. | A→B와 B→A에서 부호가 반전된다. |
| 측정기 모드 | 실제 계기 연결을 연습한다. | 전압계 병렬, 전류계 직렬을 구분한다. |

활동 제작 UI를 구현할 때 교사가 빠른 값 보기를 비활성화하고 측정기로만 값을 얻도록 제한하는 흐름을 제공한다. 현재 범위는 [현재 작업 현황](../implementation/current-phase.md)을 따른다.
