# 축전기 충전 방전 관찰 기획

상태: 2026-10-22 사용자 결정에 따라 dev의 C0~C4를 구현하고 검토했다. 축전기 배치·초기 조건·분석 재생·같은 시각의 2D/3D·계기·기록·출력을 사용할 수 있다. [C4 결과](../testing/rc-c4-results.md), [C5 기술 확인과 미확인 범위](../testing/rc-c5-results.md), [현재 현황](../implementation/current-phase.md)을 따른다. 실제 기기·수업 사용자 수용은 남아 있다. 2026-10-22 사용자가 dev 커밋·배포를 승인했으며 게시 상태는 [현재 현황](../implementation/current-phase.md)을 따른다.

스위치나 부품값을 한 번 바꾼 뒤, 여러 축전기의 전압·전하와 회로 전류가 새 평형으로 바뀌는 과정을 관찰한다. 변화 중에는 회로 조건을 다시 바꾸지 못하게 하여 한 조작의 원인과 결과를 연결한다. 관찰이 끝나면 충분한 시간이 지난 최종 평형으로 전환하고 다음 조작을 허용한다.

## 구현된 사용 흐름

1. 만들기의 **예제 회로 → 축전기 충전·방전**을 열거나 팔레트에서 축전기를 놓는다. 축전기 값 또는 본체를 선택해 C와 부호 있는 초기 전압을 입력하고 **초기 조건 적용**을 누른다. C는 양수여야 한다. 분수·SI 단위를 사용할 수 있다.
2. 초기 전압은 화면에 설명한 첫 단자 전위에서 둘째 단자 전위를 뺀 값이다. 선택 기호의 +/−는 이 기준 방향이며 순간 전하 부호가 아니다. 회전해도 물리적 단자 역할은 유지한다.
3. 분석에 들어가면 2D 판·리드의 전위 색과 3D 판의 높이·색, 선택한 축전기의 양단 전압과 판별 전하를 같은 프레임으로 관찰한다. 전류 무늬도 실험 재생 제어를 따른다. C와 초기 전압은 분석 중 수정하지 않는다.
4. 일시정지에서 탐침을 놓고 기록한다. 표에 최초 관찰/조작 번호와 초가 붙으며, 최종 평형 기록은 초 대신 **최종 평형**으로 표시한다. 재생 중 회로 조절과 기록은 잠기고 탐침 이동은 가능하다.
5. 평형에서 스위치를 바꾸거나 저항·직류 전원 값을 초안으로 입력한 뒤 **적용**한다. 값 표시를 눌러도 이 적용 경로를 사용한다. 분석 진입 상태로 다시 시작하면 진입 당시 회로 설정과 초기 전압으로 복원한다.
6. 출력에서 축전기의 **초기 전압 표시**를 켜면 문서의 초기 조건을 그린다. 재생 도중의 현재 전압을 출력하지 않는다. 분수·빈칸·이동·정렬은 기존 출력과 같은 경로를 사용한다.

## 적용 위치와 첫 버전의 범위

기존 **회로 만들기 / 분석하기 / 회로도 출력** 구조를 유지한다. 사용자가 말한 측정 모드는 분석하기 전체의 실험 세션에 해당한다. 측정 도구를 켜거나 끄는 행동은 충전·방전을 시작하거나 초기화하지 않는다.

축전기가 없는 문서는 기존 DC 분석·연속 조절·작동 경계를 그대로 사용한다. 축전기가 있는 문서는 분석 전체를 선형 RC 경로로 다룬다. 첫 버전에서는 독립된 다른 부분에 있더라도 다이오드가 함께 있으면 RC 분석을 지원하지 않는다. 이는 혼합 엔진을 제공하지 않는 범위 제한이며 다이오드와 축전기가 물리적으로 공존할 수 없다는 뜻이 아니다.

2D·3D 전위, 전류 표시, 계기, 탐침은 같은 시각의 결과를 사용한다. 판별 전하 +Q/−Q는 축전기 상세값으로 제공하고 전하 표식이 두 판 사이를 통과하지 않게 한다. 시간 그래프 편집·여러 실험 곡선 겹치기·전체 재생 이력 탐색은 이번 첫 버전에 넣지 않는다. 기존 경로 전위 그래프는 현재 시각을 표시할 수 있다.

RC 세션에는 작은 `이상적 RC` 표시와 설명을 제공한다. 기존 노랑·빨강 경고가 없다는 것을 실물 안전 판정으로 표현하지 않는다. 설명에는 실제 정격·열·파손을 계산하지 않는 모델임을 적는다.

## 흐름 1 초기 조건을 정하고 분석 시작

1. 만들기에서 축전기를 배치하고 C와 초기 전압을 설정한다. 기본 C는 100 µF를 설계 초기값으로 두며 초기 전압은 0 V다.
2. 초기 전압의 부호는 고정된 단자 a→b 기준이다. 편집할 때 실제 기호 옆에 기준 방향을 보여 주며 화면 회전으로 전압 부호를 바꾸지 않는다. 사용 문구는 부품 이름과 보이는 단자 방향을 사용한다.
3. 분석 진입 시 회로와 초기 조건의 일관성을 먼저 검사한다. 충전 상태와 이상적인 전원·도선 제약이 충돌하면 분석을 시작하지 않고 해당 부품과 수정 방법을 보여 준다.
4. 유효하면 분석 진입 스냅샷을 보존하고 t=0에서 관찰을 시작한다. 처음부터 평형이면 변화 연출 없이 평형 상태로 들어간다.

오류 안내는 `C₁의 초기 전압과 연결된 전원 전압이 맞지 않습니다. 저항을 사이에 넣거나 초기 전압을 바꾸세요.`처럼 회로에서 찾을 수 있는 이름을 쓴다. 내부 진단 ID를 본문 대신 표시하지 않는다.

## 흐름 2 한 번 조작하고 변화를 관찰

평형에서 스위치를 누르면 다음 접점으로의 변경을 미리 검증한다. 저항·직류 전원 조절창에서는 숫자나 슬라이더가 입력 초안만 바꾸며 `적용`할 때 한 번의 조작이 된다. 자동 왕복과 누르고 있는 동안의 연속 적용은 RC 세션에서 제공하지 않는다.

다음 회로와 시작 전하가 유효하고 전체 관찰 계획을 계산할 수 있을 때 조작을 확정한다. 변경이 불가능하면 현재 평형·문서·Undo 이력을 보존하고 초안에서 수정할 수 있게 한다. 계산 중의 추가 클릭을 큐에 넣어 나중에 실행하지 않는다.

관찰 중에는 스위치·저항·전압·초기 조건·구조 변경을 명령 실행 단계에서 잠근다. 화면 이동·확대·보기 전환·전압 탐침·비접촉 전류 센서는 허용한다. 조절 버튼을 숨기는 것만으로 잠금을 구현하지 않는다.

## 재생과 아이콘

각 조작의 물리 경과 시간은 0에서 다시 시작한다. 배율 표시는 항상 보이고 `1배`, `0.002배`, `10배`처럼 물리 시간과 화면 시간의 비율을 나타낸다. 정수 배율로 반올림해 실제 시간을 다르게 계산하지 않는다.

| 계산된 안정화 시간 T | 시작 시 재생 | 노출 제어 |
|---|---|---|
| 0 또는 이미 기준 안 | 평형 전환으로 이동 | 불필요한 대기 없음 |
| 0 < T < 0.5초 | 배율 T / 1초, 화면 관찰 1초 | 일시정지·재개 |
| 0.5초 ≤ T < 5초 | 1배 | 일시정지·재개 |
| T ≥ 5초 | 1배 | 일시정지·재개, 배속, 넘기기 |

배속 아이콘은 현재 1/2/5/10/50/100배 중 선택하는 작은 메뉴를 연다. 이번 조작에서 바꾼 배율만 적용하고 다음 조작에서는 위 규칙으로 돌아간다. 5초 조건은 계산된 물리 시간 기준이며 아이콘 노출은 그 조작이 끝날 때까지 유지한다.

버튼은 글자 대신 일시정지·재개·빠르게 재생·끝으로 이동 아이콘을 쓴다. 현재 배율과 시간은 버튼 밖의 상태값으로 표시한다. 키보드 초점, 툴팁, 스크린리더 이름으로 각 기능을 설명하고 터치에서도 충분한 누름 영역을 확보한다. 넘기기의 접근성 이름은 `최종 평형으로 넘기기`다.

일시정지하면 물리 시간을 고정한다. 탐침을 옮겨도 같은 프레임에서 측정하며, 이 시각의 전압·전류를 기록할 수 있다. 실행 중 기록은 비활성화하고 일시정지 또는 평형에서만 허용한다. 배속 변경은 시각을 되감지 않는다. 브라우저 탭이 숨겨지면 자동 일시정지하며 복귀 시 재개 아이콘을 누르도록 한다.

## 최종 평형으로의 전환

기준에 도달하거나 넘기기를 누르면 상태를 `평형으로 전환 중`으로 바꾸고 약 200 ms 동안 관찰 구간의 남은 실제 응답을 시간 압축해 보여 준다. 단순 위치 보간으로 전하·전류를 만들어 내지 않는다. 끝에서만 계산된 최종 평형을 적용한다. 모션 감소 설정에서는 즉시 전환한다.

이 짧은 전환은 정상 배율 재생이 아니다. 유한 경과 시간 숫자 대신 `평형으로 전환 중`을 표시하며 일시정지·기록·추가 회로 조작은 잠근다. 완료하면 `평형 · 충분한 시간이 지난 상태`로 바꾸고 조절을 허용한다. 최종값을 T초의 정확한 상태처럼 표시하거나 시간 그래프의 유한 시각에 붙이지 않는다.

넘기기는 회로값과 도달할 평형을 바꾸지 않는다. 처음부터 관찰할 때와 같은 최종 전압·전하를 사용한다. 다음 조작의 t=0은 그 평형에서 시작하므로, 여러 조작에 걸친 경과 시간을 하나의 연속된 유한 시간으로 합산하지 않는다.

## 조작 가능 상태

| 상태 | 회로 조건 변경 | 관찰과 기록 | 탈출 |
|---|---|---|---|
| 준비·다음 조작 검사 | 잠금 | 마지막 유효 결과, 새 기록 잠금 | 만들기로 나가기 |
| 재생 중 | 잠금 | 보기·탐침·일시정지, 기록 잠금 | 다시 시작·만들기로 나가기 |
| 일시정지 | 잠금 | 같은 시각의 측정·기록·재개 | 다시 시작·만들기로 나가기 |
| 평형 전환 중 | 잠금 | 전환 표시, 기록 잠금 | 만들기로 나가기 |
| 평형 | 한 번씩 적용 | 측정·기록 | 다시 시작·만들기로 나가기 |
| 계산 실패 | 이전 확정 상태 보존 | 실패 지점의 새 결과는 표시하지 않음 | 다시 시작·만들기에서 수정 |

RC 분석 중 문서 Undo/Redo는 제공하지 않는다. 사용자는 만들기로 돌아간 뒤 기존 문서 이력을 사용한다. 시간 프레임을 Undo 이력으로 쌓지 않는다.

다시 시작은 분석 진입 스냅샷으로 회로값과 초기 전압을 복원하고 첫 관찰부터 재생한다. 세션 중 조작을 되돌리는 한 번의 문서 명령 묶음으로 처리하며 변경이 없으면 이력을 추가하지 않는다. 만들기·출력으로 나갈 때는 현재 확정된 회로 설정을 유지하고 일시적인 충전 상태를 버린다. 다시 분석에 들어가면 그 문서의 초기 전압으로 새 실험을 시작한다.

## 측정과 출력 경계

RC 회로에서 등가저항 측정과 자동 값 변화 실험은 첫 버전에서 비활성화한다. 전원을 분리해 시험 전압을 넣는 기존 등가저항 도구가 충전 상태와 섞이지 않게 한다. 축전기가 없는 기존 회로에는 이 제한을 적용하지 않는다.

측정 기록에는 조작 번호, 해당 조작의 유한 경과 시간 또는 최종 평형 구분, 회로 조건, 수치 품질을 보존한다. 과도응답 근삿값을 정확한 분수값으로 승격하지 않는다. 저장 파일은 실험의 회로 설정과 초기 조건만 담으며 재생 위치나 현재 전하를 저장하지 않는다.

회로도 출력은 공통 축전기 기호·C·이름·초기 조건 표기를 문서에서 생성한다. 과도응답의 현재 프레임 캡처나 시간 그래프 출력은 이번 범위에 없다. 출력에서 초기 전압은 사용자가 표시를 켰을 때만 보이며 현재 충전 전압으로 오해되지 않게 이름을 붙인다.

## 완료 기준

같은 초기 조건과 조작이면 기기·FPS·배속·넘기기 여부와 무관하게 같은 최종 평형을 얻어야 한다. 빠른 충전의 감속, 긴 충전의 아이콘, 중간 측정과 잠금, 초기화, 실패 시 보존은 [수용 사례](../testing/rc-transient-cases.md)로 확인한다. 다음 구현 관문은 [설계의 구현 순서](../architecture/rc-transient.md#구현-순서와-관문)를 따른다.
