# 출력 표기 정렬 기획

상태: UX 주요 결정 확정, 구현 전 설계. 2026-10-21.

회로도 출력에서 이름·값·기호 표기·주석·화살표를 적은 조작으로 가지런히 놓는다. 드래그 중에는 맞출 위치를 보여 주고 가까이 가면 붙이며, 여러 표기를 선택하면 선택 전체 범위를 기준으로 정렬한다. 시험지 그림을 마무리할 때 반복되는 눈대중 조정을 줄이는 것이 목표다.

이 문서는 앞으로 구현할 동작이다. 현재 기능은 [현재 현황](../implementation/current-phase.md), 구현 경계는 [출력 정렬 설계](../architecture/output-alignment.md), 공개 계약 제안은 [ADR-040](../../decisions/ADR-040-output-alignment.md)을 따른다. 문서 작성과 UX 확정은 기능 구현·배포를 의미하지 않는다.

## 문서 읽는 순서

| 순서 | 문서 | 답하는 질문과 상세 기준의 위치 |
|---|---|---|
| 1 | 이 기획서 | 어떤 경험을 제공하는가. 사용자 결정·조작 규칙·수용 시나리오를 정의한다 |
| 2 | [ADR-040](../../decisions/ADR-040-output-alignment.md) | 왜 이 구조를 선택하는가. 대안과 공개 계약 변경의 근거·상태를 설명한다 |
| 3 | [출력 정렬 설계](../architecture/output-alignment.md) | 어떻게 구현하고 검증하는가. 자료형·계산·명령·외부 코드의 경계를 정의한다 |

구현할 항목을 찾을 때는 설계서의 [UX와 구현 검증의 대응](../architecture/output-alignment.md#ux와-구현-검증의-대응)에서 시작한다. 사용자 동작의 의미는 이 기획서에, 구현 방법은 설계서에 상세히 두며 ADR은 선택 이유를 요약한다. 기존 저장소의 요구사항·accepted ADR 우선순위는 그대로 적용한다.

## 사용자와 목표

주 사용자는 회로를 완성하고 시험지·수업 자료용 그림을 정리하는 교사다. 만들기 화면의 부품 배치와 배선을 마친 뒤 출력 화면에서 표기만 다듬는다.

| 작업 | 목표 경험 | 완료 기준 |
|---|---|---|
| 이름을 부품 기호 중앙에 놓기 | 이름을 끌면 부품 중심과 일치할 때 세로 안내선과 붙는 느낌을 얻는다 | 별도 정렬 메뉴 없이 중심을 맞춘다 |
| 여러 값을 같은 줄에 놓기 | 값들만 선택하고 글자 기준선을 맞춘다 | 이름·부품·도선은 그대로이고 값만 같은 줄에 놓인다 |
| 글자나 화살표의 간격 정리 | 드래그 중 같은 간격을 추천하거나 선택 후 간격을 균등하게 한다 | 선택 밖 요소와 화살표 모양을 바꾸지 않는다 |
| 마지막 미세 조정 | 자동 맞춤을 잠시 해제하거나 방향키로 조금씩 움직인다 | 추천 위치를 거부하고 원하는 위치에 놓을 수 있다 |
| 결과 복사·저장 | 정리한 배치가 그대로 출력된다 | SVG·PNG에 선택 상자·안내선·손잡이가 포함되지 않는다 |

## 사용자에게 확인한 결정

2026-10-21 사용자 답변으로 다음 네 가지를 확정했다. 별도의 확인 대기 항목은 없다. 이후 절의 세부 조작은 이 결정을 구체화한 설계이며, 스냅 거리 등 감도 수치는 사용성 검증에서 조정할 수 있다.

| 항목 | 확정 내용 |
|---|---|
| 움직이는 대상 | 기존 범위를 유지한다. 이름·값·주석·화살표를 움직이고 부품 기호·도선은 고정된 정렬 기준으로 사용한다 |
| 자동 맞춤 | 기본 켜기. 화면에서 켜고 끌 수 있으며 Alt를 누르는 동안만 일시 해제한다 |
| 여러 요소 선택 | 기존 빈 공간 드래그의 화면 이동을 유지한다. 별도 영역 선택 도구와 Shift+클릭을 제공한다 |
| 정렬 명령의 기준 | 항상 선택 전체 범위를 기준으로 한다. 마지막 선택 요소 고정·기준 요소 지정 기능은 제공하지 않는다 |

## 적용 대상과 제외 범위

넓은 화면의 회로도 출력 편집에 적용한다. 작은 화면은 현재처럼 보기·이동·확대·그림 복사·파일 저장을 제공한다. 넓은 화면의 터치 입력은 편집할 수 있다.

| 대상 | 선택과 이동 | 맞춤 기준 |
|---|---|---|
| 부품 이름·값·표시된 전압/전류 | 각각 독립 선택·이동 | 글자 기준선, 좌우·상하 가장자리, 중앙 |
| 표기를 대신하는 사각 빈칸 | 해당 이름·값과 같은 선택 단위 | 사각형 가장자리·중앙, 원래 표기의 기준선 |
| 화살표의 기호와 값 | 본체와 독립 선택·이동 | 글자와 같은 기준 |
| 화살표 본체 | 본체와 딸린 표기를 한 묶음으로 이동 | 묶음 외곽과 본체의 끝점·중앙 |
| 점 주석·일반 글자 주석 | 현재 주석 단위로 이동. 점과 그 글자를 새로 분리하지 않는다 | 점 위치 또는 글자/묶음 외곽 |
| 전기 부품 본체 | 표시 설정을 여는 기존 선택만 유지. 정렬 이동 대상에서 제외 | 부품 중심축. 이름·값은 자기 부품 중심을 우선 구별한다 |
| 도선 | 선택·이동 대상에서 제외 | 보이는 구간의 끝 위치와 방향. 연결 관계는 만들지 않는다 |

새 부품, 회로 자동 배치, 배선 경로 수정, 부품 크기 변경, 회전 스냅, 화살표 길이 조절 스냅, 영구 그룹, 자동 충돌 회피는 이번 범위에 없다. 이름과 값의 내용·표시·빈칸 설정은 기존 기능을 사용한다. 서로 다른 요소를 정렬해 겹치게 놓는 것은 허용하며, 앱이 임의로 다시 벌리지 않는다.

### 용어와 선택 단위

| 용어 | 이 문서에서의 의미 |
|---|---|
| 표기 | 이름·값·전압·전류·화살표 기호 등의 글자와 이를 대신하는 사각 빈칸 |
| 부품 기호 | 저항·전지 등 전기 부품을 그린 본체. 출력에서 움직이지 않는다 |
| 화살표 본체 | 출력 주석의 선과 화살촉. 전기 부품 본체와 구분한다 |
| 화살표 묶음 | 본체를 이동할 때 함께 따라가는 본체와 딸린 기호·값. 영구 그룹은 아니다 |
| 선택 단위 | 독립적으로 이동·정렬할 대상 하나. 표기 하나, 주석 하나, 화살표 묶음 하나가 각각 한 단위다 |
| 선택 범위 | 선택 단위의 표시 외곽을 합친 범위. 화살표 묶음은 함께 움직이는 글자도 포함한다 |

화면 용어와 코드의 `part` 값은 설계서의 [출력 선택 모델](../architecture/output-alignment.md#출력-선택-모델)에서 대응한다.

## 화면 구성

출력 상단 도구막대의 선택 도구 옆에 `영역 선택`, `자동 맞춤`, `정렬`을 둔다. 위치는 선택 여부에 따라 바뀌지 않는다.

- `영역 선택`은 누른 상태를 표시한다. 다음 영역 선택을 마치면 기본 선택 도구로 돌아간다.
- `자동 맞춤`은 기본 켜짐을 표시한다. 설명은 “가까운 정렬 위치에 맞춥니다. Alt를 누르면 잠시 해제합니다.”로 제공한다. 설정은 앱을 사용하는 동안 유지하되 회로 파일에 저장하지 않는다.
- `정렬`은 이동 가능한 선택 단위가 2개 이상일 때 활성화한다. 펼침 메뉴에 정렬 기능을 모아 둔다. 같은 간격 기능은 3개 이상일 때 활성화한다.
- 선택 수를 `표기 3개 선택`처럼 표시한다. 단일 대상의 설정과 다중 선택의 정렬 상태를 구분한다.

다중 선택에서는 첫 번째 요소의 이름 편집·삭제를 전체 선택의 동작처럼 노출하지 않는다. 기존 단일 대상 설정은 단일 선택으로 돌아가면 제공한다. 다중 삭제·복사 기능은 이번에 추가하지 않는다.

주석을 추가할 때의 기존 도선 맞춤도 같은 자동 맞춤 토글과 Alt 해제를 따른다. 생성 중에 표기 간 정렬을 새로 계산하지는 않으며, 추가한 뒤 드래그할 때 이 문서의 정렬 보조를 적용한다.

## 흐름 1 이름을 끌어 맞추기

1. 사용자가 저항 이름 `R₁`을 누른다. 이름만 선택 윤곽을 표시한다. 누르는 순간 표시 설정 패널을 새로 열어 화면 크기를 바꾸지 않는다.
2. 이름을 끌면 원래 위치에서의 이동을 미리 보여 준다. 자기 저항 기호의 중심축 가까이 가면 얇은 세로 안내선이 이름과 기호를 잇고 이름이 중심에 붙는다.
3. 다른 이름과 같은 줄 가까이에 오면 가로 안내선이 나타나며 글자 기준선이 맞는다. X·Y축은 따로 보정하므로 가로 이동만 맞거나 두 축이 동시에 맞을 수 있다.
4. Alt를 누르면 보정과 안내선을 즉시 해제하고 원래 포인터 이동을 따른다. 놓으면 가까운 후보를 다시 평가한다. 영구 켜기/끄기 값은 바뀌지 않는다.
5. 포인터를 놓으면 화면에서 마지막으로 본 보정 위치를 한 번에 저장한다. 한 번의 실행 취소로 원래 배치로 돌아간다.

이동 없이 클릭한 경우는 기존처럼 해당 대상의 표시 설정을 연다. 드래그나 드래그 취소는 패널의 열림 상태를 바꾸지 않는다. 스냅은 드래그 중 위치를 보정하고 놓을 때 확정하며, 이후에도 두 요소를 붙잡는 관계를 저장하지 않는다. 글자 내용·글자 배율·부품 회전이 바뀌어 정렬이 달라지면 사용자가 다시 정리한다.

## 흐름 2 값만 여러 개 선택해 정렬하기

1. `10 Ω`을 클릭한 뒤 Shift+클릭으로 `20 Ω`, `30 Ω`을 추가한다. 이미 선택한 값을 Shift+클릭하면 그 값만 제외한다. 이름과 값은 같은 부품에 속해도 별개로 선택된다.
2. 또는 `영역 선택`을 누르고 값들 주위를 드래그한다. 원칙적으로 상자에 완전히 들어온 이동 가능 요소만 선택한다. 화살표는 선과 화살촉이 모두 들어오면 본체를 선택하며, 상자 밖의 딸린 글자도 함께 움직일 묶음에 포함한다. 놓기 전 선택 윤곽으로 이 범위를 보여 준다. 투명한 터치 판정 여백은 포함 여부에 사용하지 않으며 드래그 방향에 따라 기준이 달라지지 않는다.
3. 영역 선택은 기존 선택을 교체한다. Shift를 누르면 기존 선택에 추가한다. 터치에서는 영역 선택 중 사용할 수 있는 `선택에 추가` 토글로 같은 동작을 제공한다.
4. 영역 선택을 놓으면 선택을 확정하고 기본 선택 도구로 돌아간다. 선택 상자만 만들고 문서를 수정하지 않는다. 취소하면 시작 전 선택을 복원한다.
5. `정렬 → 글자 기준선 맞춤`을 누른다. 아래 정렬 메뉴의 기준에 따라 세 값이 같은 줄에 놓인다. 예를 들어 기준선이 80, 88, 100이면 모두 90으로 이동한다.
6. 선택을 유지해 이어서 간격을 조절하거나 묶음을 이동할 수 있다. 정렬 한 번은 실행 취소 한 번이다.

선택한 요소 중 하나를 그대로 드래그하면 전체 선택이 같은 거리만큼 이동한다. 선택 내부의 상대 위치는 유지하며 전체를 하나의 이동 묶음으로 스냅한다. 선택 밖 요소를 보조키 없이 누르면 단일 선택으로 바뀐다. Shift+클릭이나 영역 선택으로 다중 선택을 만드는 동안에는 표시 설정 패널을 새로 열지 않는다. 기본 선택 도구에서 빈 곳을 클릭하면 선택을 해제하고, 빈 곳을 드래그하면 선택을 유지한 채 화면을 이동한다.

### 정렬 메뉴의 정확한 의미

여기서 선택 범위는 이동 가능한 선택 단위의 표시 외곽을 합친 범위다. 화면이나 출력 이미지의 가장자리를 기준으로 사용하지 않는다.

| 명령 | 기준과 이동 |
|---|---|
| 왼쪽 맞춤 / 오른쪽 맞춤 | 선택 범위의 왼쪽 / 오른쪽 가장자리에 각 선택 단위의 같은 가장자리를 맞춘다 |
| 가로 중앙 맞춤 | 선택 범위의 X축 중앙에 각 선택 단위의 X축 중앙을 맞춘다 |
| 위쪽 맞춤 / 아래쪽 맞춤 | 선택 범위의 위쪽 / 아래쪽 가장자리에 각 선택 단위의 같은 가장자리를 맞춘다 |
| 세로 중앙 맞춤 | 선택 범위의 Y축 중앙에 각 선택 단위의 Y축 중앙을 맞춘다 |
| 글자 기준선 맞춤 | 글자·사각 빈칸만 선택했을 때 제공한다. 기준선 최솟값과 최댓값의 중간 높이에 맞춘다. 분수·아래첨자 외곽 중심을 기준선으로 대신하지 않는다 |
| 가로 같은 간격 / 세로 같은 간격 | 양 끝 요소를 그대로 두고 사이의 요소를 움직여 외곽 사이 빈 공간을 같게 한다. 다른 축 좌표는 유지한다 |

같은 간격 배치에서 양 끝 사이에 모든 요소가 들어갈 공간이 없으면 해당 명령을 비활성화하고 “요소를 조금 벌린 뒤 다시 시도하세요.”를 제공한다. 겹침을 음수 간격으로 허용하거나 중앙 간격으로 의미를 바꾸지 않는다. 정렬 명령에는 드래그 스냅을 다시 적용하지 않는다. 이미 같은 위치라면 이력을 추가하지 않는다.

## 흐름 3 화살표와 간격 맞추기

화살표 본체를 끌면 기호·값도 현재 상대 위치를 유지하며 이동한다. 기호 또는 값만 끌면 해당 글자만 이동한다. 화살표 본체와 그 글자가 동시에 선택되면 본체 묶음 하나로 정리하고 글자를 두 번 이동하지 않는다. 선택 윤곽과 선택 수에서도 이 관계가 보이게 한다.

같은 줄의 글자 또는 화살표 사이로 요소를 옮기면 양옆 빈 공간이 같아지는 위치에서 간격 표시와 함께 붙는다. 이미 가까운 두 요소가 만든 간격을 이어가는 위치도 후보가 된다. 관련 없는 이름·값·부품·긴 도선을 모두 섞어 간격을 추천하지 않는다.

도선은 다음처럼 제한해서 참조한다.

- 수평 화살표는 가까운 수평 도선 구간의 시작·끝 X좌표에 본체 끝점 또는 중앙을 맞출 수 있다. 수직은 Y축에 같은 원칙을 적용한다.
- 도선 위로 화살표를 끌어당기는 수직 방향의 흡착은 제공하지 않는다. 도선을 기준으로 한 맞춤은 그 도선과 떨어진 거리를 임의로 정하지 않는다.
- 직각 화살표는 각 수평·수직 변을 같은 방식으로 참고하되 전체가 평행 이동한다. 임의 각도 화살표는 다른 요소와의 외곽·중앙 맞춤만 적용한다.
- 도선과 화살표 사이의 권장 간격 생성, 다른 화살표와 도선 사이 간격 복제는 후속 범위다. 이번 같은 간격 기능은 이동 가능한 요소 사이의 빈 공간에 적용한다.

화살표를 선택한 상태의 끝 손잡이는 기존 길이 조절이다. 이때 그룹 이동·스냅·정렬을 동시에 적용하지 않으며 반대편 끝·각도·직각 유지 규칙을 지킨다. 여러 요소가 선택됐을 때는 개별 화살표 길이 손잡이를 표시하지 않는다.

## 입력과 피드백

| 상황 | 동작 |
|---|---|
| 자동 맞춤 켜짐 | 근처 후보에만 붙고 멀리 있는 정렬 위치로 도약하지 않는다. 숨긴 요소는 후보에서 제외한다 |
| 안내선 | 가로·세로의 실제 맞춤 기준을 얇은 점선으로 표시한다. 같은 간격은 대응하는 두 간격에 같은 표식을 표시한다. 숫자 거리 입력 UI는 추가하지 않는다 |
| 추천이 겹침 | 가까운 후보를 고르되 비슷한 거리라면 자기 부품 중심·글자 기준선·동종 표기를 구별한다. 이미 붙은 위치는 조금 벗어날 때까지 유지해 떨림을 줄인다 |
| 키보드 | Tab으로 표기에 접근하고 Space로 단일 선택, Shift+Space로 선택 추가/제외, Enter로 단일 표시 설정을 연다. 입력창 안에서는 이 단축키를 가로채지 않는다 |
| 미세 이동 | 방향키와 기존 터치 방향 버튼을 유지한다. 방향키는 2 문서 단위, Shift+방향키는 10 단위이며 자동 맞춤을 적용하지 않는다 |
| 터치 | 미선택 표기 길게 누르기·선택 표기 바로 드래그·겹친 대상 목록을 유지한다. Alt 대신 자동 맞춤 토글을 사용한다 |
| 두 번째 손가락 | 진행 중 편집/영역 선택을 취소하고 기존 두 손가락 화면 이동·확대로 전환한다 |
| Escape·포인터 취소·캡처 손실·창 초점 이탈 | 미리보기·안내선을 제거하고 문서 변경을 남기지 않는다. 늦게 도착한 pointerup으로 확정하지 않는다 |
| 도구·문서·모드·출력 설정·실제 화면 크기 변경 | 진행 중 동작을 취소한다. 출력 모드를 나가면 출력 전용 선택을 정리한다 |

안내선은 조작을 가로채지 않는다. 윤곽·점선·같은 간격 표식으로 색에만 의존하지 않고 관계를 표시한다. 정렬 완료 시 “표기 3개의 글자 기준선을 맞췄습니다.”처럼 결과를 알리되 드래그 프레임마다 음성 안내를 반복하지 않는다. 사용자용 이름은 `R₁ 값`, `I₁ 화살표 기호`처럼 만들고 저장 ID를 드러내지 않는다.

## 수용 시나리오

아래는 구현 완료 때 확인할 조건이며 현재 검증 완료 결과가 아니다.

각 번호에 대응하는 구현 절과 검사 위치는 설계서의 [UX와 구현 검증의 대응](../architecture/output-alignment.md#ux와-구현-검증의-대응)에서 확인한다.

1. R₁ 이름을 부품 중심 가까이 끌면 안내선과 미리보기가 일치하고 놓은 뒤 위치가 튀지 않는다.
2. 이름·값을 각각 선택할 수 있으며 값 세 개만 기준선 정렬해도 이름·회로 기하·물리값은 그대로다.
3. 50%, 100%, 200% 화면 확대에서 같은 화면 거리로 스냅이 걸린다. 출력 글자 배율 변경과 화면 확대는 서로 다른 설정으로 처리된다.
4. 분수, 아래첨자, 서로 다른 글자 크기, 사각 빈칸에서 기준선·가장자리·중앙 정렬의 결과가 각각 정의와 일치한다.
5. 자동 맞춤 끄기와 Alt 일시 해제는 안내선까지 해제하며, 키보드 미세 이동은 스냅에 막히지 않는다.
6. 영역 선택과 기본 화면 이동을 구분한다. 취소한 영역 선택은 이전 선택을 보존하며 두 번째 손가락으로 선택이 확정되지 않는다.
7. 화살표 본체와 기호·값을 함께 포함해 선택해도 이중 이동이 없다. 본체만 영역 안에 들어온 경우에도 바깥의 딸린 글자를 묶음 윤곽으로 예고하고 함께 이동한다. 기호·값만 선택하면 독립 이동한다.
8. 선택 밖 요소는 정렬로 움직이지 않는다. 같은 간격은 양 끝을 보존하고 공간 부족 시 위치를 바꾸지 않는다.
9. 선택 요소 이동·정렬 각각을 실행 취소 한 번으로 복구하고 다시 실행할 수 있다. 이동 없는 클릭과 원위치 복귀는 이력을 남기지 않는다.
10. 숨긴 이름·값·주석은 선택·스냅·정렬 범위에 포함되지 않는다. 다시 표시하면 저장된 기존 위치를 사용한다.
11. SVG·PNG·그림 복사에 확정 배치는 반영되고 선택·안내선·스냅 설정은 포함되지 않는다. 저장 후 재열기에서도 배치를 유지한다.
12. 작은 화면의 읽기 전용 출력과 기존 이름 편집·빈칸·화살표 길이 조절·표시 설정 진입은 유지된다.

## 요구사항 연결

TCH-001의 표기 독립 이동과 TCH-002의 출력 주석을 정렬 조작으로 확장한다. TCH-003의 문서 기반 재생성·편집 UI 제외, DAT-001/002의 저장·복원, ADR-012의 부품·도선 고정과 한 번의 드래그 이력을 유지한다. EDT-005의 만들기 영역 선택 규칙을 출력에 그대로 적용하지 않는다. 두 화면의 빈 공간 드래그 목적이 다르기 때문이다.

구현 단계에서 위 수용 시나리오를 TCH-001/002/003의 수용 기준과 해당 테스트에 반영한다. 현재 accepted 요구사항을 미구현 동작으로 덮어쓰지 않는다.
