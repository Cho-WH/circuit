# 상호작용 규칙

## 선택 상태 표시 효과

- 부품 타일, 측정 도구 타일, 데스크톱·모바일 탐침 선택은 `SelectionButton`을 공유한다. `selected` 값으로 접근성 상태(`aria-pressed`)와 테마색 1px 윤곽을 함께 표시한다.
- 선택 음영·하단 강조선은 사용하지 않는다. 기존 아이콘·배치·연결 상태 점은 유지하며 선택 전후 버튼 크기가 변하지 않는다. 키보드 초점 윤곽은 선택 표시와 별도로 유지한다.
- 상단 작업·후기 탭과 2D/3D 토글은 각각의 탐색·전환 디자인을 유지한다.

## 부품 배치

- 데스크톱은 드래그 앤드 드롭을 지원한다.
- 터치는 부품을 선택한 뒤 캔버스를 탭해 배치한다. 모바일의 +부품 팝업은 탭 선택 후 닫히며, 넓은 화면의 라이브러리에서는 길게 눌러 끌어올 수도 있다. 빈 공간에서는 즉시 배치하고 도선 위에서는 실제 기호·방향·양쪽 연결을 확인한 뒤 **삽입**으로 확정한다.
- 배치 전 반투명 미리보기와 단자 위치를 표시한다.
- 부품 하나를 놓은 뒤 기본적으로 선택 도구로 돌아간다.
- 연속 배치는 명시적인 옵션이나 보조키로 활성화한다.
- 부품 이동 중 미리보기와 놓은 뒤의 배선 결과는 같아야 한다. 움직인 단자에서 가장 가까운 코너만 가로·세로 축에 맞추고 가운데 경로와 분기점·다른 가지를 보존한다. 양 끝이 같은 변위로 이동하면 도선 전체도 평행 이동한다.
- 격자 이내 움직임과 원위치 복귀는 편집 기록을 만들지 않는다. Escape·포인터 취소·창 초점 이탈은 미리보기만 취소한다.

## 배선

- 단자에서 배선을 시작하면 연결 가능한 단자를 강조한다.
- 수평·수직 경로를 점선으로 미리 보여 준다.
- 자동 경로가 적용되기 전에 최종 경로를 사용자가 예측할 수 있어야 한다.
- 빈 공간 클릭·탭은 현재 경유 구간을 확정하고 다음 구간을 시작한다. 가로/세로 우선 전환 버튼 또는 `/`는 마지막 미확정 구간만 바꾼다. Backspace 또는 되돌리기 버튼은 마지막 경유점만 취소하고 Esc는 전체 배선을 취소한다. 방향키로 배선 커서를 이동하고 Enter로 점을 확정할 수 있다.
- 도선을 선택하면 각 선분 중앙에 사각 손잡이를 표시한다. 가로 구간은 위아래, 세로 구간은 좌우로 드래그하거나 손잡이에 초점을 두고 방향키로 이동한다. 전기적 끝점은 유지하고 인접 구간만 늘인다. 코너는 영구 잠금점이 아니며, 부품에 가장 가까운 코너는 부품 이동 시 조정될 수 있다.
- 회로 편집에서는 실제 연결을 분기점 점으로 표시한다. 회로도 출력에서는 점을 숨기고 비연결 교차의 아치로 구분한다.
- 분기점이 없는 교차선은 전기적으로 연결하지 않는다.

도선 위 새 부품의 직렬 삽입과 교차 연결/분리를 지원한다. 불필요한 중간 분기점은 합친 경로로 미리보기와 삽입을 계산한다. 공간 부족·꺾임·실제 분기점 주변의 배치 실패는 320ms 동안 원과 X 효과만 표시하며 이유나 가까운 위치를 안내하지 않는다. 배치 초안은 유지한다. 전압계는 빈 공간에 배치해 병렬로 연결한다. 이동·경로 편집 규칙은 [ADR-016](../../decisions/ADR-016-local-wire-routing.md), 분기점 규칙은 [ADR-018](../../decisions/ADR-018-junction-lifecycle.md)을 따른다.

기본 선택 상태에서 단자·일반 분기점 가까이 가면 해당 점만 별도로 강조한다. 단자·끝단·일반 분기점 클릭은 바로 배선을 시작한다. 노드 선택 메뉴나 수동 삭제는 제공하지 않는다. 도선의 첫 클릭은 선택으로 끝나고, 이후 포인터를 움직이면 도선 위에 원형 분기 후보와 마우스 쪽으로 수직하게 뻗는 반투명 가지 도선을 표시한다. 일반 배선의 호버·클릭에는 문구 버블과 하단 안내문을 표시하지 않는다. 클릭으로 분기 배선을 시작하되, 분기점은 연결 완료까지 임시 상태다. 취소하면 원본이 유지되고 완료한 분기는 한 번의 실행 취소로 복원한다.

교차에는 현재 상태인 `연결` 또는 `비연결`만 작은 읽기 전용 버블로 표시한다. 배선 진행 중이 아니면 교차점 자체의 클릭·탭·Enter/Space로 연결을 토글한다. 배선 중 연결된 교차점을 누르면 연결을 해제하지 않고 도착점으로 사용한다. 새 배선으로 생긴 교차 안내는 다른 클릭·작업·Esc로 닫고 재호버로 다시 표시한다. 별도 분기점·교차 연결 도구는 기본 툴바에서 제거하고 배선 버튼은 보조 진입점으로 유지한다. 네 갈래 직교 교차만 기존 판정으로 쌍을 정해 분리한다. T자·겹침·앵커가 있는 점은 분리하지 않고 일반 배선 시작 처리를 따른다. 비연결 가로 도선은 아치로 넘어가며 SVG·PNG도 같은 표시를 사용한다. 상세 계약은 [ADR-013](../../decisions/ADR-013-wire-editing-ux.md)에 있다.

### 터치와 키보드 배선

네 갈래 직교 교차점은 클릭·탭·Enter/Space로 연결·비연결을 전환한다. 끝단·일반 분기점은 같은 조작으로 즉시 배선을 시작한다.

- 단자 탭은 배선을 시작하고 끝 단자·분기점 탭은 완료한다. 배선 중이 아닐 때 일반 분기점 첫 탭은 배선 시작이며 네 갈래 직교 교차는 연결·비연결을 전환한다. 도선을 도착점으로 탭하면 후보를 표시하고 `여기에 연결` 버튼으로 확정한다.
- 도선 탭은 선택과 분기 후보 표시다. 다른 위치를 탭해 후보를 옮기고 `여기서 가지 뻗기`로 시작한다. 확정·취소는 캔버스 모서리의 44px 체크·닫기 아이콘으로 제공하고 같은 후보를 다시 탭해도 확정할 수 있다.
- 단자 판정은 화면 기준 44 CSS px 이상으로 유지한다. 겹친 후보는 원래 위치와 선으로 대응하는 번호 표지와 이름 목록으로 구별한다. 접근성 이름에는 부품명·단자 방향을 유지한다. 축소 상태에서도 부품 중심은 선택할 수 있다.
- 한 손가락의 짧은 스와이프는 화면 이동이다. 미선택 부품 몸체는 450ms 길게 눌러 집고, 이미 선택된 부품은 바로 끈다. 길게 누르기 전 10 CSS px 넘게 움직이면 화면 이동으로 유지한다. 두 손가락 확대·이동은 부품·측정·출력 드래그를 취소하며 모든 손가락을 뗄 때까지 후속 클릭을 억제한다.
- 배선 중 빈 곳 탭은 경유 구간을 확정한다. 배선 중이 아니면 후보를 숨긴다. 취소 버튼·Esc는 시작점·경유 구간·후보를 함께 폐기한다. 도구·모드·문서 변경도 오래된 배선 초안을 폐기한다.
- Tab으로 단자·도선·교차에 초점을 옮기고 Enter/Space로 배선을 시작하거나 교차 상태를 전환한다. 호버 대기 시간, 길게 누르기, 더블탭은 필수가 아니다.

## 값 수정

- 부품 옆 값 표시를 눌러 바로 수정한다.
- `10`, `1k`, `1.5 kΩ`, `1000 ohm` 같은 입력을 허용한다.
- 내부에는 SI 기본 단위로 저장한다.
- 파싱 실패 시 이전 값을 유지하고 원인을 설명한다.
- 회로 위 입력창에서 Enter로 적용하고 Escape 또는 취소 버튼으로 닫는다. 키보드 초점은 값 표시로 돌아간다.

## 모드별 공간

새 회로·빈 회로 만들기는 문서 교체에 성공하면 만들기·편집 화면으로 전환하고 상세 패널을 닫는다. 데스크톱은 부품 목록을 표시하고 모바일은 +부품 팝업을 접어 둔다. 기존 파일 열기·보관본 복원은 현재 모드를 유지한다.

분석하기는 왼쪽 부품 팔레트를 전압 탐침·전류 센서·등가저항 도구로 바꾼다. 도구 종료·Escape로 측정을 종료한다. 보기 설정은 도구와 독립이며 기록·경로 그래프는 하나씩 연다. 선택 상태의 회로 위 값 입력과 측정 중 상세 설정의 부품 선택·값 입력을 지원한다. 3D에서 도구를 선택하면 배치를 위해 2D로 전환한다. 전압 탐침은 3D 전환 후에도 활성 상태를 유지하고 높이 차 눈금·탐침 교환·기록을 제공한다. 탐침 영역은 2D·3D에서 같은 배치를 사용한다. 3D에서 빨강·검정 탐침을 누르면 해당 탐침을 활성화하고 2D로 전환한다. 상단 전압 탐침을 다시 눌러도 도구를 유지하며 2D로 전환한다. 맞바꾸기·기록·도구 종료는 3D에서도 바로 적용한다. 전류·등가저항 도구는 3D 전환 시 종료한다. 위치와 기록은 보존한다. 전지 분리 안내·복원은 ADR-021을 따른다. 출력 모드는 부품 라이브러리와 편집 툴바를 숨긴다. 출력 모드의 편집 도구·미리보기·그림 복사는 중앙 상단에 유지하고, 표시 설정은 선택하거나 버튼을 눌러 연다. 측정 기록은 회로와 별도로 브라우저에 보관하며 표 복사·CSV 저장을 지원한다.

## 선택과 명령

분기점 수동 삭제는 제공하지 않는다. 노드를 삭제 대상으로 보내도 명령이 거절되며 연결된 도선은 유지된다. 도선 삭제 후 영향을 받은 노드만 정리하며 고립점은 제거하고 두 도선 접점은 굴곡을 보존해 합친다. 실제 분기·열린 끝·기준점·주석 앵커는 자동으로 없애지 않는다. 관계없는 기존 노드는 유지한다.

선택·마우스 호버·키보드 초점은 사각 테두리 대신 요소 윤곽으로 표시한다. 부품은 호버 때 약 3.5%, 선택 때 약 5.5% 확대하며 살짝 떠오르는 짧은 탄성 전환과 진한 그림자로 구분한다. 실제 클릭 영역은 움직이지 않는다. 움직임 감소 설정에서는 확대·이동을 생략한다.

부품 클릭 영역은 기호와 함께 회전하며 주변에 화면 기준 12px 여백을 둔다. 도선 클릭·호버 영역은 확대율과 무관하게 폭 32px로 유지한다. 도선은 연결 위치를 유지하고 선 두께와 그림자로 강조한다. 단자·분기점의 원형 초점과 값 편집의 밑줄 초점을 유지한다.

선택한 부품 가까이에 다음 명령을 표시한다.

- 회전
- 복사
- 삭제
- 추가 메뉴

우클릭과 길게 누르기는 보조 경로이며 유일한 조작 경로가 되어서는 안 된다.

부품 삭제는 연결된 도선을 유지하고 부품의 두 단자 자리를 도선으로 잇는다. 전원·계기·열린 스위치에도 같은 규칙을 적용하며 회로를 새로 계산한다. 기존 도선의 굴곡과 분기는 유지되고 기준점·주석은 같은 위치에 남는다. 함께 선택한 도선은 삭제하며, 연결이 없는 부품은 흔적 없이 지운다. 한쪽만 연결된 부품을 지우면 반대쪽은 열린 도선 끝으로 남는다. 삭제 버튼·Delete 키 모두 한 번의 실행 취소로 복원한다. 상세 규칙은 [ADR-017](../../decisions/ADR-017-delete-components-keep-wiring.md)을 따른다.

삭제 과정에서 만든 중간 연결점에 도선 두 개만 만나면 경로를 합쳐 점을 없앤다. 실제 분기·열린 끝과 기준점·주석이 있는 점은 유지한다. 기존 문서의 다른 연결점은 일괄 정리하지 않는다. 미지원 다단자 입력을 삭제할 때에는 서로 다른 단자를 연결하지 않고 각 단자에 붙었던 배선끼리의 연결만 보존한다.

## 터치 이동과 작은 화면

회로 만들기·전위 2D·측정·회로도 출력의 캔버스 위에서는 일반 마우스 휠로 확대·축소한다. Ctrl/⌘를 누른 휠도 같은 동작이며 포인터가 가리킨 회로 위치를 유지한다. 캔버스 밖의 스크롤은 가로채지 않는다. 확대 범위는 기존 버튼과 같고 회로 문서·실행 취소 기록에는 영향을 주지 않는다. 3D의 기존 휠 조작은 유지한다.

별도의 화면 이동 모드·방향 버튼은 두지 않는다. 선택 도구에서 마우스로 빈 공간을 끌거나 기존 가운데 버튼 드래그로 화면을 이동한다. 캔버스 자체에 초점이 있고 배치·배선 중이 아니면 방향키로도 이동한다. 터치의 한 손가락 이동과 두 손가락 확대·이동은 유지한다. 확대·축소 도구는 캔버스 최하단 오른쪽에 두고, 전위 보기 2D의 접지 표기는 같은 줄 왼쪽에 배치한다. 좁은 화면의 긴 접지 위치는 말줄임하고 전체 이름은 접근 가능한 표기와 툴팁으로 유지한다.

터치의 선택 상태는 집힌 상태와 구분한다. 집으면 반투명·작은 상승과 그림자를 표시하고 화면 이동/핀치는 캔버스 가장자리로 구분한다. 선택 후 **이동 → 목적지 탭 → 놓기**는 같은 이동 미리보기와 명령을 사용한다. 취소·원위치 복귀는 기록을 만들지 않는다. 두 손가락 조작은 이동을 취소하고 모든 손가락 해제까지 편집을 재시작하지 않는다.

작은 화면의 선택 명령은 하단에 둔다. 값 편집 중 부품 목록을 접고 세로 화면은 하단, 짧은 가로 화면은 오른쪽에 편집창을 둔다. 분수·음수·단위 입력을 제한하지 않는다. 화면 크기·키보드 변화에도 초안·선택·화면 배율을 유지한다. 자동 시야 이동만 복구하며 이후의 사용자 이동·확대를 덮어쓰지 않는다. 드래그 중 회전은 이동을 취소한다.

출력은 미선택 표기의 길게 누르기, 선택 표기/손잡이의 즉시 드래그, 겹친 표기의 이름 목록, 방향 버튼 미세 이동, 한 손가락 화면 이동과 두 손가락 확대를 지원한다. 작은 화면은 정밀 표기·주석 편집을 숨기고 읽기 전용 화면 이동·확대·복사·저장·그림 설정만 제공한다. 위의 출력 편집 제스처는 넓은 화면에서 제공한다. 복수 선택 전용 터치 모드·확대경·가장자리 자동 이동·진동은 이번 최소 지원 범위에 넣지 않는다.

출력 표기의 포인터 선택은 표시 설정을 즉시 열지 않는다. 데스크톱에서 이동 없이 놓은 클릭이나 Enter 선택으로 열며, 드래그·취소는 기존 패널 상태를 유지한다. 설정이 닫힌 첫 드래그에도 같은 규칙을 적용한다.

## 전환 스위치

전환 스위치(SPDT)는 공통·A·B의 세 단자를 제공한다. 기존 스위치처럼 값 표기 클릭/Enter 또는 기호 더블클릭으로 A/B를 바꾸며 이름·값과 상세 패널의 ‘A로 전환’/‘B로 전환’ 버튼도 같은 명령을 사용한다. 선택 상태는 즉시 적용된다. 출력과 분석 과부하·파손 잠금에서는 상태를 바꿀 수 없다. 세 단자 부품은 도선 직렬 삽입 대상에서 제외하며 삭제는 서로 다른 접점을 단락시키지 않고 외부 배선을 보존한다. 예제의 ‘브릿지 정류 회로’에서 전원 방향과 도통하는 다이오드 쌍의 변화를 관찰할 수 있다([ADR-029](../../decisions/ADR-029-changeover-switch.md)).

## 자동화 규칙

자동 기능은 다음 순서를 지킨다.

1. 변경 결과 미리보기
2. 사용자 동작
3. 적용
4. 즉시 실행 취소 가능

전기 연결을 조용히 추측해 바꾸지 않는다.

## 즉시 계산

기본 직류 회로에는 복잡한 실행 설정을 요구하지 않는다. 회로가 바뀌면 결과를 갱신하고 상태를 짧게 표시한다.

- `계산 완료`
- `아직 닫힌 전류 경로가 없습니다.`
- `전위 기준점을 지정해야 합니다.`

## 3D 전위 높이 전환

전위 범례의 색상바를 클릭·탭하면 세 색상표의 막대만 보이는 선택 메뉴가 열린다. 기본값은 전체 스펙트럼이며 파랑 → 노랑, 검붉은색 → 노랑으로 바꿀 수 있다. 체크 표시로 현재 선택을 구분하고 선택하면 메뉴를 닫고 색상바로 초점을 돌린다. 방향키·Home/End로 후보를 이동하고 Enter/Space로 선택하며 Escape·Tab·바깥 클릭으로 닫는다. 메뉴의 키 입력은 회로 편집 명령으로 전달하지 않는다. 메뉴는 화면 경계 안에 배치하고 2D·3D·작업 모드 변경 뒤에도 현재 앱 세션의 선택을 유지한다. 새로 앱을 열면 전체 스펙트럼으로 시작한다.

- 현재 2D 회로가 사라지지 않고 기울어진 뒤 같은 x-y 위치가 전위에 따라 올라가거나 내려간다.
- 기본 카메라는 직교 투영을 사용한다.
- 정면, 사선, 위에서, 보기 초기화 버튼을 제공한다.
- 높이 강조 정도를 `높이 ×1`처럼 배율로 표시한다.
- 2D → 3D 진입은 운영체제·브라우저의 움직임 감소 설정과 관계없이 높이·카메라 전환을 재생한다. 첫 진입은 1100ms, 같은 문서의 재진입은 900ms다. 직접 카메라를 조작하면 전환을 중단한다.
- 정면·사선·위에서·보기 초기화의 카메라 전환은 움직임 감소 설정이면 즉시 최종 시점으로 이동한다.
- 3D를 열지 못하면 2D 보기로 돌아갈 수 있으며, 넓은 화면에서는 경로 전위 그래프도 사용할 수 있다.

## 오류 피드백

회로 진단은 캔버스 왼쪽 위에 작은 아이콘으로 표시한다. 빈 회로·미연결 단자·기준점과 연결되지 않은 부분은 정보 아이콘, 단락 등 나머지 경고·오류는 경고 아이콘으로 구분한다. 계산 엔진의 진단 코드는 유지한다. 아이콘 클릭·탭·키보드 활성화로만 설명 말풍선을 열고, 닫기·바깥 클릭·Esc 또는 초점 이탈로 닫는다. 같은 코드의 안내는 묶고 기존 **회로에서 위치 보기**를 제공한다. 진단이 없으면 아이콘도 숨긴다.

아이콘과 말풍선은 회로 위에 겹쳐 표시하며 도구 막대나 하단에 공간을 확보하지 않는다. 안내의 표시·내용 변경으로 캔버스 크기나 시야를 바꾸지 않는다. **회로에서 위치 보기**·**전체 보기**처럼 사용자가 요청한 시야 이동은 유지한다.

모든 오류는 다음 순서로 설명한다.

1. 현재 어떤 상태인지
2. 물리적으로 왜 문제가 되는지
3. 사용자가 무엇을 고칠 수 있는지

예:

> 전원의 두 단자가 도선으로 직접 연결되어 있습니다. 이상적인 도선의 저항은 0 Ω이므로 이 모델에서는 전류를 유한한 값으로 계산할 수 없습니다. 직접 연결된 도선을 제거하거나 저항을 추가하세요.

문제 요소를 강조하고 가능한 경우 `연결되지 않은 단자 보기`, `직전 상태로 되돌리기` 같은 행동을 함께 제공한다.

## 접근성

- 보이는 단자가 작아도 실제 판정 영역은 화면 기준 44 CSS px 이상으로 둔다. 터치 후보 목록·확정·선택 명령은 48 CSS px 높이를 목표로 한다.
- 모든 아이콘에는 텍스트 이름 또는 툴팁을 제공한다.
- 축약 조작의 툴팁은 밝은 배경·둥근 모서리와 앱 공통 글꼴을 사용한다. 마우스를 잠시 올리거나 키보드로 초점을 주면 표시하고 Escape·클릭·스크롤로 닫는다. 측정 기록의 보기 버튼은 “측정 기록 보기”로 안내한다.
- 색만으로 상태를 전달하지 않는다.
- 200% 확대에서도 주요 기능과 텍스트가 잘리지 않아야 한다.
- 키보드 초점은 현재 부품·단자·도구에서 명확히 보여야 한다.


## 측정 작업 공간 (MEA-001~003, SIM-005)

분석 화면에서 측정 도구와 상태·측정값·기록 동작은 왼쪽 패널에 배치한다. 경로 그래프는 상단 보기 설정에서, 기록 보기는 왼쪽 패널에서 연다. 작은 화면은 ADR-021의 같은 높이 공용 바에서 보기/측정을 교체한다. 2D/3D·전위·전류는 segmented 디자인으로 선택 상태를 표시한다. 전위는 데스크톱 색상과 공통 함수로 색상만 바꾸며 숫자를 유지한다. 공통 색상표·기록·추가 설정은 더보기로 접는다. 뒤로는 위치·기록·보기 설정을 유지하며, 기록과 가변저항 조절은 회로 위에 뜬다. 경로 그래프는 숨긴다.

데스크톱 분석 패널은 가변저항 유무와 관계없이 폭 226px, 측정 도구 3열과 탐침 아이콘·이름 가로 배치를 기본으로 사용한다. 조절창을 열고 닫아도 패널 폭과 측정 도구 배치는 유지한다.

데스크톱 측정값은 2D·3D가 공유하는 LCD 표시창에 전압·전류·저항 이름과 함께 표시한다. 표시창과 조작 행은 얇은 테두리의 측정기 영역으로 묶고 기존 패널 배경색을 유지한다. 연녹색 배경과 안쪽 그림자는 표시창 안에만 적용하며 숫자는 고정폭 46px을 기준으로 크게, 단위는 작게 기준선을 맞춘다. 긴 값은 글자 크기를 줄이고 필요한 경우 줄바꿈하여 생략하지 않는다. 바로 아래에는 `기록 · + 추가 · 보기 · 전원 아이콘`을 채움 없는 작은 버튼 한 줄로 배치한다. 추가는 기존 측정 기록을 저장하고, 보기는 측정표를 열고 닫으며, 전원 아이콘은 도구를 종료한다. 도구 종료 후에도 기록 보기를 유지한다. 탐침·도구 선택·가변저항 조절 영역과 수치 형식·계산·저장 방식은 유지한다.

등가저항에서는 모든 전원을 개방해 계산하고 전원 기호·이름·값을 흐리게, 양쪽 리드에 간격을 두어 표현한다. 다른 부품과 탐침용 단자는 정상 표시한다. 전원 분리 아이콘에 호버·키보드 초점·탭을 주면 “실제 저항계는 전원을 분리한 회로에 작은 시험 신호를 보내 저항을 측정해요.”가 뜬다. 초점이 벗어나거나 Esc를 누르면 닫힌다. 전압·전류로 바꾸면 전원은 정상 표시한다.

탐침은 빨강·검정 손잡이와 +/− 기호, 접점으로 구분한다. 단자 또는 도선을 누르면 활성 탐침을 놓고 빨강 다음 검정으로 전환한다. 전류 센서는 부품 또는 도선 구간을 눌러 놓고 도선 방향에 맞춰 회전한다. 놓인 도구는 드래그로 옮긴다. 교차·분기점에서 모호한 도선은 자동 선택하지 않는다. 모바일은 도구 선택 뒤 탭으로 배치하고, 키보드는 단자·도선·부품에서 Enter로 선택한다. 구조·위치 변경은 회로 만들기에서 하고, 분석 중 값 수정은 선택 상태의 회로 위 입력이나 상세 설정에서 지원한다. 모드 전환 시 측정 기록과 탐침 선택을 유지한다.

## 회로 위 이름·값 편집

값을 클릭하거나 선택 부품의 이름·값 편집을 열면 두 입력을 함께 수정한다. 이름 옆에 표기 미리보기를 표시한다. `R_1`은 숫자 아래첨자, `R_{eq}`는 묶은 아래첨자로 표시된다. Enter·적용으로 함께 저장하고 Escape·취소로 초안을 버린다. 실행 취소도 두 변경을 함께 복원한다. 스위치의 기존 클릭 전환을 유지하며 이름 변경은 선택 도구의 편집 버튼에서 연다.

## 작업 화면과 피드백 (2026-09-24)

데스크톱 상단은 문서·파일, 작업 모드, 현재 도구의 세 줄로 구성한다. 작은 화면은 문서·만들기/분석 탭·파일 메뉴를 한 줄로 합치고 현재 도구와 함께 두 줄로 유지한다. 설명 행과 반복 안내 대신 도구 아이콘·선택 상태를 사용한다. 상세 패널은 현재 도구 행에서 열고 닫으며 출력에서는 선택 대상의 기호·값과 그림 설정을 표시한다. 좁은 화면은 아래쪽 설정 패널을 사용하고 보조 도구는 더보기로 접는다. 출력 설정은 그림 설정만 제공한다.

측정값은 데스크톱의 왼쪽 표시창 또는 모바일의 공용 바에서 즉시 갱신한다. 전압 측정에서 작은 탐침 아이콘 옆은 각 지점의 전위, 큰 숫자는 전위차다. 위치 목록 대신 회로를 직접 선택하며, 측정표는 기록 보기로 연다. 기록·메모는 별도 브라우저 저장소에서 복원하고 표 복사·CSV로 내보낸다. 새로고침 때 초기화되는 실행 취소 이력과 구분한다.

자동 저장 성공은 체크 표시, 실패는 파일 저장 행동으로 전달한다. 일반 성공 알림은 status, 실패는 alert로 구분하고 실패 알림은 직접 닫을 때까지 유지한다. 그림 복사 성공은 버튼 내부의 체크와 복사됨 표시를 사용한다. 3D 준비·전환·취소 계약은 ADR-006을 따른다.

스위치를 선택한 뒤 **이름·값**을 열면 이름과 함께 상세 설정과 같은 **스위치 열기 / 닫기** 버튼으로 상태를 바꿀 수 있다. 상태 버튼은 즉시 반영하며 편집창과 이름 초안을 유지한다. 적용 버튼은 이름만 확정한다. 취소 또는 Escape는 이름 초안만 버리고 이미 바꾼 스위치 상태는 유지한다. 상태와 이름 변경은 각각 실행 취소할 수 있다. 상태를 직접 누르거나 스위치를 두 번 눌러 전환하는 기존 조작도 유지한다.

## 회로 시작 메뉴

모바일의 +부품은 공통 FloatingPanel 안에 부품 타일을 열며 탭 선택 후 닫는다. 예제는 같은 팝업의 접힌 목록에서 고르고 새 회로는 파일 메뉴에서 만든다. 데스크톱의 예제 회로와 공통 파일 메뉴는 방향키 탐색, Escape·바깥 클릭 닫기를 지원한다. 팝업은 화면 경계 안에 배치한다. 예제 이름은 휘트스톤 브릿지, 저항 사이 접지를 사용한다.

측정표는 데스크톱의 왼쪽 기록 보기로 회로 아래에 펼친다. 모바일은 보기·측정 바의 더보기에서 열며 회로 위 아래쪽에 겹쳐 표시한다. 기록 버튼은 패널을 자동으로 열지 않는다. 조건별로 위치·값을 비교하고 행별 메모·삭제를 지원한다. 위치를 누르면 당시 회로를 읽기 전용으로 확인한다. [ADR-022](../../decisions/ADR-022-measurement-notebook.md).

## 가변저항으로 비교하기

회로 만들기에서 가변저항의 값을 누르면 현재 저항값과 최솟값·최댓값을 직접 설정한다. 상세 설정에서도 현재값과 범위를 편집한다. 이름·현재값·범위는 적용 시 함께 저장하며, 취소하면 편집 전 상태를 유지한다. 설정한 현재값은 분석하기의 계산과 슬라이더에 그대로 이어진다. 새 가변저항 이름은 `VR_1`, `VR_2`처럼 숫자를 아래첨자로 표시한다. 분석하기에서는 회로에서 가변저항을 누르면 왼쪽 조절창이 나타나며 슬라이더를 움직이거나 저항값을 입력한다. 선택을 해제하거나 다른 부품을 누르면 조절창은 숨겨진다. 측정 도구를 함께 사용할 수 있고 탐침은 그대로 유지된다. 여러 가변저항도 회로에서 직접 고르며 드롭다운은 두지 않는다. 조절창이 숨겨져도 자동 조절은 계속되고 다시 선택하면 실행 상태를 확인하고 일시 정지할 수 있다. 슬라이더 아래 저항 자동 조절 재생 버튼으로 범위를 천천히 왕복한다. 실행 중에는 일시 정지 버튼으로 바뀌며 다시 재생하면 멈춘 값과 진행 방향에서 이어진다. 직접 입력하면 자동 조절은 멈춘다. 측정값 기록은 당시 저항값을 포함한 회로 조건을 보존한다.

분석하기의 일반 선택은 2D·3D에서 같은 상태 처리 함수를 사용한다. 빈 공간 클릭은 부품 선택과 도선 net 강조를 함께 해제한다. 3D 카메라 드래그·다중 터치·취소된 포인터 동작은 선택 클릭으로 처리하지 않는다.

분석하기에서 단자와 전위 숫자 표지는 2D·3D 모두 해당 지점에 연결된 net을 선택한다. 부품 몸체와 도선은 각각의 요소를 선택하며, 연결망 선택 시 이전 부품 선택을 해제한다. 전압 탐침 도구가 활성화되어 있으면 기존 측정 동작을 따른다.
