# 상호작용 규칙

## 부품 배치

- 데스크톱은 드래그 앤드 드롭을 지원한다.
- 터치는 부품을 선택한 뒤 캔버스를 탭해 배치할 수 있다.
- 배치 전 반투명 미리보기와 단자 위치를 표시한다.
- 부품 하나를 놓은 뒤 기본적으로 선택 도구로 돌아간다.
- 연속 배치는 명시적인 옵션이나 보조키로 활성화한다.

## 배선

- 단자에서 배선을 시작하면 연결 가능한 단자를 강조한다.
- 수평·수직 경로를 점선으로 미리 보여 준다.
- 자동 경로가 적용되기 전에 최종 경로를 사용자가 예측할 수 있어야 한다.
- 실제 연결은 분기점 점으로 표시한다.
- 분기점이 없는 교차선은 전기적으로 연결하지 않는다.
- 자동 정리 결과는 한 번의 실행 취소로 되돌릴 수 있어야 한다.

## 값 수정

- 부품 옆 값 표시를 눌러 바로 수정한다.
- `10`, `1k`, `1.5 kΩ`, `1000 ohm` 같은 입력을 허용한다.
- 내부에는 SI 기본 단위로 저장한다.
- 파싱 실패 시 이전 값을 유지하고 원인을 설명한다.

## 선택과 명령

선택한 부품 가까이에 다음 명령을 표시한다.

- 회전
- 복사
- 삭제
- 추가 메뉴

우클릭과 길게 누르기는 보조 경로이며 유일한 조작 경로가 되어서는 안 된다.

## 자동화 규칙

자동 기능은 다음 순서를 지킨다.

1. 변경 결과 미리보기
2. 사용자 동작
3. 적용
4. 즉시 실행 취소 가능

전기 연결을 조용히 추측해 바꾸지 않는다.

## 즉시 계산

기본 직류 회로에는 복잡한 실행 설정을 요구하지 않는다. 회로가 바뀌면 결과를 갱신하고 상태를 짧게 표시한다.

- `계산 완료`
- `아직 닫힌 전류 경로가 없습니다.`
- `전위 기준점을 지정해야 합니다.`

## 3D 전위 높이 전환

- 현재 2D 회로가 사라지지 않고 기울어진 뒤 같은 x-y 위치가 전위에 따라 올라가거나 내려간다.
- 기본 카메라는 직교 투영을 사용한다.
- 정면, 사선, 위에서, 보기 초기화 버튼을 제공한다.
- 높이 과장값을 `전위 높이 4배 강조`처럼 표시한다.
- 움직임 감소 설정에서는 애니메이션 없이 최종 상태로 전환한다.
- 3D 사용이 어려운 기기에는 2D 경로 전위 그래프를 제공한다.

## 오류 피드백

모든 오류는 다음 순서로 설명한다.

1. 현재 어떤 상태인지
2. 물리적으로 왜 문제가 되는지
3. 사용자가 무엇을 고칠 수 있는지

예:

> 전원의 두 단자가 도선으로 직접 연결되어 있습니다. 이상적인 도선의 저항은 0 Ω이므로 이 모델에서는 전류를 유한한 값으로 계산할 수 없습니다. 직접 연결된 도선을 제거하거나 저항을 추가하세요.

문제 요소를 강조하고 가능한 경우 `연결되지 않은 단자 보기`, `직전 상태로 되돌리기` 같은 행동을 함께 제공한다.

## 접근성

- 보이는 단자가 작아도 실제 터치 영역은 약 40 px 이상으로 둔다.
- 모든 아이콘에는 텍스트 이름 또는 툴팁을 제공한다.
- 색만으로 상태를 전달하지 않는다.
- 200% 확대에서도 주요 기능과 텍스트가 잘리지 않아야 한다.
- 키보드 초점은 현재 부품·단자·도구에서 명확히 보여야 한다.


## 측정 작업 공간 (MEA-001~004)

측정 모드는 편집과 분리한다. 부품 라이브러리·배선/편집 도구·속성 편집을 표시하지 않고 상단에 전압/전류/등가저항 도구, 탐침 또는 가지 선택, 측정값과 기록 동작을 배치한다. 회로는 중앙, 기록·보존 법칙·값 변화 실험은 보조 패널에 둔다. 모바일은 같은 도구 순서를 유지하고 기록 패널을 회로 아래로 배치한다.

긴 시작 안내 대신 선택 중/미연결/연결됨 상태, +/- 기호, 선택 테두리로 탐침 상태를 구분한다. 단자 또는 도선을 누르면 활성 탐침을 연결한다. 전류 모드에서는 부품을 눌러 측정 가지를 바꾼다. 회로 편집 버튼으로 돌아가야 구조·값·위치를 바꿀 수 있다. 모드 전환 시 측정 기록과 탐침 선택을 유지한다.
