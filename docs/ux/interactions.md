# 상호작용 규칙

## 부품 배치

- 데스크톱은 드래그 앤드 드롭을 지원한다.
- 터치는 부품을 선택한 뒤 캔버스를 탭해 배치할 수 있다.
- 배치 전 반투명 미리보기와 단자 위치를 표시한다.
- 부품 하나를 놓은 뒤 기본적으로 선택 도구로 돌아간다.
- 연속 배치는 명시적인 옵션이나 보조키로 활성화한다.
- 부품 이동 중 미리보기와 놓은 뒤의 배선 결과는 같아야 한다. 이동하지 않은 부품끼리 연결된 도선의 모양은 유지한다.
- 격자 이내 움직임과 원위치 복귀는 편집 기록을 만들지 않는다. Escape·포인터 취소·창 초점 이탈은 미리보기만 취소한다.

## 배선

- 단자에서 배선을 시작하면 연결 가능한 단자를 강조한다.
- 수평·수직 경로를 점선으로 미리 보여 준다.
- 자동 경로가 적용되기 전에 최종 경로를 사용자가 예측할 수 있어야 한다.
- 회로 편집에서는 실제 연결을 분기점 점으로 표시한다. 회로도 출력에서는 점을 숨기고 비연결 교차의 아치로 구분한다.
- 분기점이 없는 교차선은 전기적으로 연결하지 않는다.

도선 위 새 부품의 직렬 삽입과 교차 연결/분리를 지원한다. 도선 가까이에서 실제 기호와 양쪽 배선을 미리 보고 놓는다. 공간 부족·꺾임·교차 가까이는 이유를 표시하며, 전압계는 빈 공간에 배치해 병렬로 연결한다. 연결된 기존 부품의 이동 정책은 바꾸지 않는다.

기본 선택 상태에서 단자·일반 분기점 가까이 가면 해당 점만 별도로 강조한다. 클릭하면 배선을 시작한다. 도선의 첫 클릭은 선택으로 끝나고, 이후 포인터를 움직이면 도선 위에 원형 분기 후보와 마우스 쪽으로 수직하게 뻗는 반투명 가지 도선을 표시한다. 일반 배선의 호버·클릭에는 문구 버블과 하단 안내문을 표시하지 않는다. 클릭으로 분기 배선을 시작하되, 분기점은 연결 완료까지 임시 상태다. 취소하면 원본이 유지되고 완료한 분기는 한 번의 실행 취소로 복원한다.

교차에는 현재 상태인 `연결` 또는 `비연결`만 작은 읽기 전용 버블로 표시한다. 배선 진행 중이 아니면 교차점 자체의 클릭·탭·Enter/Space로 연결을 토글한다. 배선 중 연결된 교차점을 누르면 연결을 해제하지 않고 도착점으로 사용한다. 새 배선으로 생긴 교차 안내는 다른 클릭·작업·Esc로 닫고 재호버로 다시 표시한다. 별도 분기점·교차 연결 도구는 기본 툴바에서 제거하고 배선 버튼은 보조 진입점으로 유지한다. 네 갈래 직교 교차만 자동으로 쌍을 정한다. T자·겹침·주석이나 기준점이 달린 분기점에는 해제 버튼을 제공하지 않는다. 비연결 가로 도선은 아치로 넘어가며 SVG·PNG도 같은 표시를 사용한다. 상세 계약은 [ADR-013](../../decisions/ADR-013-wire-editing-ux.md)에 있다.

### 터치와 키보드 배선

- 단자·분기점 탭은 배선을 시작하고 끝 단자 탭은 완료한다. 도선을 도착점으로 탭하면 후보를 표시하고 `여기에 연결` 버튼으로 확정한다.
- 도선 탭은 선택과 분기 후보 표시다. 다른 위치를 탭해 후보를 옮기고 `여기서 가지 뻗기`로 시작한다. 확정·취소는 캔버스 모서리의 44px 체크·닫기 아이콘으로 제공하고 같은 후보를 다시 탭해도 확정할 수 있다.
- 단자 판정은 화면 기준 44px 이상으로 유지한다. 여러 후보가 겹치면 각 원래 위치와 가는 선으로 이어지는 원형 선택 아이콘을 펼친다. 접근성 이름에는 부품명·단자 방향을 유지한다. 축소 상태에서도 부품 중심은 선택할 수 있다.
- 한 손가락 드래그는 화면 이동, 이미 선택된 부품 몸체에서 시작한 드래그는 부품 이동이다. 두 손가락 확대·이동이 시작되면 부품 드래그를 취소하며 손을 뗀 뒤의 클릭도 연결로 처리하지 않는다.
- 빈 곳 탭은 후보를 숨기되 진행 중인 배선은 유지한다. 취소 버튼·Esc는 시작점과 후보를 함께 폐기한다. 도구·모드·문서 변경도 오래된 시작점을 폐기한다.
- Tab으로 단자·도선·교차에 초점을 옮기고 Enter/Space로 배선을 시작하거나 교차 상태를 전환한다. 호버 대기 시간, 길게 누르기, 더블탭은 필수가 아니다.

## 값 수정

- 부품 옆 값 표시를 눌러 바로 수정한다.
- `10`, `1k`, `1.5 kΩ`, `1000 ohm` 같은 입력을 허용한다.
- 내부에는 SI 기본 단위로 저장한다.
- 파싱 실패 시 이전 값을 유지하고 원인을 설명한다.
- 회로 위 입력창에서 Enter로 적용하고 Escape 또는 취소 버튼으로 닫는다. 키보드 초점은 값 표시로 돌아간다.

## 모드별 공간

전위·문제 모드는 부품 라이브러리와 편집 툴바를 숨긴다. 상세 패널과 전위 경로 그래프는 기본 접힘이다. 출력 모드의 편집 도구·미리보기·그림 복사는 중앙 상단에 유지하고, 표시 설정은 선택하거나 버튼을 눌러 연다. 측정 기록은 회로 저장과 별도로 CSV로 보관한다.

## 선택과 명령

선택·마우스 호버·키보드 초점은 사각 테두리 대신 요소 윤곽으로 표시한다. 부품은 호버 때 약 3.5%, 선택 때 약 5.5% 확대하며 살짝 떠오르는 짧은 탄성 전환과 진한 그림자로 구분한다. 실제 클릭 영역은 움직이지 않는다. 움직임 감소 설정에서는 확대·이동을 생략한다.

부품 클릭 영역은 기호와 함께 회전하며 주변에 화면 기준 12px 여백을 둔다. 도선 클릭·호버 영역은 확대율과 무관하게 폭 32px로 유지한다. 도선은 연결 위치를 유지하고 선 두께와 그림자로 강조한다. 단자·분기점의 원형 초점과 값 편집의 밑줄 초점을 유지한다.

선택한 부품 가까이에 다음 명령을 표시한다.

- 회전
- 복사
- 삭제
- 추가 메뉴

우클릭과 길게 누르기는 보조 경로이며 유일한 조작 경로가 되어서는 안 된다.

## 자동화 규칙

자동 기능은 다음 순서를 지킨다.

1. 변경 결과 미리보기
2. 사용자 동작
3. 적용
4. 즉시 실행 취소 가능

전기 연결을 조용히 추측해 바꾸지 않는다.

## 즉시 계산

기본 직류 회로에는 복잡한 실행 설정을 요구하지 않는다. 회로가 바뀌면 결과를 갱신하고 상태를 짧게 표시한다.

- `계산 완료`
- `아직 닫힌 전류 경로가 없습니다.`
- `전위 기준점을 지정해야 합니다.`

## 3D 전위 높이 전환

- 현재 2D 회로가 사라지지 않고 기울어진 뒤 같은 x-y 위치가 전위에 따라 올라가거나 내려간다.
- 기본 카메라는 직교 투영을 사용한다.
- 정면, 사선, 위에서, 보기 초기화 버튼을 제공한다.
- 높이 과장값을 `전위 높이 4배 강조`처럼 표시한다.
- 움직임 감소 설정에서는 애니메이션 없이 최종 상태로 전환한다.
- 3D 사용이 어려운 기기에는 2D 경로 전위 그래프를 제공한다.

## 오류 피드백

모든 오류는 다음 순서로 설명한다.

1. 현재 어떤 상태인지
2. 물리적으로 왜 문제가 되는지
3. 사용자가 무엇을 고칠 수 있는지

예:

> 전원의 두 단자가 도선으로 직접 연결되어 있습니다. 이상적인 도선의 저항은 0 Ω이므로 이 모델에서는 전류를 유한한 값으로 계산할 수 없습니다. 직접 연결된 도선을 제거하거나 저항을 추가하세요.

문제 요소를 강조하고 가능한 경우 `연결되지 않은 단자 보기`, `직전 상태로 되돌리기` 같은 행동을 함께 제공한다.

## 접근성

- 보이는 단자가 작아도 실제 터치 영역은 약 40 px 이상으로 둔다.
- 모든 아이콘에는 텍스트 이름 또는 툴팁을 제공한다.
- 색만으로 상태를 전달하지 않는다.
- 200% 확대에서도 주요 기능과 텍스트가 잘리지 않아야 한다.
- 키보드 초점은 현재 부품·단자·도구에서 명확히 보여야 한다.


## 측정 작업 공간 (MEA-001~004)

측정 모드는 편집과 분리한다. 부품 라이브러리·배선/편집 도구·속성 편집을 표시하지 않고 상단에 전압/전류/등가저항 도구, 탐침 또는 가지 선택, 측정값과 기록 동작을 배치한다. 회로는 중앙, 기록·보존 법칙·값 변화 실험은 보조 패널에 둔다. 모바일은 같은 도구 순서를 유지하고 기록 패널을 회로 아래로 배치한다.

긴 시작 안내 대신 선택 중/미연결/연결됨 상태, +/- 기호, 선택 테두리로 탐침 상태를 구분한다. 단자 또는 도선을 누르면 활성 탐침을 연결한다. 전류 모드에서는 부품을 눌러 측정 가지를 바꾼다. 회로 편집 버튼으로 돌아가야 구조·값·위치를 바꿀 수 있다. 모드 전환 시 측정 기록과 탐침 선택을 유지한다.

## 회로 위 이름·값 편집

값을 클릭하거나 선택 부품의 이름·값 편집을 열면 두 입력을 함께 수정한다. 이름 옆에 표기 미리보기를 표시한다. `R_1`은 숫자 아래첨자, `R_{eq}`는 묶은 아래첨자로 표시된다. Enter·적용으로 함께 저장하고 Escape·취소로 초안을 버린다. 실행 취소도 두 변경을 함께 복원한다. 스위치의 기존 클릭 전환을 유지하며 이름 변경은 선택 도구의 편집 버튼에서 연다.
