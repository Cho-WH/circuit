# 기능 완료의 정의

요청한 동작이 구현되고, 변경의 영향과 위험에 맞는 검증으로 결과를 확인하면 완료한다. 구현은 관련 요구사항·물리 규칙·모듈 계약을 따르고, 변경된 계약은 문서와 함께 갱신한다.

## 변경에 맞는 검증

- 계산·연결·저장 변경은 관련 fixture, 물리 불변식과 이전 데이터 호환성을 중심으로 확인한다.
- 편집·화면·출력 변경은 영향을 받는 사용자 동작과 표현을 확인한다. 실행 취소, 입력 방식, 접근성 등도 변경과 관련된 부분을 살핀다.
- 문서 변경은 내용과 참조의 일치 여부를 확인한다.

기존 테스트와 사용자 확인 결과를 우선 활용하고, 새로운 동작과 버그 재발 방지에 필요한 검증을 추가한다. 검증 범위는 사용자의 지시를 우선하며, 충분한 근거가 확보되면 작업을 마무리한다.

## 결과 기록

수행한 검증과 중요한 미확인 사항을 간결하게 기록한다. 코드 검사, 브라우저 확인, 실기기·사용자 검증, 공개 배포는 각각 확인한 범위를 명확히 표현한다. 주요 변경과 검증 근거는 [작업 기록](mvp-tracker.md)에 남긴다.
