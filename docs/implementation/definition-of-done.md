# 기능 완료의 정의

기능은 다음 조건을 모두 만족해야 완료된다.

## 요구사항

- 연결된 요구사항 ID가 있다.
- 모든 수용 기준이 관찰 가능한 문장으로 정의되어 있다.
- 적용되는 물리 규칙과 fixture가 연결되어 있다.

## 코드

- 모듈 책임과 의존 방향을 지킨다.
- 공개 타입과 오류 처리가 포함된다.
- 핵심 계산은 결정론적이다.
- 새 추상화는 실제 경계와 교체 이유가 있다.

## 테스트

- 단위 또는 모듈 통합 테스트가 있다.
- 대표 정상 조건과 실패 조건을 모두 포함한다.
- 계산 변경은 관련 fixture와 물리 불변식 테스트를 통과한다.
- 편집 변경은 실행 취소·다시 실행을 검증한다.
- 출력 변경은 SVG·PNG 시각 회귀를 검증한다.

## 사용자 경험

- 학생·교사가 이해할 수 있는 한국어 문구가 있다.
- 마우스와 터치의 결과가 일관된다.
- 키보드 경로가 있다.
- 색상만으로 의미를 전달하지 않는다.
- 움직임 감소 설정을 고려한다.

## 데이터와 문서

- 저장 형식이 바뀌면 버전과 마이그레이션을 제공한다.
- 공개 인터페이스나 구조 결정이 바뀌면 ADR을 갱신한다.
- 요구사항, 스키마, fixture, 코드가 같은 의미를 가진다.

## 데모

- 실제 사용자 흐름에서 작동하는 예제가 있다.
- 오류가 발생해도 앱이 멈추지 않고 상태와 수정 행동을 설명한다.
