## 후속 범위와 미검증

단계 6~7의 공유·활동 배포·교실 알파는 이번 1차 범위 밖이다. 실제 교사·학생 사용성, 교사의 2분 제작 목표, 실제 프린터·워드프로세서 붙여넣기는 수행하지 않았다. 파일 선택기와 다운로드 파일 재열기의 도구 제한은 검증 범위 문서에 따로 남겼다. 원격 배포·push·PR은 수행하지 않았다.
