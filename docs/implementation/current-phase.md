# 현재 작업 현황

기준일: 2026-10-05. 앱 `0.1.0`, 현재 저장 형식 `edu-circuit` v6·측정 기록 v5, 브랜치 `codex/mvp`. 이전 형식은 변환 없이 거부한다.

**단계 0~5 기능 MVP, 후속 개선과 다이오드 확장 D0~D4를 구현했다. 단계 6 활동·공유와 단계 7 교실 알파는 미완료다.** 범위와 종료 조건은 [단계 계획](phases.md), 미반영 후보·실기기 과제는 [남은 작업](follow-up.md)을 따른다.

## 다이오드 확장 구현 (2026-10-05, D0~D4)

사용자와 합의한 [다이오드 기획](diode-mvp.md)과 [ADR-026](../../decisions/ADR-026-diode-boundary-analysis.md)을 구현했다. 정확한 0.7 V 해석과 구간선형 부품 모델, 비유일한 해의 전압차·전류 합 질의, 교육용 프로필, 만들기 사전 경고와 분석 과부하·파손을 기존 편집·측정·출력 경로에 연결했다. 예제 메뉴의 다이오드 순방향 회로로 시작할 수 있다.

만들기는 현재값의 노랑/빨강 느낌표만 제공하고, 분석 진입·가변저항 임계 통과에서 연출한다. 자동 왕복은 첫 위험에서 멈추고 빨강 이후에는 값 변경·현재 측정·새 기록을 잠근다. 회로 수정으로 돌아오면 원본과 마지막 확정값을 보존한다. 내장 프로필은 고정된 교육용 가정이며 실물 정격이 아니다. 열 축적·냉각·실제 파손 시간·파손 후 연쇄 고장은 계산하지 않는다.

현재 변경은 로컬 구현이며 아직 푸시·배포하지 않았다. 코드·대표 브라우저 화면의 검증 근거는 [작업 추적](mvp-tracker.md)과 [수용 사례](../testing/diode-cases.md)에 기록한다. 실제 교실·실기기·보조기술 검증은 미완료이며 단계 6~7과 구별한다.

## 현재 구현

### 정확 직류 연산 (2026-10-02)

SIM-008 / [ADR-024](../../decisions/ADR-024-exact-dc-arithmetic.md)에 따라 입력·저장·MNA·도선 KCL·측정·기록의 정확 유리수 연산을 구현했다. 브리지 균형점의 중앙 저항·양쪽 도선 전류는 정확히 0이며 실제 작은 전류는 보존한다. 당시 회로 v5·측정 기록 v4를 사용하고 이전 형식 호환을 제거했다. 2026-10-02의 [비용 검증](../testing/exact-dc-performance.md)에서 전체 746개 테스트와 반복 갱신을 통과했고, 데스크톱의 일반 예제 2D·3D 자동 조절은 원활했다. 이 수치와 형식은 당시 실적이며 현재 저장 계약은 위의 v6·v5다.

**계산 과부하 방지 구현:** ADR-025와 계산 명세 §7의 4,096비트·GCD 내부 반복 1,000,000회 예산을 적용했다. 선형 해석은 초과 시 공통 MNA를 스케일 조정·부분 피벗 LU·최대 2회 보정·신뢰도 검사로 근사 해석한다. 당시 기록 v4에 추가한 ≈와 오차 전달은 현재 기록 v5·2D·3D에서도 유지하며 방향 불확실 전류의 띠·점열·화살표를 생략한다. 다이오드 상태·부등식 탐색도 요청 예산 안에서 처리하고 완료하지 못하면 미확인으로 반환한다. 불안정하거나 유효성 검사를 완료하지 못한 입력을 정상·파손으로 확정하지 않는다. 비용 및 검증 결과는 [최신 보고서](../testing/exact-dc-performance.md)를 따른다.

노드 수명과 삽입은 ADR-018을 따른다. 도선 삭제로 영향받은 노드만 정리하며 노드 클릭 즉시 배선 시작, 중간 접점의 경로 병합 후 삽입, 짧은 배치 실패 효과를 지원한다.

## 커밋과 배포 확인 기준

- 이번 다이오드 구현은 푸시·배포하지 않은 로컬 변경이다.

- 게시 주소는 [공개 앱](https://cho-wh.github.io/circuit/)이며, `codex/mvp` 푸시로 배포한다. 최신 게시 커밋과 성공 여부는 [Pages 실행 기록](https://github.com/Cho-WH/circuit/actions/workflows/deploy-pages.yml)에서 확인한다. 로컬 작업 트리와 공개 사이트의 반영 상태는 구분한다.
- 2026-09-30 게시 대상에는 분석 화면·측정표 통합, 3D 전압 탐침, 자동 높이·회전축 수정, L자 전압 눈금과 드래그 중 수평 스냅이 포함된다. 놓은 시점은 유지한다.
- 검증 근거는 [검증 범위](../testing/mvp-coverage.md), 최근 변경 기록은 [작업 추적](mvp-tracker.md)에 모은다. 실제 교사·학생·모바일·보조기술 검증을 코드 완료와 구분한다.

숫자 입력·표시는 ADR-019의 quantity 공통 모듈을 사용한다. p·n 입력, 정확한 분수/접두어 변환, 자동 단위·4자리 지수·원시 숫자 선택, 그래프/표의 같은 축 단위와 실제 부품 이름 표시를 지원한다. 표시 선택은 상세 설정에서 부품별 속성으로 저장하며 전체 적용을 지원한다.
