## 현재 구현

### 채택된 계산 개선 명세 — 구현 대기 (2026-10-02)

SIM-008 / [ADR-024](../../decisions/ADR-024-exact-dc-arithmetic.md)로 입력·저장·MNA·도선 KCL·측정·기록의 정확 유리수 연산을 채택했다. [상세 명세](../physics/exact-dc-arithmetic.md)는 확정했으며 현재 엔진은 여전히 number 기반, 저장 형식은 v4다. 브리지 균형점의 잔여 전류는 아직 코드에서 해결되지 않았다. 공개 타입·저장 이행과 정확성 검증은 구현 때 진행하고, 연산 비용·자동 조절 부하 검증은 사용자 요청에 따라 후속으로 남긴다.

노드 수명과 삽입은 ADR-018을 따른다. 도선 삭제로 영향받은 노드만 정리하며 노드 클릭 즉시 배선 시작, 중간 접점의 경로 병합 후 삽입, 짧은 배치 실패 효과를 지원한다.

| 영역 | 지원 범위 |
|---|---|
| 회로·계산 | 이상적인 선형 직류 MNA, 명시적 단자·도선 ID, 구조화 진단, 명령·실행 취소 |
| 부품·편집 | 직류 전원·저항·가변저항·스위치·전류계·전압계, 회로 위 이름·값 편집, 분수·아래첨자, 문맥 배선·직렬 삽입·교차 연결/분리, 경유점 배선·선분 이동·부품 이동 시 경로 국소 보존(ADR-016), 부품 삭제 시 도선 연결 유지(ADR-017) |
| 전위 | 2D 숫자·색·등전위, 3D 기준면·자동 높이 축척·상대 배율·전압차·경로 그래프. 실제 표시 영역으로 진입/보기 초기화 시 높이를 맞춤. 후면·왼쪽 L자 전압 눈금과 세부 보조선, 드래그 중 수평 스냅. 세 색상표 중 기본은 전체 스펙트럼 |
| 전류 | 전위색을 유지한 2D·3D 공통 비례 띠·전류별 등간격 무늬, 자동 축척·두께 배율·화면 안 일시 정지. 직렬 경계 연속 이동·분기/합류 페이드·시점 이동 안정화, 3D 바닥 도선 유지, 상세 설정의 수치·상태 확인(ADR-020) |
| 분석 | 전위·측정을 분석하기에 통합. 왼쪽 선택형 측정 도구, 독립적인 보기 설정, 하나씩 여는 기록·경로 패널, 측정 중 부품 값 수정. 전지 분리 버튼으로 등가저항 시작·표시 복원. 탐침 배치는 2D, 전압은 3D에서도 위치·값·교환·기록 유지 및 높이 차 표시 (ADR-021, ADR-006) |
| 가변저항 | 만들기에서 양수 범위 설정, 분석 좌측의 슬라이더·수치 입력·자동 왕복. 고정 축척과 시점에서 실시간 계산·측정·기록, 연속 조작 실행 취소 (ADR-023) |
| 측정표 | 하단 조건별 측정표, 위치·방향·값·메모, 행별 삭제, 당시 회로 보기, 표 복사·CSV, 별도 로컬 저장·복원. 별도 값 변화 실험 패널은 유보 (ADR-022) |
| 출력 | 공통 SVG·PNG·미리보기·그림 복사, 실제 부품 이름 수정·실제 값 읽기 전용·표시·빈칸·독립 위치·배율, 분수·수학 글꼴, 직선/직각 화살표 편집, 접지·투명 배경·해상도 설정 |
| 터치 | 길게 눌러 배치·이동, 도선 삽입 확인, 밀집 후보 선택, 탭 이동·출력 방향 버튼, 다중 터치 취소, 입력 초안·시야 보존. 실기기 수용 검증은 남음 |
| 저장 | 브라우저 자동 저장·보관과 JSON 파일 분리, v1~v3 순차 마이그레이션. UI·계산 상태는 CircuitDocument 밖에서 관리 |
| 후기 | Firebase 익명 작성·본인 수정/삭제·공개/비공개, Google 관리자 보관함. [운영 설정](firebase-setup.md) |

조작은 [빠른 시작](../ux/quick-start.md)과 [상호작용](../ux/interactions.md), 기술 결정은 [ADR 색인](../../decisions/README.md)을 따른다. 3D 전환·카메라·라벨 수명은 ADR-006, 저장 형식과 출력 계약은 ADR-012가 기준이다.

## 커밋과 배포 확인 기준

- 게시 주소는 [공개 앱](https://cho-wh.github.io/circuit/)이며, `codex/mvp` 푸시로 배포한다. 최신 게시 커밋과 성공 여부는 [Pages 실행 기록](https://github.com/Cho-WH/circuit/actions/workflows/deploy-pages.yml)에서 확인한다. 로컬 작업 트리와 공개 사이트의 반영 상태는 구분한다.
- 2026-09-30 게시 대상에는 분석 화면·측정표 통합, 3D 전압 탐침, 자동 높이·회전축 수정, L자 전압 눈금과 드래그 중 수평 스냅이 포함된다. 놓은 시점은 유지한다.
- 검증 근거는 [검증 범위](../testing/mvp-coverage.md), 최근 변경 기록은 [작업 추적](mvp-tracker.md)에 모은다. 실제 교사·학생·모바일·보조기술 검증을 코드 완료와 구분한다.

숫자 입력·표시는 ADR-019의 quantity 공통 모듈을 사용한다. p·n 입력, 정확한 분수/접두어 변환, 자동 단위·4자리 지수·원시 숫자 선택, 그래프/표의 같은 축 단위와 실제 부품 이름 표시를 지원한다. 표시 선택은 상세 설정에서 부품별 속성으로 저장하며 전체 적용을 지원한다.
