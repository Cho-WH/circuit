# 현재 작업 현황

기준일: 2026-09-23. 앱 `0.1.0`, 저장 형식 `edu-circuit` v2, 브랜치 `codex/mvp`.

**단계 0~5 기능 MVP와 아래 후속 개선을 구현·검증했다.** 회로도 출력 편집, 저장 v2 호환 변환, 분수·아래첨자, 수학 글꼴과 글자 배치, 이름·값 동시 편집, 가변저항 표기를 로컬 커밋으로 정리했다. 이후 사용자 요청으로 Firebase 게시판을 연결했으며 기존 개선까지 함께 GitHub Pages에 배포하도록 승인받았다.

## 구현된 범위

| 영역 | 현재 상태 |
|---|---|
| 이름 편집 | 회로 위 이름·값 동시 편집, R_1·R_{eq} 아래첨자, 예제 이름 첨자 표기 |
| 수치 입력 | 명시적 분수 입력·저장·재편집, 공통 화면·SVG·PNG 분수 표시, 계산 결과는 소수 유지 |
| 부품 | 직류 전원·저항·가변저항·스위치·전류계·전압계. 가변저항은 일반 저항과 같은 계산 모델 |
| 회로·계산 | 명시적 ID 연결, 이상적인 선형 직류 MNA, 구조화 진단, 편집 명령·실행 취소, JSON·자동 저장 |
| 전위 | 2D 숫자·색·등전위, 3D 기준면·높이·부호 있는 전압 차이, 경로 그래프 |
| 측정 | 탐침, 임시 직렬 전류계, 등가저항, KCL·KVL, 모드 간 유지되는 기록·CSV, 값 변화 실험 |
| 문제·출력 | 이름·값 편집/표시/사각 빈칸, 독립 드래그, 글자 배율, 자유 점·화살표·글자, 공통 SVG·PNG·미리보기·그림 복사, 기본 접지 숨김·접지 기호 토글, 투명 배경·고해상도 토글, Libertinus Math 기호·수치 |
| 표기 배치 | 기본 글자 1.5배, 가로 부품의 좁은 상하 간격, 분수 높이를 반영한 공통 이름·값 배치 |
| 화면 개선 | 회로 공간 확대, 접히는 보조 패널, 회로 위 값 편집, 공통 기호 미리보기, 출력 작업 상단 배치 |
| 선택·배선 | 사각 선택 테두리 제거, 여유 있는 판정 영역, 상승·확대 강조, 단자에서 시작하는 문맥 배선, 분기선 힌트, 교차점 직접 토글 |
| 터치 | 후보 확인·취소 아이콘, 겹친 단자의 아이콘 선택, 화면 이동·핀치, 취소 후 잘못된 클릭 억제 |
| 후기 게시판 | 서울 Standard DB·규칙·인덱스 배포 및 운영 비공개 작성/수정/삭제 검증 완료. Google 관리자 등록·보관함 접근 확인 완료 |

일반 배선 호버·클릭의 텍스트 버블과 하단 안내는 제거했다. 선택 도선에는 원과 마우스 방향의 희미한 가지를 표시한다. 교차점에는 현재 상태 `연결`/`비연결`만 표시하며 교차점 자체를 눌러 전환한다. 자세한 조작은 [상호작용](../ux/interactions.md), 연결 변경의 지원 경계는 [ADR-013](../../decisions/ADR-013-wire-editing-ux.md)을 따른다.

## 검증과 남은 범위

검증은 변경별로 실행했다. [작업 추적](mvp-tracker.md)에 실행 범위·실패 수정·브라우저 관찰을, [검증 범위](../testing/mvp-coverage.md)에 초기 MVP의 요구사항별 근거와 남은 한계를 기록한다. 과거 테스트 수를 현재 전체 스위트의 통과 수로 해석하지 않는다.

- 실제 교사·학생 사용성, 2분 제작 목표, 실제 모바일 터치·프린터·외부 문서 붙여넣기와 전체 보조기술 검증은 남아 있다.
- 후기 게시판은 Analytics 없는 Firebase Spark 단일 프로젝트를 사용한다. 서울 Standard DB와 보안 규칙·인덱스를 배포하고 실제 비공개 작성·수정·삭제를 검증했다. 관리자 Google 계정 등록과 브라우저 보관함 접근을 확인했다. 사용자 승인에 따라 이전 로컬 개선까지 GitHub Pages에 배포했고 CI 전체 성공 및 공개 게시판 로딩을 확인했다. [설정 기록](firebase-setup.md), [게시판 구조](../architecture/feedback.md)를 참조한다.
- 단계 6의 공유·활동 배포와 단계 7의 교실 알파는 미완료다. 기존 활동 정책 계약이나 정적 사이트 게시를 이 단계의 완료로 보지 않는다.

시작과 사용법은 [빠른 시작](../ux/quick-start.md), 전체 문서 탐색은 [문서 색인](../index.md)을 참조한다.
