# 현재 작업 현황

기준일: 2026-09-24. 앱 `0.1.0`, 저장 형식 `edu-circuit` v4, 브랜치 `codex/mvp`.

**단계 0~5 기능 MVP와 후속 개선을 구현했다. 단계 6 활동·공유와 단계 7 교실 알파는 미완료다.** 범위와 종료 조건은 [단계 계획](phases.md), 미반영 후보·실기기 과제는 [남은 작업](follow-up.md)을 따른다.

## 현재 구현

노드 수명과 삽입은 ADR-018을 따른다. 도선 삭제로 영향받은 노드만 정리하며 노드 클릭 즉시 배선 시작, 중간 접점의 경로 병합 후 삽입, 짧은 배치 실패 효과를 지원한다.

| 영역 | 지원 범위 |
|---|---|
| 회로·계산 | 이상적인 선형 직류 MNA, 명시적 단자·도선 ID, 구조화 진단, 명령·실행 취소 |
| 부품·편집 | 직류 전원·저항·가변저항·스위치·전류계·전압계, 회로 위 이름·값 편집, 분수·아래첨자, 문맥 배선·직렬 삽입·교차 연결/분리, 경유점 배선·선분 이동·부품 이동 시 경로 국소 보존(ADR-016), 부품 삭제 시 도선 연결 유지(ADR-017) |
| 전위 | 2D 숫자·색·등전위, 3D 기준면·높이·전압차·경로 그래프. 세 색상표 중 선택하며 기본은 전체 스펙트럼; 선택 메뉴는 색상바·체크만 표시 |
| 측정 | 두 탐침·비접촉 전류 센서·등가저항·KCL/KVL·기록 CSV·값 변화 실험. 저항 모드에서는 모든 직류 전원을 개방 |
| 출력 | 공통 SVG·PNG·미리보기·그림 복사, 이름/값 표시·빈칸·독립 위치·배율, 분수·수학 글꼴, 직선/직각 화살표 편집, 접지·투명 배경·해상도 설정 |
| 터치 | 길게 눌러 배치·이동, 도선 삽입 확인, 밀집 후보 선택, 탭 이동·출력 방향 버튼, 다중 터치 취소, 입력 초안·시야 보존. 실기기 수용 검증은 남음 |
| 저장 | 브라우저 자동 저장·보관과 JSON 파일 분리, v1~v3 순차 마이그레이션. UI·계산 상태는 CircuitDocument 밖에서 관리 |
| 후기 | Firebase 익명 작성·본인 수정/삭제·공개/비공개, Google 관리자 보관함. [운영 설정](firebase-setup.md) |

조작은 [빠른 시작](../ux/quick-start.md)과 [상호작용](../ux/interactions.md), 기술 결정은 [ADR 색인](../../decisions/README.md)을 따른다. 3D 전환·카메라·라벨 수명은 ADR-006, 저장 형식과 출력 계약은 ADR-012가 기준이다.

## 커밋과 배포 확인 기준

- 팔레트 선택 커밋 [`ab1f54a`](https://github.com/Cho-WH/circuit/commit/ab1f54a)는 `origin/codex/mvp`에 푸시했다. 해당 커밋의 Actions·공개 배포 성공은 이 문서에서 확인하지 않았다.
- 마지막으로 확인해 기록한 공개 배포는 [`a26c193`](https://github.com/Cho-WH/circuit/commit/a26c1934774c587e5e7052933bf338b3bca945c3)이다. [Pages 실행](https://github.com/Cho-WH/circuit/actions/runs/35967493539)과 별도 [코드 검증](https://github.com/Cho-WH/circuit/actions/runs/35967493654)이 성공했다. 이는 현재 서버 상태를 재조회한 결과가 아니다.
- 검증 근거는 [검증 범위](../testing/mvp-coverage.md), 최근 변경 기록은 [작업 추적](mvp-tracker.md)에 모은다. 실제 교사·학생·모바일·보조기술 검증을 코드 완료와 구분한다.
