# 현재 작업 현황

기준일: 2026-09-24. 앱 `0.1.0`, 저장 형식 `edu-circuit` v4, 브랜치 `codex/mvp`.

**단계 0~5 기능 MVP와 후속 개선을 구현했다.** 현재 문서는 v4로 저장하며 v1~v3 파일을 순차 변환해 연다. 회로도 출력의 직선·직각 화살표는 끝점 드래그, 회전·반전, 기호·값의 독립 편집과 위치 조절을 지원한다. Firebase 후기 게시판은 운영 서비스에 연결했다. 2026-09-23 기준 최신 작업 커밋 `ad5ad76`은 `origin/codex/mvp`에 반영되었다. 앞선 공개 배포 검증은 [Firebase 설정 기록](firebase-setup.md)에 있으며, 최신 푸시의 Pages 결과는 별도로 확인하지 않았다.

## 검증과 남은 범위

검증은 변경별로 실행했다. [작업 추적](mvp-tracker.md)에 실행 범위·실패 수정·브라우저 관찰을, [검증 범위](../testing/mvp-coverage.md)에 초기 MVP의 요구사항별 근거와 남은 한계를 기록한다. 과거 테스트 수를 현재 전체 스위트의 통과 수로 해석하지 않는다.

- 실제 교사·학생 사용성, 2분 제작 목표, 실제 모바일 터치·프린터·외부 문서 붙여넣기와 전체 보조기술 검증은 남아 있다.
- 후기 게시판은 Analytics 없는 Firebase Spark 단일 프로젝트를 사용한다. 서울 Standard DB와 보안 규칙·인덱스를 배포하고 실제 비공개 작성·수정·삭제를 검증했다. 관리자 Google 계정 등록과 브라우저 보관함 접근을 확인했다. Firebase 연결 시점에는 GitHub Pages CI 성공과 공개 게시판 로딩을 확인했다. [설정 기록](firebase-setup.md), [게시판 구조](../architecture/feedback.md)를 참조한다.
- 단계 6의 공유·활동 배포와 단계 7의 교실 알파는 미완료다. 기존 활동 정책 계약이나 정적 사이트 게시를 이 단계의 완료로 보지 않는다.

시작과 사용법은 [빠른 시작](../ux/quick-start.md), 전체 문서 탐색은 [문서 색인](../index.md)을 참조한다.

## 프론트엔드 디자인 적용

2026-09-24 [디자인 검토·개선 제안](../ux/2026-09-24-frontend-design-review.md)의 공통 화면·문구·파일 메뉴·측정/출력 패널·3D 준비와 전환을 구현했다. 따뜻한 중성색과 올리브 강조, 평평한 도구 위계, 세 줄 헤더를 적용했고 1536×695에서 기본 회로 영역의 상단을 234px에서 140px로 줄였다. 모바일은 390×844 브라우저에서 확인했다.

3D는 2D를 유지한 채 글꼴·바닥·첫 렌더를 준비한다. 첫 진입 1100ms, 재진입 900ms, 시점 전환 700ms를 사용하고 입력·모드 전환으로 중단할 수 있다. 출력 복사는 버튼 내부에서 완료를 표시한다. 회로 파일 저장과 브라우저 보관을 분리했으며 보관본 불러오기는 실행 취소할 수 있다. 저장 형식·계산 규칙은 바뀌지 않았다.

관련 8개 테스트 파일의 65개 검사, 타입·모듈 경계·배포 빌드를 통과했다. 실제 휴대전화 터치·전체 보조기술·200% 브라우저 확대·FPS 측정은 별도 미검증 범위다.

## 측정 도구와 문구 개선

전압·등가저항은 짧은 탐침봉 두 개, 전류는 회로를 변형하지 않는 비접촉 센서로 측정한다. 클릭·탭으로 놓고 드래그로 옮기며 키보드 대상 선택을 지원한다. 상단의 위치 목록과 삽입 비교를 직접 조작으로 대체하고, 기록·값 바꿔 보기·전류 및 전압의 합 확인 문구를 정리했다. 요구사항 MEA-002와 [ADR-015](../../decisions/ADR-015-non-contact-measurement.md), 등가저항의 ADR-011을 함께 반영했다. 저장 형식은 유지한다.

관련 4개 파일의 107개 검사를 변경별로 통과했고 타입·모듈 경계·배포 빌드를 확인했다. 데스크톱 직렬·브리지, 390×844 화면, 탐침 부호 반전·센서 드래그·등가저항 범위·기록을 브라우저에서 확인했다. 실제 휴대전화의 터치 감각은 미검증이며 터치 이벤트는 자동 검사했다.

## 저항 측정의 전원 분리

저항 모드는 탐침 위치와 관계없이 모든 직류 전원을 개방한다. 전원 기호·표기를 흐리게 하고 양쪽 리드에 간격을 두며, 짧은 아이콘 툴팁은 실제 저항계의 작은 시험 신호를 설명한다. 전원 포함/제외 설정은 제공하지 않는다. SIM-005, ADR-011·015와 현재 안내 문서를 일치시켰다. 저항 모드 및 기존 측정 47개 테스트와 타입 검사를 통과했다. 저장 형식과 저수준 계산 API는 유지한다.

## 3D 높이 조절 라벨 안정화

높이 변경마다 라벨을 재생성하던 구조와 전역 버튼 위치 애니메이션의 충돌을 수정했다. 라벨을 ID별로 재사용하고 3D 투영 좌표를 즉시 적용하며 화면 해제 시 정리한다. 관련 3개 파일의 23개 검사와 타입 검사를 통과했고, 브라우저에서 높이 변경 직후 계산 위치와 실제 표시 위치의 일치 및 중복 라벨이 없음을 확인했다.

기존 실행 탭의 자동 갱신에서 이전 렌더 콜백과 라벨이 남는 경로도 보완했다. 개발 중 3D 코드 교체는 장면을 재생성하며, 문제가 있던 탭을 새로고침하지 않고 높이를 왕복 조절해 중복 라벨이 사라지는 것을 확인했다.
