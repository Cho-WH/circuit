# 남은 작업과 검증

기준일: 2026-10-05. 완료된 UX 검토 문서의 미완료 항목과 이후 확정된 설계를 구별한다. 유보 후보는 구현 약속이나 착수 승인이 아니며, 기존 단계·종료 조건은 [단계 계획](phases.md)을 따른다.

## 다이오드 확장 구현과 남은 검증

[다이오드 확장 D0~D4](diode-mvp.md)와 [ADR-026](../../decisions/ADR-026-diode-boundary-analysis.md)을 구현했다. 정확한 0.7 V 해석, 직결·병렬 회로의 구간선형 부품 모델, 고정된 교육용 프로필, 노랑/빨강 경계와 분석 세션 UX를 포함한다. 현재 저장은 회로 v6·측정 기록 v5이며 이전 형식은 변환 없이 거부한다.

만들기는 현재값의 사전 경고만, 분석 진입·가변저항 임계 통과는 과부하/파손 사건으로 처리한다. 프로필은 실물 정격이 아니며 열 축적·냉각·실제 파손 시간·파손 후 연쇄 고장은 제외한다. 이번 구현은 푸시·배포 전이다. 교실에서의 원인 이해, 실제 기기·프로젝터·보조기술 검증은 아래의 미완료 과제로 남긴다.

## 계획된 후속 단계

### 정확 직류 연산의 부하 대응 (2026-10-02)

- SIM-008 / [ADR-024](../../decisions/ADR-024-exact-dc-arithmetic.md)의 정확값 경로와 당시 회로 v5·측정 기록 v4를 구현했다. 아래 비용 수치는 2026-10-02의 실적이며, 현재 형식은 다이오드 확장의 v6·v5다. 이전 형식 지원은 사용자 지시로 제외했다.
- [첫 비용 검증 완료](../testing/exact-dc-performance.md): 일반 예제 pipeline은 p95 1ms 미만, 브리지 2D·3D 자동 조절은 약 60 Hz를 유지했다. 30,030회 갱신에서 누적 힙 증가 경향은 관찰되지 않았다.
- **계산 과부하 방지 구현 완료**: ADR-025의 요청별 정확 계산 예산, 스케일링·부분 피벗 LU·오차/민감도 검사와 근사 품질 전달을 당시 기록 v4에 구현했고 현재 기록 v5에서도 유지한다. 구체적인 선형 근사 정책은 계산 명세 §7.6을 따른다. 다이오드 탐색은 후보·부등식·행렬 할당량도 제한하며 미완료 탐색을 미확인으로 반환한다.
- 큰 분모·큰 저항비 사례의 수 초 계산은 예산 중단 후 근사 수용 또는 구조화 실패로 끝낸다. 계산·검증·표시 모델 준비까지 포함한 비용을 최신 보고서에 기록했다. 실행 분리·취소, 대형 행렬 할당 제한과 추가 소거 최적화는 별도 후보다.
- 저사양 교실 기기·모바일, 초기 3D 준비, 장시간 브라우저 메모리와 여러 조절기 동시 실행은 별도 확인한다. 단일 데스크톱 측정으로 제품 입력 한도를 확정하지 않는다.

| 범위 | 남은 내용 | 기준 |
|---|---|---|
| 단계 6 활동·공유 | 활동 제작·배포 UI, 예측 질문·단계별 공개·초기화, URL 또는 공유 코드. 기존 명령 권한 검사를 모든 입력 경로에서 보장하고 교사 원본과 학생 작업본을 분리 | [단계 6](phases.md#단계-6--활동과-공유), [ADR-005](../../decisions/ADR-005-share-link.md). 로그인 없는 시작·원본 보존이 종료 조건 |
| 단계 7 교실 알파 | 실제 사용자 과제, 태블릿·크롬북·스마트폰 보정, 접근성·복구·저장 검증·오류 보고, 공개 예제·짧은 도움말 보강 | [단계 계획](phases.md), [사용성 검증](../testing/usability.md) |

## 유보한 개선 후보

| 후보 | 다음에 결정·확인할 내용 |
|---|---|
| 터치 복수 선택 (EDT-005) | 키보드 없이 선택 집합을 만드는 명시적 모드와 그룹 이동·정렬 |
| 정밀 조작 | 손가락 위 보조 미리보기·접점 확대경, 가장자리 자동 화면 이동. 실제 도착점 표시를 유지하고 손가락 가림·밀집 후보 배치를 실기기에서 평가 |
| 진동 | 지원 환경에서 집기·확정의 선택적 보조 피드백. 시각 피드백을 대체하지 않음 |
| 모션 마무리 | 모든 표면의 종료 애니메이션, 모드 밑줄의 연속 위치 보간. 필수 구현 계획에는 미포함 |
| 배선 확장 | 이미 연결된 부품의 도선 재삽입, 공간 부족 시 주변 배선 조정, T자·겹침·다중 교차의 연결 쌍 지정은 별도 정책이 필요. 현재 지원 경계는 [ADR-013](../../decisions/ADR-013-wire-editing-ux.md) 유지 |
| 성능 | FPS·첫 3D 준비 지연 측정, 큰 번들 청크의 비용 평가. 실제 측정 후 최적화 우선순위 결정 |
| 측정 학습 활동 | 별도 값 변화 실험·법칙 확인 UI는 제거. 가변저항 슬라이더·자동 왕복과 기존 측정표 연계는 ADR-023으로 구현. 학습 목적과 조작 흐름을 재설계한 뒤 별도 승인으로 구현. 기존 계산 API는 유지 (ADR-021, MEA-004 deferred) |
| 3D 측정 | 3D 직접 탐침 배치·선택과 2D 대응, 3D 재진입 시 카메라 자세 복원. 전압 탐침의 2D 위치를 3D에서 관찰·교환·기록하는 기능은 구현됨. 전류·등가저항 측정 조작은 2D (ADR-021) |
| 3D 내부 유지보수 | 선·튜브·점의 생성/재사용은 primitives로 분리됨(ADR-023). 라벨 배치의 추가 분리는 실제 변경 필요가 생기면 검토. 현재 동작과 생명주기 테스트를 유지하며 범용 렌더링 계층은 만들지 않음 |

3D 전환은 1100/900/700ms로 확정되어 이전 짧은 시간 제안은 미완료 항목이 아니다. 구현한 다이오드 외의 새 물리 소자·교류·LMS·AI 등 MVP 비목표를 이번 정리로 작업 목록에 올리지 않는다. [제품 범위](../product/scope.md)와 [확장 지점](../architecture/extension-points.md)은 유지한다.

## 아직 완료하지 않은 검증

- 실제 iOS Safari·Android Chrome·태블릿의 길게 누르기/스크롤/문맥 메뉴, 다중 터치·해제 순서·포인터 캡처·OS 취소·앱 복귀, OS 키보드·텍스트 선택·회전·초안·시야 보존. 450ms/10px 집기 기준과 목표 크기·간격은 손 떨림·오조작 관찰로 평가한다.
- 교사·학생 과제 성공률, 제작 시간, 전위·전위차·전류·3D 대응 이해. 설명 없는 터치 과제와 최소 지원 수용 검사는 [사용성 검증](../testing/usability.md)에 보존했다.
- 200% 브라우저 확대, 스크린리더 읽기 순서·선택/집기/놓기/취소 알림, 키보드 초점·모달 복귀, 대비·색각 사용자·프로젝터 가독성, 움직임 감소 흐름.
- 실제 프린터, 워드프로세서 그림 붙여넣기, OS 파일 선택을 통한 JSON 왕복, 내려받은 JSON/SVG/PNG/CSV 재열기와 내용 비교, 브라우저 클립보드 거부 시 대체 경로.
- 교실의 장시간 사용·복구·교육 효과. 자동 이벤트 검사나 작은 브라우저 창에서의 확인을 실기기·사람 대상 검증으로 기록하지 않는다.
