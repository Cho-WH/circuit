# 남은 작업과 검증

현재 구현은 [현재 현황](current-phase.md)에 정리한다. 아래 후보는 착수 승인이 아니며 [단계 계획](phases.md)의 종료 조건을 따른다.

## 미완료 단계

| 범위 | 남은 내용 |
|---|---|
| 단계 6 활동·공유 | 활동 제작·배포 UI, 예측 질문·단계별 공개·초기화, URL/공유 코드. 명령 권한 보장, 교사 원본과 학생 작업 분리. [ADR-005](../../decisions/ADR-005-share-link.md)는 proposed |
| 단계 7 교실 알파 | 교사·학생 과제 검증, 실제 태블릿·크롬북·스마트폰, 접근성·복구·오류 보고. [사용성 기준](../testing/usability.md) |

## 유보 후보

사용자에게 안내하는 장기 개발 방향은 학생과 함께 탐구하는 활동 모드와 소자 종류·특성·설정·표현의 확장이다. 구체적인 지원 범위와 일정은 아직 확정하지 않았다.

| 후보 | 결정하거나 확인할 내용 |
|---|---|
| 구버전 지원 확대 | 원본 보호·세 선택지·v5 복원은 ADR-039로 구현. v1~4 변환은 실제 파일과 수요를 확인한 뒤 별도 판단하며 범용 손상 복구는 구현하지 않음 |
| 소자·세부 특성 확장 | 수업에 필요한 소자 종류와 특성·설정·표현의 세분화. 대상 소자·물리 모델·우선순위는 별도 정의하며 현재 지원 범위를 바꾸지 않음 |
| 정밀 편집 | 접점 확대경·손가락 가림 보완·가장자리 자동 이동, 그룹 정렬. 영역 복수 선택·복사는 구현됨 |
| 배선 확장 | 이미 연결된 부품의 도선 재삽입, 공간 부족 시 경로 조정, 복잡한 교차 연결 쌍 지정 |
| 성능 | 큰 행렬 할당·동기 계산의 실행 분리/취소, 큰 번들·첫 3D 준비 비용. [측정 근거와 한계](../testing/exact-dc-performance.md). 원인 불명 FPS 증상으로 선제 최적화하지 않음 |
| 학습 활동 | 별도 값 변화 실험·법칙 확인 UI의 학습 목적 재설계. 기존 가변저항·측정표와 계산 API는 유지 |
| 3D 측정 | 직접 탐침 배치와 재진입 카메라 복원. 현재 전압 탐침의 관찰·교환·기록은 지원하고 배치 및 전류·등가저항 조작은 2D |
| 표현·유지보수 | 종료 모션·선택적 진동·라벨 배치 분리는 실제 필요를 확인한 뒤 판단. 범용 렌더링 계층은 만들지 않음 |

## 시험지 그림 편집의 후속 제안

2026-10-22 사용자의 제안 요청에 따라 정리했다. 이후 1번은 사용자가 단일 드래그의 본체 간격 스냅으로 구체화·승인하여 로컬 구현했다. 2~5번 순위는 기대 효용과 구현 범위를 고려한 제안이며 착수 승인이 아니다. 구현 시 대상과 UX를 확정하고 관련 요구사항·ADR·검사를 갱신한다.

이미 있는 가장자리·중앙·기준선 정렬, 같은 간격, Alt 해제, Shift 직선 이동은 기본 배치 도구로 충분하다. 다음 후보는 시험지 그림을 마무리할 때 반복하는 작업을 줄이는 데 초점을 둔다.

| 우선순위 | 제안과 사용 예 | 현재 기능과의 차이·첫 구현 경계 |
|---|---|---|
| 1 → 로컬 구현 | 부품 본체와 표기의 같은 간격 스냅 | 사용자 확정 범위는 단일 이름/값 드래그·같은 종류/회전/역할/방향이며, 연결선을 제외한 본체를 기준으로 한다. 두 쌍의 간격 점선을 표시한다. 일괄 상대 배치·도선/화살표 간격 복제는 포함하지 않았다. [UX](../ux/output-alignment.md#부품-본체와-표기-사이-같은-간격)·[설계](../architecture/output-alignment.md#본체-간격-후보) |
| 2 | 선택 표기의 일괄 빈칸·숨김·위치 초기화. 저항값 세 개를 한 번에 빈칸으로 바꾸기 | 현재 단일 표기에 이미 있는 설정을 복수 선택으로 확장한다. 선택한 이름/값 부분에만 적용하고 하나의 Undo로 복구한다. 혼합 상태·적용 불가 대상을 구분한다. 숨긴 표기는 캔버스에서 재선택할 수 없으므로 숨김 해제 경로를 함께 설계한다. 주석 본체까지 포함한 임의 일괄 속성 편집은 제외한다 |
| 3 | 출력 주석 복제. 맞춰 둔 전류 화살표를 복제해 다른 가지에 놓고 I₂로 수정하기 | 현재는 주석을 새로 추가해야 한다. 화살표 길이·방향·딸린 표기의 상대 위치를 복제하되 새 ID를 부여하고 내용은 사용자가 수정한다. 점·글자·화살표에 한정하며 부품 이름·값을 주석으로 복제하거나 전기 부품을 복제하지 않는다. 초기에는 단일 주석 복제 버튼부터 검토한다 |
| 4 | 내보내기 크기·여백 설정과 축소 가독성 확인. 시험지에 넣을 그림 폭을 정해 글자가 너무 작아지지 않는지 확인하기 | 현재 글자 배율·고해상도·투명 배경은 있지만 최종 삽입 폭 기준의 확인은 없다. SVG/PNG의 출력 크기·여백·글자 크기를 함께 보여 주는 방안을 검토한다. cm/mm와 PNG 픽셀의 변환 기준을 명시하고 문서 프로그램이 크기를 그대로 적용하는지는 별도 확인한다. A4 페이지·문항·배점 편집까지 확대하지 않는다 |
| 5 | 답안 빈칸 크기 선택. 짧은 수치와 식을 적는 빈칸을 구분하기 | 현재 빈칸 전환은 지원한다. 소/중/대 같은 제한된 폭부터 검토하며 글자 배율과의 관계·출력 잘림을 확인한다. 저장 속성 추가가 필요하면 스키마와 호환성을 먼저 정한다. 자유 변형 손잡이는 우선 도입하지 않는다 |

다음 후보는 2이며 화살표를 많이 쓰는 실제 시험지에서는 3을 먼저 선택할 수 있다. 도선과 화살표 간격 복제는 관련 수요가 확인되면 1의 후속으로 검토한다. 현재 요청은 1의 첫 버전까지이며 이 후보들로 자동 확장하지 않는다.

문제용/해설용 보기 저장은 활용 가능성이 있지만 어떤 표기를 정답으로 볼지와 보기별 배치 보존을 먼저 정해야 하므로 뒤로 둔다. 영구 그룹·레이어·전체 자동 충돌 회피·범용 페이지 편집도 현재 우선순위에서는 제외한다.

## 아직 완료하지 않은 검증

- 출력 정렬의 실제 태블릿·보조기술·외부 문서 붙여넣기 사용성. 자동 제스처 검사와 데스크톱 브라우저 확인은 [기획의 수용 시나리오](../ux/output-alignment.md#수용-시나리오)를 기준으로 수행한다.

- 실제 iOS Safari·Android Chrome의 길게 누르기·스크롤·다중 터치·해제 순서·포인터 취소·앱 복귀·OS 키보드·회전·초안/시야 보존과 오조작 관찰.
- 교사·학생의 과제 성공률·제작 시간, 전위/전압차/전류/3D 대응 및 작동 경계 이해.
- 200% 확대, 스크린리더·키보드 초점, 대비·색각·프로젝터 가독성·움직임 감소 흐름.
- 실제 인쇄·워드프로세서 붙여넣기, OS 파일 선택과 내려받은 JSON/SVG/PNG/CSV 재열기, 클립보드 거부 대체 경로.
- 저사양 기기·장시간 사용의 메모리·복구·응답성. 자동 이벤트 검사나 작은 브라우저 창 확인으로 실기기 검증을 대신하지 않는다.
