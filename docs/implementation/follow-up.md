# 남은 작업과 검증

현재 구현은 [현재 현황](current-phase.md)에 정리한다. 아래 후보는 착수 승인이 아니며 [단계 계획](phases.md)의 종료 조건을 따른다.

## 미완료 단계

| 범위 | 남은 내용 |
|---|---|
| 단계 6 활동·공유 | 활동 제작·배포 UI, 예측 질문·단계별 공개·초기화, URL/공유 코드. 명령 권한 보장, 교사 원본과 학생 작업 분리. [ADR-005](../../decisions/ADR-005-share-link.md)는 proposed |
| 단계 7 교실 알파 | 교사·학생 과제 검증, 실제 태블릿·크롬북·스마트폰, 접근성·복구·오류 보고. [사용성 기준](../testing/usability.md) |

## 유보 후보

사용자에게 안내하는 장기 개발 방향은 학생과 함께 탐구하는 활동 모드와 소자 종류·특성·설정·표현의 확장이다. 구체적인 지원 범위와 일정은 아직 확정하지 않았다.

| 후보 | 결정하거나 확인할 내용 |
|---|---|
| 저장 시스템 재정비 | 읽기 실패 시 원본 보존·자동 저장 재개 조건, 백업·복구 흐름과 구버전 지원을 함께 설계. 사용자 요청으로 이번 UX 개선에서는 유보 |
| 소자·세부 특성 확장 | 수업에 필요한 소자 종류와 특성·설정·표현의 세분화. 대상 소자·물리 모델·우선순위는 별도 정의하며 현재 지원 범위를 바꾸지 않음 |
| 정밀 편집 | 접점 확대경·손가락 가림 보완·가장자리 자동 이동, 그룹 정렬. 영역 복수 선택·복사는 구현됨 |
| 배선 확장 | 이미 연결된 부품의 도선 재삽입, 공간 부족 시 경로 조정, 복잡한 교차 연결 쌍 지정 |
| 성능 | 큰 행렬 할당·동기 계산의 실행 분리/취소, 큰 번들·첫 3D 준비 비용. [측정 근거와 한계](../testing/exact-dc-performance.md). 원인 불명 FPS 증상으로 선제 최적화하지 않음 |
| 학습 활동 | 별도 값 변화 실험·법칙 확인 UI의 학습 목적 재설계. 기존 가변저항·측정표와 계산 API는 유지 |
| 3D 측정 | 직접 탐침 배치와 재진입 카메라 복원. 현재 전압 탐침의 관찰·교환·기록은 지원하고 배치 및 전류·등가저항 조작은 2D |
| 표현·유지보수 | 종료 모션·선택적 진동·라벨 배치 분리는 실제 필요를 확인한 뒤 판단. 범용 렌더링 계층은 만들지 않음 |

## 아직 완료하지 않은 검증

- 실제 iOS Safari·Android Chrome의 길게 누르기·스크롤·다중 터치·해제 순서·포인터 취소·앱 복귀·OS 키보드·회전·초안/시야 보존과 오조작 관찰.
- 교사·학생의 과제 성공률·제작 시간, 전위/전압차/전류/3D 대응 및 작동 경계 이해.
- 200% 확대, 스크린리더·키보드 초점, 대비·색각·프로젝터 가독성·움직임 감소 흐름.
- 실제 인쇄·워드프로세서 붙여넣기, OS 파일 선택과 내려받은 JSON/SVG/PNG/CSV 재열기, 클립보드 거부 대체 경로.
- 저사양 기기·장시간 사용의 메모리·복구·응답성. 자동 이벤트 검사나 작은 브라우저 창 확인으로 실기기 검증을 대신하지 않는다.
