# 단계 4 구현 계약

관련 요구사항: SIM-004~005, MEA-001~004. 저장 문서는 v1을 유지한다.

## 책임

- 메인: `simulation`의 등가저항 및 KCL·KVL 계산, 계측 화면과 연결 상태 통합.
- 구현 Sol: `measurement`의 탐침 질의, 임시 직렬 전류계, 값 변화 실험, 기록과 CSV.
- 검증 Sol: fixture·불변식·실패 조건 및 실제 계측 흐름 검증. 구현자는 검사를 실행하지 않는다.

## 핵심 계약

- 전압 질의는 빨강−검정이며, 미연결·미정 전위는 숫자를 반환하지 않는다.
- 전류계는 선택한 부품의 첫 전기 단자에 직렬 삽입한다. 원본은 보존하고 임시 문서와 계기 ID를 반환한다. 화면에서 원본/삽입 후 연결을 전환한다.
- 등가저항은 컴파일된 두 net과 명시적인 외부 전원 제외 목록을 받는다. ADR-011의 부하/전체 회로 구분을 따른다.
- 0 V 제약은 등가저항 계산에서만 연결 축약한다. 1 V 시험 전원으로 해석하며 개방·단락·실패를 구분한다.
- KCL은 선택 net에서 나가는 전류의 부호 합, KVL은 연속 폐경로의 전위 변화 합이다. 항별 부호와 단위, 잔차와 허용오차를 표시한다.
- 기록은 당시 문서와 조건, 원시 수치와 단위를 복제해 고정한다. 화면 반올림 값을 계산 입력으로 쓰지 않는다.
- 값 변화 실험은 원본의 복제본마다 계산하고 x축 변수·단위와 y축 물리량·단위를 보존한다. 실패 표본은 그래프에서 연결하지 않는다.

구현 모듈은 `probeVoltage(compilation, result, red, black)`, `insertSeriesAmmeter(document, { componentId, ammeter, newWireId })`, `parameterSweep(document, request, compiler, engine)`, `createMeasurementRecord(document, fields)`, `measurementsToCsv(records)`를 공개한다. 결과는 `{ ok, value?, diagnostics }` 구조로 반환한다. 전류계 ID와 위치, 기록 시각은 호출자가 명시한다. 전원은 positive 단자를 삽입 시작점으로 사용한다.

CSV는 영어 필드명과 별도 `unit` 열을 쓰며 조건과 당시 문서 JSON을 함께 보존한다. 외부 측정은 `source`로 구분한다. 그래프는 최대 100개 표본으로 제한하고 미정 표본 사이를 선으로 잇지 않는다.

## 검증 사례

- FIX-02/03/05/10 탐침 반전, 같은 net, 미연결, 부유 전위.
- FIX-01/03 직렬 계기의 전류·회로 불변성, 병렬 단락 진단.
- FIX-01~04/09/10 부하 등가저항, 전체 회로의 전원 0 V 치환, 개방·단락.
- 정상 fixture KCL·KVL, 열린 경로 거부, 없는 net·요소 거부.
- 변경 전후 기록 구분, CSV 인용과 수식으로 오해될 수 있는 텍스트 처리.
- 값 변화에 대한 오옴 법칙, 오류 표본과 입력 범위 방어.
