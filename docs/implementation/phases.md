# 단계별 구현 계획

각 단계는 모듈 하나가 아니라 사용자가 끝까지 경험할 수 있는 작은 흐름을 완성한다.

## 단계 요약

| 단계 | 이름 | 주요 산출물 | 종료 상태 |
|---:|---|---|---|
| 0 | 기반 설계 | 문서 스키마, 모듈 경계, 테스트 환경, ADR | 이후 변경 원칙과 검증 기준이 확정됨 |
| 1 | 물리 시제품 | 고정 회로 연결망, MNA, 진단, 숫자 표시 | 대표 회로 계산 정확성 확인 |
| 2 | 편집기 핵심 | 부품 배치, 배선, 명령, 실행 취소, 로컬 저장 | 직렬·병렬 회로를 직접 만듦 |
| 3 | 전위 시각화 | 색상, 등전위, 3D 높이, 경로 그래프 | 핵심 교육 가치 검증 |
| 4 | 측정·진단 | 전압·전류 측정, 오류 설명, KCL·KVL | 학생 탐구 흐름 완성 |
| 5 | 교사 출력 | 문제·정답, 라벨, SVG·PNG·클립보드 | 1차 MVP, 교사 제작 흐름 완성 |
| 6 | 활동·공유 | 허용 조작, 예측·공개, 초기화, 링크 | 수업 배포 흐름 완성 |
| 7 | 교실 알파 | 사용성, 성능, 접근성, 복구, 버그 수정 | 실제 수업에서 반복 사용 가능 |

## 단계 0 — 기반 설계

주요 작업:

- 저장소, 코드 스타일, 자동 테스트·빌드 환경
- `CircuitDocument` v1, 단위·ID 규칙, 요구사항 ID 체계
- 모듈 import 규칙과 ADR 양식
- FIX-01~FIX-10 문서와 기대 결과

종료 조건:

- 스키마 검증과 저장→열기 왕복 테스트 통과
- 핵심 모듈의 UI 의존 금지 규칙을 자동 검사
- 단계 1 전에 필요한 ADR 후보 목록 확정

## 단계 1 — 물리 시제품

주요 작업:

- 고정 회로를 `CompiledCircuit`로 변환
- MNA로 전위·전류·전력 계산
- 부유 회로, 단락, 충돌 전원 진단
- 기준점 변경 불변식 테스트

종료 조건:

- FIX-01~FIX-10 계산·진단 테스트 통과
- 행렬 구현이 `SimulationEngine` 밖으로 노출되지 않음
- 한 페이지 데모에서 회로 선택과 값 변경이 즉시 결과로 이어짐

## 단계 2 — 편집기 핵심

주요 작업:

- SVG 캔버스, 기본 부품, 단자, 직각 도선, 분기점
- Add/Move/Connect/SetValue/Delete 명령과 실행 취소
- 문서→연결망→계산 전체 흐름
- 자동 저장과 JSON 저장·열기

종료 조건:

- 설명 없이 직렬·병렬 회로를 구성
- 교차선과 분기점이 전기적으로 정확히 구분
- 100회 실행 취소·다시 실행 후 문서와 화면 일치

## 단계 3 — 전위 시각화

주요 작업:

- 전위 숫자, 색상 범례, 등전위 강조
- 2D 위치를 공유하는 3D 전위 높이 보기
- 주요 경로 제안과 전위 그래프
- 자동·고정 색상 범위와 움직임 감소

종료 조건:

- 같은 `net`이 모든 보기에서 같은 전위
- 2D↔3D 전환에서 위치 대응 유지
- 사용자 테스트에서 전위 높이 표현의 의미를 설명함

## 단계 4 — 측정과 진단

주요 작업:

- 두 탐침 전압계와 가지 삽입 전류계
- 등가저항과 KCL·KVL 표시
- 진단 코드와 학생용 설명·수정 행동 연결
- 측정 기록표와 CSV

종료 조건:

- 잘못된 측정 연결에서 앱이 멈추지 않음
- 빠른 값 보기와 측정기 모드가 구분됨
- 예측→측정→전위 확인 활동이 완결됨

## 단계 5 — 교사 출력과 1차 MVP

주요 작업:

- 문제·정답 표시 규칙, 지점 라벨, 화살표, 미지수
- 화면과 분리된 인쇄용 SVG 렌더러
- PNG, 클립보드, 흑백, 투명 배경
- 수업 화면 기본 기능

종료 조건:

- 같은 회로에서 문제지·정답지를 즉시 전환
- 확대해도 SVG 선과 글자가 깨지지 않음
- 교사가 회로 제작부터 문서 붙여넣기까지 2분 내 수행

## 단계 6 — 활동과 공유

주요 작업:

- `ActivityDefinition`과 `ActivityPolicy`
- 허용 조작을 명령 단계에서 강제
- 예측 질문, 단계별 공개, 초기화
- URL 또는 공유 코드

종료 조건:

- 버튼·단축키·명령 API 어느 경로에서도 금지 동작 거부
- 학생이 로그인 없이 활동 시작
- 초기화가 교사 원본을 손상시키지 않음

## 단계 7 — 교실 알파

주요 작업:

- 실제 과제 수행 관찰과 우선순위 수정
- 태블릿·크롬북·스마트폰의 터치와 성능 보정
- 접근성, 복구, 마이그레이션, 오류 보고 보강
- 공개 예제와 짧은 도움말

종료 조건:

- 핵심 과제 성공률과 시간 목표 충족
- 치명적 데이터 손실과 계산 오류 없음
- 사용자 피드백에 따른 변경이 요구사항과 ADR에 반영됨

## 첫 세로 조각

9 V 전원과 9 Ω 저항 하나가 미리 놓인 화면에서 다음 흐름을 완성한다.

1. 고정 회로 데이터와 스키마 검증
2. 연결망 구성과 MNA 계산
3. 간단한 2D SVG 표시와 저항값 입력
4. 전위 숫자·색상·높이 중 최소 표현
5. 자동 저장과 다시 열기
6. FIX-01 자동 테스트와 간단한 사용자 과제
