## 2026-09-24 팔레트 선택 — `ab1f54a`

- VIS-001/002/004: 사용자가 확정한 A/C RGB 색상점과 B의 남색 확장·빨강 유지 함수를 보존했다. 기본은 전체 스펙트럼이고 동일 PotentialModel을 2D·3D에 전달한다. 팔레트는 문서 밖 세션 상태이며 전위·높이·저장 형식은 바꾸지 않는다.
- 색상바를 눌러 세 그라데이션과 체크 표시에서 선택한다. 이름은 접근성 레이블로 유지한다. portal 경계·키보드·초점 복귀·바깥 클릭 닫기·단일 전위의 단색 범례를 제공한다.
- 관련 8개 파일 162개 검사·타입·모듈 경계·빌드 통과. 이름 제거 후 메뉴 5개·타입 검사 재통과. 실제 2D/3D 적용·표지 좌표 유지·모바일 크기 메뉴 경계 확인. 상세 범위는 검증 문서에 모았다.
- `origin/codex/mvp` 푸시 완료. 이 기록에서는 해당 커밋의 배포 결과를 검증하지 않았다.

## 2026-09-24 문서 간소화

완료된 UX 검토 3종·옛 화면 캡처·중간 실행 로그를 제거하고 현황·검증·운영 문서를 압축했다. 향후 단계와 유보 후보는 남은 작업에, 학생·교사·실기기 수용 과제는 사용성 문서에 보존했다. 색상 비교용 임시 웹앱과 전용 자료·로그·초기 후보 캡처도 삭제했다. 정식 팔레트·회귀 테스트·요구사항·ADR·스키마·fixture·기능 코드는 유지한다. 로컬 링크 111개·앵커·명세·공백 검사를 통과했고, 원문의 UX·터치 수용 과제 보존과 삭제 자료 참조 0건을 확인했다. 코드 테스트·빌드는 반복하지 않았다.
