3D 시점 전환 지연은 로컬·배포판 모두 정상화되어 원인이 확정되지 않았다. 라벨 크기 읽기/위치 쓰기를 묶는 개선은 유지하되, 특정 수정의 효과로 단정하거나 추가 최적화를 착수하지 않는다.

실제 교실·모바일·보조기술·장시간 사용 검증은 미완료다. [남은 검증](follow-up.md)을 따른다.
