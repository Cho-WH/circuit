# 작업과 검증 기록

현재 범위는 [현황](current-phase.md), 규칙은 요구사항·ADR·물리 문서, 실행 근거는 [검증 범위](../testing/mvp-coverage.md), 미완료 항목은 [남은 작업](follow-up.md)을 따른다. 새 기록은 변경 결과·회귀 방지 이유·실제 검증·미완료만 남긴다. 중간 대화·역할 분담·반복 테스트 수·커밋 대기 상태는 누적하지 않는다.

## 2026-09-26 출력 부품 이름·값을 실제 회로와 통일

- TCH-001~003, ADR-012: 출력에서 부품 값 입력을 제거하고 실제 값을 읽기 전용으로 표시한다. 실제 값 변경은 회로 만들기에서 수행하며 표시·숨김·사각 빈칸·위치 이동은 출력에서 설정한다. 이름 변경은 SetLabel로 실제 부품 이름에 반영한다. 화살표 주석의 기호·값 문구 편집은 사용자 요청에 따라 유지한다.
- 부품 출력의 Text·Display 처리와 관련 테스트·설명을 제거했다. 사용자 지시에 따라 해당 기능의 구형 파일 호환 처리나 추가 마이그레이션은 만들지 않는다. 출력 모드 명령 단계에서도 물리값 및 출력용 문자·Display 변경을 차단한다.
- 이름의 다른 모드 반영·실행 취소/다시 실행·자동 저장, 부품 값 읽기 전용, 표시·빈칸, 화살표 문구 편집을 회귀 검증했다. 전체 Vitest 576개 통과·24개 건너뜀(기존 Firestore 에뮬레이터 전용), 타입·빌드·모듈 경계 73개 소스·Python 명세·공백 검사 통과. 기존 큰 청크 경고는 남는다.
- 로컬 프로덕션 빌드의 헤드리스 Chrome 1280×900·390×900에서 부품 이름 동기화·값 잠금·표시/빈칸·저장 후 새로고침을 확인했다. 실제 생성한 683×346 PNG 미리보기와 편집 패널의 배치를 스크린샷으로 확인했으며 페이지 오류는 없었다. 실제 모바일 하드웨어 검증은 별도다.

## 2026-09-26 운영체제 설정과 독립적인 3D 진입

- VIS-004, QLT-001, ADR-006: 사용자 결정에 따라 2D → 3D 높이·카메라 진입 전환을 운영체제·브라우저의 움직임 감소 설정과 관계없이 재생한다. 첫 진입 1100ms·동일 문서 재진입 900ms와 직접 조작에 의한 중단을 유지한다. 요구사항·ADR·상호작용 문서를 같은 기준으로 갱신했다.
- 회귀 테스트는 움직임 감소 켜짐/꺼짐 × 1100ms/900ms의 시작·중간·완료 높이와 카메라 이동, 완료 콜백·프레임 정리를 검증한다. 별도 카메라 프리셋은 기존 움직임 감소 설정을 따르는 것도 확인했다.
- 전체 Vitest 573개 통과·24개 건너뜀(기존 Firestore 에뮬레이터 전용), 타입 검사·프로덕션 빌드·모듈 경계 73개 소스·Python 명세 검증·공백 검사 통과. 기존 큰 청크 경고는 남는다.
- 연결형 브라우저 도구의 실행 환경 오류를 우회해 로컬 프로덕션 빌드를 별도 헤드리스 Chrome에서 검증했다. 1280×900에서 움직임 감소 켜짐/꺼짐 각각 첫 진입 약 1133ms(68프레임), 재진입 약 933ms(55~56프레임) 동안 투영된 라벨 좌표가 연속 변경됐고 페이지 오류는 없었다. 움직임 감소가 켜진 진입·완료 스크린샷에서 평면 회로에서 전위 높이 지도로 전환됨을 확인했다. 다른 운영체제·실제 모바일 기기 검증은 수행하지 않았다.

## 2026-09-24 빠른 시작 안내 재구성

- P-04, EDT-001, VIS-004, TCH-001/003, DAT-001, QLT-001: 기본 편집·측정·예제를 짧게 소개하고, 도선 위 저항 삽입 한 가지를 제안한다. 3D 전위 높이와 문제지용 회로도 제작을 공통 부품 기호 기반 SVG 예시·설명·실제 메뉴 경로로 안내한다. 저장은 하단 한 문단으로 줄였다. 물리 계산·출력 기능·공개 계약·문서 v4 변경은 없다.
- 수용 기준은 핵심 두 기능과 진입 경로를 구별할 수 있음, 3D 높이를 전위로 설명함, 파일 저장과 브라우저 자동 저장을 구분함, 좁거나 낮은 화면에서도 본문과 닫기 동작에 접근 가능함, 도움말을 열고 닫아도 현재 회로·화면을 보존함이다. 안내 본문을 키보드로 스크롤할 수 있고, 열린 동안 배경 회로의 편집 단축키를 차단한다.
- 도움말 초점 순환·Escape/버튼/바깥 클릭 닫기·초점 복귀·모드와 확대 유지·배경 편집 차단 회귀 5개를 추가했다. 관련 5개 테스트 파일 124개(워크스페이스·전위·출력·명세 포함), 타입·모듈 경계 73개 소스·프로덕션 빌드·변경 코드 포맷·공백 검사를 통과했다. 기존 큰 청크 경고는 남는다.
- 메인이 로컬 브라우저의 1280×900, 390×844, 320×568, 640×450에서 그림·문구·줄바꿈·본문 스크롤과 고정 닫기 버튼을 확인했다. 320px 화면의 본문 가로 넘침 없음, 두 닫기 버튼 44px 높이, PageDown 본문 이동, Escape 후 물음표 초점 복귀를 확인했고 콘솔 오류는 없었다. 실제 모바일 하드웨어·보조기술·브라우저 200% 확대의 실사용 검증은 별도다.

## 2026-09-24 출력 그림 복사 버튼 가독성

- TCH-001/003: 출력 도구막대의 포괄적인 span 글자색과 버튼 배경 규칙이 공통 primary 스타일을 덮어쓰지 않도록 범위를 좁혔다. 출력 전용 강조색 중복 선언은 제거했다. 새 색상이나 상태를 추가하지 않고 일반·hover·복사 완료의 글자와 아이콘이 기존 공통 강조 버튼 스타일을 따른다.
- 별도 5174 브라우저에서 기본 흰 글자, hover의 기존 짙은 강조색, 복사 완료 문구·체크 아이콘의 흰색을 계산된 스타일과 화면으로 확인했다. 변경 전 라벨은 회청색 rgb(97,112,131), 변경 후 흰색이다. 복사 완료도 확인했다. 출력 테스트 8개·Vite 빌드·공백 검사 통과. 기존 큰 청크 안내는 유지된다.

## 2026-09-24 분기점 정리와 배치 실패 효과 — ADR-018

- EDT-001/002/003/005, SIM-001: 삭제로 영향받은 노드만 연결 수에 따라 정리한다. 고립점 제거·두 도선 병합을 공통 `editor/wire-topology.ts`로 분리하고 열린 끝·실제 분기·앵커·굴곡을 보존한다. 노드 수동 삭제와 선택 메뉴는 제거했다. 일반 분기점은 끝단과 같은 기존 처리로 즉시 배선을 시작하며, 네 갈래 직교 교차는 기존 연결·비연결 토글을 유지한다. DeleteElements는 노드 ID가 있으면 문서와 이력을 보존하고 거절한다.
- 삽입 후보와 명령이 정리된 연속 경로를 공유한다. 관계없는 문서 영역은 그대로 두고 미리보기와 확정의 노드·도선 경로를 일치시킨다. 배치 불가 위치는 320ms 원/X 효과만 보여 주며 이유·근처 안내 없이 초안을 유지한다. 저장 v4는 변경하지 않는다.
- 전체 30개 파일 564개 테스트 통과 및 네 갈래 토글 유지 후 관련 93개 검사 재통과, Firestore 환경 의존 1개 파일 24개 검사는 기존 설정대로 건너뜀. 타입·모듈 경계(72개 소스)·명세·빌드·공백 검사 통과. 빌드의 큰 청크 안내는 남아 있다.
- 별도 5174 브라우저에서 일반 분기점 첫 클릭 즉시 배선 시작과 노드 메뉴 부재, 중간 노드 위치의 직렬 삽입과 노드 제거, 실제 분기점 삽입 거절의 X 표시·배치 도구 유지 확인. 마우스·터치 효과 수명과 불변 이력은 Canvas 테스트로 검증했다. 실제 터치 기기 수용 검증과 부품이 사라지는 별도 현상 조사는 남겨 둔다.

## 2026-09-24 일반 휠 확대·축소

- EDT-001, VIS-004, TCH-001: 회로 만들기·전위 2D·측정의 공통 캔버스와 회로도 출력에 일반 휠 확대·축소를 추가했다. 포인터 아래의 문서 좌표를 유지하고 기존 버튼의 확대 범위를 따른다. Ctrl/⌘ 휠도 지원하며 캔버스 밖 스크롤은 유지한다. 3D·터치 조작과 회로 문서는 변경하지 않는다.
- 두 캔버스는 로컬 non-passive wheel 리스너를 공유하여 페이지 스크롤·브라우저 확대의 동시 실행을 막는다. 빌드 중 발견한 배치 처리의 중복 voltmeter 조건은 앞선 조기 반환에 이미 포함되어 있어 제거했다.
- 검증: 터치·편집 테스트 31개(회로/출력 휠의 방향·포인터 고정·Ctrl 호환·캔버스 밖 이벤트·문서 불변 포함), 타입 검사·빌드·모듈 경계 72개 소스 통과. 최종 브라우저에서 회로 편집·전위 2D·측정·출력의 실제 일반 휠 확대·축소를 확인했다. 회로 편집 단자 기준점 이동은 0.1px 미만이며 콘솔 오류는 없었다. 기존 큰 청크 안내는 유지된다.

## 2026-09-24 하단 조작부 정리

- EDT-001, VIS-001/004: 사용자 검토에 따라 상단 화면 이동 모드와 공통 캔버스 하단 방향 버튼을 제거했다. 선택 도구의 빈 공간 마우스 드래그·캔버스 방향키로 이동하며 기존 가운데 버튼·터치 조작을 유지한다. 마우스 이동량은 실제 화면 배율을 사용해 가로세로 여백이 있을 때도 손의 이동 거리와 일치시킨다.
- 2D 접지 표기와 확대·축소 도구를 공통 하단 줄의 왼쪽·오른쪽에 배치했다. 접지 표기는 별도 행을 차지하지 않으며 긴 이름만 말줄임한다. 다른 회로 화면도 확대·축소 도구를 최하단에 유지한다.
- 검증: 터치·편집 테스트 29개(마우스·방향키 이동, 세로 여백 포함), 전위 workspace·3D 수명 테스트 15개, 타입 검사·빌드·모듈 경계 검사 통과. 최종 브라우저의 360×800과 1280×720에서 하단 표기/확대 도구의 비겹침, 빈 공간 드래그, 2D↔3D 회로 영역·viewBox 유지를 확인했다. 만들기·측정·출력 화면에서도 화면 이동 버튼이 없고 확대 도구가 유지된다. 콘솔 오류 없음. 실제 터치 기기 검증은 별도다.

## 2026-09-24 전위 보기 도구막대와 접지 표기

- VIS-001/002/004, PV-01/05, ADR-006: 접지 위치를 2D·3D 하단의 `접지(0V): [접지 위치]`로 통일했다. 모바일 색상바와 설정 버튼을 같은 줄에 묶고, 3D에서 전류 화살표 항목은 숨기되 공간을 유지해 전환 때 도구막대 높이가 바뀌지 않도록 했다. 2D 확대·이동 도구는 접지 표기 위에 배치했다. 계산·저장 형식·카메라 보간은 변경하지 않았다.
- 수용 기준: 전환 전후 도구막대·회로 영역의 위치와 크기, 2D viewBox와 기준 단자의 화면 좌표가 같고, 접지 표기와 조작 도구가 겹치지 않는다.
- 코드 검증: 관련 전위·팔레트·3D 수명 테스트 4개 파일 24개, TypeScript, Vite 빌드, 모듈 경계 69개 소스 통과. 기존 큰 청크 안내는 유지된다.
- 최종 빌드 브라우저 검증: 360×800, 390×844, 768×1024, 1280×720에서 전환 전후 위 기준이 일치했다. 390px의 도구막대는 양쪽 모두 95.8px로 유지되며 기존 47px 재배치가 사라졌다. 모바일 그래프·상세 설정 동시 표시에서도 회로 영역과 viewBox·단자 좌표가 유지됐다. 하단 표기·색상바/설정 한 줄 배치를 시각 확인했고 콘솔 오류는 없었다. 실제 모바일 기기 검증은 별도다.

## 2026-09-24 구조 정리와 화면 책임 분리

- QLT-003, SIM-002, EDT-001/002/004/005, DAT-001, VIS-007: simulation 해석기를 내부 solver로 이동해 index↔measurements 순환을 제거했다. 기존 공개 API·물리 계산·문서 v4는 유지한다. 경계 검사는 TypeScript 구문을 읽고 모듈 내부 런타임 순환도 잡으며, 주석과 type-only 참조를 구분한다.
- `useCircuitSession`에 문서 이력·화면 모드 검사·단일/묶음 명령·자동 저장을 모았다. `useCanvasDragSession`에 이동 세션·캡처·미리보기를, `InlineComponentEditor`에 입력 초안·오류·초점을, `PotentialSettings`에 전위 설정 표시를 분리했다. Prettier를 개발 의존성으로 추가하고 변경 파일에만 적용했다. 새 전역 상태 계층이나 독립 기능 패키지는 추가하지 않았다.

스위치 편집창의 라디오 선택은 사용자 요청으로 제거했다. 상세 설정의 스위치 열기/닫기 버튼을 공통 SwitchStateButton으로 추출해 두 화면에서 재사용한다. 인라인 편집은 적용 전 초안을 유지한다. 관련 UI 테스트·타입 검사를 통과했으며 라이브 검증은 사용자 요청대로 생략했다.

스위치 열기/닫기는 사용자 요청에 따라 버튼 클릭 즉시 SetProperties로 반영하도록 변경했다. 편집창과 이름 초안을 유지하고 이름 적용·상태 변경은 각각 실행 취소한다. 취소는 이름 초안만 버린다. 관련 UI 테스트 13개와 타입 검사 통과. 라이브 검증은 생략했다.

스위치 버튼 재사용 점검에서 상태 반전 콜백이 상세 설정과 캔버스 경로에 중복된 것을 확인했다. App.toggleSwitch 하나로 합쳐 상세 설정·인라인 수정창·회로 직접 조작에서 동일한 SetProperties 실행 경로를 사용하도록 정리했다.

## 2026-09-26 모바일 회로 시작 메뉴 정리

- EDT-005: 빈 회로의 + 아래 이름을 표시하고 모바일 팔레트를 빈 회로 → 예제 회로 → 세로 구분선 → 부품 목록 순서로 배치했다.

- 예제와 문서 제목을 휘트스톤 브릿지, 저항 사이 접지로 변경했다.

## 2026-09-29 공통 전류 흐름 시각화 — ADR-020

### 최종 반영 상태

- 전류 화살표를 전위색의 비례 띠와 가지별 등간격 점 열로 교체했다. 전류가 클수록 띠가 두껍고 점 간격이 좁다. 축척은 자동이며 두께 배율만 상세 설정에서 조절한다.
- 직렬 도선·부품 경계는 연속 통과하고 분기·합류의 짧은 구간에서만 페이드한다. 점 열의 시작 위상은 강제로 맞추지 않는다. 카메라 이동 중 경로 내 위치와 SVG 노드를 유지하고, 정지 후 화면 간격을 한 번 조정한다.
- 상단 설명 밴드는 제거하고 화면 왼쪽 위에 공통 도구 스타일의 일시 정지 버튼만 둔다. 3D 바닥 회로도의 도선은 유지한다. 저장 형식과 물리 해석 계약은 바꾸지 않는다.
- 최종 규약은 [ADR-020](../../decisions/ADR-020-current-visualization.md), [전류 시각화](../physics/current-visualization.md), VIS-006/CV-01~05에 정리했다. 아래는 구현 중간 단계와 수정 순서에 따른 검증 이력이며, 초기 고정 축척·범례·바닥 도선 제거는 후속 수정으로 대체되었다.

### 초기 구현과 검증 이력

- VIS-006, CV-01~05: 부품·도선마다 해석 결과의 부호 있는 전류를 사용한다. 전류 크기는 같은 축척의 선형 비례 띠와 수치로, 관습적 방향은 등속·등간격 무늬로 표시한다. 무늬는 전자나 고정 전하 묶음이 아니다. 화면 투영 후 호 길이를 사용하므로 3D 저항 경사·높이 배율에 따라 표시 속도가 증가하지 않는다.
- 순수 전류 모델·소자 경로 정책·화면 호 길이 계산을 visualization에 두고, DOM 수명과 표시 시계는 current-view에 분리했다. 2D SVG와 3D 카메라 투영 어댑터가 같은 표시기를 재사용한다. 도선 교차의 비연결 bridge도 공통 기호 경로를 사용한다. 저장·해석 계약은 유지하며, 향후 축전기·다이오드는 명시적 경로 정책과 해석기 상태가 필요하다.
- 축척은 값 편집 중 유지하고 축척 맞춤으로 전체를 갱신한다. 0 A·미정 도선 고리·계산 실패·미세 비영 전류·축척 초과를 구분한다. 열린 스위치·전압계의 내부 경로를 잇지 않는다. 일시 정지·움직임 감소·숨김·뷰 해제에서 RAF를 중단하고 리스너·DOM을 해제한다.
- 전체 656개 테스트 통과(36개 파일, Firestore 전용 1개 파일 24개 제외). 타입·Vite 빌드·모듈 경계(87개 소스)·명세·공백 검사 통과. 실제 Three.js 투영 후 등속, KCL·부호·전원 단자 순서, 배치·높이 불변식, 고정 축척, 미래 미지원 소자 연결 차단, 프레임 수명과 마우스·키보드 구간 선택을 검사했다. 기존 큰 청크 안내는 남는다.
- 메인이 실제 브라우저 1280×720 및 390×844에서 확인했다. 직렬 1 A, 병렬 도선 3 A·1 A·2 A, 2D/3D 전환, 높이 배율 최대 변경, 일시 정지/재생, 모바일 범례 줄바꿈과 화면 맞춤, 열린 스위치의 0 A 및 양쪽 뷰의 무늬·띠 0개를 확인했다. 콘솔 오류는 없었다. 도선 선택 수치가 갱신되지 않던 App 연결을 수정하고 회귀 테스트를 추가했다. 검증 후 기존 회로를 실행 취소로 복원했다. 실제 모바일 기기와 배포 검증은 수행하지 않았다.

### 사용자 피드백 반영 — 전위 색상·밀도·연속 경로·카메라 이동

- 기존 도선 잉크·3D 튜브·바닥 도선을 전류 띠로 대체했다. 선택 히트 영역과 부품 기호를 유지하며 띠에는 기존 전위 팔레트와 색상 토글을 적용한다. 상단 전류 밴드를 제거하고 화면 안 왼쪽 위에 일시 정지/재생 버튼만 둔다. 수치와 두께 배율은 상세 설정에서 확인한다.
- 고정 축척·맞춤을 최대 전류 기준 자동 축척과 ×0.25~×3 두께 배율로 바꿨다. 무늬 간격은 상대 전류에 반비례한다. 단자 ID 기준 직렬 도선·소자를 한 경로로 묶고 닫힌 경로의 이음새도 연속으로 처리한다. 분기는 가지별 밀도를 사용한다. 이산 무늬의 밀도 근사와 표시/물리 시간의 경계는 ADR-020과 CV 규약에 기록했다.
- 시점 이동 중 점이 튀는 문제는 매번 새로 배치하던 SVG·무늬를 ID별로 유지하고 점의 선분 내 위치를 재투영하도록 수정했다. 화면 밖 점 노드를 풀링하고 이동이 끝난 뒤 한 번만 간격을 교차 전환한다. 전환 종료 후 30 CSS px/s로 이동한다. 도선·점 SVG를 20회 재투영하는 동안 추가 생성 0회, 노드 동일성, 정지 중 재투영, 교차 전환 완료 후 3 px/100 ms를 자동 검사했다.
- 최종 전체 663개 테스트 통과(36개 파일, Firestore 전용 24개 제외), 타입·Vite 빌드·명세·모듈 경계(88개 소스) 검사 통과. 기존 큰 청크 안내는 남는다. 직렬 경계와 분기, 반대 부호 전원, 겹치지만 연결되지 않은 단자, 전위 팔레트 3종의 2D/3D 일치, 두께/무늬 간격 독립성, 숨김·해제 수명을 확인했다.
- 실제 브라우저에서 2D/3D 전환, 사선·정면·위에서 카메라 이동, 전위 색상 띠, 두께 ×3 변경 시 14→42 px 및 무늬 개수 유지, 일시 정지와 390×844 모바일 버튼 배치·가로 넘침 없음을 확인했다. 개발 중 Hot Refresh의 의존 배열 변경 경고를 확인해 2D 투영 어댑터도 변경 시 재생성하도록 했다. 실제 기기 성능·터치와 배포 검증은 수행하지 않았다.

### 분기·합류 전환과 일시 정지 버튼

- VIS-006: 실제 연결 ID의 분기·합류에만 3.5 px 접점과 바깥 8 px 페이드를 적용했다. 가지별 점 간격·속도·시작 위상을 유지하고 직렬 경계에는 적용하지 않는다. 화면상 비연결 교차를 접점으로 처리하지 않는다. 접점은 전위색을 유지하며 2D·3D 공통 표시기를 사용한다.
- 전체 666개 테스트 통과(Firestore 전용 24개 제외), 타입·Vite 빌드·모듈 경계(88개 소스)·명세 검사 통과. 기존 큰 청크 안내는 남는다. 분기/합류의 대칭 페이드, 속도·간격 보존, 비연결 교차, 재투영 시 접점 DOM 재사용과 제거를 검사했다. 메인은 2D 병렬 회로를 확인했으며 사용자가 라이브 테스트 통과를 확인했다.
- 사용자 추가 요청에 따라 일시 정지 버튼을 공통 도구 버튼과 같은 투명 배경·차분한 아이콘색·5 px 모서리로 조정했다. 정지 상태에는 연한 녹색 배경과 강조색 아이콘을 사용한다. 키보드 초점과 모바일 44 px 조작 영역은 유지한다. 이 스타일 수정 후 추가 검증은 사용자 요청으로 생략했다.

### 3D 전류 모드의 바닥 도선 유지

- VIS-006: 바닥 SVG의 도선을 제거하던 처리를 삭제했다. 바닥 회로도는 전류 표시 여부와 무관하게 유지하며 전류 토글 때 바닥 텍스처를 다시 만들지 않는다.
- 최소 검증 요청에 따라 기존 3D 전류 수명 테스트 1개만 실행해 통과했다. 켜기·끄기 전후 바닥 객체 유지·텍스처 재생성 없음과 공중 튜브 숨김을 확인했다. 전체 테스트·빌드·브라우저 검증은 생략했다.

### 전류 시각화 테스트 정리

- 속도 검사를 실제 2D·3D 저항 경로와 서로 다른 전류 밀도의 비교로 모았다. 자동 축척의 0→미세 전류→일반 전류 전환은 두께·일시 정지 상태 유지와 함께 확인한다. 과거 UI 클래스 부재 검사와 페이드 중간값 고정 검사를 정리하고, 표시기를 통한 분기·합류 검사와 짧은 경로의 경계 검사는 유지했다.
- 물리량·직렬 연결·비연결 교차·카메라 이동·프레임 해제·바닥 도선의 회귀 검사는 유지했다. 제품 코드는 변경하지 않았다. 관련 4개 파일의 테스트 40개가 통과했으며 전체 테스트·빌드·라이브 검증은 추가 실행하지 않았다.

### 3D 자동 높이 축척

- VIS-004: 기존 3D host 크기 측정·사선 카메라·경계 투영·전압축 눈금 계산을 재사용해 목표 높이를 산출한다. 표시용 전위 모델만 선형 재축척하고 같은 모델로 전류 경로·축·라벨을 만든다. 높이 슬라이더는 기본 ×1, ×0.25~×3의 상대 배율이다.
- 진입 때 목표 높이를 정하고 기존 보기 초기화에서 갱신한다. 영역 크기·카메라 조작 중에는 높이가 유지된다. 기존 패널 가림·카메라 여백 처리를 유지하며 별도 UI 영역 분석이나 관찰자를 추가하지 않았다.
- 관련 4개 파일 39개 테스트와 타입 검사 통과. mV/V/kV 높이 정규화, 부호·색상·net 연결 보존, 0 V 평면, 배율 변경 중 초점·카메라 유지, 리사이즈 후 보기 초기화를 확인했다. 전체 테스트·빌드·라이브 브라우저 검증은 실행하지 않았다.

### 위에서 보기 이후 회전 기준축 수정

- VIS-004: 카메라 기준축을 초기화 이후 Z-up으로 유지해 OrbitControls와 일치시켰다. 위에서 보기와 진입 시작은 +Z축 꼭대기를 유지하며 자세를 직접 지정해 2D 화면 방향을 보존한다. 전환 중에도 기준축을 바꾸지 않는다.
- 타입 검사와 기존 3D 수명 테스트 15개 통과. 실제 OrbitControls를 사용하는 일회성 실행으로 위에서 보기의 화면 방향과 회전 후 Z축 기준 자세를 확인했다. 사용자 요청에 따라 영구 테스트는 추가하지 않았으며 라이브 브라우저 검증은 생략했다.

### 분석하기 1차 통합 — ADR-021

- VIS-001~006, MEA-001~004, SIM-005: 작업을 회로 만들기 / 분석하기 / 회로도 출력으로 통합했다. 왼쪽 부품 팔레트의 공간·타일 스타일을 측정 도구에 재사용하고 기존 계산·측정·시각화 모듈을 유지했다. 선택과 탐침 배치를 구분하고 도구 종료·Escape를 제공한다.
- 보기 설정과 탐침 위치를 독립적으로 유지한다. 기록·경로 그래프·값 변화 실험·법칙 확인은 하나씩 열며 기록·실험 초안은 유지한다. 선택 상태에서 회로 위 값을 수정하고, 측정 중에는 상세 설정의 부품 선택·값 입력으로 결과를 즉시 갱신한다. 구조 변경 명령은 분석 모드에서 차단한다.
- 전원이 있으면 짧은 안내와 전지 분리하고 측정 버튼으로 등가저항을 시작한다. 모든 전원 개방 계산과 기호의 리드 분리 표시를 재사용하며 원본 문서는 보존한다. 분리 중 정상 작동 상태의 숫자·색상·전류·3D·빠른 값과 관련 분석 패널을 억제하고 종료 시 이전 표시를 복원한다. 무전원 회로는 즉시 측정한다.
- 3D에서 도구를 고르면 2D로 이동하고 3D 버튼은 측정 도구를 종료한다. 위치·기록은 유지한다. 3D 직접 탐침 조작과 재진입 카메라 자세 복원은 후속으로 남긴다.
- 관련 12개 파일의 테스트 215개 통과(첫 실행 200개, 마지막 수정 후 통합·3D 수명 18개 재확인 중 3개 중복). 타입·모듈 경계·명세·공백 검사를 통과했다. 새 통합 테스트 3개는 상태 보존·값 갱신·분리 조건·복원·3D 경계에 집중한다. 기존 계산 fixture와 측정 수치 검증을 재사용했다.
- 실제 브라우저에서 전위 표시와 3 V 탐침의 공존, 3 Ω 전지 분리 표시, 도구 종료 후 정상 표시, 3D → 2D 탐침 복원, 390×844 도구·측정값·기록 패널을 확인했다. 작은 화면에서 기록 패널이 화면 밖으로 밀리던 배치를 수정했다. 확인한 콘솔 오류는 없었다. 전체 테스트·배포 빌드·실기기 터치·교사/학생 사용성 검증은 실행하지 않았다. 커밋·푸시는 하지 않았다.
