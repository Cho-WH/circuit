# MVP 작업 추적

이 문서는 **실행 당시의 작업·검증 이력**이다. 현재 구현 범위와 커밋·배포 상태는 [현재 작업 현황](current-phase.md)을 따른다. 아래 테스트 수는 각 시점의 실행 범위이며, 합산하거나 현재 전체 스위트 통과 수로 해석하지 않는다.

## 기록 원칙

초기 단계 0~5는 메인 Astra가 계약·물리 핵심·통합을 맡고 구현·검증 Sol이 분담했다. 최종 시각 검증과 MVP 완료 후 개선은 사용자 지시에 따라 메인이 직접 수행한다. 새 명시적 요청 전까지 서브 에이전트를 호출하지 않는다.

변경 영향에 맞는 검사를 실행하고 실패·수정·미검증 범위를 구분한다. 코드가 바뀌지 않은 문서 정리는 링크·참조만 확인한다. 세부 검증 명령은 [개발 운영](../operations/development-workflow.md)에 둔다.

- 0 Ω: 직렬 닫힌 스위치와 전류계는 0 V 제약으로 전류를 구한다. 병렬 중복 경로에서는 유일하지 않은 전류를 꾸며내지 않고 진단한다. 전원과 0 Ω 경로 충돌을 구분한다. 관련 ADR-003.

## 초기 MVP 검증 기록

아래는 단계 0~5를 처음 완료했을 때의 실제 실행 결과다. 이후 수정에 대한 검증은 후속 항목에 별도로 기록한다.

- 단계 0: 검증 Sol이 Vitest 2개 파일 78개 테스트, TypeScript, 모듈 경계(7개 소스), Vite 빌드, Python 명세 검증을 실행해 모두 통과했다. 금지 import·순환 의존·내부 import에 대한 실패 테스트도 포함했다.
- 단계 1: 3개 파일 123 테스트, 타입·경계·명세·빌드 검사 통과. 브라우저에서 FIX-01의 1 A→저항 18 Ω 변경 후 0.5 A, FIX-06/07/08의 진단과 수치 숨김, FIX-10의 기준점 변경을 확인했다. 브라우저 경고·오류 0, npm audit 0건.
- 단계 2: 4개 파일 160 테스트, 타입·경계(16 소스)·빌드·명세 통과. 데스크톱에서 새 회로→배선→값 수정→복사·정렬·회전·이동·실행 취소·기준점·분기점·새로고침 복구를 확인했다. 390×844 모바일에서 겹침·가로 넘침 없이 이름과 값이 읽혔다. 파일 선택기의 자동화 broker 문제로 실제 브라우저 업로드 검사는 수행하지 못했으며, 유효·무효 파일 파싱과 저장 보존은 모듈 테스트로 검증했다. Blob 다운로드 이벤트 수집도 도구에서 확인되지 않았으므로 다운로드 파일 자체의 브라우저 검증은 후속 확인 대상으로 남긴다.

- 단계 3: 5개 파일 170 테스트, 타입·경계(19 소스)·명세·빌드(1877 모듈) 통과. 2D 숫자·색·전류, 고정 범위, 기준점 변경, 등전위, 제안/직접 경로와 양방향 강조를 확인했다. 3D 카메라·축척·예제 변경 시 재맞춤, FIX-05 열린 스위치 단절, FIX-07 전위 미정과 높이 제외를 확인했다. 모바일 390×844 페이지 가로 넘침 없이 읽힘. Three 지연 청크 501.87 kB(압축 126.72 kB)의 비차단 크기 경고가 있다. 앱 기원 콘솔 오류는 없었고 확장 프로그램 메시지 채널 오류 2건은 앱과 구분했다. 실제 학생·교사의 의미 이해와 시간 목표는 미검증이다.

- 단계 4 중간: 측정 모듈 집중 검사 41개 통과. 브라우저에서 FIX-02 ±6 V, R2 임시 전류계 1 A, 부하 9 Ω/전체 회로 0 Ω, 기록·CSV 트리거, KCL·KVL, 21개 조건 그래프를 확인했다. 모바일 기록 버튼의 흰 바탕/흰 글자 문제를 수정했으며 최종 검증 중이다.

- 단계 4 최종: 6개 파일 211 테스트, 타입·경계(22 소스)·명세·빌드(1880 모듈) 통과. FIX-06/07/08에서 수치 미정과 한국어 진단, 모바일 기록 버튼 대비 수정, 390×844 가로 넘침 없음과 콘솔 오류 0을 확인했다. CSV 다운로드 동작은 트리거까지 확인했으며 실제 파일 내용은 모듈 테스트로 검증했다.

- 단계 5 중간: 표기·주석·출력 집중 검사 14개와 타입 검사 통과. 브라우저에서 문제/정답 표시, 주석 편집·실행 취소·다시 실행, 흑백·투명·여백 64·4배 PNG를 확인했다. 실제 PNG는 정답 2876×1812, 문제 2876×1908로 디코딩되었고 투명 배경과 문제 표기가 확인됐다. 클립보드 쓰기는 성공했으며 외부 문서 붙여넣기는 미검증이다.

- 최종 시각 검증(메인 Astra): 데스크톱의 낮은 창에서 전위 화면이 작아지고 상태줄이 밀리는 점을 수정했다. 초기 회로 맞춤, 좁은 세로 공간의 그래프 높이·축 글자, 주석 충돌 회피를 보정했다. 3D의 최소 높이와 카메라 투영 경계 맞춤을 수정해 전위 지도 상단 잘림을 해결했다. 측정 탐침 +/−와 6 V 표시, 문제지의 물음표·빈칸·주석 및 실제 PNG를 직접 확인했다. 모바일 390×844의 2D/3D, 네 모드 탭과 PNG를 확인하고 미리보기 오른쪽 잘림을 고쳤다. 실제 PNG 2061×1335 디코딩 및 페이지 client/scroll width 374/374를 확인했다.

- 최종 코드 게이트(검증 Sol): 7개 파일 228 테스트, 타입 검사, 모듈 경계 24 소스, 명세 검증, 1882 모듈 빌드 통과. Three 지연 청크 502.30 kB(압축 126.87 kB)의 비차단 크기 경고가 있다. `git diff --check`에서 공백 오류는 없었다. 마지막 시각 수정 후 전체 코드 게이트를 다시 통과했다.

## 초기 MVP 완료 시점의 상태

단계 0~5 기능 MVP를 완료했다. 최종 시각 검증은 사용자의 변경 지시에 따라 메인 Astra가 직접 수행했고, 이후 검증 Sol은 코드 검사만 수행했다. Git 원격은 `https://github.com/Cho-WH/circuit.git`, 브랜치는 `codex/mvp`이며 구현은 작업 트리에 보존했다. 이 초기 완료 시점에는 배포·push·PR을 하지 않았다. 이후 GitHub Pages 게시 설정을 추가했으며, 현재 작업 트리의 게시 상태는 [현재 작업 현황](current-phase.md)을 따른다.

[요구사항별 검증 범위](../testing/mvp-coverage.md)에 실제 사용자 연구와 도구 제한을 정리했다. [빠른 시작](../ux/quick-start.md)에서 실행·사용·저장·출력을 안내한다. 공유 및 학생 활동 배포는 단계 6, 실제 교실 사용성 검증은 단계 7의 후속 작업이다.

## 후속 — 문맥 배선과 모바일 최소 조작 (2026-09-23)

이 항목은 첫 구현의 기록이다. 당시의 행동 버튼·하단 안내·후보 문구는 이후 [안내 문구 제거와 교차 직접 토글](#후속--안내-문구-제거와-교차-직접-토글-2026-09-23)에서 아이콘과 직접 조작으로 바뀌었다.

- 관련 요구사항: EDT-001/002/003/005, SIM-001. 사용자 승인한 데스크톱·터치 흐름을 구현했다. 기본 툴바의 분기점·교차 연결을 제거하고 단자 시작, 선택 도선의 분기 후보, 교차의 연결/해제 행동 버튼으로 통합했다.

- 모바일: 도선 후보 탭 이동과 명시적 확정, 하단 안내/취소, 겹친 후보의 부품·단자 방향 선택, 선택 전 한 손가락 화면 이동·선택 부품 드래그·두 손가락 확대를 제공한다. 확대·취소·창 초점 이탈 후 클릭을 배선으로 처리하지 않는다. 축소 화면의 부품 중심은 단자 영역이 가리지 않게 했다.

## 후속 — 익명 후기·피드백 게시판 미리보기 (2026-09-23)

- 관련 요구사항: DAT-005, QLT-001. 메인이 직접 구현·검증했으며 서브 에이전트는 사용하지 않았다.
