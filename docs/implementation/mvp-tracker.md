# MVP 작업 추적

이 문서는 **실행 당시의 작업·검증 이력**이다. 현재 구현 범위와 커밋·배포 상태는 [현재 작업 현황](current-phase.md)을 따른다. 아래 테스트 수는 각 시점의 실행 범위이며, 합산하거나 현재 전체 스위트 통과 수로 해석하지 않는다.

## 기록 원칙

초기 단계 0~5는 메인 Astra가 계약·물리 핵심·통합을 맡고 구현·검증 Sol이 분담했다. 최종 시각 검증과 MVP 완료 후 개선은 사용자 지시에 따라 메인이 직접 수행한다. 새 명시적 요청 전까지 서브 에이전트를 호출하지 않는다.

변경 영향에 맞는 검사를 실행하고 실패·수정·미검증 범위를 구분한다. 코드가 바뀌지 않은 문서 정리는 링크·참조만 확인한다. 세부 검증 명령은 [개발 운영](../operations/development-workflow.md)에 둔다.

### 단계 1 실험 작업

- 0 Ω: 직렬 닫힌 스위치와 전류계는 0 V 제약으로 전류를 구한다. 병렬 중복 경로에서는 유일하지 않은 전류를 꾸며내지 않고 진단한다. 전원과 0 Ω 경로 충돌을 구분한다. 관련 ADR-003.

## 초기 MVP 검증 기록

아래는 단계 0~5를 처음 완료했을 때의 실제 실행 결과다. 이후 수정에 대한 검증은 후속 항목에 별도로 기록한다.

- 단계 0: 검증 Sol이 Vitest 2개 파일 78개 테스트, TypeScript, 모듈 경계(7개 소스), Vite 빌드, Python 명세 검증을 실행해 모두 통과했다. 금지 import·순환 의존·내부 import에 대한 실패 테스트도 포함했다.
- 단계 1: 3개 파일 123 테스트, 타입·경계·명세·빌드 검사 통과. 브라우저에서 FIX-01의 1 A→저항 18 Ω 변경 후 0.5 A, FIX-06/07/08의 진단과 수치 숨김, FIX-10의 기준점 변경을 확인했다. 브라우저 경고·오류 0, npm audit 0건.
- 단계 2: 4개 파일 160 테스트, 타입·경계(16 소스)·빌드·명세 통과. 데스크톱에서 새 회로→배선→값 수정→복사·정렬·회전·이동·실행 취소·기준점·분기점·새로고침 복구를 확인했다. 390×844 모바일에서 겹침·가로 넘침 없이 이름과 값이 읽혔다. 파일 선택기의 자동화 broker 문제로 실제 브라우저 업로드 검사는 수행하지 못했으며, 유효·무효 파일 파싱과 저장 보존은 모듈 테스트로 검증했다. Blob 다운로드 이벤트 수집도 도구에서 확인되지 않았으므로 다운로드 파일 자체의 브라우저 검증은 후속 확인 대상으로 남긴다.

- 단계 3: 5개 파일 170 테스트, 타입·경계(19 소스)·명세·빌드(1877 모듈) 통과. 2D 숫자·색·전류, 고정 범위, 기준점 변경, 등전위, 제안/직접 경로와 양방향 강조를 확인했다. 3D 카메라·축척·예제 변경 시 재맞춤, FIX-05 열린 스위치 단절, FIX-07 전위 미정과 높이 제외를 확인했다. 모바일 390×844 페이지 가로 넘침 없이 읽힘. Three 지연 청크 501.87 kB(압축 126.72 kB)의 비차단 크기 경고가 있다. 앱 기원 콘솔 오류는 없었고 확장 프로그램 메시지 채널 오류 2건은 앱과 구분했다. 실제 학생·교사의 의미 이해와 시간 목표는 미검증이다.

- 단계 4 중간: 측정 모듈 집중 검사 41개 통과. 브라우저에서 FIX-02 ±6 V, R2 임시 전류계 1 A, 부하 9 Ω/전체 회로 0 Ω, 기록·CSV 트리거, KCL·KVL, 21개 조건 그래프를 확인했다. 모바일 기록 버튼의 흰 바탕/흰 글자 문제를 수정했으며 최종 검증 중이다.

- 단계 4 최종: 6개 파일 211 테스트, 타입·경계(22 소스)·명세·빌드(1880 모듈) 통과. FIX-06/07/08에서 수치 미정과 한국어 진단, 모바일 기록 버튼 대비 수정, 390×844 가로 넘침 없음과 콘솔 오류 0을 확인했다. CSV 다운로드 동작은 트리거까지 확인했으며 실제 파일 내용은 모듈 테스트로 검증했다.

- 단계 5 중간: 표기·주석·출력 집중 검사 14개와 타입 검사 통과. 브라우저에서 문제/정답 표시, 주석 편집·실행 취소·다시 실행, 흑백·투명·여백 64·4배 PNG를 확인했다. 실제 PNG는 정답 2876×1812, 문제 2876×1908로 디코딩되었고 투명 배경과 문제 표기가 확인됐다. 클립보드 쓰기는 성공했으며 외부 문서 붙여넣기는 미검증이다.

- 최종 시각 검증(메인 Astra): 데스크톱의 낮은 창에서 전위 화면이 작아지고 상태줄이 밀리는 점을 수정했다. 초기 회로 맞춤, 좁은 세로 공간의 그래프 높이·축 글자, 주석 충돌 회피를 보정했다. 3D의 최소 높이와 카메라 투영 경계 맞춤을 수정해 전위 지도 상단 잘림을 해결했다. 측정 탐침 +/−와 6 V 표시, 문제지의 물음표·빈칸·주석 및 실제 PNG를 직접 확인했다. 모바일 390×844의 2D/3D, 네 모드 탭과 PNG를 확인하고 미리보기 오른쪽 잘림을 고쳤다. 실제 PNG 2061×1335 디코딩 및 페이지 client/scroll width 374/374를 확인했다.

- 최종 코드 게이트(검증 Sol): 7개 파일 228 테스트, 타입 검사, 모듈 경계 24 소스, 명세 검증, 1882 모듈 빌드 통과. Three 지연 청크 502.30 kB(압축 126.87 kB)의 비차단 크기 경고가 있다. `git diff --check`에서 공백 오류는 없었다. 마지막 시각 수정 후 전체 코드 게이트를 다시 통과했다.

## 초기 MVP 완료 시점의 상태

단계 0~5 기능 MVP를 완료했다. 최종 시각 검증은 사용자의 변경 지시에 따라 메인 Astra가 직접 수행했고, 이후 검증 Sol은 코드 검사만 수행했다. Git 원격은 `https://github.com/Cho-WH/circuit.git`, 브랜치는 `codex/mvp`이며 구현은 작업 트리에 보존했다. 이 초기 완료 시점에는 배포·push·PR을 하지 않았다. 이후 GitHub Pages 게시 설정을 추가했으며, 현재 작업 트리의 게시 상태는 [현재 작업 현황](current-phase.md)을 따른다.

[요구사항별 검증 범위](../testing/mvp-coverage.md)에 실제 사용자 연구와 도구 제한을 정리했다. [빠른 시작](../ux/quick-start.md)에서 실행·사용·저장·출력을 안내한다. 공유 및 학생 활동 배포는 단계 6, 실제 교실 사용성 검증은 단계 7의 후속 작업이다.

## 후속 — 익명 후기·피드백 게시판 미리보기 (2026-09-23)

- 관련 요구사항: DAT-005, QLT-001. 메인이 직접 구현·검증했으며 서브 에이전트는 사용하지 않았다.

- 삭제는 원문과 삭제 시각을 보존한다. 공개/본인 목록에서 제외하고 개발 모드 관리자 보관함에서만 삭제 표시로 남긴다. 공개 DTO에서 비공개 글·인증 ID·비밀번호 검증 자료를 제외한다.
- 최종 검증: 게시판 계약 15개, React 통합 6개 및 기존 명세·경계 78개로 총 99개 테스트 통과. TypeScript, 모듈 경계 검사, Vite 배포 빌드 통과. 기존 주 앱/3D 청크의 500kB 경고는 남아 있으며 게시판은 별도 지연 로딩 청크다.
- 127.0.0.1:5177의 별도 테스트 저장소에서 데스크톱·390×844 화면, 공개 글 작성·더 읽기, 비공개 글의 본인 목록 이동/공개 목록 제외, 잘못된 비밀번호 거부, 삭제 후 공개 목록 제외·관리자 원문/삭제 표시, 새로고침 영속성, Escape 닫기와 호출 버튼 초점 복귀를 확인했다. 작성·삭제 후 초점 복귀 문제를 수정하고 통합 테스트로 재검증했다.
- 검증 중 다른 회로 편집 파일의 HMR 훅 순서 오류가 발생하여 새로고침 후 게시판 흐름을 다시 검증했다. 실제 휴대전화 하드웨어·서버 권한·원격 동시성은 미검증이다.
- Firebase 연결/운영 관리자 인증은 수행하지 않았다. 현재 로컬 미리보기이며 브라우저 저장소는 보안 경계가 아니다. 후속 서버 인증, 권한, 비밀번호 확인, 원자적 한도 처리 조건은 ADR-014와 `docs/architecture/feedback.md`에 기록했다. 회로 문서 저장 형식과 물리 계산은 변경하지 않았다.

## 후속 — 안내 문구 제거와 교차 직접 토글 (2026-09-23)

- 사용자 최신 지시에 따라 배선 호버·클릭 버블, 하단 상태 안내와 편집 힌트줄을 제거했다. 터치 확정/취소는 체크·닫기 아이콘, 겹친 후보는 원래 위치에 선으로 대응하는 원형 아이콘으로 제공한다. 접근성 이름은 유지한다.
- 선택 도선의 분기 후보는 원형 표시와 화면 기준 34px의 반투명 가지 도선이다. 가로 도선은 포인터 위/아래, 세로 도선은 왼쪽/오른쪽에 가지를 표시한다.
- 전환 가능한 교차점 자체의 클릭·탭·Enter/Space로 연결을 토글한다. 버블은 클릭을 가로채지 않고 현재 상태 `연결` 또는 `비연결`만 표시한다. 배선 중 연결된 교차점 클릭은 도착 연결로 처리한다. T자·참조된 분기점의 분리 제한은 유지한다.
- 검증: 배선 상태·Canvas 관련 32개 테스트 통과, 최종 TypeScript 통과. 브라우저에서 교차 직접 연결→직접 비연결, 일반 문구 없는 분기선 표시와 체크/닫기 아이콘을 확인했다. 전체 테스트·빌드 반복은 생략했다. 요구사항·ADR-013·상호작용·빠른 시작 문서를 최신 조작에 맞췄다.

## 후속 — 현황 문서와 중복 계획 정리 (2026-09-23)

- 현재 구현·커밋/배포 보류·남은 범위는 현재 작업 현황에 모으고 README와 문서 색인을 진입점으로 정리했다. 초기 MVP와 후속 검증 수치, 이전 배선 UI는 실행 당시의 이력으로 구분했다.
- 완료된 measurement-plan.md의 측정 계약은 모듈 구성·측정 규약에, worksheet-plan.md의 표시 속성·출력 계약은 ADR-012에 통합한 뒤 두 계획서를 삭제했다. UX 검토 보고서·14개 화면·측정 JSON과 기존 검증 근거는 보존했다.
- 현재 네 가지 모드와 문맥 배선·터치 조작을 문서에 반영하고, 활동 배포·시작 체험 등의 미래 구상을 현재 사용법과 구분했다. 실행·검증·Pages 운영 설명은 개발 운영 문서로 모았다.
- 문서 검증: Markdown 49개에서 로컬 링크 130개·앵커 3개, 요구사항의 문서 참조 5개를 확인했으며 누락 0건이다. 삭제한 계획서로 향하는 링크도 없다. 문서만 정리했으므로 코드 테스트·빌드는 재실행하지 않았다. 커밋·푸시는 사용자 요청으로 보류했다.

문서 정리 후 사용자가 커밋·푸시 재개를 승인했다. UX·문맥 배선·후기 로컬 미리보기와 문서 정리를 함께 반영한다. 기존 검증은 반복하지 않으며 배포 성공은 Actions 결과와 구분한다.

## 후속 — 탐구 예제 배치 정리 (2026-09-23)

- 관련 요구사항: EDT-002/003, VIS-001/005. 원인은 fixture 좌표의 일괄 확대와 단자 방향을 고려하지 않은 기본 꺾임이었다. 혼합 회로의 전원 관통, 브리지의 저항·라벨 관통과 중복 배선을 실제 화면에서 확인했다.
- 예제별 부품 위치·회전·분기점·꺾임을 선언하는 배치표로 교체했다. 단일·직렬·열린 스위치·기준점 이동은 정돈된 사각 루프, 병렬은 같은 폭의 두 수평 가지와 하단 중앙 전원, 혼합은 상하 대칭 병렬부와 바깥쪽 복귀선, 브리지는 좌우 저항 쌍과 중앙 연결로 구성했다.
- 앱 목록은 FIX-01/02/03/04/05/09/10의 7개로 한정했다. 진단 연습 3개와 연결 연습, 관련 그룹·사용 안내를 제거했다. 원래 진단·배선 fixture는 회귀 테스트에 필요하므로 유지하며 앱 예제 모듈에서 가져오지 않는다.
- 연결 ID·전기 속성·기준점·저장 형식은 유지한다. 기존 자동 저장 회로를 강제로 재배치하지 않는다. 기존 예제를 열어 둔 사용자는 다른 예제를 선택한 뒤 원하는 예제를 다시 불러오면 새 배치가 적용된다.
- 검증: 예제 16개 검사와 기존 Canvas 20개, 총 36개 통과. 7개 모두에서 컴파일·해석 결과 보존, 원본 불변, 재배치 안정성, 직교 배선, 교차·중복 선분·기호 관통 없음과 병렬 대칭을 확인했다. 1280×720 브라우저에서 7개를 하나씩 열어 기호·값·분기·외곽 배선과 기준점 표시를 확인했다.
- Vite 프로덕션 번들 생성 통과, 기존 500 kB 청크 경고 유지. 전체 TypeScript 검사는 동시에 변경 중인 FeedbackAdminPage.tsx의 admin/adminPreview 속성 불일치(TS2339)로 실패했다. 예제 관련 오류는 보고되지 않았으며 별도 관리자 작업은 수정하지 않았다. 전체 테스트는 반복하지 않았다.

### 접지 도구 표시 통일

사용자 요청으로 기준점 도구를 회로의 접지 기호와 같은 형태의 아이콘 및 `접지(0V)` 이름으로 변경했다. 버튼 문구·툴팁·접근성 이름과 빠른 시작 문서를 맞췄으며 기존 기준점 지정 동작은 유지한다. 전체 TypeScript 검사와 실제 브라우저 표시 확인을 통과했다. 단순 표시 변경이므로 테스트·빌드는 반복하지 않았다.
