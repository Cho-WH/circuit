# 다이오드 확장 기획과 구현 순서

- 결정일: 2026-10-05
- 상태: 설계 확정, 구현 전
- 기준 구현: `codex/mvp`의 1차 MVP 0.1.0, 회로 v5·측정 기록 v4
- 기술 결정: [ADR-026](../../decisions/ADR-026-diode-boundary-analysis.md)

## 1. 목적과 완료 경험

일반 수업에서는 0.7 V 다이오드로 전압·전류를 계산하고, 직결·병렬·작은 저항 회로에서는 학생이 실제 연결의 문제를 관찰하고 수정한다.

완료 경험은 **만들기에서 최소 사전 경고 → 분석 진입 또는 가변저항 경계 통과 → 작동 중 과부하/파손 연출 → 회로 수정 → 재분석**이다. 별도의 설명 화면이나 수정 정답 버튼을 추가하지 않는다.

회로는 대부분 이상 조건으로 다룬다. 필요한 경계에서는 전원 내부저항과 다이오드의 유한한 도통 기울기를 사용한다. 열 축적·냉각·온도·실제 파손 시간은 계산하지 않고, 검증된 DC 결과에 따른 교육용 사건을 연출한다.

## 3. 첫 버전 범위

### 포함

- 일반 다이오드의 A/K 방향·공통 기호·값 표시·저장·출력.
- 정확한 0.7 V 교과서 해석과 구간선형 부품 특성 해석.
- 해 없음·비유일·계산 미확인을 내부적으로 구별하는 엔진.
- 직결·병렬·역전압·전력 부담에 대한 명시적 프로필 판정.
- 만들기의 노랑/빨강 사전 느낌표와 최소 클릭 안내.
- 분석 정상·과부하·파손 사건·수정 복귀.
- 가변저항의 임계 통과, 자동 왕복 중단, 기록·표시의 일관성.

### 이번에 구현하지 않음

- 열 상태 적분, 실제 ℃, 냉각 시간, 열폭주·파손 시각 예측.
- 파손 후 개방/단락 회로 해석과 연쇄 고장.
- 실제 전지 화학·소모·도선 길이 저항·접촉저항.
- LED 발광, 역항복 전류, 트랜지스터·축전기·정전류 전원의 동시 구현.
- 다이오드 회로의 새 저항 측정 방식, 새 계기·범용 실험 도구 프레임워크.

## 4. 현재 코드에서 변경이 필요한 지점

| 영역 | 작업 |
|---|---|
| `domain`, `component-library`, 공통 기호 | 다이오드 단자 역할·프로필·현재 지원 형식을 추가하고 화면/출력에서 공유 |
| `connectivity` | 기존 ID 연결을 유지하며 계산용 내부 요소를 제작 문서와 분리 |
| `simulation` | 다이오드 stamping·정확 상태 탐색·계수 분류·제약 검증·공통 예산 확장 |
| `measurement` | 전압차·KCL 결합 직접 질의, 비유일/부분 유효 결과, 다이오드 Ω 측정 누락 방지 |
| `diagnostics` | 계산 진단과 부품 위험을 코드·요소 ID로 구별 |
| `app/analyze`, 분석 세션 | 현재 리비전의 사전 평가, 모델 선택, 위험 사건과 빨강 잠금 |
| 기존 진단 팝업 | 왼쪽 위 아이콘의 노랑/빨강과 짧은 원인 표시 |
| `app/parameters` | 현재값 판정, 자동 왕복 중단, 이산 위치 확인, 조작 후 상태 유지 |
| `visualization`, `current-view`, `potential-3d` | 같은 해석 결과, 과부하 국소 효과, 파손 시 현재값 중단, 기본 회로 보존 |
| 측정표·저장·출력 | 모델/프로필 조건 보존, 파손 UI는 저장·출력 원본에 포함하지 않음 |

새 계산기·새 전체 화면을 따로 만들지 않는다. 실제로 공유하는 두 전기 모델과 분석 세션 경계에 필요한 최소 타입만 추가한다.

## 5. 단계별 구현

### D0 — 규범·프로필·기준 회로 고정

작업:

- EDT-001/004/007/008, SIM-001~008, MEA-001~003, VIS-001~007, DAT-001~003, TCH-001~003의 다이오드 확장 조항과 관련 물리 규칙을 갱신한다.
- 저장소 규범 우선순위를 지키며 ADR-003/010/011/015/020~025의 적용 범위·확장 계약을 같은 변경에 맞춘다.
- 전원·일반 다이오드·저항의 내장 프로필 ID/버전, 전기 특성, `continuousMax`, `damageAt`, 근거·적용 범위를 표로 확정한다.
- [시험용 프로필](../testing/diode-cases.md)은 수치 검증에만 쓴다. 기본 제품값은 교육용 가정 또는 실제 부품 자료를 명시하여 따로 정한다.
- 현재 회로 v5·기록 v4를 임의로 재해석하지 않는다. 새 필드가 필요한 현재 지원 버전과 왕복·지원 밖 입력 거부 계약을 함께 고정한다. 기존 방침대로 불필요한 과거 형식 변환은 추가하지 않는다.
- 한국 고등학교 교과서·공공 수업 자료를 확인해 다이오드 기호·A/K 표기 근거를 정하고 공통 기호에 반영한다.

종료 조건:

- 구현자가 임의의 전류 상한·파손 배수를 고를 필요 없이 프로필과 경계 시험을 실행할 수 있다.
- 이 단계의 요구사항·공개 타입·스키마·기준 회로가 일치한다.
- 수치가 확정되지 않은 프로필로 노랑/빨강 제품 동작을 출시하지 않는다.

### D1 — 정확한 다이오드 엔진

작업:

- 0.7 V 상보 조건과 ON/OFF 후보 선형계.
- 모순·유일·아핀 해 분류, 부등식 검사, 전체 허용 결과의 관측량 질의.
- 적용 범위가 확인된 전압 제약 사전 검사.
- 후보·부등식 증가를 포함하는 전체 요청 예산과 수치 근사 검증.
- 기존 선형 저항 fixture와 문서 원본 불변성 유지.

종료 조건: 순방향·역방향·문턱·직렬 OFF의 부유 중간 전위·병렬 전류·전원 모순 사례를 정확히 구별한다. 고정 후보 순서와 요청 예산으로 결과·품질·진단을 재현한다. warm start는 이 계약을 검증한 뒤 검토할 후속 최적화다.

### D2 — 부품 모델과 위험 판정

작업:

- 전원 내부저항과 양의 다이오드 도통저항을 기존 해석 경로에 연결.
- 직결·대칭 병렬·고정 편차의 유한 전류·전압·전력 검증.
- 정상/노랑/빨강 순수 판정과 수치 품질 검사.
- 교과서/부품 모델 선택, 연속 조절의 세션 조건 고정.
- 현재값으로 만드는 사전 평가와 분석 진입 결과의 일치.

종료 조건: 이상 해 실패를 곧바로 파손시키지 않는다. 정격에서 전류를 잘라 주지 않는다. 위험 근거와 화면에 전달하는 값이 같은 부품 모델 결과다.

### D3 — 만들기 경고와 분석 사건

작업:

- 기존 왼쪽 위 진단 아이콘을 이용한 사전 경고.
- 분석 진입·임계 통과의 노랑/빨강 연출과 짧은 원인.
- 빨강 사건의 단일 실행, 값/기록 잠금, 늦은 결과 폐기.
- `회로 수정` 복귀와 원본·현재값·시야 보존.
- 자동 왕복의 첫 위험 중단, 노랑 수동 조절, 동작 줄이기.

종료 조건: [UX 수용 사례](../testing/diode-cases.md)의 상태 전이가 성립하며 만들기·기록 보기·출력에서 파손 연출이 발생하지 않는다.

### D4 — 측정·3D·저장·출력 통합

작업:

- 부분적으로 확정 가능한 전압·전류, Ω 미지원 경계.
- 모델/프로필을 포함한 측정 조건·기록·CSV.
- 전위 색·높이·전류의 결과 일치와 중간 극값이 잘리지 않는 축척.
- 공통 기호 출력과 파손 UI의 원본 분리.
- 대표 데스크톱·모바일 화면에서 짧은 경고·파열·복귀 검증.

종료 조건: 교사가 정상 수업 회로를 계산·측정·출력하고, 학생이 경계 회로를 분석·수정·재분석하는 두 흐름을 끝까지 수행한다.

## 6. 다음 확장

LED는 D4 이후 전기 프로필·밝기·전류/전력/역전압 경계를 추가한다. 밝기 포화가 과부하를 숨기지 않게 같은 사건 체계를 사용한다. 일반 다이오드에 발광을 붙이지 않는다.

정전류 전원은 전지의 내부저항과 구별되는 별도 출력 특성으로 추가한다. 항복·전류 제한·온도 피드백을 넣을 때에는 기존 해 존재 판정의 적용 범위를 다시 증명하거나 제한한다.

## 7. 검증과 완료 기록

문서 설계의 완료와 기능 구현의 완료를 구별한다. 각 단계에서 변경에 직접 관련된 기존 검사와 [새 수용 사례](../testing/diode-cases.md)를 실행하고, 결과는 [작업 추적](mvp-tracker.md)에 간단히 기록한다. 현재 문서의 기대 결과를 구현 테스트 통과로 기록하지 않는다.

기존 단계 6 활동·공유, 단계 7 교실 알파와 실기기 과제는 별도 계획으로 남는다. 이 설계 확정은 해당 기능들의 구현 완료나 모든 후속 기능의 동시 착수를 뜻하지 않는다.
