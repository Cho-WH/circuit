# 다이오드 직류 엔진 설계

상태: [ADR-026](../../decisions/ADR-026-diode-boundary-analysis.md)에 따른 확정 설계, 구현 전.

현행 [이상 DC 모델](ideal-dc-model.md)과 [정확 연산 명세](exact-dc-arithmetic.md)를 확장한다. 위험 색상·연출은 [부품 경계](circuit-operating-boundaries.md)와 [UX](../ux/diode-analysis.md)의 책임이다. 이 문서의 미정·모순·예산 상태를 학생용 문구로 그대로 노출하지 않는다.

## 1. 범위와 불변식

- 독립 직류 전압원, 양의 선형 저항, 이상 도선·스위치·계기, 고정 강하 다이오드를 지원한다.
- 일반 다이오드의 교과서 강하는 정확히 `7/10 V`다. 역누설·항복·접합용량·온도 변화는 이 모델에 없다.
- 같은 문서와 해석 옵션은 같은 물리값·품질·진단·위험 결과를 반환한다. 첫 구현은 실행 이력과 무관한 고정 후보 순서를 사용한다.
- `SimulationEngine.solve(CompiledCircuit, SolveOptions)`와 기존 MNA·rational 경계를 확장한다. UI가 행렬·상태 마스크를 다루지 않는다.
- 구조·부품 값·고정된 프로필 차이는 모델 입력, 해석 결과·파손 모습·연출 시간은 문서 밖 상태다.
- 0 Ω 축약은 기존 규칙을 따르며 다이오드를 도선으로 축약하지 않는다.

## 2. 단자와 다이오드 식

단자 역할 `anode`(A), `cathode`(K)를 명시한다. 회전·배열 순서·화면 좌표로 극성을 정하지 않는다.

$$
v_D=V_A-V_K,\qquad i_D: A\to K
$$

교과서 모델은 다음 상보 조건이다.

$$
i_D\ge0,\qquad s_D=7/10-v_D\ge0,\qquad i_Ds_D=0
$$

| 후보 상태 | 선형 식 | 추가 검사 |
|---|---|---|
| ON | `v_D = 7/10` | `i_D >= 0` |
| OFF | `i_D = 0` | `v_D <= 7/10` |

`v_D = 7/10, i_D = 0`은 두 후보에 속하지만 같은 물리적 경계 상태다. 마스크 수를 해의 수로 해석하지 않는다. 이 경계에서 양의 흐름을 만들어 표시하지 않는다.

## 3. 계산 절차

1. 문서·단자·연결을 검증하고 0 Ω 연결을 기존 규칙대로 컴파일한다.
2. 적용 범위가 맞으면 §5의 정확한 전압 제약 검사를 수행한다.
3. 다이오드 ID에 따른 고정 순서로 상태를 탐색한다. 이전 해를 먼저 쓰는 warm start는 요청 예산·품질·진단의 결정론을 유지하는 검증을 마친 뒤 도입할 후속 최적화다.
4. 각 후보의 MNA 선형계를 계수에 따라 모순·유일·자유도 존재로 구별한다.
5. 선형계의 결과에 ON/OFF 부등식을 적용하여 실제 허용되는 후보인지 확인한다.
6. 원래 회로식의 KCL, 전원 전압식, 저항식, 다이오드 조건을 재검증한다.
7. 허용 해 전체에서 필요한 물리량을 질의하여 확정값과 비확정값을 구별한다.

작은 회로에서는 모든 ON/OFF 후보를 열거하는 구현을 기준으로 삼을 수 있다. 이후 후보 재사용·가지치기를 추가하더라도 결과와 수용 기준은 같아야 한다. 검증하지 않은 후보나 시간 초과를 성공으로 반환하지 않는다.

## 4. 특이계와 허용 해 집합

현재의 특이 행렬 `null` 경로는 다음 세 가지로 분리한다.

- **모순:** `0 = nonzero` 행이 존재.
- **유일:** 일관되고 자유변수가 없음.
- **자유도 존재:** 일관되며 다음과 같은 아핀 해가 존재.

$$
x=x_0+Nz
$$

다이오드 조건을 대입하면 남은 제약은 `Hz <= h` 형태다. 계수가 부족하더라도 부등식이 자유도를 없앨 수 있다. 반대로 임의로 자유변수를 0으로 놓은 값은 관측값으로 확정하지 않는다.

첫 구현은 정확한 계수 소거와 예산이 있는 Fourier–Motzkin 소거 등 작은 선형 부등식 검사로 실현 가능성과 질의 범위를 구한다. 중복 제약 정규화·모순 조기 발견·생성 제약 수 제한을 함께 둔다. 일반 목적 최적화 프레임워크를 별도 도입하지 않는다.

### 전체 해를 한 허용집합으로 표현하는 최적화

위 수동 회로 범위에서 검증된 한 해를 얻었을 때 다음 관계를 이용할 수 있다.

- 모든 양의 저항의 양단 전압·전류는 다른 해에서도 같다.
- 기준 해에서 `i_D > 0`인 다이오드는 모든 해에서 `v_D = 7/10`이다.
- 기준 해에서 `v_D < 7/10`인 다이오드는 모든 해에서 `i_D = 0`이다.
- 나머지 경계 소자는 KCL·전원식과 `i_D >= 0`, `v_D <= 7/10`으로 제한한다.

근거는 두 해의 차이에 대한 Tellegen 관계와 저항·다이오드의 단조성이다. 저항 항 `Δv²/R`과 다이오드 항 `Δv Δi`는 음수가 아니며 그 합은 0이므로 각각 0이다. 기준 해에서 고정된 저항 전압과 위 활성 조건을 유지한 선형 허용집합에서는 경계 다이오드의 상보성도 전체 회로식에 의해 성립한다.

이 최적화는 기존의 전 상태 열거를 대체하기 전에 작은 회로의 전체 후보 해와 대조한다. 능동소자·음저항·다른 비선형 모델에 이 성질을 일반화하지 않는다.

### 물리량을 직접 질의

전압은 `V_red - V_black`, 도선 전류는 필요한 단자 전류의 KCL 선형결합을 전체 허용집합에서 평가한다. 개별 항이 비유일하다는 이유만으로 그 차이·합도 비유일하다고 판단하지 않는다.

- 같은 net의 전위차는 정확히 0 V다.
- OFF가 확정된 다이오드의 전류는 정확히 0 A다.
- 절대 전위가 정해지지 않아도 두 점 사이 전압은 정해질 수 있다.
- 병렬 다이오드 전류가 개별적으로 비유일해도 합계는 정해질 수 있다.
- 이상 도선 고리의 각 도선 전류는 여전히 비유일할 수 있다.

내부 질의 결과는 확정값, 범위/비유일, 확인 불가를 구별한다. 아핀 기저와 부등식 행렬은 엔진 내부에 둔다. 부유 전위를 임의의 0 V·색·3D 높이로 채우지 않는다.

## 5. 이상 전압 제약의 사전 검사

적용 대상은 이상 도선·0 V 연결, 양의 저항, 독립 이상 전압원, 고정 강하 다이오드다. `V_a - V_b <= c`를 간선 `b -> a`, 가중치 `c`로 표현한다.

| 요소 | 차분 제약 간선 |
|---|---|
| `V_a - V_b = E`인 전원 | `b -> a: E`, `a -> b: -E` |
| 다이오드 | `K -> A: 7/10` |
| 이상 도선 | 양방향 가중치 0; 연결 축약 후 생략 가능 |
| 양의 저항 | 전압 크기의 별도 제약 없음 |

정확한 Bellman–Ford 음수 순환은 이상 DC 해가 없다는 증거다. 관련 소자 ID를 진단에 보존한다.

이 범위에서는 전압 제약의 실현 가능성으로 해 존재를 확인할 수도 있다. 실현 가능한 전위에서 `Σ (V_a - V_b)²/(2R)`를 최소화하는 볼록 이차문제의 KKT 조건이 저항 KCL과 다이오드 전류·상보 조건을 제공하기 때문이다. 이는 가지 전류의 유일성이나 부품의 안전성을 보장하지 않는다.

전류원, 정전류 제한 전원, 항복 구간, 트랜지스터 등으로 범위를 넓힐 때 이 완전성 판정을 그대로 사용하지 않는다. 음수 순환을 발견해도 파손으로 바로 연결하지 않고 부품 모델을 검토한다.

## 6. 유한한 부품 특성 모델

전원은 기전력 `E`와 양의 내부저항 `R_s`로 컴파일한다.

$$
V_{terminal}=E-R_sI_{source}
$$

여기서 `I_source`는 전원의 +단자에서 부하로 나가는 공급 방향을 양으로 한다. 기존 MNA의 전압원 가지전류를 사용할 때는 이 공급 전류 규약으로 부호를 변환한다.

필요한 내부 절점과 저항은 계산 전용 요소이며 제작 문서에 추가하지 않는다. 모든 해당 전원에 같은 선택된 프로필 정책을 적용한다.

다이오드는 다음 식으로 확장한다.

$$
i_D\ge0,\quad V_0+R_{on}i_D-v_D\ge0,\quad i_D(V_0+R_{on}i_D-v_D)=0
$$

- ON 행은 `v_D - R_on * i_D = V_0`다.
- OFF는 `i_D = 0`, `v_D <= V_0`다.
- `R_on > 0`이며 도통 기울기를 수치 수렴용 임의 `gmin`으로 대신하지 않는다.
- `V_0`는 구간의 절편이다. 특정 전류에서의 순방향 전압과 구별한다.
- 동일한 두 부품은 대칭 분배, 서로 다른 저장된 특성은 그 차이에 따른 분배를 만든다.
- 전원 내부저항만 추가하고 다이오드 강하를 완전히 평평하게 유지하면 병렬 분배의 비유일성이 남는다.

첫 버전은 OFF/ON 두 구간이면 충분하다. 후속의 단조 PWL 곡선도 모든 도통 구간의 기울기를 양수로 유지한다. 상태별 선형계·검증·예산 처리를 공유한다.

정격은 회로식에 전류 상한으로 넣지 않는다. 전류·전압·전력은 해당 부품 모델에서 함께 구하고 [경계 판정](circuit-operating-boundaries.md)에 전달한다. 내부저항이 있다고 부유 OFF 절점 전위나 이상 도선 고리까지 모두 유일해진다고 가정하지 않는다.

## 7. 계산 예산과 결과 품질

[ADR-025](../../decisions/ADR-025-bounded-approximate-dc.md)의 정확 연산 예산을 요청 전체에 적용한다. 후보를 바꿀 때 비트·GCD 예산을 초기화하지 않는다. 상태 후보 수·생성 부등식 수·행렬 할당량도 같은 요청의 비용으로 제한한다. 추가 상한은 구현 성능 시험에서 고정한다.

- 수치 근사는 선택한 물리 모델을 그대로 푸는 경로다.
- 부품 특성 모델 선택은 물리 모델의 선택이며, 계산 예산 초과와 별개다.
- 잔차가 작다는 것만으로 다이오드 부등식·상태가 유효하다고 승인하지 않는다.
- 근사 오차가 0·부호·위험 임계를 가로지르면 확정된 사건으로 만들지 않는다.
- 탐색 미완료·예산 초과·검증 실패를 이상 해 부재나 물리적 과부하로 변환하지 않는다.
- 독립 해석 부분의 유효 결과는 보존할 수 있으나, 파손 사건 이후의 전체 분석 중단은 별도 UX 정책이다.

결과에는 `physicalModel`, `profileRevision`, `arithmeticQuality`를 구별하는 출처가 필요하다. 기존 quality의 의미를 물리 모델 선택으로 덮어쓰지 않는다. 정확 유리수로 푼 부품 모형도 실제 부품에 대한 정밀 예측은 아니다.

## 8. 측정·표시 연결의 변경

| 현재 경로 | 다이오드 확장의 계약 |
|---|---|
| 특이계에서 모든 결과를 비움 | 모순·비유일·확정 가능한 질의를 분리 |
| 개별 전위 둘을 읽고 뺌 | 전압차 자체를 허용 해 집합에서 질의 |
| 개별 가지 전류를 읽고 도선 KCL 합산 | 필요한 합 자체를 질의하여 상쇄·합계 확정을 보존 |
| 모든 측정을 전역 오류로 차단 | 질의와 관련된 해석 부분의 유효성을 판단 |
| 저항만 추려 1 V 시험원으로 등가저항 계산 | 다이오드를 누락한 결과 반환 금지 |
| 가변저항 범위 양 끝으로 축척 확정 | 다이오드 상태 전환에 따른 내부 극값을 고려 |

### 등가저항의 첫 지원 범위

선택 포트에 관련된 해석 부분에 다이오드가 있으면 기존 선형 등가저항 값을 확정하지 않는다. 사용 중인 다이오드를 삭제하거나 한 작동점의 ON/OFF 상태로 고정해서 저항값을 만들지 않는다. 다이오드가 없는 독립 저항 부분에는 기존 측정을 유지한다.

다이오드 시험, 정적 `V/I`, 소신호 미분저항은 서로 다른 측정이다. 이번 버전에 함께 추가하지 않고 짧은 미지원 안내만 제공한다. 시험 전원의 가상 해석과 과거 기록 보기는 파손 연출 트리거가 아니다.

### 가변저항과 축척

현행 ADR-023의 양 끝 극값 근거는 한 저항을 변화시키는 선형 회로에 한정된다. 다이오드 상태가 변하면 중간의 전위·가지 전류가 양 끝보다 커질 수 있다.

- 현재의 검증된 값을 반드시 표시 범위에 포함한다.
- 한 조절 중에는 범위를 함부로 축소하지 않고 필요할 때 확장한다.
- 그림의 굵기·밝기가 포화해도 물리값과 위험 판정은 포화시키지 않는다.
- 범위 양 끝만으로 모든 중간값의 안전을 보장하지 않는다.
- 위험 사건은 적용된 정확한 매개변수 값에서 판단하며 입력·사건 처리는 [UX 규칙](../ux/diode-analysis.md)을 따른다.

## 9. 확장 준비

부품 등록은 기호, A/K 단자, 편집 속성, 전기 모델, 출력 표기를 분리한다. LED는 전기 프로필·정격·밝기 표현을 이 경계에 추가하며 일반 다이오드에는 발광을 붙이지 않는다. 역항복·정전류 전원·열 피드백을 추가할 때 모델의 수학적 적용 범위와 측정 계약을 다시 검토한다.

수용 수치와 퇴행 방지 사례는 [다이오드 수용 사례](../testing/diode-cases.md), 오픈소스 근거는 [참고 조사](../research/diode-engines.md)에 둔다.
