# 이상적 직류 물리 모델

## 적용 범위

MVP는 선형 직류 저항 회로를 다룬다. 모든 계산과 사용자 설명은 아래 모델을 기준으로 한다.

| 요소 | MVP 모델 | 후속 확장 |
|---|---|---|
| 직류 전원 | 지정 전압을 유지하는 이상적 전압원 | 내부저항, 전압 제한 |
| 도선 | 저항 0 Ω, 같은 `net` 전체가 같은 전위 | 도선 저항과 길이 |
| 저항 | 온도에 무관한 선형 저항 | 허용오차, 온도 계수 |
| 열린 스위치 | 두 단자 사이 연결 없음 | 누설, 접점 모델 |
| 닫힌 스위치 | 이상적인 0 Ω 연결 | 접촉저항, 바운스 |
| 전압계 | 무한대 입력저항 | 유한 입력저항 |
| 전류계 | 0 Ω 내부저항 | 내부저항, 퓨즈 |
| 전구 | MVP 제외 또는 고정 저항성 부하로 명시 | 온도에 따른 비선형 저항 |

서로 다른 모델을 설명 없이 섞지 않는다. 실제 특성을 일부 반영하는 경우 화면에 `실제 특성 포함`을 표시한다.

## 기본 관계

- 저항: `V = IR`
- 부품 전력: 수동 부호 규약에서 `P = VI`
- 분기점: 유입 전류의 합과 유출 전류의 합이 같다.
- 폐회로: 한 바퀴를 따라 전위 변화의 합이 0이다.

## 수정 절점 해석법

계산기는 절점 전위와 이상적 전압원을 흐르는 전류를 미지수로 둔다.

- 저항 `R`은 두 절점 사이에 컨덕턴스 `G = 1/R`를 더한다.
- 이상적 전압원은 전압 관계식과 전원 전류 미지수를 추가한다.
- 열린 스위치는 두 단자를 연결하지 않는다.
- 닫힌 스위치와 전류계의 0 Ω 처리는 `ADR-003`에서 확정한다.

초기에는 일반 수업 회로의 작은 행렬을 읽기 쉬운 조밀 행렬로 구성한다. 행렬 풀이 구현은 `SimulationEngine` 안에 숨긴다.

## 기준점

절점 전위는 기준점에 따라 달라진다. 기본 제안은 전지 음극 0 V지만 항상 화면에 표시하고 변경할 수 있어야 한다.

기준점을 바꾸어도 다음 값은 변하지 않는다.

- 두 점 사이 전위차
- 가지 전류
- 부품 양단 전압
- 부품 전력

## 전력 부호

- 저항과 같은 수동 부품은 소비 전력을 양수로 보고한다.
- 전원은 공급 전력이 음수가 될 수 있다.
- UI는 `소비`와 `공급`을 구분해 표시한다.
- 표시 반올림값을 물리 검증에 사용하지 않는다.

## 계산 실패와 진단

수치 해를 임의로 만들어 내지 않는다. 다음 조건은 구조화된 진단으로 반환한다.

- `FLOATING_SUBCIRCUIT`
- `SOURCE_SHORT`
- `CONFLICTING_SOURCES`
- `UNCONNECTED_TERMINAL`
- `SINGULAR_SYSTEM`

진단 구조는 [`schemas/diagnostic.schema.json`](../../schemas/diagnostic.schema.json)을 따른다.
