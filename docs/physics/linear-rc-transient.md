# 선형 RC 과도응답과 안정화 규약

상태: 2026-10-22 채택 규약, C0 검증·C1 공개 계약·C2 제품 순수 엔진 반영. 사용자 물리 범위와 평형 전환 선택은 [UX 결정](../ux/rc-transient.md#사용자에게-확인한-결정)을 따른다. [ADR-041](../../decisions/ADR-041-linear-rc-transient.md)·SIM-009는 `accepted`이며 기존 DC 계산 계약을 변경하지 않는다. C1 저장 계약은 [ADR-042](../../decisions/ADR-042-rc-contracts-storage.md)를 따른다. 실행 근거와 수치 한계는 [C0 결과](../testing/rc-c0-results.md)에 둔다.

이 규약은 한 번의 조작 뒤 조건이 고정된 RC 회로에서 전하의 시간 변화와 도달 가능한 평형을 정의한다. UI의 재생 속도·프레임 수와 물리 계산을 분리한다. 초기 전하를 잊거나 계산을 쉽게 만들기 위해 가상의 저항·누설을 추가하지 않는다.

## 지원 모델과 부호

| 요소 | 모델 |
|---|---|
| 축전기 | 일정한 C > 0인 이상적인 비극성 소자. ESR·누설·유전 흡수·정격·파손 없음 |
| 저항·가변저항·저항성 부하 | 구간 내 일정한 R > 0. 0 Ω는 기존 연결 제약으로 취급하며 수치상 작은 저항으로 바꾸지 않음 |
| 전지·직류 전원 | 구간 내 일정한 이상적 전압원. 조작 시 전압 계단 변화 허용 여부를 초기 조건과 함께 검사 |
| 스위치·전환 스위치 | 조작 순간 연결 변경, 이후 고정. 바운스·접촉저항 없음 |
| 도선·전류계 | 이상적인 0 Ω 연결·0 V 제약. 미정인 도선 고리 전류를 임의 배분하지 않음 |
| 전압계·비접촉 측정 | 전류를 끌어오지 않음 |

다이오드·코일·교류·시간에 따라 바뀌는 전원·제어원·조작 중 C 변경은 지원하지 않는다. 축전기가 포함된 첫 버전 문서는 전체를 이 모델로 평가한다. 기존 DC의 부품 프로필에 따른 자동 모델 전환·과부하·파손 판정을 RC 결과에 적용하지 않는다. 전원 내부저항이 필요하면 사용자가 명시적으로 저항을 배치한다.

축전기 단자 a에서 b로 전압과 전류 방향을 정한다. 회전은 이 방향을 바꾸지 않는다.

```text
v_C = V_a - V_b
q_a = C v_C, q_b = -q_a
i_a = dq_a/dt = C dv_C/dt, i_b = -i_a
W_C = (1/2) C v_C²
```

도선 전류 계산에 축전기 단자 전류를 포함해 KCL을 지킨다. 자유전하 표식이 유전체를 통과하는 표현은 사용하지 않는다. 판의 두 전하는 서로 반대이며 외부 공간에 대한 별도 공통 전하·기생 정전용량은 모델링하지 않는다.

## 초기 조건과 조작 직후

첫 분석은 문서의 축전기별 초기 전압을 사용하며 기본은 0 V다. 이후 조작은 이전 구간의 최종 평형 전압을 사용한다. C는 분석 중 고정이므로 이 전압으로 전하를 정할 수 있다. 상태 매핑은 부품·단자 ID 기준이며 새 net 번호·화면 방향으로 매핑하지 않는다.

충격 전류가 없는 유효한 조작에서는 `v_C(0+) = v_C(0-)`다. 저항 전류와 일부 절점 전위는 즉시 달라질 수 있으므로 조작 전 전류를 조작 후 전류의 초기 조건으로 고정하지 않는다.

새 도선·스위치·전원 제약과 모든 축전기 시작 전압이 동시에 성립하는지 검사한다. 전압이 다른 축전기들의 직접 병렬 연결, 충전된 축전기의 직접 단락, 전압이 다른 이상적 전원에 직접 연결처럼 전압 점프를 요구하는 조작은 `RC_IMPULSE_REQUIRED`로 거부한다. 저항 없는 연결을 모두 금지하는 것은 아니다. 이미 같은 전압인 제약 등 일관된 연결은 허용하고, 결정되지 않는 가지 전류만 미정으로 유지한다.

처음 지정한 초기 전압들끼리 KVL에 모순되는 경우는 `RC_INITIAL_CONDITION_CONFLICT`다. 초기 전압을 자동 투영하거나 조용히 수정하지 않는다. 새 조작이 거부되면 이전 회로와 상태를 보존한다.

## 회로식과 상태 축약

연결 컴파일 뒤 MNA 형태 `E z' + K z = b`를 만든다. z에는 절점 전위와 필요한 제약 전류가 포함되므로 E는 일반적으로 특이하다. 따라서 E를 바로 역행렬로 만들거나 모든 축전기 전압을 독립 상태로 가정하지 않는다.

전압원·0 Ω·종속 축전기 제약과 기준 자유도를 먼저 분리하고, 대수 변수를 제거해 독립적인 에너지 저장 좌표 x의 식을 얻는다.

```text
M x' + G x = f
M: 양의 정부호, G: 대칭 양의 준정부호
```

이 수동 RC 형태로 축약됨을 수치 잔차와 구조 검사로 확인한 회로만 해석한다. 축약할 수 없는 입력을 작은 누설을 넣어 강제로 풀지 않는다. 기준점 변경은 전압차·전류·전하를 바꾸지 않는다. 축전기가 연결하는 부분을 단순히 DC 개방으로 나누어 서로 다른 기준 그룹으로 처리하면 안 된다. 동적 제약까지 포함해 기준 그룹과 질의의 유일성을 결정한다.

`M = L Lᵀ`를 사용해 `H = L⁻¹ G L⁻ᵀ`를 구성하면, y = Lᵀx에 대한 감쇠 행렬 H는 대칭이다. `H = U Λ Uᵀ`의 구조를 이용해 지수응답을 평가한다. C0의 수치 변환에는 삼각 선형 풀이를 사용하며, 오차 인증용 M⁻¹은 정확 유리수 풀이로 계산한다. 내부 계산 방법과 수치 검사는 [설계](../architecture/rc-transient.md#계산-파이프라인)를 따른다.

## 최종 평형과 보존되는 전하

평형에서 축전기 전류는 0이지만 축전기 전압은 일반적으로 0이 아니다. 단순 DC 개방 풀이만으로 최종 전압을 결정하지 않는다.

양의 감쇠율에 대응하는 상태는 지수적으로 수렴한다. 구조적으로 감쇠율이 0인 상태는 부유 도체의 보존 전하 등으로 초기값이 남을 수 있다. 예를 들어 외부와 단절된 충전 축전기는 초기 전압을 그대로 유지한다. 이러한 상태는 평형 미도달이나 방전으로 처리하지 않는다.

0 감쇠 상태에 지속적인 구동이 있으면 유한 평형이 없으므로 `RC_NO_FINITE_EQUILIBRIUM`을 반환한다. 구조적으로 0임을 확인하지 못한 작은 양의 감쇠율을 0으로 잘라서는 안 된다. 극도로 느리거나 수치적으로 구별할 수 없는 경우는 계산 미확인으로 보고한다.

최종 평형은 `Gx∞ = f`에 시작 전하에서 유도한 보존 제약을 함께 적용해 결정한다. 개별 절대 전위나 이상적 도선 고리 전류의 비유일성과, 축전기 상태·관측 전압차의 유일성을 구분한다. 가능한 경우 기존 유리수 연산으로 최종값을 구할 수 있지만, 근사 초기 상태에서 유도된 값은 정확값으로 승격하지 않는다.

## 지수응답과 남은 변화의 상한

감쇠 부분의 관측량 y는 아래처럼 계산한다. 여기서 y는 전압 또는 전류 하나이며, 같은 감쇠율의 항은 합쳐 기저 선택에 따른 상쇄 차이를 줄인다.

```text
y(t) = y∞ + Σ a_k exp(-λ_k t), λ_k > 0
B_y(t) = Σ |a_k| exp(-λ_k t)
모든 s ≥ t에 대해 |y(s) - y∞| ≤ B_y(t)
```

B는 실제 차이보다 보수적일 수 있으나 단조 감소한다. 여러 지수항이 잠깐 상쇄되는 시점을 안정화로 오인하지 않는다. 단일 RC에서는 `τ = R_th C`, `λ = 1/τ`이며 B가 실제 남은 차이와 같다. 고립 보존 상태는 y∞에 포함되어 B에 넣지 않는다.

위 부등식은 정확한 계수에 대한 수학적 관계다. C0는 축약·초기 상태·평형을 유리수로 계산하고, binary64 모드 후보의 정확 회로식 잔차에서 모든 시각의 응답 오차 상한 E_y를 유도한다. `B̂_y(t)=Σ upper(|â_k| exp(-λ̂_k t))+E_y`로 실제 남은 변화를 덮는다. 지수 평가는 방향 반올림 구간으로 계산한다. 잔차가 작다는 이유만으로 오차 보증을 주장하지 않으며, [에너지 상한 증명과 적용 조건](../testing/rc-c0-results.md#계산-방식과-오차-상한)을 충족하지 못하면 안정화 시간을 확정하지 않는다.

## 안정화 정책

C0 검증 정책 ID는 `rc-c0-envelope-1`이다. 상대 0.1%는 이번 기획의 기준이며 아래 절대 바닥값과 수치 예산으로 시제품을 검증했다. C1에서 같은 수치의 제품 정책 `rc-envelope-1`과 수치 출처 `rc-modal-1`을 확정했다. 실제 제품 계산 연결은 C2다. 정책의 숫자나 변화 규모 정의를 변경하면 문서·기대값·출처 ID를 함께 갱신한다.

| 항목 | 설계값 | 의미 |
|---|---|---|
| 상대 허용률 r | 0.001 | 이번 조작의 감쇠 변화 규모에 대한 0.1% |
| 전압 절대 허용량 A_V | 1 µV | 미세한 변화가 무한히 상대 오차에 묶이지 않게 하는 바닥값 |
| 전류 절대 허용량 A_I | 1 pA | 전압과 별개의 단위를 가진 바닥값 |
| 관측량별 규모 S_y | Σ \|â_k\| | 인증한 후보 응답의 모드 진폭 합. 정확 고유분해 진폭 합과 동일하다고 가정하지 않음 |
| 관측량별 허용량 ε_y | A_y + r S_y | 안정화 종료 기준 |
| 수치 오차 예산 | ε_y의 최대 1% | 안정화 허용량과 별도로 관리하는 계산 품질 기준 |

상대 기준에 y∞를 사용하지 않으므로 0 V로 방전할 때도 판정할 수 있다. 작은 물리량을 정확한 0으로 바꾸지는 않는다. 이 정책은 ‘변화를 언제 그만 관찰할지’의 기준이며 수치 반올림·전류 방향·과부하 기준이 아니다.

판정 대상 집합은 모든 축전기 전압, 유일한 부품 전압·전류, 같은 동적 기준 그룹 안의 모든 유일한 net 쌍 전압차다. 도선 센서로 유일하게 측정할 수 있는 전류도 포함하거나 가지 전류 오차 합으로 보수적으로 포함한다. 화면에 켜진 계기·탐침만 검사하지 않는다. `q=Cv`인 전하는 C별 전압 허용량으로 대응시키며 독립된 느슨한 기준을 만들지 않는다. 전력은 유도량으로 품질을 전파하며 이 정책이 전력 0.1%를 보장한다고 표시하지 않는다.

모든 대상에서 `B̂_y(T) ≤ ε_y`가 성립하는 보수적인 T를 구한다. 0 시각 검사 → 상한을 두 배씩 확장 → 이분 탐색으로 수렴시키며, 탐색 예산·시간 표현 범위를 넘으면 미확인으로 반환한다. 무작정 5τ, 가장 큰 개별 RC, 최근 프레임 변화량, 벽시계 timeout으로 대체하지 않는다.

절대 바닥값과 계산 오차를 무시할 수 있는 단일 RC에서는 0.1%에 도달하는 시간이 `ln(1000)τ ≈ 6.9078τ`다. R_th=10 kΩ, C=100 µF이면 약 6.91초다. 여러 축전기의 T는 모든 모드·관측량에서 계산하며 `7 × 최대 개별 RC`로 단정하지 않는다.

## 평형 전환의 물리적 의미

T는 관찰을 끝내도 되는 유한 시각이다. 사용자 결정에 따라 T에 도달하거나 넘기기를 누르면 **충분한 시간이 지난 극한 상태 x∞로 명시적으로 이동**한다. 전환 전 유한 프레임의 잔여 전하를 오류 보정처럼 덮어쓰는 것이 아니라, 남은 물리 과정을 생략하는 별도 사건이다.

전환 연출 중간값도 같은 응답의 뒤쪽 시각을 평가한다. 정상 물리 시간 표시와 기록은 잠그고, 마지막 프레임은 `timeKind: equilibrium`으로 구분한다. x∞를 유한한 T의 값으로 기록하지 않는다. 다음 조작은 x∞를 초기 상태로 사용한다. 손실은 모델의 저항에서 t→∞ 동안 발생한 것으로 해석하며 전하 보존 제약을 계속 만족한다.

## 범위와 실패

C·R·전압은 기존 정확 입력을 유지하고 유효한 양수 C 및 유한 입력을 검사한다. 사용자 입력 가능 범위를 임의로 소형 전자부품 범위에 고정하지 않는다. 실제 지원은 축약 가능성·표현 범위·수치 품질·계산 예산으로 판단한다. 기본값과 지원 한계를 혼동하지 않는다.

| 진단 | 조건 | 처리 |
|---|---|---|
| RC_UNSUPPORTED_ELEMENT | 다이오드 등 범위 밖 요소 포함 | 모델 제한 안내, 분석 시작 거부 |
| RC_INITIAL_CONDITION_CONFLICT | 초기 전압과 회로식 모순 | 초기 조건 수정 안내 |
| RC_IMPULSE_REQUIRED | 새 제약이 축전기 전압 점프 요구 | 해당 조작 거부, 명시적인 저항 또는 조건 수정 안내 |
| RC_NO_FINITE_EQUILIBRIUM | 보존 상태에 지속 구동 등 | 평형이 있다고 가장하지 않음 |
| RC_NUMERICAL_UNVERIFIED | 축약·조건수·감쇠율·오차 불확실 | 마지막 유효 상태 보존 |
| RC_BUDGET_EXCEEDED | 크기·연산·탐색 상한 초과 | 계산 범위 안내, 안정화로 오인하지 않음 |

진단은 ADR-042/043의 RC 공개 계약에서 사용한다. C2는 근사 초기 상태를 RC_NUMERICAL_UNVERIFIED로 거부하며 정확 평형의 승계를 지원한다. 실패와 작은 물리값·부유 기준·비유일한 전류를 같은 오류로 합치지 않는다.

## 근거와 검증 연결

회로의 감쇠 시간은 전체 RC 행렬의 특성에 좌우된다는 참고는 Vandenberghe·Boyd·El Gamal의 [RC 회로 지배 시정수 논문](https://web.stanford.edu/~boyd/papers/rc.html)을 따른다. 본 앱의 부유 전하 처리·종료 오차·UX 수치는 이 논문에서 가져온 제품 규칙이 아니라 위에서 정한 설계다.

행렬 지수의 수치 계산 대안은 Al-Mohy·Higham의 [scaling and squaring 논문](https://eprints.maths.manchester.ac.uk/1300/)을 참고한다. 수동 RC에서는 대칭 축약 구조를 우선 활용한다. 외부 코드를 도입할 경우 버전·라이선스·발췌 범위를 구현 때 별도로 기록한다.

초기 조건·과도 계산을 구분하는 비교 자료는 [ngspice 초기 조건 설명](https://nmg.gitlab.io/ngspice-manual/analysesandoutputcontrol_batchmode/initialconditions/ic_setinitialconditions.html)이다. ngspice의 휴리스틱·누설 보정·기본 허용오차를 앱 계약으로 자동 채택하지 않는다. 실행 가능한 수용 조건은 [검증 계획](../testing/rc-transient-cases.md)에 연결한다.
