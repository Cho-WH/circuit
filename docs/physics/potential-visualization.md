# 전위 시각화 규약

전위 색상과 3D 높이는 장식이 아니라 물리 모델의 표현이다. 아래 규칙은 숫자, 색상, 높이, 경로 그래프에 공통으로 적용한다.

## 규칙

| ID | 규칙 |
|---|---|
| PV-01 | 수동 접지만 표시하며 이동·삭제할 수 있다. 자동 기준 기호·하단 설명은 숨긴다. |
| PV-02 | 같은 이상적 도선과 분기점은 정확히 같은 숫자·색상·높이를 가진다. |
| PV-03 | 저항에서 양단 전위 사이의 변화를 표현한다. 이는 집중소자 모델을 교육적으로 펼친 표현임을 설명한다. |
| PV-04 | 열린 스위치의 두 단자는 서로 다른 전위를 가질 수 있고 3D에서 연결되지 않는다. |
| PV-05 | 색상 범례에 최소·최대·0 V를 표시한다. |
| PV-06 | 단일 회로는 자동 범위를 기본으로 하고 비교 활동은 동일한 고정 범위를 사용한다. |
| PV-07 | 미정 전위에 임의 색·높이를 주지 않는다. 독립 기준 정책은 표시된 각 0 V에 대한 상대 전위를 사용하며 기준 간 전압 비교를 금지한다. |
| PV-08 | 색만 사용하지 않고 숫자·부호·선 강조를 함께 제공한다. |

정본은 [`requirements/physics-rules.yaml`](../../requirements/physics-rules.yaml)이다.

## 숫자 전위

앱은 [ADR-033](../../decisions/ADR-033-independent-references.md)에 따라 독립 영역을 계산한다. 탐침 소속 구분은 유지하지만 자동 기준 접지 기호·하단 설명은 표시하지 않는다([ADR-037](../../decisions/ADR-037-manual-ground-display.md)). 같은 색·높이가 회로 사이의 같은 전위를 뜻하지 않으며, 다른 기준 사이에는 전압차·3D 높이 차 눈금·연속 경로 그래프를 만들지 않는다. 실제 전류 자유도·모순·미확인 값은 기준 지정으로 채우지 않는다.

- 주요 절점에 `A 9.0 V`처럼 표시한다.
- 전위 숫자는 일정한 어두운 글자로 표시하고 전위 색은 도선·테두리·연결선에 유지한다. 밝은 색상에서도 숫자를 읽을 수 있도록 한다.
- 수동 접지만 표시한다.
- 두 점을 선택하면 `V_AB = V_A - V_B`를 표시한다.
- 두 점의 순서를 바꾸면 크기는 같고 부호만 반전된다.

## 색상

1. 결정된 절점 전위의 최소·최대 또는 교사가 설정한 고정 범위를 구한다.
2. 전위를 0~1 범위로 정규화한다.
3. 확정된 세 색상표 중 하나를 구간별 선형 보간한다. 기본은 **전체 스펙트럼**(남색 → 파랑 → 청록 → 초록 → 노랑 → 빨강)이며 **파랑 → 노랑**, **검붉은색 → 노랑**도 제공한다. 모든 순서는 낮은 전위 → 높은 전위다. 2D·3D와 범례는 visualization의 같은 색상점을 사용하며, 단일 전위의 범례는 해당 색상표의 중간색 단색으로 표시한다. 색각 차이를 보완하는 숫자·부호·높이 표시는 유지한다.
4. 숫자와 범례를 함께 표시한다.
5. 최소값과 최대값이 같은 경우 단일 전위 상태로 처리한다.

색상바를 누르면 세 색상바와 이름이 있는 메뉴가 열린다. 색상표 선택은 회로 문서 밖의 화면 상태이며 전위·기준점·범위·높이를 바꾸지 않는다. 같은 색으로 비교하려면 색상표와 고정 범위를 모두 맞춘다. 스펙트럼은 색상 구분을 위한 표현이며 명도가 전위에 비례하지 않는다. 승인된 RGB 색상점과 스펙트럼 식은 `src/visualization/palettes.ts`에 보존한다.

부유 영역은 회색 사선, 점선 테두리, `전위를 정할 수 없음` 문구로 표시한다.

## 등전위 강조

절점 하나를 선택하면 같은 `net`의 모든 도선, 단자, 분기점을 함께 강조한다.

표시 예:

> B, C, D점은 같은 이상적 도선으로 연결되어 모두 6.0 V입니다.

## 3D 전위 높이

높이는 다음 식으로 정한다.

`z = scale × (V - V_reference)`

3D 표시의 `scale`은 자동 기본 축척에 사용자 높이 배율(기본 ×1, ×0.25~×3)을 곱한다. 자동 기본 축척은 목표 높이를 0 V를 포함한 전압축 눈금 범위로 나눈 값이다. 모두 0 V이면 평면으로 표시하며 전위 미정 절점은 높이 계산에서 제외한다. 색상 범위 설정은 높이 축척과 독립이다.

목표 높이는 실제 3D 컨테이너와 기본 사선 시점을 기준으로 구한다. 기존 카메라의 바닥 경계 투영을 재사용해 바닥 크기의 약 75%를 유지하고, 화면상 추가 높이는 바닥의 세로 폭 이내로 제한한다. 기존 카메라 여백을 사용하며 겹치는 패널의 가림 영역은 별도로 분석하지 않는다. 목표 높이는 진입 때 정하고 보기 초기화로 갱신한다. 카메라·패널·영역 크기 변경 중에는 유지하며 전압값 변경에는 축척만 다시 계산한다. 자동 축척이므로 서로 다른 회로의 절대 전압은 축 눈금과 숫자로 비교한다.

- `scale`은 교육적 과장값이며 실제 공간 높이가 아니다.
- 2D의 x-y 위치를 유지한다.
- 같은 `net`은 하나의 평평한 높이를 이룬다.
- 전원은 상승 또는 하강으로 표현한다.
- 저항은 양단 전위 사이를 경사 또는 계단으로 연결한다.
- 열린 스위치는 서로 다른 높이의 끊어진 단자로 표시한다.
- 기본 카메라는 직교 투영을 사용한다.
- 높이 안내선은 회로와 여백을 둔 후면(+Y)·왼쪽(-X)을 같은 높이에서 L자로 잇는다. 양 끝에 주요 눈금 숫자를 두고 0 V는 실선, 주요 눈금은 옅은 점선, 그 사이의 작은 눈금은 더 옅은 점선으로 표시한다. 주요 구간을 4~5등분하되 작은 눈금에는 숫자를 붙이지 않는다. 정면에서는 같은 높이의 수평선으로 읽히며 시점에 따라 위치를 바꾸지 않는다.

## 전압 탐침과 3D 높이 차

2D에서 놓은 탐침의 x-y 위치를 유지하고 접촉 net의 높이에 빨강·검정 표식을 둔다. 두 점에서 같은 높이의 보조선을 치수선까지 연결하며 치수선 양 끝은 같은 x-y를 가진다. 표시값은 기존 측정 API의 V_red − V_black이고 화면 거리로 계산하지 않는다. 0 V는 높이 차 0, 미연결·전위 미정은 확정 눈금 없음으로 표시한다. 자동 축척과 진입 진행률을 장면과 동일하게 적용한다. 전위 숫자·색상을 숨겨도 사용자가 선택한 두 점의 측정값은 표시한다.

## 경로 전위 그래프

경로는 `Net → Component → Net` 순서의 목록이다.

- 이상적 도선 구간은 수평선이다.
- 전원은 상승 또는 하강이다.
- 저항은 양단 전위 사이의 변화다.
- 그래프 구간은 회로 요소 ID를 보존한다.
- 회로나 그래프의 한 구간을 가리키면 대응 구간을 함께 강조한다.
- 첫 구현은 자동 제안된 주요 폐회로와 교사 지정 경로를 지원한다.

## 전류와의 구분

- 전위: 숫자, 색상, 높이
- 전류 방향: 화면 경로를 등속 이동하는 표시용 무늬
- 전류 크기: 자동 축척의 비례 띠·전류에 따른 무늬 밀도와 상세 설정의 A 단위 숫자

무늬 속도·간격은 실제 전자 속도·밀도·전하량·신호 전달을 뜻하지 않는다. 2D·3D는 같은 구간 전류와 축척을 사용하고 화면 투영 후 호 길이로 무늬 속도를 정한다. [전류 시각화 규약](current-visualization.md)과 [ADR-020](../../decisions/ADR-020-current-visualization.md)을 따른다.


### 3D 기준면과 안내 표시

원래 회로 기호와 배선을 투명한 0 V 기준면에 표시한다. 음의 전위는 이 면 아래에 표시하며, 부유 영역에 임의 높이를 부여하지 않는다. 세로 눈금은 V 단위이며 높이 축척을 바꾸어도 전압값은 변하지 않는다. 수직 점선은 같은 x-y 위치의 대응을 안내하며 전기적 연결을 의미하지 않는다. 선택 부품의 ΔV는 첫 단자 전위에서 둘째 단자 전위를 뺀 값이다. 열린 스위치에서 전압 차이를 안내해도 전도 경로는 생성하지 않는다.

## 가변저항 비교

조절 대상의 저항 범위 양 끝을 기존 직류 해석으로 계산해 전위 범위를 구한다. 다른 조건이 같은 동안 색·높이·눈금 축척을 유지하며, 사용자 고정 색 범위와 높이 배율을 존중한다. 표시 범위는 app에서 제공하고 3D는 회로를 계산하지 않는다. 각 갱신은 실제 저항값에서의 정상 상태이며 과도 응답이나 계산값 보간이 아니다. [ADR-023](../../decisions/ADR-023-live-parameters.md) 참조.
