# 전위 시각화 규약

전위 색상과 3D 높이는 장식이 아니라 물리 모델의 표현이다. 아래 규칙은 숫자, 색상, 높이, 경로 그래프에 공통으로 적용한다.

## 규칙

| ID | 규칙 |
|---|---|
| PV-01 | 기준 전위를 항상 표시한다. 기본 제안은 전지 음극 0 V이며 사용자가 변경할 수 있다. |
| PV-02 | 같은 이상적 도선과 분기점은 정확히 같은 숫자·색상·높이를 가진다. |
| PV-03 | 저항에서 양단 전위 사이의 변화를 표현한다. 이는 집중소자 모델을 교육적으로 펼친 표현임을 설명한다. |
| PV-04 | 열린 스위치의 두 단자는 서로 다른 전위를 가질 수 있고 3D에서 연결되지 않는다. |
| PV-05 | 색상 범례에 최소·최대·0 V·기준점을 표시한다. |
| PV-06 | 단일 회로는 자동 범위를 기본으로 하고 비교 활동은 동일한 고정 범위를 사용한다. |
| PV-07 | 전위가 정해지지 않은 부유 영역에는 임의 색이나 높이를 주지 않는다. |
| PV-08 | 색만 사용하지 않고 숫자·부호·선 강조를 함께 제공한다. |

정본은 [`requirements/physics-rules.yaml`](../../requirements/physics-rules.yaml)이다.

## 숫자 전위

- 주요 절점에 `A 9.0 V`처럼 표시한다.
- 기준점 표기를 화면에서 유지한다.
- 두 점을 선택하면 `V_AB = V_A - V_B`를 표시한다.
- 두 점의 순서를 바꾸면 크기는 같고 부호만 반전된다.

## 색상

1. 결정된 절점 전위의 최소·최대 또는 교사가 설정한 고정 범위를 구한다.
2. 전위를 0~1 범위로 정규화한다.
3. 접근성을 고려한 팔레트로 보간한다.
4. 숫자와 범례를 함께 표시한다.
5. 최소값과 최대값이 같은 경우 단일 전위 상태로 처리한다.

부유 영역은 회색 사선, 점선 테두리, `전위를 정할 수 없음` 문구로 표시한다.

## 등전위 강조

절점 하나를 선택하면 같은 `net`의 모든 도선, 단자, 분기점을 함께 강조한다.

표시 예:

> B, C, D점은 같은 이상적 도선으로 연결되어 모두 6.0 V입니다.

## 3D 전위 높이

높이는 다음 식으로 정한다.

`z = scale × (V - V_reference)`

- `scale`은 교육적 과장값이며 실제 공간 높이가 아니다.
- 2D의 x-y 위치를 유지한다.
- 같은 `net`은 하나의 평평한 높이를 이룬다.
- 전원은 상승 또는 하강으로 표현한다.
- 저항은 양단 전위 사이를 경사 또는 계단으로 연결한다.
- 열린 스위치는 서로 다른 높이의 끊어진 단자로 표시한다.
- 기본 카메라는 직교 투영을 사용한다.

## 경로 전위 그래프

경로는 `Net → Component → Net` 순서의 목록이다.

- 이상적 도선 구간은 수평선이다.
- 전원은 상승 또는 하강이다.
- 저항은 양단 전위 사이의 변화다.
- 그래프 구간은 회로 요소 ID를 보존한다.
- 회로나 그래프의 한 구간을 가리키면 대응 구간을 함께 강조한다.
- 첫 구현은 자동 제안된 주요 폐회로와 교사 지정 경로를 지원한다.

## 전류와의 구분

- 전위: 숫자, 색상, 높이
- 전류 방향: 화살표
- 전류 크기: 화살표 굵기 또는 제한된 움직이는 점

움직이는 점의 속도는 실제 전자 표류 속도나 신호 전달 속도를 뜻하지 않는다.


### 3D 기준면과 안내 표시

원래 회로 기호와 배선을 투명한 0 V 기준면에 표시한다. 음의 전위는 이 면 아래에 표시하며, 부유 영역에 임의 높이를 부여하지 않는다. 세로 눈금은 V 단위이며 높이 축척을 바꾸어도 전압값은 변하지 않는다. 수직 점선은 같은 x-y 위치의 대응을 안내하며 전기적 연결을 의미하지 않는다. 선택 부품의 ΔV는 첫 단자 전위에서 둘째 단자 전위를 뺀 값이다. 열린 스위치에서 전압 차이를 안내해도 전도 경로는 생성하지 않는다.
