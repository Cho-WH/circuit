# 측정과 수치 표시 규약

## 전압계

- 빨강 탐침과 검정 탐침을 두 점에 연결한다.
- 표시값은 `V_red - V_black`이다.
- 탐침 순서를 바꾸면 값의 부호만 반전되어야 한다.
- 같은 점에 두 탐침을 연결하면 0 V를 표시하고 그 의미를 안내한다.
- 탐침이 완전히 연결되지 않은 상태에서는 수치값을 확정하지 않는다.

## 전류 측정

- 측정 탭은 비접촉 센서로 부품 또는 도선 구간을 선택한다. 원본 연결·위치·배선을 변경하지 않는다.
- 부품 전류는 해석 결과의 가지 전류를 읽는다. 도선 전류는 해당 도선을 제외한 연결 그래프의 한쪽에서 단자 유입 전류를 합산한다(KCL). 같은 net에 속해도 분기 전후 전류는 다르다.
- 도선을 제외해도 양 끝이 연결되는 이상적 도선 고리는 개별 전류가 유일하지 않으므로 WIRE_CURRENT_UNDEFINED로 반환한다. 해석 실패·누락된 전류에도 수치를 확정하지 않는다.
- 화면은 크기와 관습적 전류 방향 화살표를 표시한다. 기록은 부호 있는 원시 값과 기준 방향을 보존한다. 0 A에는 화살표를 표시하지 않는다.
- 회로 만들기의 전류계 부품은 이상적인 0 V 요소이며 직렬 연결 학습에 사용한다. 전원 양단 병렬 연결은 AMMETER_PARALLEL_TO_SOURCE로 진단한다.
- 탐침 위치와 센서 선택은 일시적인 UI 상태다. [ADR-015](../../decisions/ADR-015-non-contact-measurement.md)를 따른다.

## 등가저항

1. 사용자가 선택한 두 점을 측정 포트로 정한다.
2. 저항 측정 모드에서는 모든 직류 전원을 계산 회로에서 분리한다. 전원은 0 V 도선으로 치환하지 않고 개방한다. 탐침 위치와 전압값에 관계없이 같은 규칙을 적용한다.
3. 남은 수동 회로의 0 V 제약을 연결 축약하고 포트에 1 V 시험 전압원을 연결한다.
4. 시험 전류 `I`에서 `R_eq = 1 V / I`를 구한다. 모든 병렬 경로를 포함하며 선택한 부품의 속성값을 그대로 읽지 않는다.
5. 경로가 없으면 개방(∞ Ω), 실제 단락 경로는 0 Ω으로 구분한다. 탐침이 미완성인 경우 값은 확정하지 않는다.

실제 저항계는 전원이 분리된 회로에 작은 시험 신호를 가해 저항을 측정한다. 화면의 짧은 툴팁은 이 원리를 설명한다. 현재 계산의 1 V는 선형 회로의 저항을 구하기 위한 정규화된 시험값이며 실제 계기의 시험 크기·레인지·비이상성은 모델링하지 않는다.

전원 기호·이름·값은 흐리게 표시하고 양쪽 리드에 간격을 둔다. 탐침이 닿는 회로 쪽 단자는 유지한다. 원본 문서는 변경하지 않으며 다른 측정 모드에서는 전원을 정상 표시한다. 기록에는 모든 전원을 분리한 조건과 해당 전원 이름을 남긴다.

3 Ω·6 Ω 직렬 회로에서는 각 저항 양단이 3 Ω·6 Ω, 전원 단자 사이가 9 Ω이다. 같은 저항을 병렬 연결하면 어느 저항 양단에서도 2 Ω이다. 공개 계산 API의 독립원 비활성화 계약과 화면의 전원 분리 정책은 [ADR-011](../../decisions/ADR-011-resistance-port.md)을 따른다.

## 법칙 확인·측정 기록·값 변화 실험

- KCL은 선택 net에서 나가는 전류의 부호 합, KVL은 연속 폐경로의 전위 변화 합이다. 항별 부호·단위·잔차·허용오차를 표시하고 열린 경로나 존재하지 않는 대상을 거부한다.
- 기록은 당시 문서와 조건, 원시 수치와 단위를 복제해 고정한다. 외부 측정은 `source`로 구분하고 기록 시각은 호출자가 제공한다. 화면 반올림 값을 계산 입력으로 쓰지 않는다.
- CSV는 영어 필드명과 별도 `unit` 열을 쓰며 조건과 당시 문서 JSON을 보존한다. RFC 인용 규칙과 수식으로 해석될 수 있는 텍스트 처리를 적용한다.
- 값 변화 실험은 원본의 복제본마다 계산한다. x축 변수·단위와 y축 물리량·단위를 보존하고 최대 100개 표본으로 제한한다. 실패 표본은 수치를 확정하지 않고 그래프에서 연결하지 않는다.
- 측정 기록은 앱 메모리에 유지된다. 모드 전환 시 보존되지만 페이지를 닫거나 새로고침하기 전에 CSV로 저장해야 한다.

공개 함수는 [모듈 계약](../architecture/modules.md), fixture별 검증 근거는 [MVP 검증 범위](../testing/mvp-coverage.md)를 참조한다.

## 빠른 값 보기

부품을 선택하면 다음을 카드로 확인할 수 있다.

- 부품 양단 전압
- 가지 전류
- 소비 또는 공급 전력

빠른 값 보기는 측정기 연결 학습과 구분한다. 활동 정책에 따라 비활성화할 수 있다.

## 숫자 형식

- quantity 공통 모듈을 사용하며 표시값을 계산 입력으로 다시 사용하지 않는다.
- 기본 자동 단위는 p~M 접두어와 최대 소수 두 자리를 사용한다. 작은 비영 값을 0으로 만들지 않으며 접두어 범위 밖에서는 지수 표기를 사용한다.
- 유효 숫자 모드는 4자리로 표시하고 e 대신 × 10과 위첨자 지수를 쓴다. 원래 숫자 모드는 기본 단위의 원시 숫자를 지수 없이 표시한다.
- 부품의 값·빠른 값·측정·3D 부품 전압차·회로도 출력·SVG·PNG에 해당 부품의 옵션을 적용한다. 기록은 당시 설정을 유지하고 단일 부품에 속하지 않는 절점·합계·축은 자동 단위를 사용한다. 그래프와 대응 표는 같은 축 단위를 사용한다. CSV는 원시 숫자와 기본 단위를 유지한다.
- 명시적 입력 분수는 자동 단위 모드에서 분자·가로선·분모로 유지한다. 다른 표시 모드로 바꿔도 저장된 분수는 보존한다. 자동 계산 결과를 분수로 추정하지 않는다.
- 이름 입력은 공백 제거 후 1~160자를 명령 단계에서 검증한다. HTML·SVG·PNG의 수식 기울임 규칙을 공유하며 단위는 정자로 유지한다.
- 상세 경계와 정밀도는 [ADR-019](../../decisions/ADR-019-quantity-input-and-display.md)를 따른다.

## 입력 형식

다음 표현을 같은 값으로 해석할 수 있어야 한다.

- `1k`
- `1 kΩ`
- `1000 ohm`
- `0.001 MΩ`

`3/4`, `-3/4 V`, `3/4 kΩ`도 허용한다. 분수 입력은 계산용 SI 수치와 입력 표기를 함께 보존하며, 소수로 재입력하면 분수 표기를 해제한다. 분모가 0이거나 불완전한 입력·맞지 않는 단위이면 이전 값을 유지한다. 전위 범위와 값 변화 실험의 시작·끝도 동일한 파서를 사용한다.

입력은 p·n·u/μ/µ·m·k·M을 지원한다. 소수·분수·접두어를 정확한 정수 비율로 결합한 뒤 계산용 number로 한 번만 반올림한다. 예를 들어 10u는 0.00001, 0.1/0.3은 1/3의 가장 가까운 number가 된다. 분모 0, 단위 불일치, 음의 저항, 오버플로·0으로의 언더플로는 거부한다.
