# 측정과 수치 표시 규약

## 전압계

- 빨강 탐침과 검정 탐침을 두 점에 연결한다.
- 표시값은 `V_red - V_black`이다.
- 탐침 순서를 바꾸면 값의 부호만 반전되어야 한다.
- 같은 점에 두 탐침을 연결하면 0 V를 표시하고 그 의미를 안내한다.
- 탐침이 완전히 연결되지 않은 상태에서는 수치값을 확정하지 않는다.

## 전류계

- 측정할 가지를 선택해 회로를 끊고 이상적인 0 V 요소를 삽입한다.
- 삽입 전후의 연결 상태를 화면에서 명확히 보여 준다.
- 전류계를 전원 양단에 병렬 연결하면 `AMMETER_PARALLEL_TO_SOURCE` 진단을 반환한다.
- 원본 `CircuitDocument`를 몰래 영구 변경하지 않는다. 측정 질의 또는 임시 해석 요소로 처리한다.

## 등가저항

1. 사용자가 선택한 두 점을 측정 포트로 정한다.
   - 부하 측정이면 명시한 외부 여자 전원을 먼저 분리한다. 전체 회로 측정이면 제외하지 않는다. UI에서 두 대상을 구분하고 분리한 전원 ID를 표시한다. FIX-01~04·09·10의 포트 기대값은 부하 측정이다. 자세한 결정은 [ADR-011](../../decisions/ADR-011-resistance-port.md)을 따른다.
2. 독립 전압원은 0 V, 독립 전류원은 0 A로 만든다.
3. 포트에 1 V 시험 전압원을 연결한다.
4. 시험 전류 `I`에서 `R_eq = 1 V / I`를 구한다.
5. 연결 없음, 0 Ω, 부유 조건을 진단한다.

실제 저항계 동작은 별도의 후속 모델이다.

## 빠른 값 보기

부품을 선택하면 다음을 카드로 확인할 수 있다.

- 부품 양단 전압
- 가지 전류
- 소비 또는 공급 전력

빠른 값 보기는 측정기 연결 학습과 구분한다. 활동 정책에 따라 비활성화할 수 있다.

## 숫자 형식

- 내부 계산은 충분한 정밀도를 유지한다.
- 기본 표시는 유효숫자 3자리다.
- 정수에 가까운 값은 문맥에 맞게 단순화한다.
- `0.003 A`는 `3.00 mA`, `1500 Ω`는 `1.50 kΩ`처럼 SI 접두어를 사용한다.
- `2.999999 V`는 `3.00 V`처럼 표시한다.
- 시험지에서는 정수, 소수 자리수, 유효숫자를 교사가 고정할 수 있다.
- 표시값을 다시 계산 입력으로 사용하지 않는다.

## 입력 형식

다음 표현을 같은 값으로 해석할 수 있어야 한다.

- `1k`
- `1 kΩ`
- `1000 ohm`
- `0.001 MΩ`

단위 파싱 실패 시 이전 값을 유지하고 허용 형식을 안내한다.
