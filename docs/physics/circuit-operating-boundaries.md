# 회로 작동 경계와 부품 프로필

상태: [ADR-026](../../decisions/ADR-026-diode-boundary-analysis.md)의 D0 고정 프로필, 부품 모델·경계 판정·모델 선택과 분석 세션 연동을 구현했다. 검증 범위는 [수용 사례](../testing/diode-cases.md)를 따른다.

이 문서는 전기적 계산과 노랑·빨강 판정의 정본이다. 화면 문구와 사건 수명은 [다이오드 분석 UX](../ux/diode-analysis.md)를 따른다.

## 1. 네 가지 책임

| 책임 | 입력과 결과 |
|---|---|
| 전기 모델 | 회로·프로필로 유한한 전압·전류·전력을 계산 |
| 작동 경계 | 검증된 물리량을 부품별 허용 경계와 비교 |
| 분석 세션 | 분석 진입·값 변경에서 사건 발생과 재생 여부를 결정 |
| 연출 | 노랑 과부하 또는 빨강 파열·파손을 짧게 표현 |

열 적분, 실제 온도, 고장까지의 시간, 온도에 따른 전류 변화는 없다. 전력은 순간 DC 작동점의 물리량으로 사용한다. 애니메이션 경과 시간이나 프레임 수를 위험도에 누적하지 않는다.

## 2. 부품 프로필

프로필은 버전이 있는 명시적 모델 입력이다. 내장 프로필도 ID와 버전을 고정하고, 사용자가 적용한 부품 차이는 저장하여 재현한다. 부품을 다시 선택하거나 분석을 재실행한다고 특성이 바뀌지 않는다.

| 대상 | 전기 특성 | 경계 평가량 |
|---|---|---|
| 전원 | 기전력, 양의 유효 내부저항 | 공급 전류, 내부손실 `I²R_s`; 지원 프로필에 한해 역전류 |
| 일반 다이오드 | 교과서 7/10 V, 부품 모델 `V_0`, 양의 `R_on` | 순방향 전류, 양의 소비전력, 역전압 크기 |
| 저항·가변저항 | 입력한 선형 저항 | 소비전력 `I²R` |
| LED(후속) | 색상/종류별 순방향 곡선, 밝기 함수 | 전류·전력·역전압; 밝기와 경계는 별도 |

도선은 이상적인 0 Ω로 유지한다. 화면 길이·재질·접촉 상태를 추정하지 않는다. 전원의 내부 계산 저항을 회로도에 사용자가 놓은 저항처럼 추가하지 않는다.

### 경계 필드

각 지원 평가량에는 다음 두 값을 독립적으로 둔다.

- `continuousMax`: 정상 작동으로 다루는 상한.
- `damageAt`: 즉시 파손 사건을 연출하는 교육용 경계.

같은 평가량에서 `0 <= continuousMax < damageAt`을 검증한다. 경계가 정의되지 않은 평가량을 임의의 기본값으로 판정하지 않는다. 실제 부품 데이터의 정격과 교육용 `damageAt`은 별개이며 후자가 실제 즉시 파손을 보장한다는 설명을 하지 않는다.

모든 부품의 `damageAt`을 `정격 × 2` 같은 공통 배수로 자동 생성하지 않는다. D0에서 전원·다이오드·저항별 기본 프로필을 아래 표로 고정했다. [시험 전용 프로필](../testing/diode-cases.md)의 수치를 제품 기본값으로 사용하지 않는다.

프로필 표에는 ID·버전, 전기 특성값, 각 경계, 교육용 가정/실제 부품 근거, 적용 범위를 기록한다. 이 표가 비어 있는 부품은 물리적 파손을 연출할 수 없다.

### D0에서 확정한 내장 교육용 프로필 (2026-10-05)

아래 값은 특정 판매 부품의 정격이 아닌 **교실용 가상 부품의 명시적 교육 가정**이다. 전원·부하의 범위를 기존 6~12 V, 수 Ω 수업 예제에 맞추고, 다이오드는 작은 전류의 순방향 관찰부터 직결 부담까지 구별하도록 정했다. 파손 경계는 실제 고장 전류·온도·시간의 예측이 아니며 각 평가량에 독립적으로 선정했다. 시험 전용 10 Ω/10 Ω 프로필에서 복사한 값이 아니다.

| ID / revision | 적용 부품·전기 특성 | 평가량 | continuousMax | damageAt |
|---|---|---|---|---|
| `edu-source` / 1 | 가상 실험 전원, E는 사용자 설정, R_s = 1 Ω | 양의 공급 전류 | 5 A | 12 A |
| 위와 같음 | 위와 같음 | 내부 손실 I²R_s | 25 W | 80 W |
| `edu-diode` / 1 | 일반 다이오드, V_0 = 7/10 V, R_on = 2 Ω | 순방향 전류 | 1/5 A | 3/4 A |
| 위와 같음 | 위와 같음 | 양의 소비전력 | 3/10 W | 1 W |
| 위와 같음 | 역방향 누설·항복 전류는 계산하지 않음 | 역전압 | 30 V | 60 V |
| `edu-resistor` / 1 | 가상 실험용 저항·가변저항, R은 사용자 설정 | I²R | 25 W | 100 W |

같은 부품·같은 위험 수준에서는 표의 평가량 순서로 대표 원인을 선택하며, 여러 부품은 안정된 부품 ID 순서를 따른다. 전원 역전류 경계는 이번 프로필에 등록하지 않는다. 해당 경계가 없다는 것이 실제 충전 가능성을 뜻하지 않는다. 새 부품에는 `operatingProfile: { id, revision: 1 }`을 저장한다. v6 문서에서 참조가 생략되면 해당 타입의 위 revision 1을 고정 기본값으로 사용한다. 기본 수치를 바꾸려면 새 revision과 지원 계약이 필요하다.

### 종류 선택 프로필 (2026-10-07)

위 edu-diode@1과 생략 참조의 수치는 기존 저장본을 위해 보존한다. 새 다이오드는 edu-diode-signal@1을 사용하며 종류 선택으로 edu-diode-power@1과 교체한다. 단자·기호·교과서 7/10 V 식은 같다.

| ID / revision | R_on | 순방향 전류 정상/파손 | 소비전력 정상/파손 | 역전압 정상/파손 |
|---|---|---|---|---|
| edu-diode-signal / 1 | 2 Ω | 1/5 A / 3/4 A | 3/10 W / 1 W | 75 V / 100 V |
| edu-diode-power / 1 | 1/20 Ω | 6 A / 10 A | 6 W / 12 W | 1000 V / 1200 V |

1N4148과 6A10을 참고한 교육용 가정이며 파손 경계는 실물 고장을 보증하는 정격이 아니다. 대전류용 6 A에서 1 V·6 W, 10 A에서 1.2 V·12 W가 된다. 전원 기준은 바꾸지 않는다. 출처·선정 이유·선택 UI·저장 정책은 [종류 설계](../ux/diode-kinds.md), 결정은 [ADR-028](../../decisions/ADR-028-diode-kinds.md)을 따른다.

`sourceResistanceOhm`, `diodeThresholdV`, `diodeOnResistanceOhm`의 선택적 정확값으로 고정 특성 차이를 저장할 수 있다. 내부저항·도통저항은 양수, 절편은 음수가 아니어야 한다. 특성 변경은 경계를 바꾸지 않는다. 모르는 프로필 ID·버전과 다른 부품의 특성 속성은 거부한다. 미리 정한 다이오드 종류 선택만 제공하며 사용자 정격 편집기는 추가하지 않는다. 종류를 교체하면 기존 다이오드 편차를 제거하고 새 프로필을 적용한다.

정상 수업 예로 5 V–1 kΩ–다이오드는 교과서 전류 4.3 mA를 유지한다. 부품 모델 직결은 5 V에서 43/30 A이므로 파손 경계를 넘는다. 기존 9 V–9 Ω 저항 예제는 교과서 1 A·9 W, 부품 모델 0.9 A·7.29 W로 정상 범위다. 고정 프로필·형식은 [도메인 테스트](../../tests/diode-domain.test.ts), 전기식·경계 비교는 [엔진 테스트](../../tests/diode-engine.test.ts), 내장 프로필의 화면 상태 전이는 [세션 테스트](../../tests/diode-session.test.ts)로 확인한다.

## 3. 위험 판정

각 평가량을 음수가 아닌 부담량 `q`로 변환한다. 예를 들어 다이오드는 `max(i_D, 0)`, `max(v_D i_D, 0)`, `max(-v_D, 0)`을 각각 전류·전력·역전압으로 본다. 전원의 내부손실은 공급 전력의 부호와 별개로 `I²R_s`다.

| 비교 | 부품 상태 |
|---|---|
| 모든 지원량이 `q <= continuousMax` | 정상 |
| 하나 이상 `continuousMax < q < damageAt`, 빨강 없음 | 과부하(노랑) |
| 하나 이상 `q >= damageAt` | 파손(빨강) |

회로의 위험 표시는 부품 중 가장 높은 수준을 사용하고 관련 부품·원인 코드·근거 값을 함께 보존한다. 같은 수준에서 여러 원인이 있으면 프로필의 원인 우선순위와 안정된 부품 순서로 대표 원인을 고른다. 다른 관련 부품은 클릭하여 확인할 수 있다.

이상 해가 없거나 전류가 비유일하다는 사실만으로 노랑·빨강을 반환하지 않는다. 계산 예산 초과·수치 검증 실패·부유 전위도 파손 원인이 아니다. `assessment: unverified`와 정상 판정을 내부적으로 구별한다.

### 근사값이 임계에 가까울 때

위험 비교는 반올림 전 값과 수치 품질을 사용한다. 현재 구현은 정확값이면 직접 비교하고 근사값이면 오차 범위를 함께 비교한다. 오차 범위가 경계를 가로지르면 그 경계는 확인되지 않은 것으로 남긴다. 빨강은 경계 초과가 확인된 경우에만 확정한다. 과부하만 확실하고 파손은 확인되지 않은 경우에는 그 확인된 수준만 반환한다. 정상도 모든 관련 상한 이내임을 확인한 경우에만 확정한다. 근사 오차가 붙은 프로필 특성·경계 입력은 정확 프로필로 받아들이지 않는다.

이 판단을 위해 가짜 허용오차로 작은 전류를 0으로 만들거나 위험 임계를 이동하지 않는다. UI는 확인되지 않은 결과를 새 위험 사건으로 재생하지 않으며 오래된 다른 리비전의 색상도 재사용하지 않는다.

## 4. 교과서 모델과 부품 모델 선택

두 모델은 같은 원본문서와 저장된 프로필에서 만들어진다. 모델 선택은 전기 해석 조건이며, 학생의 탐침 위치·부품 선택·카메라와 무관하다.

### 최초 분석과 만들기의 사전 평가

1. 현재 확정된 부품 값에서 교과서 모델을 해석한다.
2. 다이오드가 있거나 부품 위험을 평가하는 대상에서는 같은 입력의 부품 모델도 평가한다. 동일 입력의 검증된 결과는 캐시할 수 있다.
3. 다음 중 하나면 부품 모델을 현재 분석 결과로 선택한다.
   - 이상 작동점이 없거나, 다이오드·전원 등의 필요한 전류가 하나로 정해지지 않음.
   - 교과서 결과를 그대로 표시하면 프로필의 정상 범위를 벗어난 물리량을 표시하게 됨.
   - 부품 모델에서 노랑 또는 빨강이 확인됨.
   - 내부저항·부품 편차를 관찰하는 조건을 명시적으로 사용함.
   - 아래 연속 조절 정책이 부품 모델을 요구함.
4. 위 조건이 없고 일반 수업값이 확정되면 교과서 모델을 유지한다.
5. 색상은 검증된 부품 모델의 판정으로 정한다. 이상값으로 빨강을 발동한 뒤 경계 아래로 감소한 다른 전류를 화면에 표시하지 않는다.

단순한 이상 해 실패를 물리적 위험으로 치환하지 않는다. 예를 들어 `E = V_0 = 0.7 V` 직결은 이상 전류가 비유일할 수 있지만 양의 내부저항·도통저항 모형에서는 0 A다.

### 연속 조절 정책

다이오드가 있는 가변저항 연속 관찰은 분석 진입 때 부품 모델로 고정한다. 순수 저항 회로의 기존 이상 해석은 유지한다. 이 정책으로 경계 통과 도중 이상값과 부품값을 번갈아 사용하여 전류가 되튀는 것을 막는다. 새로운 연속 전원 조절을 추가할 때도 같은 원칙을 적용한다.

만들기의 노랑·빨강은 이 정책에서 **현재 저항값으로 지금 진입할 결과**만 뜻한다. 조절 범위 어딘가에 위험 구간이 있다는 이유로 현재 경고하지 않는다.

일반 분석 중 명시적 값 수정으로 부품 모델이 필요해지면 해당 결과를 선택하고 그 세션에서는 유지한다. 과부하·파손을 확인하면 마지막 값과 관찰 조건을 잠그므로 같은 세션에서 값을 되돌리거나 위험 수준을 다시 변경하지 않는다. 노랑의 현재 전압·전류 측정과 기록은 허용한다. 회로 초기화로 만들기에 돌아온 뒤 값을 고치고 다시 분석할 때 새 세션의 조건을 결정한다.

부품 모델에서 해석해도 모든 평가량이 정상일 수 있다. `부품 특성 적용` 자체는 노랑이 아니다. 확인되지 않은 부품 모델을 안전 판정으로 간주하지 않는다.

## 5. 표시·측정·기록의 일관성

- 선택된 한 모델의 결과로 같은 연결 회로의 전위·전류·전력·3D·밝기를 구성한다.
- 전원의 설정 기전력과 현재 단자전압을 구별한다. 다이오드의 교과서 설정 강하와 부품 모델의 실제 계산 전압도 혼동하지 않는다.
- 부품 모델의 출처는 수치의 ≈와 기록 조건으로 보존한다. 캔버스의 별도 `부품 특성` 배지는 사용하지 않는다.
- 물리 모델의 근사 여부와 정확/근사 수치 해법은 서로 다른 메타데이터다.
- 기록 조건 키에는 모델과 프로필 버전을 포함한다. 모델이 다른 점을 같은 조건의 연속 측정으로 묶지 않는다.
- 현재 회로 v6·측정 기록 v5는 고정 프로필 참조와 당시 모델·프로필·수치 출처를 보존한다. 물리 모델의 ≈ 표시는 정확 유리수에 수치 오차 메타데이터를 붙여 만들지 않는다.
- 노랑에서 측정값은 유효하다. 빨강 이후의 현재 측정은 중단하며 파손 전 기록은 보존한다.

## 6. 실제로 표현하는 현상과 적용 한계

전원 내부저항과 소자의 양의 기울기로 직결 회로의 유한 전류·전압 처짐·병렬 분배를 계산한다. 과부하·파손 표시는 이 결과에 적용한 교육용 경계 사건이다.

- 외부 저항이 없어도 해당 전원·부품 조건에서 정상으로 판정될 수 있다.
- 대칭 프로필은 대칭 전류, 고정된 작은 차이는 반복 가능한 불균형을 만든다.
- 공통 저항은 총전류에, 가지 저항은 분배 민감도에도 영향을 준다. 모양만 보고 성공·실패를 판정하지 않는다.
- 역전압이 큰데 전류가 0인 경우에도 역전압 경계를 평가할 수 있다. 이를 가짜 발열 전력으로 변환하지 않는다.
- 단순 차단 모델에서 역항복 전류를 계산했다고 주장하지 않는다. 실제 항복전압과 최대 허용 역전압도 구별한다.
- 일반 전지를 자동 정전류 전원으로 바꾸지 않는다. 실제 전류 제한·보호 차단은 별도 전원 모델의 후속 기능이다.
- 빨강 이후 파손 회로의 정상 상태·연쇄 고장은 이번 범위에 포함하지 않는다.

시험용 프로필과 경계값 직전·동일·초과 사례는 [수용 사례](../testing/diode-cases.md), 기본값 확정과 구현 순서는 [구현 계획](../implementation/diode-mvp.md)에 둔다.

2026-10-07 [ADR-030](../../decisions/ADR-030-diode-equilibrium.md): 교과서·부품 모델 모두 기존 회로식의 허용 해에서 다이오드 전압 제곱합을 최소화한 평형을 사용한다. 역전압 경계도 그 결과로 평가한다. 프로필에 유한 누설 특성을 추가하지 않고, 결과의 profileRevision 지문에 diode-equilibrium-1 정책을 포함한다.
