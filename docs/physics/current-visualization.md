# 전류 시각화 규약

관련 요구사항은 VIS-006, 결정은 [ADR-020](../../decisions/ADR-020-current-visualization.md)이다. 현재 물리 범위는 이상적인 선형 직류 저항 회로다.

| 규칙 | 표현 |
|---|---|
| CV-01 | 전류는 해석 결과와 단자 기준 부호를 따른다. 구간마다 계산하며 화면 배치나 전위 경사로 추정하지 않는다. |
| CV-02 | 크기는 선형 비례 띠와 전류에 따른 무늬 밀도로 표시한다. 무늬는 관습적 방향으로 등속 이동하고 간격은 상대 전류에 반비례한다. 실제 캐리어 밀도·속도와 동일시하지 않는다. |
| CV-03 | 무늬는 화면에 투영된 경로의 호 길이를 기준으로 등속 이동한다. 긴 경사 구간은 표시상 통과 시간이 길어지며 전류값은 동일하다. |
| CV-04 | 도선 고리의 미정, 계산 실패, 0 A, 미세 비영 전류를 구분한다. 열린 스위치와 전압계는 전류 경로를 잇지 않는다. |
| CV-05 | 표시 시계는 물리 시계와 독립이다. 전하 축적·과도 응답·신호 지연을 무늬의 이동이나 개수로 계산하지 않는다. |

## 축척과 비교

해석 결과의 최대 전류를 기준으로 매번 자동 축척을 적용한다. 기본 최대 띠 너비는 14 CSS px이고 상세 설정의 전류 두께 배율(×0.25~×3)을 곱한다. 따라서 한 회로 안의 비율을 비교하는 표현이며, 값 변경 전후나 서로 다른 회로의 절대 전류를 띠만으로 비교하지 않는다. 상세 설정의 선택 구간 수치와 측정 기능에서 실제 A 값을 확인한다. 미세한 비영 전류의 띠를 최소 너비로 부풀리지 않는다.

전류 보기에서는 기존 2D 도선 잉크와 3D 도선·경사 튜브를 숨기고 진한 반투명 띠로 대체한다. 3D 바닥 회로도의 도선은 그대로 유지한다. 도선 띠에는 기존 전위 색상과 선택한 팔레트를 유지한다. 색상 표시를 끄면 중립색을 사용한다. 부품 기호·이름과 선택 판정은 유지한다. 상단 설명 밴드·범례·축척 맞춤 버튼은 제거하고 화면 안 왼쪽 위에 일시 정지 버튼만 둔다. 수치·상태는 상세 설정에서 확인한다.

## 무늬 밀도와 연속성

화면상의 속도는 30 CSS px/s로 일정하다. 최대 전류의 기준 간격은 34 CSS px이고, 다른 구간의 간격은 `34 × I_max / |I|`로 정한다. 이 시각적 모델에서는 단면을 지나는 무늬의 빈도가 상대 전류에 비례한다. 전하 운반자 하나의 실제 궤적이나 밀도를 재현하는 모델은 아니다.

실제 단자 ID로 연결된, 유입·유출이 하나씩이며 같은 전류인 도선·부품을 하나의 경로로 합친다. 개별 도선이나 저항 경계에서 무늬 위상을 초기화하지 않는다. 단순 닫힌 회로는 경로 길이에 맞는 정수 개수의 무늬를 등간격 배치해 한 바퀴의 이음새도 연속으로 만든다. 이때 밀도는 기준값에 가장 가까운 정수 개수(최소 1개)로 근사하며, 이동 속도와 비례 띠 너비는 바뀌지 않는다. 분기점에서는 각 가지의 전류에 맞는 밀도를 사용하며 개별 무늬의 분배·재결합을 실제 전하 보존의 계산으로 취급하지 않는다.

2D·3D는 같은 전류와 자동 축척을 사용한다. 3D 높이는 전위 차이의 도식이며 실제 공간 높이·소자 내부 전기장·입자 가속을 나타내지 않는다. 정지한 카메라에서는 투영된 모든 경로에서 같은 화면 속도를 유지한다. 카메라 이동 중에는 기존 무늬의 경로 선분·선분 내 위치를 유지한 채 새 화면에 투영한다. 마지막 투영 변경 후 140 ms 동안 시점이 멈추면 새 화면 간격으로 220 ms 교차 전환한다. 이 전환이 끝나면 새 투영 경로에서 다시 30 CSS px/s를 유지한다. 카메라 운동에 따른 화면상의 이동은 전류나 입자 가속을 나타내지 않는다. 일시 정지·움직임 감소 설정은 무늬를 정지시키며, 방향은 재생하거나 상세 설정에서 확인한다.

### 저항 조절 중 표시

값이 변하기 시작하면 점열을 160 ms 동안 흐리게 지우고, 전류 띠 두께·색상·측정값은 계속 갱신한다. 사라지는 점의 간격을 바꾸어 역주행이나 가속을 만들지 않는다. 수동 조절을 마치고 값이 300 ms 이상 안정되면 최신 간격의 점열을 160 ms 동안 나타낸다. 자동 조절 실행 중에는 끝점 정지나 조절창 닫기에도 점열을 숨기며, 일시 정지한 뒤 같은 안정 대기를 적용한다. 이는 표시 전환 시간이며 전류가 전달되는 물리적 지연을 뜻하지 않는다. 전류 간격을 별도의 단계로 양자화하지 않는다.

### 분기·합류의 표시 전환

가지마다 일정한 간격을 유지하고 시작 위상을 강제로 동기화하지 않는다. 실제 연결 ID에 분기·합류가 있는 경우에만, 접점 중심에서 경로를 따라 3.5 CSS px 안의 점을 숨기고 이어지는 8 CSS px 구간에서 부드럽게 나타나거나 사라지게 한다. 전위색의 작은 접점 원은 유지한다. 속도나 간격을 조절하지 않으며 직렬 도선·부품 경계는 계속 연속 통과한다. 화면에서 겹칠 뿐인 다른 경로에는 이 효과를 적용하지 않는다. 이 전환은 개별 점을 실제 전하로 추적하지 않는 표시상의 절충이며, 접점에 전하가 축적되거나 소멸한다는 뜻이 아니다.

## 보존과 소자

전하 저장을 모델링하지 않는 접점의 유입·유출 전류 합은 같다. 현재 저항 모델의 양쪽 단자 전류는 크기가 같으며 전력은 `P=VI=I²R`다. 저항 이후 전류가 소모되거나 입자가 빨라지는 표현을 만들지 않는다. 전원 전류는 실제 해석 부호를 사용하므로 공급 상태에서 낮은 전위에서 높은 전위로 흐를 수 있다.

향후 축전기는 전류와 양쪽 판의 반대 부호 전하를 따로 표현한다. 일정 C에서 `q_a=C(V_a−V_b)`, `i_a=dq_a/dt`이며 자유전하 표식이 유전체를 통과하지 않는다. 다이오드의 흐름은 채택한 모델 결과를 따르고 누설·항복·저장 상태를 임의로 만들어 내지 않는다. 소자 내부 경로는 명시적 정책이 필요하다. 현재 미지원 소자를 추가할 때 저항의 연속 경로를 자동 상속하지 않는다.

## 가변저항 비교

조절 중에는 저항 범위 양 끝에서 얻은 최대 전류(도선 포함)를 너비·간격의 같은 기준으로 사용한다. 두께 배율은 유지한다. 전류가 바뀌면 기존 점열과 첫 표시점의 위치를 유지하며 간격을 갱신한다. 점열을 프레임마다 처음부터 생성하지 않는다. 이는 정상 상태 사이의 시각적 전환이며 속도·개별 점을 실제 전하의 운동으로 해석하지 않는다. [ADR-023](../../decisions/ADR-023-live-parameters.md) 참조.
