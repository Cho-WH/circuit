# 용어

| 용어 | 설명 |
|---|---|
| API | 모듈이 다른 모듈에 공개하는 함수와 데이터 약속 |
| Adapter | 핵심 기능과 특정 기술을 연결하는 변환 계층 |
| ADR | 중요한 기술 결정을 배경, 선택, 결과와 함께 기록한 문서 |
| CircuitDocument | 저장·공유되는 회로 구조의 유일한 원본 |
| CompiledCircuit | 화면 좌표와 라벨을 덜어내고 계산 가능한 `net`과 요소로 바꾼 회로 |
| Deterministic | 같은 입력에서 언제나 같은 결과가 나오는 성질 |
| Diagnostic | 회로의 오류·경고·안내를 코드와 관련 요소로 표현한 구조 |
| Fixture | 테스트에 반복 사용하는 기준 회로와 기대 결과 |
| MNA | 수정 절점 해석법. 절점 전위와 전압원 전류를 방정식으로 푸는 방법 |
| Migration | 오래된 저장 파일을 새 형식으로 변환하는 과정 |
| Net | 이상적인 도선으로 직접 이어져 같은 전위를 갖는 연결망 |
| Renderer | 데이터를 화면 또는 파일의 그림으로 바꾸는 모듈 |
| Schema | 저장 데이터의 필드와 형식을 정의하는 규칙 |
| Snapshot | 특정 시점의 문서 상태 사본 |
| Vertical slice | 데이터, 계산, 화면, 저장을 작은 범위에서 끝까지 연결한 기능 단위 |
| 수용 기준 | 기능 완료를 판단할 수 있는 관찰 가능한 조건 |
| 추상화 | 구현 방법을 숨기고 필요한 역할과 입출력만 약속하는 것 |
