# ADR-015: 비접촉 측정과 도선 전류

- 상태: accepted
- 결정일: 2026-09-24
- 요구사항: MEA-001~004, SIM-002, SIM-005

## 결정

측정 탭은 회로 문서·도선 경로를 바꾸지 않는 탐침봉과 비접촉 전류 센서를 사용한다. 계기 연결 학습은 회로 만들기의 전압계·전류계 부품으로 수행한다. 탐침·센서 배치는 앱 상태이며 저장 형식 변경은 없다.

`probeCurrent(document, compilation, result, target)`는 부품 또는 도선 ID를 받고 부호 있는 amperes, from/to endpoint와 구조화 진단을 반환한다. 부품은 기존 branchCurrents를 읽으며 전원은 positive → negative를 기준으로 한다. 도선은 start → end 방향이다. 해당 도선을 제거한 순수 도선 그래프의 start 쪽에서 부품 단자 유입 전류를 합한다. 따라서 같은 net의 분기 전후 전류를 구분한다. 제거 후에도 end로 도달하면 이상적인 도선 고리이므로 WIRE_CURRENT_UNDEFINED를 반환한다. 해석 실패나 필요한 전류 누락에도 수치를 만들지 않는다.

화면은 전류 크기와 실제 방향 화살표를 표시한다. 기록에는 원시 부호와 기준 방향을 함께 남긴다. 0 A에는 방향을 표시하지 않는다. 공개 insertSeriesAmmeter 계약은 유지하되 측정 탭의 화면·계산 경로에서는 사용하지 않는다.

## 화면 경계

`app/measurement-tools`가 도구 모양, 도선의 실제 접촉 위치, 스냅과 드래그를 맡는다. 도선 위치는 segment와 비율로 기억하고 전압·저항 질의에는 연결 ID를 넘긴다. 기하 좌표로 전기 연결을 만들지 않는다. 교차·분기점에서 모호한 도선은 임의 선택하지 않는다. 탭과 클릭으로 배치하고 놓인 도구는 드래그로 옮긴다. 잘못된 드롭·취소는 기존 위치를 보존한다. 키보드 대상 선택과 삭제도 지원한다.

상단에는 도구·측정값·기록을 두고 위치 목록과 삽입 전후 비교는 표시하지 않는다. 등가저항은 ADR-011에 따라 모든 전원을 분리한 회로를 측정한다. 전원을 흐리게 표시하고 리드를 끊어 표현하며, 아이콘 툴팁으로 실제 저항계의 시험 신호 원리를 설명한다.

## 수용 기준과 검증

- 예제 7개의 모든 부품 측정에서 회로와 경로가 불변이다.
- 병렬 예제의 공통선 3 A, 분기선 1 A·2 A와 도선 방향 반전을 구분한다.
- 열린 회로의 0 A, 전원 단자 배열 역전, 도선 고리와 해석 실패를 처리한다.
- 탐침 교환 시 전압 부호가 반전된다. 터치 드래그·취소 후 다음 탭을 방해하지 않는다.
- 측정 기록은 모드 간 유지되고, CSV에는 당시 회로·대상·부호 기준이 남는다.

검증은 `non-contact-measurement`, `measurement-workspace`, `measurement`, `simulation` 테스트와 대표 화면 확인으로 제한한다.
