# ADR-032: 영역 선택과 위치 지정 복사

- 상태: accepted
- 결정일: 2026-10-08
- 관련: EDT-001/002/005, ADR-001/002/013/016/018

사용자 승인에 따라 [선택·복사 설계](../docs/ux/selection-copy.md)를 적용한다. 만들기 선택 도구의 빈 공간 드래그는 즉시 영역 선택으로 바꾸며, ADR-002의 빈 공간 한 손가락/마우스 화면 이동 정책은 이 경우에 한해 대체한다. 분석·출력의 입력 정책은 유지한다.

복사는 선택이 있을 때 상단에 나타나는 하나의 버튼으로 시작한다. 마우스는 움직이는 미리보기 후 클릭, 터치는 탭한 곳의 고정 미리보기 후 버블 버튼으로 확정한다. 단일 부품은 기존 삽입을 공유하고 묶음은 부품 겹침을 거부한다. 자동 전기 연결을 추가하지 않는다.

기존 Paste·InsertComponentOnWire와 권한/이력을 재사용한다. copySelection은 명시적으로 선택한 도선도 복사하며 외부 끝단을 독립 연결점으로 바꾼다. ID 연결과 현재 v6/v5 저장 구조는 유지하고 UI 미리보기를 문서에 넣지 않는다. 새 범용 드래그 프레임워크는 만들지 않는다.

`MoveComponents.positions`는 함께 선택한 연결점 ID도 받는다. 두 끝점이 같은 변위로 움직인 도선은 전체 경로를 평행 이동한다. 연결점 직접 삭제는 계속 거부하며, 영역 선택의 삭제는 부품·도선만 기존 명령에 전달한다. 연결점 정리는 ADR-018을 유지한다.
