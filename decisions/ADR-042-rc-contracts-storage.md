# ADR-042: C1 축전기 공개 계약과 저장 버전

C2 후속: [ADR-043](ADR-043-rc-product-engine.md)에서 도선 질의·질의 실패 상태·엔진 객체 소유권을 구체화했다. 회로 v7·기록 v6는 유지한다.

- 상태: accepted
- 결정일: 2026-10-22
- 관련 요구사항: SIM-009, MEA-006, DAT-001~003, DAT-006
- 사용자 승인: dev에서 C1 공개 계약·저장 형식 구현 및 검증
- 상위 결정: [ADR-041](ADR-041-linear-rc-transient.md). 이후 C2 엔진·C3 세션·C4 관찰 UI까지 연결했으며 후속 결정은 ADR-043~045를 따른다

## 결정

회로 현재 버전은 **v7**, 측정 기록은 **v6**다. 기존 DC 계산식·연결 의미·정확값은 변경하지 않는다. `CircuitDocument`에는 축전기 C·초기 전압·단자와 표시 설정만 저장한다. 현재 전하·시각·응답 plan·계산 행렬은 런타임 계약에만 존재한다.

`capacitor`는 정확 정규형 `properties.capacitanceF > 0`와 부호 있는 `properties.initialVoltageV`를 필수로 갖는다. 생성 기본은 100 µF·0 V다. 역할 a와 b가 각각 하나인 두 단자를 요구하고, 초기 전압·전류 방향은 a→b다. 회전과 단자 배열 순서는 전기 방향을 바꾸지 않는다. 근사 입력·작동 프로필·임의의 실행 상태 속성은 허용하지 않는다. capacitor 컴파일 결과에는 C·초기 전압·원래 a/b 단자 ID를 보존한다.

`domain` 공개 index에 RcEngine·RcPrepareRequest·RcPlan·RcFrame·RcInitialState·RcTime·RcResult·RcReading을 제공한다. simulation index는 이 타입을 재수출하며 실제 엔진은 C2에서 구현한다. plan은 엔진 소유의 불투명 핸들이고 공개 summary에 준비 시점·최종 축전기 상태, 안정화 시간과 가장 느린 시정수를 제공한다. frame은 조작 번호·회로 리비전·frame ID·같은 물리 시각·기준 그룹·계산량과 비유일 목록을 담는다. 행렬·모드는 공개하지 않는다. query는 해당 엔진이 만든 원래 frame에 호출한다. 세부 필드는 [C1 결과](../docs/testing/rc-c1-results.md)를 따른다.

스칼라는 기존 Rational/StoredScalar를 재사용하되 근사값에 `{ reason: 'rc-modal', policy: 'rc-modal-1', absoluteError }`를 붙인다. 분수 모양 저장 자체는 정확성을 의미하지 않는다. DC 근사 사유/정책과 RC 사유/정책을 교차 조합할 수 없으며 오차는 유한한 비음수여야 한다. DC SimulationResult와 RcFrame은 별도 계약이고 RC 값을 DC 결과로 위장하지 않는다. RC 수치 오차 인증은 C2 책임이며 기존 일반 사칙연산의 메타데이터 전파만으로 C0의 엄밀한 상한을 대체하지 않는다.

모델은 linear-rc@1, 수치 출처는 rc-modal-1, 안정화 정책은 rc-envelope-1이다. 후자는 C0의 상대 0.001·전압 1 µV·전류 1 pA·수치 예산 1%를 유지한다. 정책 ID는 검증용 rc-c0-envelope-1과 제품 계약을 구분한다. 미정 수치를 0으로 채우지 않는다. C0 진단과 같은 RC_* 코드를 Diagnostic 형태로 정의하고, DC 엔진은 축전기를 받으면 RC_ENGINE_REQUIRED로 거부한다.

## 측정과 시간 출처

기록의 선택적 `transient: RcFrameContext`에 모델/리비전·수치/안정화 정책·circuitRevision·operationIndex·frameId·time을 저장한다. 초기 구간 번호는 0이고 이후 조작마다 증가한다. finite는 유한한 비음수 seconds를 가지며 equilibrium에는 seconds가 없어야 한다. 평형을 유한한 T초로 기록하지 않는다.

RC 기록은 축전기가 있는 스냅샷의 simulation 전압·전류에만 허용한다. DC provenance를 함께 넣거나 RC 근사 메타데이터의 출처를 누락하면 거부한다. 값 자체는 정확할 수 있다. 반대로 RC 문서의 simulation 기록에 transient가 없으면 거부한다. 외부 측정은 실제로 알려진 조건만 기록한다. 원시 CSV는 RC 출처·조작·시간 종류를 독립 열로 보존한다. 기존 DC 기록의 새 RC 열은 빈 값이다. 재생 중 측정 UI와 표의 시간 표현은 C3/C4다.

## 복원과 원본 보호

| 데이터 | 정상 읽기 | 변환 경로 |
|---|---|---|
| 회로 | v7만 | 명시적 recoverDocument에서 v5→v6→v7 또는 v6→v7 |
| 측정표 | v6만 | v6 키가 없을 때 검증된 v5를 현재 채널의 새 v6 키로 복사 |

회로 v5·v6 스키마를 고정하고 각 구버전 구조 검증 뒤 새 버전의 정규형·참조·물리 의미까지 검사한다. 값·ID·배치·출력 설정은 유지하고 버전만 바꾼다. 원문은 기존 originals:v1에 보관한 뒤 자동 저장본을 교체한다. 정상 parseDocument는 구버전을 묵시적으로 바꾸지 않는다.

측정표 키는 `<channel>:edu-circuit:measurement-notebook:v6`, 백업은 같은 키의 `:backup`이다. v5 기록은 고정된 v5 기록 스키마와 회로 v6 스키마를 먼저 검증하고 스냅샷만 v7로 바꾼다. 기존 값·품질·메모·방향·위치·DC 출처를 보존하며 시간 정보를 추가하지 않는다. 원래 v5 키·백업은 변경하거나 삭제하지 않는다. 다른 채널 키는 읽지 않는다. 공용 키는 채널 키가 없을 때만 후보가 된다.

v6 키가 존재하면 v5로 되돌아가지 않는다. 현재 키가 손상되면 같은 버전 백업만 사용한다. 구버전 기본본 실패 시 그 버전의 백업을 검사할 수 있다. 지원 밖 버전·원문 오류는 빈 저장 공간으로 간주하지 않는다. 새 v6 키를 만들기 직전에 대상 키 부재와 읽었던 원문의 동일성을 재검사한다. 변환·저장 실패는 원본을 변경하지 않는다.

유효한 현재 기록을 저장할 때 이전 기록을 백업한다. 현재 기록을 읽을 수 없고 유효한 백업도 없으면 일반 저장을 거부한다. 백업에서 불러온 기록을 이후 수정·삭제하여 저장하는 경우 손상 원문을 `<channel>:edu-circuit:measurement-notebook:originals:v1`에 먼저 보관한다. 백업을 회전할 때도 손상된 이전 백업을 이 목록에 보관한다. 보관 실패 시 원문을 덮어쓰지 않는다. 검증된 기록을 새 키로 복사하는 쓰기만 실패하면 메모리 기록과 원본을 유지하고 경고한다. 다중 탭 병합은 지원하지 않는다.

이 결정은 ADR-010/022/024/026의 이전 저장 버전·구버전 변환 제한 및 ADR-039의 v5→v6 한정 범위를 위 표에 한해 대체한다. 이전 앱으로 롤백할 경우 자동 저장을 덮어쓰지 말고 원본 보관본의 v6 회로와 보존된 v5 측정 키를 사용한다. v7을 v6로 낮추는 변환은 제공하지 않는다.

## 제품 노출 경계

축전기는 C1에서 파일·타입·검증·컴파일 계약으로 등록한다. 배치 팔레트에는 노출하지 않는다. 외부 v7 파일을 열었을 때 기존 전압계로 잘못 보이지 않도록 임시 이름 표식 C를 제공하며 이는 최종 수업용 회로 기호가 아니다. 정식 교과 기호 선택과 출력 수용 검증은 C4에서 수행한다. F·C 단위는 공개 숫자 계약에서 지원한다. 충전·방전 계산·재생·계기 연결은 아직 없다.

## 검증

[C1 검증 결과](../docs/testing/rc-c1-results.md)에 현재/이전 형식 왕복, 초기 전압 부호·단자 순서, 시간 출처·오차 정책 거부, 원본 보관 실패·대상 변경·채널 격리, 기존 DC·측정·저장 회귀를 기록한다. C1 완료와 RC 제품 전체 수용은 구분한다.
