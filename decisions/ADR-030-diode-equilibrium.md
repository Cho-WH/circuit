# ADR-030: 차단 전류 0 A를 유지하는 다이오드 평형 선택

- 상태: accepted
- 결정일: 2026-10-07
- 관련 요구사항: SIM-002/003/007/008, MEA-001/002, VIS-001/006, DAT-003
- 사용자 승인: 미세전류를 측정·표현하지 않고, 스위치 개방으로 생기는 다이오드 전압의 미정을 해소한다. 재분배 과정은 생략하고 최종 직류 상태만 표시한다.

## 결정

기존 교과서·부품 모델의 회로식과 다이오드 상보 조건을 만족하는 전체 허용 해 집합에서 `Σ V_D²`를 최소화하는 해 집합을 최종 교육용 평형으로 선택한다. 모든 다이오드를 같은 가중치로 포함한다. 스위치 유무·회전·배치·ID·측정 위치에 따른 예외 규칙은 없다. 고정된 다이오드 전압은 목적값의 상수항이므로 변하지 않는다.

이 규칙은 명시적인 교육용 정상상태 선택 가정이다. 실제 반도체의 누설 특성·정전용량·초기 전하·온도·방전 시간을 정밀하게 예측한다는 뜻이 아니다. 유한한 누설저항, 수치용 작은 컨덕턴스, 임의 허용오차를 회로식에 추가하지 않는다. OFF 전류는 최종 회로식에서도 정확히 0 A이며 측정·기록·전력·전류 표시에 작은 전류를 만들거나 숨기지 않는다. 원래 흐르는 미세 비영 전류는 보존한다.

이는 ADR-026의 원래 허용 해 전체를 그대로 측정하던 정책 중 다이오드 전압의 자유도에 대한 보완이다. 예를 들어 1 V 전원과 두 직렬 다이오드는 원래 중간 전위 [0.3, 0.7] V를 허용하지만, 이제 대칭 평형 0.5 V를 계산한다. 허용 해를 임의로 하나 고르는 것이 아니라 동일한 목적식·제약으로 재현한다.

## 유지할 경계

- 5 V–스위치–1 kΩ–다이오드 직렬 회로에서 개방 시 모든 가지 전류 0 A, 저항·다이오드 양단 0 V, 스위치 양단 전압 크기 5 V다. 스위치 위치와 다이오드 방향에 무관하다.
- 전원이 유지하는 역전압·문턱 이하 전압을 0으로 만들지 않는다. 순방향 0.7 V·4.3 mA 및 브릿지 3.6 V·3.6 mA를 유지한다.
- 이미 확정된 값은 허용 해 집합을 제한해도 바뀌지 않는다. KCL·전원식·저항식·다이오드 부등식은 그대로 만족해야 한다.
- 기준 없는 독립 회로의 절대 전위, 이상 병렬 가지의 미정 전류와 모순 전원은 별개다. 임의 접지·전류 분배·거짓 해를 만들지 않는다. 다이오드 전압이 같아도 남는 전류 자유도는 보존한다.

## 구현과 예산

`simulation/equilibrium.ts`는 엔진 내부의 평형 선택만 담당한다. `piecewise`가 각 ON/OFF 후보를 정확 아핀 해와 부등식으로 검증한 뒤 평형 선택을 적용하고, 그 최종 해 집합으로 공개 결과와 `queryVoltage`·`queryCurrent`를 모두 만든다. UI나 측정 API에서 보정하지 않는다.

각 후보의 목적식은 볼록 이차식이다. 활성 제약 조합의 KKT 식을 기존 정확 `affineSolve`로 풀고, 원래 부등식과 비음수 승수를 기존 `feasible`로 검증한다. 검증된 최소 목적값을 전체 ON/OFF 후보 사이에서 비교한다. 특정 활성 면이나 자유변수 0 대입으로 해를 축소하지 않고, 최소 다이오드 전압 벡터를 만족하는 전체 아핀 가족을 보존한다.

ON/OFF 후보 1,024개에 더해 평형 활성 조합은 요청당 4,096개로 제한한다. 기존 정수·GCD·부등식 25,000개·누적 조밀 행렬 원소 1,000,000개 예산을 공유하고 새 행렬도 할당 전에 검사한다. 계산이 끝나지 않으면 해당 부분은 기존 `OPERATING_POINT_UNVERIFIED`를 반환하며 임의 0이나 완료된 평형으로 꾸미지 않는다.

## 저장·측정·화면

회로 구조와 프로필 수치를 바꾸지 않으며 저장은 회로 v6·기록 v5를 유지한다. 다이오드 계산의 기존 `provenance.profileRevision` 지문에 `diode-equilibrium-1` 정책 식별자를 포함한다. 이전 기록의 값·문서는 바꾸지 않고 새 계산과 기록 조건을 구별한다. 새 사용자 설정이나 부품 속성은 추가하지 않는다.

분석 결과·직접 측정·기록·위험 평가·2D 색상·3D 높이·전류 흐름은 같은 최종 결과를 사용한다. 미세전류 문구, 누설 설정, 재분배 애니메이션은 없다.

## 수용 검증

`diode-engine.test.ts`는 양 모델·스위치 세 위치·두 다이오드 방향의 개방/재폐쇄, 0 A, 0 V, KCL, 고정 역전압, 제약 경계에서의 평형, 직렬 분배, 기준점·ID·배열 순서 독립성, 실제 미세전류 보존을 확인한다. 기존 병렬 전류 비유일·기준 없는 전위·모순·예산 초과 검증도 유지한다.

`analysis-workspace.test.ts`는 측정 중 스위치 개방으로 700 mV → 0 V, 정확한 0 기록과 정책 출처, 모든 전류 표본 0, 미정 없는 전위 높이, 3D 상태와 탐침 유지 및 재폐쇄를 확인한다. 기존 다이오드·브릿지·저장·시각화 검증을 함께 사용한다.
