# ADR-038: 전지와 조절 가능한 직류 전원

- 상태: accepted
- 결정일: 2026-10-08
- 요구사항: EDT-001/008, MEA-003, TCH-001, DAT-001/002
- 사용자 결정: 기존 전원은 ‘전지’, 새 부품은 ‘직류 전원’으로 제공하고 원 안에 +/−가 있는 기호를 사용한다.

## 조작과 재사용

부품 목록의 두 항목은 별개이며 기존 전지 기호·값·이름은 유지한다. 직류 전원은 기본 9 V, 범위 0~12 V다. 만들기에서 현재값·범위를 설정하고 분석에서 선택하면 가변저항과 같은 왼쪽 조절창을 연다. 숫자 입력·슬라이더·자동 왕복·중간 위험 검사·조작별 실행 취소·활동 권한·측정 기록·3D 축척 유지도 기존 경로를 사용한다. 음전압은 범위에 허용하지 않으며 극성은 단자 연결로 정한다. 원과 내부 극성 기호는 목록·2D·3D 바닥·SVG·PNG의 공통 기호다. 회전 시 극성 위치는 단자를 따르고 +/− 자체는 똑바로 유지한다. 두 전원은 기존 V 접두어의 공통 이름 번호를 사용한다.

## 문서와 계산

계산 타입은 기존 `dc-voltage-source`를 공유한다. 목록용 `adjustable-voltage-source`가 `sourceKind=adjustable`, 정확값 `voltageV/voltageMinV/voltageMaxV`를 생성한다. domain의 `adjustableRangeDefinition`이 저항·전압의 속성 키와 0 허용 여부를 제공하며 domain 검증과 component-library의 조절 정의가 함께 사용한다. 전압 범위는 필수이며 `0 ≤ min < max`, `min ≤ value ≤ max`를 검증한다. 범위만 축소하면 현재값을 제한하고 기존 명령 하나로 적용한다.

이번 변경은 기존 v6 문서와 v5 기록을 변환 없이 계속 읽기 위한 선택적 필드 추가다. 회로 v6·측정 기록 v5를 유지하며 전지가 직류 전원으로 자동 변환되지 않는다. 새 범위 필드는 기존 정확값 스키마를 사용한다. 이 추가에 한해 스키마 변경마다 버전을 올린다는 확장 지침의 예외로 정한다. 새 전원이 든 문서는 해당 필드가 없는 이전 앱에서 거부될 수 있다. 구버전 변환·저장 복구 체계 개편은 별도 후속 작업이다.

두 전원은 기존 이상적 전압원과 교육용 `edu-source` 특성·작동 경계를 공유한다. 실물 장비의 정전류 제어나 역류 보호를 추가하지 않는다. 다이오드가 있는 연속 조절은 전압·저항 모두 분석 진입부터 부품 모델을 유지한다. 일반 선형 회로에서는 전원 전압에 대한 해가 아핀 함수이므로 기존 양 끝 비교 축척을 재사용하고, 다이오드 회로는 현재점 포함·범위 확대 규칙을 유지한다. 등가저항은 두 전원 모두 기존 방식으로 분리하며 안내는 ‘전원 분리’로 통일한다.

## 검증

기존 조절·분석·출력 검사에서 전압 범위의 0·경계·잘못된 입력·정확값 저장 왕복, 측정 기록, 명령 권한, 회전 극성과 출력 기호, 다이오드 모델 유지·과부하 잠금을 확인한다. 브라우저에서는 부품 배치, 범위 편집, 탐침을 유지한 실시간 조절을 확인한다.
