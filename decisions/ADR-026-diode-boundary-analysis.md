# ADR-026: 다이오드 직류 해석과 분석 모드의 과부하·파손 표현

- 상태: accepted
- 결정일: 2026-10-05
- 적용 단계: 1차 MVP 이후 다이오드 확장
- 구현 상태: D0~D4 구현 완료, 로컬 검증·화면 검수 반영. 푸시·배포 전
- 관련 기존 요구사항: EDT-001/004/007/008, SIM-001~008, MEA-001~003, VIS-001~007, DAT-001~003, TCH-001~003
- 요구사항과 스키마 반영: [구현 기록](../docs/implementation/diode-mvp.md)의 D0에서 회로 v6·측정 기록 v5, 교육용 프로필과 확장 조항을 함께 확정했다.

## 배경

기존 엔진은 이상적인 선형 직류 저항 회로를 정확 유리수로 해석한다. 0.7 V 고정 강하 다이오드를 추가하면 도통 상태를 결정해야 하며, 전지 직결·병렬 다이오드 등에서 이상 해가 없거나 가지 전류가 하나로 정해지지 않을 수 있다.

교육 목표는 이런 회로를 만든 학생이 전류·전압과 부품의 반응을 관찰하고 연결을 수정하는 것이다. 계산의 미정·실패 상태를 그대로 읽게 하거나 저항 연결을 정답으로 지시하는 경험으로 끝내지 않는다. 일반 수업의 이상값은 유지하면서 필요한 경우에만 명시적인 최소 부품 특성을 반영한다.

## 결정

1. **정확한 교과서 모델과 유한한 부품 특성 모델을 같은 엔진에서 지원한다.** 교과서 모델은 도통 시 정확히 7/10 V다. 부품 모델은 전원 내부저항과 다이오드의 양의 도통 기울기를 사용한다. 원본 문서에 보이지 않는 저항·절점을 편집 요소로 삽입하지 않는다.
2. **해석 결과와 위험 판정을 분리한다.** 이상 해의 부재·비유일성은 부품 모델이 필요한 근거이며, 곧바로 과부하나 파손을 뜻하지 않는다. 노랑·빨강은 검증된 부품 모델의 전류·전력·역전압과 명시된 부품 경계의 비교로 정한다. 정격을 전류 제한기로 사용하지 않는다.
3. **회로 만들기에서는 사전 경고만 한다.** 현재 확정된 회로와 현재 부품 값으로 분석 진입 결과를 예측한다. 기존 캔버스 왼쪽 위 아이콘을 재사용하여 노랑 느낌표는 과부하, 빨강 느낌표는 파손 예상으로 표시한다. 클릭·탭 시 관련 부품과 최소한의 주의사항만 보인다. 만들기에서는 과부하·열폭주·파손 연출을 하지 않는다.
4. **분석 진입을 회로 확정 시점으로 삼는다.** 경고 확인 모달 없이 진입한다. 노랑에서는 작동 중인 과부하 상태를, 빨강에서는 짧은 파열 후 손상된 부품과 짧은 원인을 보여준다. 경고 아이콘 바로 옆의 `회로 수정하기`로 원본과 마지막 값을 보존한 채 만들기에 돌아갈 수 있다.
5. **값 변경으로 임계를 넘으면 같은 사건을 적용한다.** 가변저항·직류 전원의 유효한 현재값으로 매번 판단한다. 초기 분석과 실시간 조절에 같은 모델 선택을 적용하고 조절 범위·가변 부품 유무·이전 모델로 강제 전환하거나 유지하지 않는다. 교과서 결과의 정상 상한 초과는 부품 모델 선택 조건이며, 위험 사건은 최종 부품 계산값으로 확정한다. 위험 상태 진입 때만 연출하며 재렌더·측정·카메라 이동은 트리거가 아니다. 과부하·파손에서 자동 왕복·수동 값 변경·Undo/Redo를 명령 단계에서 잠근다. 노랑은 현재 조건의 전압·전류 측정과 기록을 허용하되 전원 분리가 필요한 등가저항 측정은 차단한다. 값 조절은 만들기에 복귀한 뒤 재개한다.
6. **빨강 사건 이후에는 분석 세션을 중단한다.** 파손 후 개방·단락 회로를 임의로 가정하지 않는다. 실시간 측정·새 기록·전기값 변경을 잠그고, 파손 후 전류를 0 A로 만들어 표시하지 않는다. 제작 원본은 온전하게 유지하며 만들기 복귀 시 세션의 파손 표시를 초기화한다.
7. **열 축적과 실제 파손 시간은 계산하지 않는다.** 열용량·열저항·온도 적분·냉각·온도에 따른 전류 피드백은 이번 범위 밖이다. 연출의 길이는 UI 시간이며, 실제 부품의 고장 시간을 뜻하지 않는다.
8. **현재값·위험·표시의 출처를 일치시킨다.** 분석에 선택된 모델의 전압·전류·전력으로 측정과 시각화를 만든다. 위험 사건은 그 모델의 검증 결과에 근거한다. 부품 특성 적용은 수치의 근사 표기와 기록 조건으로 구별한다. 캔버스의 `부품 특성` 배지는 제거하고, 초기화 버튼은 옅은 붉은 배경과 얇은 붉은 테두리로 강조한다.

2026-10-05 후속 합의: 과부하 이후 계속 값을 바꾸며 모델 전환을 전지 성능 변화로 오해하는 일을 줄이기 위해 위 4·5·8항을 갱신했다. 노랑 잠금은 관찰 조건을 고정하는 학습 규칙이며 물리적 파손을 뜻하지 않는다. 2026-10-08에는 같은 현재값의 초기 분석·조절 결과를 일치시키도록 5항을 갱신하고 연속 조절의 선제 부품 모델·세션 유지 정책을 폐기했다.

2026-10-06 승인: [부품 설명 H01~H07](../docs/ux/operating-help.md)을 2D·3D의 공통 선택형 물음표로 제공한다. 확정된 작동 원인과 공개 전압차·전류 질의만 사용하며 회로를 다시 풀거나 위험을 다시 판정하지 않는다. 정상 교과서 계산에는 추가하지 않고, 정상 부품 계산은 선택/직접 측정 시, 과부하는 원인과 관련된 부품에 최대 3개를 표시한다. 파손 연출 중 닫고 완료 후 손상된 부품의 저장된 원인만 설명한다. 문구·선택 조건·배치·UI를 app 내부 기능으로 분리하며 렌더러는 라벨 위치만 전달한다. 앱 조작에 대한 H08~H10, 경고/측정값 옆 물음표, 설명의 저장·출력은 제외한다.

## 현행 계약과의 관계

이 ADR의 D0~D4를 기존 선형 DC 엔진·편집·측정·출력 경로에 구현했다. 현재 지원은 선형·구간선형 DC와 회로 v6·측정 기록 v5다. 확장 전 v5·v4의 검증 실적은 당시 이력으로 유지하며, 이전 형식을 변환하거나 새 프로필로 재해석하지 않는다. 다음 계약을 같은 변경 단위로 갱신했다.

내장 프로필은 [작동 경계](../docs/physics/circuit-operating-boundaries.md)에 고정한 교육용 가정이며 실물 정격이나 실제 파손 시각의 예측이 아니다. 실제 교실·실기기·보조기술 검증은 남아 있으며 코드·브라우저 검수의 근거는 [작업 추적](../docs/implementation/mvp-tracker.md)에 기록한다.

| 현행 결정 | 유지·확장 내용 |
|---|---|
| ADR-003/004/009 | 0 Ω 연결과 자체 MNA를 유지하고 다이오드 상태 탐색·계수 분류를 확장 |
| ADR-010 | 순수 계산·결정론·구조화 진단 유지. 물리 모델과 사건 상태의 계약 추가 |
| ADR-011/015 | 전압차·전류 합을 직접 질의. 다이오드를 누락한 등가저항 계산 금지 |
| ADR-012 | 파손 연출을 저장·문제지 출력 원본에 섞지 않음 |
| ADR-020/021 | 전류 무늬의 시간과 물리 판정 분리. 기존 분석 화면·명령 검사·경고 위치 재사용 |
| ADR-022 | 측정 조건에 모델·프로필을 보존. 파손 후 새로운 현재값 기록 금지 |
| ADR-023 | 가변저항 진입 사건·자동 왕복 중단 추가. 다이오드 회로에 양 끝 극값 보장을 적용하지 않음 |
| ADR-024/025 | 정확 유리수와 계산 예산을 유지. 물리 모델의 근사와 수치 연산의 근사를 구별 |

## 범위 밖

- 정밀 반도체·배터리 화학·도선 길이 저항 모델.
- 실제 열폭주, 열 적분, 실제 온도·수명·소손 시각 예측.
- 파손 이후 회로의 연쇄 고장과 수리·재고·부품 교체 시스템.
- 다이오드 추가와 동시에 구현하는 LED·트랜지스터·축전기·정전류 전원.
- 모든 소자에 같은 배수를 적용한 파손 경계, 실행마다 달라지는 숨은 편차.
