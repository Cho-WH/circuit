# ADR-022: 비교를 위한 측정표와 별도 로컬 기록

- 상태: accepted
- 결정일: 2026-09-30
- 요구사항: MEA-003, DAT-001~002

## 결정

측정값의 기록은 화면을 전환하지 않고 버튼에서 짧게 확인한다. 왼쪽 기록 보기로 회로 아래의 고정 높이 측정표를 열며 경로 그래프와 동시에 펼치지 않는다. 표가 열린 상태의 추가 기록은 회로 영역 크기를 바꾸지 않는다. 분석 화면의 크기 변경은 보던 좌표 범위를 유지하고 남은 공간에 맞춰 표시한다. 값 편집 중 키보드 시야 보정은 기존 로직을 유지한다.

표에는 짧은 측정 위치(R₁ 양단, R₁ 오른쪽 도선)·측정 종류·측정값·행별 메모·삭제를 둔다. 탐침 순서/전류 방향은 위치 툴팁과 복사/CSV에 보존하고 표의 각 행에서는 반복하지 않는다. 기록 당시 회로 보기의 탐침 순서는 그림의 색상으로 확인하며 빨강·검정 위치 설명을 텍스트로 반복하지 않는다. 전류 방향 설명은 유지한다. 회로 조건은 부품 이름과 값을 분리해 표시한다. 위치는 공통 endpointName·wireName으로 연결된 부품·단자 방향을 설명하며 분기점/도선의 저장 ID를 사용자 이름으로 노출하지 않는다. 연결점의 이웃 단자는 명시된 도선 ID 연결로 찾고, 연결된 부품이 없으면 연결점·도선처럼 표시한다. 정확한 지점은 당시 회로 보기에서 확인한다. 같은 이름 정책을 탐침 안내·접지·전류 설정·배선 후보·접근성 이름에도 적용한다. 예상값 입력을 제거한다. 표 복사 옆에 기록 초기화를 두어 전체 측정 기록과 메모를 비우며 빈 표에서는 비활성화한다. 회로·현재 탐침·측정값은 유지한다. 표 복사는 HTML과 탭 구분 텍스트를 제공하고, 화면의 CSV는 같은 내용을 한글 열 이름과 단위로 내보낸다. HTML 이스케이프와 스프레드시트 수식 텍스트 보호를 적용한다. 기존 measurementsToCsv의 원시 수치·단위·회로 JSON 계약은 유지한다.

기록 당시 문서를 스냅샷으로 보존한다. 문서 ID·부품 종류와 단자·전기 속성·도선 연결·분기점·전원 분리 여부가 같으면 같은 조건으로 묶는다. 배치·이름·수치 표시 형식·배열 순서는 조건을 나누지 않는다. 각 조건의 전원·저항값·스위치 상태를 한 번 표시한다. 조건 번호는 표의 현재 기록에서 계산한다. 이후 값 변화 비교에 사용할 틀이며 별도 실험 도구나 자동 변수 변화는 추가하지 않는다.

위치 이름을 누르면 기록 당시 회로를 읽기 전용 창에서 보여 준다. 기존 CircuitCanvas·측정 기호를 재사용하고 현재 회로와 탐침·시야를 변경하지 않는다. 전압·저항 탐침과 전류 센서의 배치를 기록 시 복제한다. 단자·분기점·부품 ID 또는 도선 ID·구간 번호·구간 내 비율을 저장하고, 당시 스냅샷과 기존 anchorPose로 정확한 접촉 위치를 재현한다. 표시 문구나 기본 위치에서 배치를 추정하지 않는다. 저항은 모든 전원을 분리한 표시를 재사용한다. 전류의 표시는 크기와 실제 방향, 저장은 원시 부호와 기준 방향을 유지한다.

## 저장과 경계

MeasurementRecord와 계산 API는 유지한다. persistence의 MeasurementEntry는 기록 ID, MeasurementRecord, 메모, sourcesDisconnected, 전류 기준 방향과 필수 anchors를 담는 별도 저장 항목이다. MeasurementAnchor·MeasurementAnchors는 persistence의 공개 데이터 타입이며 app/measurement-tools가 같은 타입을 재사용한다. 현재 도구에 해당하지 않는 탐침은 null로 기록한다. 위치 참조·도선 구간 범위·비율과 측정 대상의 일치를 로드·저장 시 검증한다. 측정 기록은 현재 해석 결과로 재사용하지 않는다.

로컬 형식은 `{ version: 2, entries: MeasurementEntry[] }`, 키는 `edu-circuit:measurement-notebook:v2`이다. 사용자 지시에 따라 위치를 보존하지 않던 측정표 v1의 호환·마이그레이션은 제공하지 않는다. v1 키를 읽거나 삭제하지 않고 새 기록부터 v2에 저장한다. 포함된 CircuitDocument에는 기존 v1→v4 검증·변환을 적용한다. 회로 문서 v4와 파일 스키마는 그대로다. 이번 측정표 v1 호환 제외는 사용자 요청에 따른 예외이며 회로 파일 호환 정책은 유지한다.

persistence가 로드·검증·쓰기·유효한 이전 사본을 맡는다. 읽기에 실패하면 저장본을 빈 목록으로 덮어쓰지 않으며 유효한 백업을 우선 복원한다. 쓰기 실패는 메모리 기록을 보존하고 사용자에게 알린다. 같은 브라우저의 작업 기록이며 회로 파일에는 포함하지 않는다. 다른 기기로의 이동은 표 복사/CSV를 사용한다. 다중 탭 병합은 현재 지원하지 않는다.

app/useMeasurementRecords는 기록 상태와 저장 연결, app/measurement-records는 조건 묶기·표시·복사 데이터, app/MeasurementTable은 표와 당시 회로 보기를 담당한다. 일반 실험 프레임워크를 만들지 않는다.

## 검증

기존 측정·분리·상태 보존 테스트를 재사용한다. 추가 검증은 조건 구분, 부호·방향, 메모/삭제 후 재마운트, 저장 왕복·손상 복구·실패, 스냅샷 이전 버전 호환, 복사 형식에 집중한다. 도선 중간에 놓은 전압·저항 탐침과 전류 센서는 기록 후 현재 위치·배선을 바꾸고 재마운트해도 미리보기에서 기록 당시 좌표를 유지하는지 확인한다. 실제 교실과 모바일 전용 UX 검증은 후속이다.
