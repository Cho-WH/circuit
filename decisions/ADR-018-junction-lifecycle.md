# ADR-018: 분기점의 국소 정리와 배선 시작

- 상태: accepted
- 결정일: 2026-09-24
- 관련: EDT-001/002/003/005, SIM-001, ADR-013/016/017

## 결정

분기점은 연결을 기록하는 ID다. 화면 좌표가 같다는 이유로 연결하거나 합치지 않는다. ADR-017의 연결점 정리를 삭제로 영향을 받은 기존 분기점에도 적용한다.

1. 도선 삭제로 도선을 잃은 분기점과 부품 대체로 만든 분기점만 정리한다. 연결이 0개면 제거, 1개면 열린 끝 유지, 2개면 경로 병합, 3개 이상이면 분기 유지다. 기준점·주석 앵커는 자동 제거하지 않는다. 폐곡선은 참조할 끝점 하나를 유지한다.
2. 경로 병합은 문서 순서상 앞선 도선 ID와 방향을 유지하고 굴곡·되접힘을 보존한다. 관계없는 문서 영역은 변경하지 않는다. 노드 수동 삭제는 제공하지 않는다. DeleteElements에 노드 ID가 포함되면 INVALID_COMMAND로 전체 명령을 거절하며 문서·이력·앵커를 유지한다. 도선은 자신의 ID가 삭제 대상일 때만 제거한다.
3. 삽입 후보는 앵커 없는 두 도선의 접점을 합친 경로에서 계산한다. 확정은 선택한 연속 경로만 같은 규칙으로 정리한다. 중간 노드가 있던 직선에도 부품을 삽입할 수 있으며 실제 분기·앵커·코너에 충분한 공간이 없으면 실패한다. 실패는 문서와 이력을 변경하지 않는다.
4. 끝단과 일반 분기점은 클릭·탭·Enter/Space로 즉시 배선을 시작한다. 기존 endpoint 배선 시작 처리를 공유하며 노드 선택 메뉴와 수동 삭제 경로를 제거한다. 네 갈래 직교 교차의 연결·비연결 전환은 ADR-013의 기존 판정과 동작을 유지한다. 진행 중인 배선의 도착점 선택은 그대로다.
5. 배치 불가 위치에서는 320ms 동안 원과 X 효과만 표시한다. 이유 문구나 가까운 위치 안내를 추가하지 않으며 배치 도구와 초안은 유지한다. 움직임 감소 설정에서는 페이드 없이 표시 후 숨긴다. 터치의 유효한 삽입은 기존 확인 버튼을 유지한다.

## 경계와 저장

- `editor/wire-topology.ts`는 연결 수·앵커·경로 병합과 선택 경로 탐색을 담당한다. 삭제 정책과 UI를 모른다. ADR-017의 `wire-edits.dissolveWireJunctions` 책임을 이 모듈로 옮긴다.
- `delete-elements.ts`는 영향받은 ID를 수집한다. `wire-edits.ts`는 정리된 경로의 삽입 후보와 문서 수정을 담당한다. 후보 조회는 복제본을 사용하고 미리보기·확정은 같은 명령을 실행한다.
- `wire-geometry`는 점 계산만, `app/wiring`은 선택·배선 상태 전환만, `PlacementFailure`는 일시적인 표시 수명만 소유한다.
- 기존 v4 Junction·Wire·waypoints를 그대로 사용한다. 저장 마이그레이션이나 전역 자동 복구를 추가하지 않는다. 부품이 사라지는 별도 현상의 원인 조사는 이번 변경 후 진행한다.

## 검증

`junction-editing.test.ts`는 연결 수별 정리, 앵커, 경로와 net 보존, 관계없는 영역 보존, 직선 접점 삽입, 분기·코너·앵커 거절, 미리보기/확정/undo/redo를 검증한다. `canvas-drag.test.ts`는 마우스·터치 실패 효과와 초안 유지, 정리된 삽입 미리보기, 끝단과 분기점의 동일한 배선 시작, 수동 삭제 경로 부재를 확인한다. 기존 부품 삭제·문맥 배선 회귀 테스트를 함께 실행한다.
