# ADR-021: 시각화와 측정의 분석 화면 통합

- 상태: accepted
- 결정일: 2026-09-29
- 요구사항: VIS-001~006, MEA-001~004, SIM-005, EDT-004

## 결정

상위 작업을 회로 만들기 / 분석하기 / 회로도 출력으로 정리한다. 분석하기에서 전위·전류 보기는 표시 설정, 전압 탐침·전류 센서·등가저항은 선택하는 측정 도구로 제공한다. 왼쪽 부품 팔레트의 공간·타일 스타일을 재사용한다. 데스크톱은 도구 목록 아래에 탐침 상태·측정값·기록·종료 버튼을 세로로 배치하여 도구 선택이 캔버스 높이를 줄이지 않게 한다. 작은 화면은 아래 공용 바 규칙을 따른다. 선택이 기본이며 측정 팔레트에는 전압·전류·등가저항만 둔다. 같은 도구를 다시 누르거나 도구 종료·Escape로 측정을 종료하고 기본 선택 상태로 돌아간다.

측정 도구를 켜도 숫자·색상·전류 표시 설정을 바꾸지 않는다. 기록·경로 그래프은 하나의 열린 패널 상태를 공유한다. 기록은 MeasurementPanel에 유지하고, 탐침·센서 위치와 보기 설정은 App에 유지한다. 도구 전환은 Canvas를 다시 만들지 않으며 기존 시야 보존 로직을 사용한다. 다른 작업으로 이동해도 위치와 기록은 남는다. 다른 문서의 위치는 초기화하고 기록은 당시 문서 스냅샷으로 구분한다.

분석의 선택 상태에서 회로 위 값을 수정할 수 있다. 측정 중에는 상세 설정의 부품 선택·값 입력으로 값을 바꾸고 측정 결과를 즉시 갱신한다. 구조 변경은 useCircuitSession의 분석 모드 명령 검사에서 차단한다. 이름·전기 속성·기준점 수정과 실행 취소를 재사용하며 학생 활동 권한은 editor가 계속 검사한다.

경로 그래프 버튼은 상단 보기 설정, 기록 보기 버튼은 왼쪽 도구 패널에 둔다. 별도의 패널 선택 밴드는 두지 않는다. 값 변화 실험·법칙 확인의 화면 구현과 전용 상태·스타일은 제거한다. 독립적인 parameterSweep·checkKcl·checkKvl 계산 API와 계약 테스트는 유지하고, 학습 활동 UI 재설계는 후속 후보로 남긴다. MEA-004는 deferred로 전환한다.

## 등가저항과 보기 복원

전원이 있는 회로는 도구 영역에 짧은 안내와 **전지 분리하고 측정** 버튼을 표시한다. 버튼을 누르기 전에는 탐침 배치·계산·기록을 시작하지 않는다. 전원이 없는 회로는 즉시 측정한다. 확인창이나 도선 삭제 명령을 사용하지 않는다.

기존 equivalentResistance의 excludeSourceIds에 모든 직류 전원 ID를 전달한다. 기존 전원 기호의 분리 표시도 재사용한다. 측정 중에는 전지 분리 상태를 표시하고 정상 작동 상태의 전위 숫자·색상·전류·3D·빠른 값·경로 그래프를 숨기거나 잠시 비활성화한다. 표시 설정은 변경하지 않고 렌더링만 억제한다. 원본 CircuitDocument·배선·저장 데이터는 유지하며 종료 시 이전 보기 설정으로 복귀한다. 기록에는 모든 전원 분리 조건과 전원 이름을 남긴다.

## 3D와 구현 경계

1차 측정 조작은 2D에서 지원한다. 3D에서는 측정 도구 선택 시 2D로 전환됨을 짧게 안내한다. 전압 탐침은 3D 버튼으로 이동해도 활성 상태·위치·측정값·기록을 유지한다. 탐침 영역은 2D·3D에서 같은 버튼과 배치를 사용한다. 3D에서 빨강·검정 탐침을 누르면 선택한 탐침을 활성화하고 2D로 전환한다. 이미 활성화된 상단 전압 탐침을 다시 눌러도 도구 종료 대신 2D로 전환한다. 기존 위치·측정값·기록을 유지하며 맞바꾸기·위치 지우기·기록·도구 종료는 3D에서도 바로 적용한다. 별도 위치 변경 버튼은 두지 않는다. 전류 센서·등가저항은 3D 전환 시 종료하며 위치·기록을 보존한다. 3D에서 등가저항에 진입한 경우 종료 시 기존 3D 보기로 복귀한다. 3D 카메라는 기존 진입·해제 수명에 따라 다시 준비되며 직접 탐침 조작과 재진입 시 카메라 자세 복원은 후속이다. 전압 측정 중 카메라 조작·탐침 교환·기록은 시야를 초기화하지 않는다. 3D의 두 탐침 표식·전위 높이 차 눈금은 ADR-006을 따른다.

계산·측정·시각화 모듈의 공개 계약은 유지한다. App이 상태와 도구를 연결하고, AnalysisTools는 팔레트, MeasurementPanel은 측정값·기록을 표시한다. 데스크톱 콘솔은 왼쪽 호스트에 portal로 배치한다. 모바일 표시만 CompactMeasurementBar로 분리하고 계산·포맷·기록 상태와 탐침 기호·메뉴를 재사용한다. 별도 범용 도구 프레임워크나 통합 계산 모듈을 만들지 않는다. 회로 문서 스키마·마이그레이션 변경은 없다. 측정표의 하단 배치·별도 로컬 기록·표 복사는 [ADR-022](ADR-022-measurement-notebook.md)을 따른다.

## 작은 화면의 공용 바 (2026-10-04)

너비 640px 이하 또는 너비 1000px 이하·높이 500px 이하에서는 제목·만들기/분석 탭·파일 메뉴를 한 줄에 배치한다. 그 아래 54px 바는 보기의 2D/3D·전위·전류·측정 버튼과 측정의 뒤로·도구 선택·측정값·탐침을 교체한다. 전위 버튼은 색상·숫자를 함께 켜고 끄며 개별 설정은 더보기에 둔다. 측정값·개별 전위의 긴 표기는 바에서 줄여 보이되 측정값 상세 팝업과 접근성 이름에 전체 값을 유지한다. 계산 정밀도는 바꾸지 않는다.

뒤로는 탐침 배치를 해제하고 보기 바를 복원하되 위치·기록·보기 설정을 보존한다. 등가저항에서는 도구를 종료해 전원과 이전 보기를 복원한다. 전압 탐침을 놓고 뒤로→3D로 이동하면 기존 높이 차 표현을 사용한다. 기록·맞바꾸기·위치 지우기는 측정 더보기, 기록 보기는 보기 더보기에서도 연다. 기록과 가변저항 조절은 캔버스 위에 떠서 기존 영역을 밀지 않는다. 경로 그래프와 수업 화면 진입 버튼은 작은 화면에서 숨긴다.

만들기 부품 목록은 +부품에서 열고 탭 선택 후 회로에 배치한다. 예제는 같은 팝업의 접힌 목록을 사용한다. 새 회로·그림 보기/저장·도움말은 파일 메뉴에 둔다. 출력은 읽기 전용 화면 이동·확대와 복사·저장·그림 설정만 제공하며 정밀 표기/주석 편집은 넓은 화면에서 제공한다. 별도 사용자 설정과 저장 상태를 추가하지 않는다.

## 검증

기존 탐침 부호·도선 전류·등가저항·기록 검증을 재사용한다. 통합 회귀 검증은 보기 설정·위치·기록·2D 시야 보존, 부품 값 수정에 따른 측정값 갱신, 전원 분리 시작 조건과 복원, 전원 없는 회로의 즉시 측정, 3D 도구 종료 경계에 집중한다. 브라우저의 대표 화면과 작은 화면 배치를 확인하고 실제 모바일·교실 사용성은 별도로 남긴다.
