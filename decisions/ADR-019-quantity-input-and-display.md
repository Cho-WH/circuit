# ADR-019: 수치 입력과 표시의 공통 모듈

- 상태: accepted
- 결정일: 2026-09-26
- 관련: EDT-004, VIS-001/005, MEA-003/004, TCH-001/002/003, ADR-012

## 결정

순수 quantity 모듈을 입력 해석과 숫자 표시의 단일 구현으로 사용한다. notation은 수식의 분수·아래첨자·기울임을 담당한다. 두 모듈은 브라우저나 React에 의존하지 않는다.

### 입력과 정밀도

- 소수, 지수 입력, 분수와 p·n·u/μ/µ·m·k·M 접두어를 지원한다. 단위 불일치, 분모 0, 음의 저항, 유한 수치 범위 초과 및 0으로 언더플로하는 입력은 거부한다.
- 소수의 계수와 10진 지수를 BigInt로 해석하고 분수와 접두어를 정확한 정수 비율로 결합한다. 마지막에 가장 가까운 IEEE 754 binary64로 한 번 반올림한다. 정확한 중간점은 짝수 유효부를 선택한다. 계산 엔진은 기존 number 계약을 유지한다.
- 입력은 256자 이하, 개별 10진 지수는 소수점 보정 후 절댓값 4096 이하로 제한한다. 최종값은 JavaScript 유한 number의 표현 범위 안이어야 한다.
- 명시적 분수는 기존 Fraction 속성에 보존한다. 편집기는 항상 원시 값 또는 저장된 분수를 읽는다. 표시된 반올림 값을 다시 저장하지 않는다. 자동 계산 결과를 분수로 추정하지 않는다.
- 이 방식은 입력 변환의 중간 반올림과 재편집에 의한 누적 오차를 방지한다. 1/3 등 이진 부동소수점으로 정확히 표현할 수 없는 수와 회로 계산의 수치 오차는 남는다.

### 표시 선택

숫자 표시 선택은 상세 설정의 값 입력 아래에 `표시: [선택 메뉴] [전체 적용]`으로 둔다. 부품의 properties.quantityMode에 auto/scientific/plain을 저장하며 기본값은 auto다. 전체 적용은 현재 부품의 옵션을 모든 부품에 한 번의 명령 묶음으로 적용한다. 저장·복사·실행 취소에 포함하며 물리값은 변경하지 않는다. 기존 v4의 확장 속성을 사용하므로 스키마 버전과 별도 마이그레이션은 변경하지 않는다. 내보내기의 quantityFormat은 명시적 부품 설정이 없을 때의 호출자 기본값으로 유지한다.

| 선택 | 규칙 | 0.00001 Ω 예시 |
|---|---|---|
| 자동 단위 | p~M 접두어, 최대 소수 두 자리, 불필요한 끝자리 0 생략. 반올림 경계에서 상위 단위로 이동 | 10 μΩ |
| 유효 숫자 | 사용자 결정에 따라 4자리, 끝자리 0 유지, e 대신 × 10과 위첨자 지수 | 1.000 × 10⁻⁵ Ω |
| 원래 숫자 | 접두어·지수 없이 기본 단위의 왕복 가능한 원시 숫자 | 0.00001 Ω |

자동 단위에서 명시적 입력 분수는 기존 표기를 유지한다. 지수·원래 숫자 모드는 같은 실제 값을 숫자로 표시하며 저장된 분수를 변경하지 않는다. 자동 단위 범위 밖이나 반올림하면 0이 되는 비영 값은 지수 표기로 보존한다. 실제 0과 계산 불능 —를 구분한다.

편집 회로·빠른 값·3D 부품 전압차·출력·SVG/PNG는 각 부품 설정을 따른다. 부품 ID 또는 서로 다른 두 단자를 측정한 값은 그 부품의 옵션을 따른다. 기록은 당시 문서의 설정을 보존하고 실험 그래프는 생성 시 변수·관찰 부품의 옵션을 각 축에 적용한다. 단일 부품에 속하지 않는 절점·축·범례·합계는 자동 단위를 사용한다. 그래프와 대응 표는 같은 축 단위를 사용한다. CSV는 원시 수치와 기본 단위를 보존한다.

### 함께 통일한 동작

- 이름은 공백 제거 후 1~160자를 명령 단계에서 검증한다. 회로 위·속성 패널·출력의 검증을 공유한다. 이름 초안은 Enter 또는 포커스 이동으로 확정하고 Escape로 취소한다. 한 번의 확정은 한 번의 실행 취소 단위다.
- 전위 그래프·경로 선택·KVL 항은 내부 ID로 대상을 찾고 실제 부품 이름을 표시한다.
- HTML, 화면 SVG와 독립 SVG는 수식 전체에 같은 기울임 규칙을 적용한 뒤 분수·아래첨자로 나눈다. 등호 뒤 단위는 정자로 유지한다.
- 격자 맞춤과 Blob 다운로드를 각각 공통 함수로 통합한다.

## 데이터 영향과 검증

문서 스키마, 계산 엔진, CSV 계약을 바꾸지 않는다. 새로운 저장 형식 마이그레이션은 없다. quantity·notation·workspace·worksheet·3D 수명 테스트, 기존 물리 fixture, 모듈 경계, 명세 검사와 Chrome 데스크톱/모바일 크기의 실제 입력·출력 확인으로 검증한다.

확대율 보정으로 글자가 커지는 모바일 편집 화면에서는 긴 값의 글자 크기를 이웃한 가로 부품 사이 간격 안에 맞춘다. 숫자 내용과 저장값은 변경하지 않는다. Enter로 값 편집창을 열 때 기본 제출 이벤트를 차단하여 열린 창이 즉시 확정되지 않도록 한다.

## 부품별 설정 UI 개정

사용자 요청에 따라 상단 공통 선택기와 값 적용 버튼을 제거했다. 부품 값은 Enter/포커스 이동으로 확정하며 Escape로 초안을 취소한다. 불완전한 값은 실제 값을 변경하지 않는다. 표시 메뉴는 자동 단위·유효 숫자·원래 숫자로 간단히 표시한다. 유효 숫자는 여전히 4자리 × 10 위첨자 형식이다. 메뉴는 선택 체크, 방향키·Home/End·Enter·Escape, 바깥 클릭 닫기를 지원한다. 전체 적용은 명령 단계의 권한 검사를 그대로 거치고 한 번에 되돌릴 수 있다.

## 스위치 인라인 편집

스위치 이름·값 수정창과 상세 설정은 공통 SwitchStateButton의 스위치 열기/닫기 버튼을 사용한다. 상태 버튼은 기존 SetProperties(state) 명령을 즉시 실행하며 이름 변경과 별도의 실행 취소 단위다. 저장 스키마와 스위치 전기 모델은 기존 계약을 사용한다. 상태는 즉시 반영하고 편집창과 이름 초안을 유지한다. 적용/취소는 이름 초안에만 작용한다.
