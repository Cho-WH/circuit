# ADR-019: 수치 입력과 표시의 공통 모듈

- 상태: accepted
- 결정일: 2026-09-26
- 관련: EDT-004, VIS-001/005, MEA-003/004, TCH-001/002/003, ADR-012

## 결정

순수 quantity 모듈을 입력 해석과 숫자 표시의 단일 구현으로 사용한다. notation은 수식의 분수·아래첨자·기울임을 담당한다. 두 모듈은 브라우저나 React에 의존하지 않는다.

### 입력과 정밀도

2026-10-02 개정: [ADR-024](ADR-024-exact-dc-arithmetic.md)의 정확 유리수 계약을 구현했다. 입력 문법과 표시 선택, quantity/notation 경계는 유지한다.

- 소수, 지수 입력, 분수와 p·n·u/μ/µ·m·k·M 접두어를 지원한다. 단위 불일치, 분모 0, 음의 저항을 거부한다.
- 소수의 계수와 10진 지수를 BigInt로 해석하고 분수·접두어를 정확히 결합해 StoredScalar를 반환한다. 계산 전 binary64 변환은 하지 않는다.
- 입력은 256자 이하, 개별 10진 지수는 소수점 보정 후 절댓값 4096 이하로 제한한다. binary64 표현 범위를 물리값의 유효성 기준으로 사용하지 않는다.
- 명시적 분수 표기는 Fraction 속성에 보존하되 실제 StoredScalar와 정확히 일치할 때만 사용한다. 편집기는 정확한 원문을 복원하고 표시 반올림값을 저장하지 않는다.
- 회로 v5와 측정 기록 v3만 지원하며 이전 형식의 변환은 제공하지 않는다.

### 표시 선택

숫자 표시 선택은 상세 설정의 값 입력 아래에 `표시: [선택 메뉴] [전체 적용]`으로 둔다. 부품의 properties.quantityMode에 auto/scientific/plain을 저장하며 기본값은 auto다. 전체 적용은 현재 부품의 옵션을 모든 부품에 한 번의 명령 묶음으로 적용한다. 저장·복사·실행 취소에 포함하며 물리값은 변경하지 않는다. v5의 표시 속성이며 정확 물리값을 변경하지 않는다. 내보내기의 quantityFormat은 명시적 부품 설정이 없을 때의 호출자 기본값으로 유지한다.

| 선택 | 규칙 | 0.00001 Ω 예시 |
|---|---|---|
| 자동 단위 | p~M 접두어, 최대 소수 두 자리, 불필요한 끝자리 0 생략. 반올림 경계에서 상위 단위로 이동 | 10 μΩ |
| 유효 숫자 | 사용자 결정에 따라 4자리, 끝자리 0 유지, e 대신 × 10과 위첨자 지수 | 1.000 × 10⁻⁵ Ω |
| 원래 숫자 | 접두어·지수 없이 기본 단위의 소수. 순환소수는 표시용 소수로 반올림 | 0.00001 Ω |

자동 단위에서 명시적 입력 분수는 기존 표기를 유지한다. 지수·원래 숫자 모드는 같은 실제 값을 숫자로 표시하며 저장된 분수를 변경하지 않는다. 자동 단위 범위 밖이나 반올림하면 0이 되는 비영 값은 지수 표기로 보존한다. 실제 0과 계산 불능 —를 구분한다.

편집 회로·빠른 값·3D 부품 전압차·출력·SVG/PNG는 각 부품 설정을 따른다. 부품 ID 또는 서로 다른 두 단자를 측정한 값은 그 부품의 옵션을 따른다. 기록은 당시 문서의 설정을 보존하고 실험 그래프는 생성 시 변수·관찰 부품의 옵션을 각 축에 적용한다. 단일 부품에 속하지 않는 절점·축·범례·합계는 자동 단위를 사용한다. 그래프와 대응 표는 같은 축 단위를 사용한다. 원시 CSV API는 수치와 기본 단위를 보존한다. 화면 측정표의 복사/CSV는 당시 표시 설정과 단위를 사용하는 [ADR-022](ADR-022-measurement-notebook.md)을 따른다.

### 함께 통일한 동작

- 이름은 공백 제거 후 1~160자를 명령 단계에서 검증한다. 회로 위·속성 패널·출력의 검증을 공유한다. 이름 초안은 Enter 또는 포커스 이동으로 확정하고 Escape로 취소한다. 한 번의 확정은 한 번의 실행 취소 단위다.
- 전위 그래프·경로 선택·KVL 항은 내부 ID로 대상을 찾고 실제 부품 이름을 표시한다.
- HTML, 화면 SVG와 독립 SVG는 수식 전체에 같은 기울임 규칙을 적용한 뒤 분수·아래첨자로 나눈다. 등호 뒤 단위는 정자로 유지한다.
- 격자 맞춤과 Blob 다운로드를 각각 공통 함수로 통합한다.

## 데이터 영향과 검증

정확값 전환의 데이터 영향은 ADR-024를 따른다. quantity·notation·workspace·worksheet·3D 수명 테스트, 기존 물리 fixture, 모듈 경계, 명세 검사와 Chrome 데스크톱/모바일 크기의 실제 입력·출력 확인으로 검증한다.

확대율 보정으로 글자가 커지는 모바일 편집 화면에서는 긴 값의 글자 크기를 이웃한 가로 부품 사이 간격 안에 맞춘다. 숫자 내용과 저장값은 변경하지 않는다. Enter로 값 편집창을 열 때 기본 제출 이벤트를 차단하여 열린 창이 즉시 확정되지 않도록 한다.

## 부품별 설정 UI 개정

사용자 요청에 따라 상단 공통 선택기와 값 적용 버튼을 제거했다. 부품 값은 Enter/포커스 이동으로 확정하며 Escape로 초안을 취소한다. 불완전한 값은 실제 값을 변경하지 않는다. 표시 메뉴는 자동 단위·유효 숫자·원래 숫자로 간단히 표시한다. 유효 숫자는 여전히 4자리 × 10 위첨자 형식이다. 메뉴는 선택 체크, 방향키·Home/End·Enter·Escape, 바깥 클릭 닫기를 지원한다. 전체 적용은 명령 단계의 권한 검사를 그대로 거치고 한 번에 되돌릴 수 있다.

## 스위치 인라인 편집

스위치 이름·값 수정창과 상세 설정은 공통 SwitchStateButton의 스위치 열기/닫기 버튼을 사용한다. 상태 버튼은 기존 SetProperties(state) 명령을 즉시 실행하며 이름 변경과 별도의 실행 취소 단위다. 저장 스키마와 스위치 전기 모델은 기존 계약을 사용한다. 상태는 즉시 반영하고 편집창과 이름 초안을 유지한다. 적용/취소는 이름 초안에만 작용한다.


### 2026-10-01 편집 진입점의 검증 통일

회로 위 편집·상세 설정·분석 실시간 조절기는 app의 `parseComponentValue`를 공유한다. quantity의 단위·분수 파서를 재사용하고 부품별 허용 값과 가변 범위를 동일하게 검사한다. 이름·값·범위의 일괄 적용과 개별 입력 확정 시점은 각 UI의 기존 계약을 유지한다.
