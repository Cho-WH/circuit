# ADR-044 RC 재생·원자적 조작·초기화 세션

- 상태: accepted
- 작성일: 2026-10-22
- 관련 요구사항: SIM-009, VIS-008, MEA-006, DAT-006
- 승인: 사용자가 dev에서 설계 기준 C3 구현·검증을 요청했다. C4 관찰·기록·기호·출력과 C5 수용·배포는 별도 단계다.

## 결정과 모듈 경계

`app/rc-session.ts`의 `RcSession`이 분석 진입 스냅샷, 후보 명령, 요청 세대, 현재 plan/frame, 재생 시계와 상태를 소유한다. `useCircuitSession`이 기존 문서/Undo 소유권과 자동 저장을 유지하고 RC 세션의 문서·프레임 확정을 같은 React 업데이트에서 발행한다. simulation의 공개 prepare/sample만 호출하며 내부 행렬·수치 모드에 접근하지 않는다. 회로 v7·측정 기록 v6와 물리 정책은 변경하지 않는다.

축전기가 있는 문서의 분석은 RC 경로로 들어간다. 축전기 없는 DC·다이오드의 기존 연속 조절·작동 경계는 유지한다. RC 분석은 과부하·파손 판정과 자동 값 왕복을 사용하지 않는다.

## 명령과 초기화

RC의 전기 조건 변경은 별도 비동기 `applyRc(command)`로만 받는다. 평형에서 스위치 state, 저항/가변저항 값, 조절형 직류 전원 전압 중 한 부품의 변경만 허용한다. 고정 전지 전압, 범위, C, 초기 전압, 구조, 기준점, 이름·표시 설정은 RC 세션에서 바꾸지 않는다. 기존 동기 execute 경로로 보내는 우회 입력도 거부한다. 파일 열기는 별도 ReplaceDocument로 허용하며 이전 실행을 취소한다. 문서 Undo/Redo도 분석 중 실행 경계에서 거부한다.

숫자와 슬라이더는 초안이다. 적용 또는 Enter에서 후보 문서 검증, 활동 권한 검사, plan 준비, t=0 및 equilibrium 프레임 확인을 수행한다. 완료 시 요청 세대·기준 History 객체·문서 내용이 그대로인지 검사하고 기존 명령 검증을 다시 거쳐 한 번의 Undo와 함께 확정한다. 준비 중 추가 조작은 거부하며 큐에 보관하지 않는다. 후보 실패는 이전 평형·문서·이력과 초안을 보존한다. 재생 중 sample 실패는 마지막 유효 프레임을 보존하고 Error로 잠근다.

다시 시작은 진입 시 스냅샷의 속성을 기존 SetProperties 명령 묶음으로 권한 검사한 뒤 정확히 복원한다. 나중에 추가한 분수 표시 힌트도 원래 스냅샷으로 돌아간다. 변경이 없으면 Undo를 추가하지 않는다. 조작 번호는 0, 충전 상태는 문서의 초기 전압으로 돌아간다. 준비 중 다시 시작도 새 세대로 이전 후보를 취소한다. 만들기·출력으로 나갈 때는 최근 확정 문서만 유지하고 실행 상태를 버린다. 재진입은 그 문서의 초기 조건에서 시작한다.

초기화가 확정되면 실행 세션의 experimentEpoch를 갱신하여 미적용 입력 초안도 초기화한다. 이 UI 식별자는 전기 리비전·물리 시간·저장 데이터에 포함하지 않는다.

## 시계와 평형

app이 단조 시계와 rAF를 제공한다. 물리 시각은 화면 경과 시간 × 배율로 구하며 프레임을 누적 적분하지 않는다. 일시정지·배속 변경에서 기준점을 옮겨 시간 점프를 막고 숨긴 탭은 자동 일시정지한다. 준비 중 탭을 숨긴 경우에도 계산 완료 뒤 자동 재생하지 않는다. 복귀는 명시적 재개가 필요하다.

안정화 시간 T에 대한 0.5초/5초 경계와 1/2/5/10/50/100배는 승인 UX를 따른다. 정확히 평형인 시작은 즉시 equilibrium, 작지만 비영인 T=0 변화는 Settling으로 구분한다. 약 200ms의 전환에서 가장 느린 시정수로 남은 실제 응답 시간을 압축하고 끝에서 별도의 equilibrium 프레임을 쓴다. 모션 감소는 즉시 평형으로 전환한다. 넘기기와 정상 종료 모두 동일한 plan의 정확 평형을 다음 조작에 넘긴다. 수치 시간 범위 초과나 sample 실패를 성공으로 바꾸지 않는다.

## 이번 단계의 제공 범위

불러온 v7 축전기 회로에서 재생·일시정지·배속·넘기기·초기화 아이콘, 시간/배율, 상태·진단과 단발 조절을 제공한다. 보조기술에는 상태 변화만 알리고 매 프레임 시간은 자동 읽지 않는다. 세션의 `canRecord()`는 Paused/Equilibrium에서만 true다. 기존 DC 기록 UI에는 RC 결과를 연결하지 않았으므로 C3 앱의 RC 기록 버튼은 계속 차단한다.

C4가 같은 `RcFrame`을 2D/3D·계기·탐침·기록에 연결한다. 임시 기호와 숨긴 축전기 팔레트도 C4까지 유지한다. 현재 화면에는 관찰 표시가 준비 중임을 안내하며 DC 숫자로 RC 프레임을 대신하지 않는다.

준비는 app의 Promise 경계 뒤 동일 스레드에서 수행한다. 지연 결과 취소는 구현했지만 Worker나 CPU 작업 중단을 구현한 것은 아니다. 큰 회로의 준비·sample 비용과 실기기 응답성은 남은 수용 항목이다. 외부 라이브러리는 추가하지 않았다.
