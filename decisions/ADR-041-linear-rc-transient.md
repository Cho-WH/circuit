# ADR-041 선형 RC 관찰과 최종 평형 전환

- 상태: accepted
- 작성일: 2026-10-22
- 관련 요구사항: SIM-009, VIS-008, MEA-006, DAT-006. 기존 SIM-008·VIS-006·MEA-001~005·DAT-001~002와의 경계 포함
- 사용자 결정: [UX 기획](../docs/ux/rc-transient.md#사용자에게-확인한-결정)의 물리 범위와 재생·평형·초기화 선택 확정
- 승인 범위: 기획·설계와 dev의 C0~C5 진행. C0~C4 구현·검토와 C5 기술 확인을 마쳤으며 실제 기기·수업 사용자 수용은 남아 있다. 2026-10-22 사용자가 dev 커밋·배포를 승인했다. 후속 구현 경계는 ADR-042~045와 단계별 결과 보고서를 따른다.

## 배경

현재 DC 엔진은 현재 회로에서 한 작동점을 계산한다. 축전기는 이전 전하가 다음 결과에 영향을 주므로 문서 한 장의 DC 풀이를 반복하는 것만으로 충전·방전을 표현할 수 없다. 사용자는 한 번 조작한 뒤 변화를 관찰하고 최종 평형에 도달해야 다음 조작을 허용하는 경험을 선택했다.

## 채택할 설계

1. 첫 버전은 여러 이상적 축전기·저항·직류 전원·스위치·이상적 계기로 이루어진 선형 RC 회로다. 다이오드 혼합·충격 전류가 필요한 조작은 거부하고 가상의 저항·누설을 추가하지 않는다.
2. 기존 DC 엔진을 유지하고 simulation 안에 RC prepare/sample 경로를 추가한다. 제약과 보존 전하를 분리한 수동 RC 상태식의 지수응답으로 시각별 결과를 계산한다. 프레임 간 수치 적분에 의존하지 않는다.
3. 모든 관련 전압·전류의 앞으로 남은 변화 상한으로 안정화를 판단한다. 상대 0.1%와 별도의 절대 바닥값·수치 오차 예산을 정책으로 관리한다. 구체적인 설계값과 수치 검증 관문은 [물리 규약](../docs/physics/linear-rc-transient.md#안정화-정책)에 둔다.
4. 기준 통과 또는 넘기기 후 최종 평형으로 명시적으로 전환한다. 다음 조작은 극한 상태에서 시작한다. 유한한 시간 프레임과 최종 평형을 기록·UI·출처에서 구분한다.
5. 초기 전압은 기본 0 V이며 만들기에서 설정한다. C·초기 전압·배선은 분석 중 고정하고, 평형에서 스위치·저항·조절 가능한 전압만 한 번씩 적용한다. 실행 중 추가 조작을 명령 단계에서 거부한다.
6. RC 첫 버전은 기존 자동 모델 전환·과부하·파손 연출을 적용하지 않는다. 이는 이상적 RC 관찰 범위의 명시적 예외이며, 축전기 없는 DC/다이오드 회로의 ADR-026 동작은 유지한다.
7. CircuitDocument에는 C와 초기 전압만 추가하고 현재 전하·재생 위치·행렬은 저장하지 않는다. C1에서 회로 v7·측정 기록 v6 및 원본을 보존하는 변환을 구현했다. 공개 계약과 지원 버전은 [ADR-042](ADR-042-rc-contracts-storage.md)를 따른다.

## 대안과 선택 이유

| 대안 | 판단 |
|---|---|
| 단일 축전기 공식만 지원 | 시제품 기준값으로 사용. 사용자 선택은 여러 축전기이므로 최종 제품 범위로는 부족 |
| 매 프레임 Euler 적분 | 프레임 수에 따라 결과가 달라지는 구현은 배제. 독립 적응 적분 자체가 틀린 방법인 것은 아님 |
| SPICE 계열 적응 적분 | 비선형·시간 변화 확장에는 유효. 이번의 고정 선형 구간은 지수응답과 평형 사전 계획을 우선 |
| RC마다 개별 시정수 | 결합된 여러 축전기의 회로 응답을 설명하지 못하므로 배제 |
| 최근 변화량 또는 고정 5τ 종료 | 느린 변화·다중 모드 상쇄·부유 전하에 취약. 전체 관측량의 남은 변화로 판단 |
| 안정화 후 유한 상태 유지 | 앞선 제안이었으나 사용자가 최종 평형 전환을 선택하여 채택하지 않음 |

## 기존 규약에 미치는 영향

- ADR-024/025: DC 정확 우선 계산은 유지한다. RC 지수응답은 별도 수치 품질·출처가 필요하며 exact로 위장하지 않는다.
- ADR-026: RC 관찰에는 작동 경계 평가를 적용하지 않는 모델 분기를 명시해야 한다. 정상 표시가 실물 정격 보장이 아님을 설명한다.
- ADR-033: 축전기의 동적 전압 제약까지 포함한 기준 그룹이 필요하다. DC 개방 분할을 그대로 적용하지 않는다.
- ADR-010/039: 새 타입·초기 조건·기록 시간 출처에 버전 변경이 필요하다. 과거 형식의 명시적 복원과 원본 보호를 유지한다.
- ADR-020: 입자 표시 시계와 물리 시간을 분리하며 축전기 내부 경로를 저항에서 자동 상속하지 않는다.

## 수용과 상태 전환

[구현 설계](../docs/architecture/rc-transient.md#구현-순서와-관문)의 C0를 독립 시제품으로 구현했다. 정확 제약 축약·보존 전하·잔차 에너지 오차 상한을 검증했고, 기존 rational과 자체 대칭 풀이를 사용한다. 초기의 개별 고유값 오차 구간 구상은 고유값 간격에 의존하지 않는 에너지 상한으로 구체화했다. 정책 rc-c0-envelope-1의 규모는 인증한 후보의 모드 진폭 합이며, 정확 응답의 잔여 변화는 별도의 상한으로 검증한다. [결과](../docs/testing/rc-c0-results.md)는 16단 성공·32단 예산 초과를 포함한 제한된 수치 범위를 명시한다.

제품 공개 계약/마이그레이션을 C1에서 확정하여 accepted로 전환했다. 세부 계약은 ADR-042, 검증은 [C1 결과](../docs/testing/rc-c1-results.md)를 따른다. C2 엔진은 [ADR-043](ADR-043-rc-product-engine.md)으로 연결했다. accepted는 설계 채택이며 C3~C5 기능 구현·수용 완료를 뜻하지 않는다. 실행 가능한 수용 조건은 [RC 수용 사례](../docs/testing/rc-transient-cases.md)에 둔다.
