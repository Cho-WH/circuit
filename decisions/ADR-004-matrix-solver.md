# ADR-004: 행렬 풀이 구현

- 상태: accepted
- 결정 시점: 단계 1 전

## 질문

MNA 선형 방정식을 자체 구현으로 풀지, 검증된 수치 라이브러리를 사용할지 결정한다.

## 고정 조건

- 행렬 구현은 `SimulationEngine` 내부에 숨긴다.
- 일반 수업 회로의 작은 조밀 행렬을 우선한다.
- 특이 행렬과 조건이 나쁜 행렬을 진단할 수 있어야 한다.
- 같은 입력에서 결정론적 결과를 반환한다.
- FIX-01~FIX-10과 물리 불변식 테스트를 통과한다.

## 대안

1. 가우스 소거를 포함한 작은 자체 구현
2. JavaScript 수치 라이브러리 사용
3. WebAssembly 선형대수 라이브러리 사용

## 평가 기준

- 정확성과 특이 조건 처리
- 번들 크기
- 오류 원인 추적 가능성
- 브라우저 호환성
- 장기 교체 비용

## 단계 1 결정

작은 조밀 MNA 행렬을 자체 가우스 소거로 푼다. 행을 계수 최대값으로 정규화하고 부분 피벗을 선택한다. 정규화된 피벗 절댓값이 `1e-13` 미만이면 유일 해를 보장하지 못하므로 `SINGULAR_SYSTEM`으로 거부한다. 비유한 결과도 거부한다. 반환 전에 원래 행렬에서 절대·상대 허용 오차로 잔차를 검사하며 실패 시 `ILL_CONDITIONED_SYSTEM`을 반환한다.

전압 제약 그래프의 불일치는 행렬 풀이 전에 `CONFLICTING_SOURCES`로 구분한다. 기준점이 없거나 도달하지 못하는 도전성 하위 회로가 있으면 `FLOATING_SUBCIRCUIT`을 반환한다. 부분 해와 임의 기준 전위는 노출하지 않는다. FIX-01~10·물리 불변식·극단값 검증을 통과했다.
