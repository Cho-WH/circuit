# ADR-039: 읽지 못한 회로의 원본 보호와 명시적 복원

- 상태: accepted
- 결정일: 2026-10-08
- 요구사항: DAT-001~003

## 결정

읽기 실패를 빈 저장 공간으로 취급하지 않는다. 자동 저장본이 손상되거나 지원 밖 형식이면 자동 저장·회로 편집을 멈추고 `새 회로로 시작`, `복원`, `백업`을 제공한다. 복원 실패 후에는 새 회로와 백업만 남긴다. 파일 열기와 수동 보관본에도 같은 안내를 사용한다. 백업은 원문 그대로의 JSON 다운로드이며 성공 여부를 추측해 원본을 지우거나 자동 저장을 재개하지 않는다.

복원은 원본의 현재 형식 검증 또는 명시적 v5→v6 변환을 먼저 시도한다. 자동 저장본이면 같은 채널의 이전 자동 저장 백업도 확인한다. v5 스키마와 예시 파일은 Git e125d50에서 고정한다. 값·단자·도선·배치·출력 정보는 유지하고 버전만 바꾼 뒤 현재 스키마·참조·물리값 검증을 통과해야 한다. v1~4, 미래 버전, 깨진 연결의 추정 복구는 지원하지 않는다. 정상 읽기 `parseDocument`와 domain은 여전히 v6만 받는다. ADR-007/010/024/026의 구버전 변환 금지는 이 명시적 v5 복원에 한해 대체한다. 기록 v5와 과거 측정값은 변환하지 않는다.

새 회로·복원 결과 적용 전에 원문을 채널별 `edu-circuit:originals:v1` 목록에 보관한다. 같은 원문은 중복 저장하지 않고 다른 원문은 유지한다. 파일 메뉴에서 다시 내려받을 수 있다. 원본 보관이나 결과 저장에 실패하면 기존 자동 저장본을 교체하지 않는다. 복원 대기 중 저장 원본이 바뀌면 오래된 안내로 덮어쓰지 않는다. 일반 저장 함수도 읽지 못한 기존 원본의 덮어쓰기를 거부한다. 정상 결과를 저장한 뒤 세션을 교체하고 자동 저장을 재개한다. 수동 보관본은 그대로 유지하고 복원 결과를 현재 자동 저장 회로로 연다.

브라우저 저장소 자체를 읽을 수 없으면 기존 저장 실패 안내와 파일 저장을 사용하며 해당 세션의 자동 저장을 중단한다. 다중 탭 병합·범용 손상 복구·브라우저 데이터 삭제 후 복구는 범위 밖이다.

## 검증

기존 저장·세션·작업 화면 검사에서 손상/구버전의 자동 저장 차단, 명시적 백업 복원, 원문 다운로드·새 회로 이후 보존, v5 정확값·연결 보존, 미래 버전·끊어진 참조 거부, 저장 공간 부족·대기 중 원본 변경을 확인한다.
