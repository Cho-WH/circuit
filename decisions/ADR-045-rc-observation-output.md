# ADR-045: C4 RC 프레임의 공통 관찰과 축전기 출력

- 상태: accepted
- 결정일: 2026-10-22
- 관련 요구사항: SIM-009, VIS-008, MEA-006, DAT-006, TCH-001~003
- 선행 결정: [ADR-041](ADR-041-linear-rc-transient.md), [ADR-042](ADR-042-rc-contracts-storage.md), [ADR-043](ADR-043-rc-product-engine.md), [ADR-044](ADR-044-rc-playback-session.md)

## 결정

`CircuitObservation`은 기존 DC `SimulationResult` 또는 `RcObservation`이다. RC 관찰은 엔진 소유 프레임을 `simulation.observeRcFrame`에서 검증한 뒤 기존 표시기에 필요한 전위·전류·기준 영역과 원래 프레임을 함께 제공한다. DC provenance와 DC affine solution을 꾸며 넣지 않는다. RC 전력은 이번 공개 계약에 없으므로 계산·표시하지 않는다.

전압 차는 `observationVoltage`를 통해 RC 엔진의 직접 질의를 사용한다. 근사 절점 전위 두 개를 빼서 상관된 오차를 잃지 않는다. 도선 전류도 계획 준비 때 구성한 KCL 질의를 사용하며 화면에서 매 프레임 회로를 다시 푼다거나 미정 값을 0으로 채우지 않는다. 3D 선택 부품의 전압도 프레임의 인증된 차를 사용한다. 계기·탐침·전위·전류·판별 전하·기록은 한 프레임을 공유한다.

각 조작의 초기값과 최종값으로 전위·높이·전류 축척을 시작하고, 중간에 더 큰 값이 나오면 확장하되 줄이지 않는다. 전류가 감소할 때 두께·색·높이 감소를 숨기지 않는다. 방향 무늬는 전하 입자나 물리 시계가 아니다. RC의 연속 샘플에서는 DC 슬라이더 조작용 전체 무늬 숨김을 사용하지 않고, 기존 교차 전환으로 최대 250 ms 간격으로 밀도를 갱신한다. 재생 일시정지와 모션 감소는 무늬도 정지한다. 물리값과 띠 두께는 같은 프레임에서 즉시 갱신한다.

## 기호·입력·출력

축전기는 같은 길이의 평행한 두 판과 양쪽 리드로 표시한다. 한국교육과정평가원 **2023학년도 9월 모의평가 물리학Ⅱ 2쪽 6번**의 회로 그림에서 축전기 표기를 직접 확인했다([EBSi 공개 원문](https://wdown.ebsi.co.kr/W61001/01exam/20220901/go3/g_phy2_mun_AM99D8AC.pdf)). 원본 그림을 복제하지 않고 공통 기호 정의로 그린다. 판 본체는 로컬 ±7 × ±22이고 출력 선 두께를 포함한 본체 경계만 정렬에 쓴다. 리드는 정렬 본체에서 제외한다.

만들기에서 C와 부호 있는 초기 전압을 한 명령으로 적용한다. 기본은 100 µF·0 V, C>0이며 정확 분수와 SI 단위를 지원한다. 초기 전압은 단자 역할 a−b에 고정하고 편집 설명에는 화면의 왼쪽/오른쪽 또는 위쪽/아래쪽 단자 이름을 쓴다. 선택한 기호의 +/−는 전압의 기준이며 실제 순간 전하 부호가 아니다. 회전과 단자 배열 순서 변경이 전기 의미를 바꾸지 않는다.

3D에서 각 판·리드는 자기 단자의 높이에 놓이고 두 판 사이에 전도 경로를 만들지 않는다. 전류 보기를 켜도 판을 숨기지 않는다. 판별 전하는 선택 부품 상세에 Qa와 −Qa로 표시한다.

2026-10-22 사용자 요청으로 2D에서도 각 판과 리드를 해당 단자 전위 색으로 표시한다. `symbolMarkup`의 선택적 `terminalColors`에는 기존 전위 모델에서 얻은 단자 ID별 색만 전달한다. 기호 모듈은 전위를 계산하지 않는다. 판은 a/b 역할로 매핑해 회전·단자 배열 순서에 독립이며, 판 사이에는 색 띠나 전도 경로를 만들지 않는다. 선택/호버는 기존 굵기·그림자로 표현하고 판의 전위 색을 유지한다. 색상을 끄거나 출력처럼 색 옵션을 생략하면 기존 기호색을 상속한다. 출력·저장·3D 계약은 유지한다.

출력 초기 전압은 기존 `voltageVisible`·`voltageBlank`·`voltageOffsetX/Y`를 축전기에 한해 초기 조건 표기로 사용한다. 기본 숨김이며 사용자가 켜면 ‘초기 전압’으로 명시한다. 이름·C·초기 조건 이동/정렬, SVG·PNG는 기존 출력 경로를 공유한다. 저장 형식은 회로 v7 그대로다. 현재 재생 전압·전하·시간을 출력 문서에 저장하거나 캡처하지 않는다.

## 기록·접근성

일시정지/평형에서만 기록 명령을 허용한다. 기록 조건 키에 초기 전압과 RC 프레임 출처를 포함해 서로 다른 시각을 같은 조건으로 합치지 않는다. 표에는 최초 관찰/조작 번호와 유한 초 또는 최종 평형을 표시한다. CSV는 시간 출처, 수치 품질, 원본 값, 오차 보증, 원본 회로 JSON을 보존한다. 표시용 첨자 변환을 이 JSON에 적용하지 않는다. 측정 기록 v6를 유지한다.

매 프레임 숫자를 스크린리더 live 영역으로 읽지 않는다. 상태 전환은 알리고 정지 후 탐침 변경·기록은 안내한다. 재생 제어는 44px 이상 누름 영역과 이름을 제공한다. RC에서는 별도의 전류 무늬 재생 버튼 대신 실험 재생 제어를 사용한다.

## 검증 및 다음 관문

[C4 결과](../docs/testing/rc-c4-results.md)에 엔진→관찰→기록·기호·출력과 기존 DC 회귀 검사를 기록한다. C4 검토 뒤 [C5 결과](../docs/testing/rc-c5-results.md)에서 실제 브라우저, 키보드, 작은 화면, 계산 비용을 확인한다. 실제 터치 기기·보조기술·사용자 수용과 배포 승인은 별도 근거 없이 완료로 표시하지 않는다.
