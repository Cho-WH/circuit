# ADR-033: 독립 회로별 전위 기준

- 상태: accepted
- 결정일: 2026-10-08
- 관련 요구사항: SIM-002~004, SIM-007/008, MEA-001, VIS-001/004, PV-01/07

## 배경

서로 연결되지 않은 폐회로는 각 회로 내부의 전압차·전류를 계산할 수 있어도 회로 사이의 전위 관계는 정해지지 않는다. 하나의 기준만 허용하여 두 번째 회로 전체를 전위 미정으로 표시하면 독립 회로를 함께 관찰하기 어렵다.

2026-10-08 후속: 자동 접지의 문서 기록·기호·하단 안내·삭제 알림 규칙은 [ADR-037](ADR-037-manual-ground-display.md)로 대체한다. 독립 기준 계산과 측정 보호는 유지한다.

## 결정

`SolveOptions.referencePolicy`에 `explicit`과 `independent`를 제공한다. 생략 시 기존 엔진의 `explicit` 계약을 유지하고 앱은 두 물리 모델 모두 `independent`로 해석한다. 기존 piecewise의 독립 영역 분할·방정식·다이오드 평형 계산을 재사용한다. 다이오드는 OFF여도 전압 부등식과 평형 조건이 있으므로 같은 영역으로 묶는다. 열린 스위치와 이상 전압계는 영역을 연결하지 않는다.

각 영역의 기준은 그 영역에 속한 문서의 `referenceNode`, 고정 ID 순서의 첫 전원 음극, 첫 net 순으로 선택한다. 전원 없는 저항망도 내부 기준을 가진다. 기준 지정은 공통 전위의 원점만 고정한다. 부품의 전압차·전류·전력과 정확한 OFF 전류 0 A는 보존하고 누설저항·미세전류는 추가하지 않는다. 실제 모순·개별 전류의 비유일성·계산 미확인은 그대로 반환한다. 기존 요청 예산은 모든 영역이 공유하며 영역별로 초기화하지 않는다.

`SimulationResult.referenceGroups`는 영역 ID·기준 net·소속 net 목록을 공개한다. `nodeVoltages`는 해당 영역의 기준에 대한 값이다. 연결하면 하나의 기준으로 통합하고, 분리하면 같은 규칙으로 다시 선택한다. 배열 순서나 조작 이력에 의존하지 않는다. 문서의 우선 기준이 합쳐진 영역에 있으면 이를 유지한다.

`queryVoltage`는 다른 영역 사이에서 `nonunique`를 반환한다. 이 검사는 비공개 해 공간 없이 결과만 복제해도 동작한다. `probeVoltage`는 `INDEPENDENT_VOLTAGE_REFERENCES`로 구별하여 안내하고 수치·기록을 만들지 않는다. 두 기준점이 각각 0 V여도 서로의 차를 0 V로 계산하지 않는다. 영역을 가로지르는 열린 스위치·전압계의 전류는 0 A지만 양단 전압은 미정이다.

탐침 소속과 전위 값은 독립 영역을 구분하며 다른 영역의 전압차·높이 차·경로 그래프를 만들지 않는다. 자동 기준 기호·하단 설명을 노출하던 UI는 [ADR-037](ADR-037-manual-ground-display.md)로 대체했다.

`CircuitDocument.referenceNode`는 하나의 수동 우선 기준으로 유지한다. 나머지 영역의 기준은 계산 결과에만 둔다. 여러 수동 기준을 별도로 저장하는 기능은 추가하지 않는다. 편집 명령의 권한 검사는 유지한다.

영역·자동 기준·A/B 표시는 계산 결과이므로 문서에 저장하지 않는다. 회로 v6·측정 기록 v5를 유지하고 불러오기·실행 취소 후 다시 계산한다. 해석 출처의 `profileRevision`에 `references:independent-1`을 포함하여 기존 기록과 구별하며 과거 기록값은 변경하지 않는다.

이 결정은 ADR-031의 “분리된 영역마다 별도 기준을 넣지 않는다”를 앱의 `independent` 정책에 한해 대체한다. `explicit` 엔진의 부유 전위 계약과 다이오드 평형이 실제 전압차·전류 자유도를 보존하는 ADR-030은 유지한다.

## 검증

- `independent-references.test.ts`: 두 폐회로·무전원 영역·두 물리 모델, 전류·전력·KCL 보존, 교차 측정 차단, 결과 복제, 스위치 연결/분리와 Undo/Redo, 기준 이동·순서 독립·현재 형식 왕복, 이상 전압계·실제 전류 비유일성·모순, 브릿지 A/B와 추가 독립 영역.
- `analysis-workspace.test.ts`: 복제한 다이오드 회로의 기준 A/B, 교차 측정·기록 차단, 같은 회로 안 측정과 출처 기록, 2D/3D 상태 공유.
- 기존 계산·측정·접지 편집·전위/전류 표시·기록 테스트와 브라우저의 두 브릿지 회로 관찰을 함께 확인한다.
