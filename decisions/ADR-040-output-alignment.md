# ADR-040 출력 표기 정렬과 파생 배치 정보

- 상태: proposed
- 제안일: 2026-10-21
- 관련 요구사항: TCH-001~003, DAT-001~002
- 사용자 UX 결정: [출력 표기 정렬 기획](../docs/ux/output-alignment.md)의 네 항목 확정
- 구현 상태: 미구현. 공개 계약의 채택·구현 완료와 UX 결정 확정을 구분한다.

먼저 [기획서의 사용자 결정](../docs/ux/output-alignment.md#사용자에게-확인한-결정)과 적용 범위를 읽고 이 ADR에서 기술 선택의 이유를 확인한다. 이어 [설계서의 UX와 구현 검증 대응표](../docs/architecture/output-alignment.md#ux와-구현-검증의-대응)에서 각 동작의 구현 경계와 검사 위치로 이동한다. 조작 규칙의 상세는 기획서, 알고리즘·타입의 상세는 설계서에 둔다.

## 배경

출력 화면은 이미 이름·값과 주석의 위치를 문서에 저장하고 동일한 문서에서 SVG·PNG를 생성한다. 여기에 자동 맞춤과 선택 정렬을 붙이려면 글자·빈칸·화살표의 위치를 편집 UI와 렌더러가 같은 의미로 읽어야 한다. DOM 외곽을 별도로 해석하거나 외부 편집기 전체를 도입하면 기존 드래그·명령·실행 취소와 책임이 겹친다.

## 제안

1. `createSvgExport`의 기존 반환값을 유지하고 정렬에 필요한 파생 `layout`을 추가한다. 표기 기준선·외곽·본체 경로는 기존 렌더링과 공통 계산을 사용한다. 타입은 export의 공개 index에서 제공하며 저장 타입으로 만들지 않는다.
2. 선택·스냅·정렬·간격 분배는 app 내부에서 처리한다. maxGraph의 기본 안내선 구조와 Excalidraw의 필요한 계산만 우리 출력 모델에 맞게 참고·수정 재사용한다. 런타임 패키지 전체는 추가하지 않는다.
3. 확정은 기존 `SetProperties`·`UpdateAnnotation` 배열과 `useCircuitSession.execute`·`editor.executeCommands`를 사용한다. 미리보기와 확정은 같은 명령 조립 함수를 사용하며 한 조작은 한 번의 Undo다.
4. 부품·도선은 출력에서 이동하지 않는다. 정렬은 선택 전체 범위 기준이며 기준 요소 고정 기능은 없다. 선택·안내선·스냅 설정은 문서 밖에 둔다.
5. 회로 v6·측정 기록 v5와 기존 출력 오프셋 필드를 유지한다. 계산·연결·저장 스키마는 변경하지 않는다.

상세 타입·제스처·후보 선택·재사용 출처와 검증 경계는 [출력 정렬 설계](../docs/architecture/output-alignment.md)에 둔다.

## 기존 결정과의 관계

ADR-012의 공통 출력, 부품·도선 고정, 일시적 미리보기, 출력에서 편집 UI 제외 원칙을 유지한다. 빈 공간의 기본 드래그는 화면 이동이며 새 영역 선택 도구에서만 영역을 선택한다. ADR-032의 만들기 화면 선택 규칙은 변경하지 않는다. ADR-008의 모듈 경계와 ADR-010·ADR-039의 검증·현재 저장 형식 계약을 유지한다.

구현 시 반환값의 추가 필드와 관련 테스트를 같은 변경 단위에서 반영한다. 기존 `svg`·`content`·`bounds`·`options`와 `exportSvg`·`exportPng` 호출은 유지한다. 이 제안만으로 accepted 요구사항이나 현재 구현 상태를 변경하지 않는다.

## 대안과 영향

Moveable·Selecto는 선택·드래그 기능을 제공하지만 현재 SVG 재생성과 포인터 처리에 통합 작업이 필요하다. 이번에는 기존 입력 수명을 유지하고 좌표 계산만 추가하는 방식을 제안한다. DOM 측정에만 의존하는 방식은 글자 기준선·빈칸 의미와 독립 출력의 일치를 보장하기 어려워 채택하지 않는다.

공통 기하를 제공하면 export 공개 반환형이 확장된다. 전체 출력 여백과 정렬 외곽을 혼동하지 않도록 분리하고 기존 출력의 잘림 방지를 유지해야 한다. 발췌·수정한 외부 소스에는 원본 커밋·저작권·라이선스·변경 사항을 보존한다.

## 수용 조건

기존 출력의 표현과 현재 저장 왕복을 유지하면서, 독립 부분 선택·같은 화면 거리의 스냅·선택 전체 기준 정렬·화살표 중복 이동 방지·실패 시 전체 취소·한 번의 실행 취소·안내선 출력 제외를 확인한다. 구체적인 수용 시나리오는 UX 문서, 검사 위치는 설계 문서에 기록한다.
