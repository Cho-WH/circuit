# ADR-029: 전환 스위치와 브릿지 정류 예제

- 상태: accepted
- 결정일: 2026-10-07
- 관련 요구사항: EDT-001/007, SIM-001/003, VIS-006, TCH-003, DAT-003
- 사용자 승인: 전환 스위치(SPDT)를 추가하고 전지 두 개로 극성을 선택하는 브릿지 정류 예제를 제공한다.

## 기호와 조작

부품 목록에 기존 스위치와 별도로 **전환 스위치**를 제공한다. 공통 가동 접점 하나가 두 고정 접점 중 하나에 닿는 SPDT 기호를 사용한다. 단자는 공통·A·B이며 A/B 글자는 회전해도 똑바로 읽힌다. 공통 기호를 목록·2D·3D 바닥·SVG·PNG에서 재사용한다. 초기 상태는 A 연결이다.

기호 근거는 [OMRON 기본 스위치 기술 설명](https://www.ia.omron.com/data_pdf/guide/29/microswitch_tg_e_3_2.pdf)의 p.6 Contact Form/SPDT 도식이다. 고등학교에서 두 접점을 선택하는 표현은 [EBSi 물리Ⅱ 평가 자료 해설](https://wdown.ebsi.co.kr/W61001/01exam/201109013/g_phy2_hsj.pdf)의 a/b 접점 연결 표현을 확인했다. 스프링 복귀나 정상 개방/폐쇄가 없는 유지형 교육 모델이므로 화면에는 NC/NO 대신 A/B와 ‘전환 스위치’ 이름을 사용한다.

기존 스위치의 값 클릭·Enter·더블클릭과 이름·값/상세 패널의 버튼을 재사용한다. 버튼은 ‘B로 전환’/‘A로 전환’을 표시한다. 한 번에 선택 상태를 바꾸는 SetProperties 명령으로 실행 취소·다시 실행·활동 권한·분석 과부하 잠금·출력 읽기 전용을 공유한다. 기존 스위치와 마찬가지로 편집창의 스위치 조작은 즉시 적용하며 이름 초안의 취소와 구별한다.

## 저장·연결·계산

새 저장 타입을 만들지 않고 기존 type=switch의 properties.switchKind=spdt, state=a|b로 표현한다. 단자는 common/throw-a/throw-b 역할을 각각 하나씩 가진다. JSON의 타입·필드·스키마는 기존 v6가 이미 허용하는 구조를 그대로 사용한다. 저장 버전은 회로 v6·측정 기록 v5를 유지하며 이전 버전은 변환 없이 거부한다. 기존 두 단자 스위치의 state=open|closed 의미는 유지한다. 잘못된 종류·상태·중복/누락 단자 역할은 domain에서 거부한다. 이전 앱은 세 단자 컴파일을 UNSUPPORTED_TERMINALS로 거부하며 두 단자 스위치로 몰래 해석하지 않는다.

domain의 switchTerminals가 배열 순서·회전과 무관하게 공통→선택 접점 쌍을 반환한다. connectivity는 이 쌍을 기존 닫힌 스위치 CompiledElement 하나로 내보낸다. 선택하지 않은 단자는 외부 배선의 독립 net에 남고 내부 가지 전류 주입은 0이다. 기존 정확 MNA·다이오드·작동 경계 엔진은 변경하지 않는다. 두 접점 동시 연결, 중간 OFF, 접점 바운스·시간 파형은 모델링하지 않는다.

전류 측정·도선 KCL·전위 높이·선택 전압은 동일한 선택 접점 쌍을 사용한다. 전류·전위 경로는 실제 가동 접점의 꺾인 기하를 따른다. 세 단자 사이의 전압을 하나로 뭉뚱그리지 않고 부품 전압은 공통→선택 접점 사이를 뜻한다. 다른 접점의 전압은 탐침으로 측정한다.

새 편집 프레임워크를 만들지 않는다. component-library의 ComponentKind는 목록/배치용 선택에만 changeover-switch를 추가하며 createComponent가 기존 switch 문서를 만든다. 회전·이동·배선·복사·붙여넣기는 기존 경로를 공유한다. 세 단자는 기존 2단자 직렬 삽입 대상이 아니다. 삭제 시 각 단자의 외부 연결만 보존하고 서로 다른 세 단자를 연결하지 않는다(ADR-017).

## 예제

FIX-14 ‘브릿지 정류 회로’는 왼쪽의 반대 극성 5 V 전원 두 개와 전환 스위치, 오른쪽 日자 다이오드 네 개와 가운데 1 kΩ 부하로 구성한다. 4개 다이오드는 신호용이다. 도선은 직각으로 배치하고 비연결 교차·겹치는 선·기호 및 표기 충돌을 피한다. 이 예제는 두 직류 상태의 비교이며 교류 시간 해석을 주장하지 않는다.

- A: 입력 +5 V, D2/D3 도통, D1/D4 전류 0.
- B: 입력 −5 V, D1/D4 도통, D2/D3 전류 0.
- 두 상태 모두 부하 전압 3.6 V, 전류 3.6 mA이며 오른쪽→왼쪽 방향을 유지한다. 선택하지 않은 전원의 전류는 정확히 0이다.

## 수용 검증

단자 배열·회전에 독립적인 선택, 잘못된 입력 거부, 양방향 브릿지 계산, 미선택 가지 전류 0, 전류/전위 경로 일치, 상태 변경·Undo/Redo·저장/복사/삭제, 활동 권한·분석 잠금·출력 제한과 공통 기호를 검증한다. 기존 예제의 배치 검사와 스위치·계산·측정 회귀를 함께 수행한다.
