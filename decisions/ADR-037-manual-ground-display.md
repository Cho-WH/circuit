# ADR-037: 수동 접지만 표시

- 상태: accepted
- 결정일: 2026-10-08
- 관련: EDT-001, VIS-001/004, PV-01/05, ADR-031/033

## 결정

사용자 요청에 따라 자동 기준은 계산에만 사용하고 접지 기호로 표시하지 않는다. 도구 명칭은 접지로 복원한다. 2D·3D 하단 기준 설명과 접지 이동·삭제 후 자동 전환 안내를 제거한다. 수동 접지만 이동·삭제할 수 있고 삭제 후 기호가 다시 나타나지 않는다.

`referenceNode`는 문서에 명시적으로 지정한 접지만 저장한다. 앱의 불러오기·편집 후 자동 지정과 전원 삽입 시 자동 지정을 제거한다. 기존 독립 영역 해석은 그대로 사용하여 기준이 없는 문서도 계산하며 정확한 차단 전류와 독립 영역 간 전압 측정 보호를 유지한다. 계산용 referenceGroups는 계속 유지하지만 기호 렌더링은 문서의 referenceNode만 따른다. 출력도 기존 문서 기반 접지 토글을 따른다.

저장 형식은 회로 v6·기록 v5를 유지한다. 기존 문서의 referenceNode에는 수동/자동 출처가 없으므로 위치로 추정하여 지우지 않고 명시된 접지로 보존한다. 사용자가 삭제하면 null이 저장되며 다시 불러와도 자동 생성하지 않는다. 예제의 명시된 접지도 유지한다.

## 검증

새 전원·삽입·독립 부품의 자동 기호 부재, 수동 접지 이동·삭제·Undo/Redo·저장 왕복, 하단 설명 부재, 2D·3D 표시와 기존 독립 회로 측정 규칙을 확인한다. 권한 거부와 도선 분할 원자성을 유지한다.
