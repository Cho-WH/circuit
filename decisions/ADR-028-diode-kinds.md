# ADR-028: 신호용·대전류용 다이오드 선택

- 상태: accepted
- 결정일: 2026-10-07
- 관련 요구사항: EDT-007/008, TCH-001/003, DAT-003

## 결정

1N4148을 참고한 신호용과 6A10을 참고한 대전류용을 [설계](../docs/ux/diode-kinds.md)의 고정 특성으로 제공한다. 새 부품은 신호용이다. 기존 이름·값/상세 편집에 공통 선택 필드를 두고 두 이름과 선택 아래 쉬운 용도 설명 한 줄만 표시한다. 정격 수치 나열이나 별도 과부하 설명은 추가하지 않는다.

기존 프로필 공개 계약을 확장하고 하나의 엔진·기호·출력 경로를 유지한다. SetDiodeKind는 만들기에서만 실행하며 기존 활동 권한 및 과부하 잠금을 적용한다. 프로필과 전기 편차 제거를 함께 수행하고 이름 변경과 묶어 원자적으로 적용한다.

회로 위 다이오드 값 자리는 전압 대신 종류명을 일반 값 글자 크기의 ½로 표시한다. componentValue·공통 배치·출력 렌더링을 공유하며 회로도 출력의 answerVisible 생략 기본값은 다이오드에 한해 false다. 사용자가 저장한 명시적 표시·빈칸·위치는 보존한다. 3D 바닥용 circuitOnly는 출력 숨김 설정과 관계없이 종류명을 표시한다. 계산 모델과 저장 구조·버전은 변경하지 않는다.

회로 v6·측정 기록 v5를 유지하며 edu-diode-signal@1, edu-diode-power@1을 추가한다. edu-diode@1과 생략된 참조의 역사적 의미는 변경하지 않는다. 새 ID를 모르는 이전 앱의 거부는 의도된 동작이다. 새 ID를 적용할 때만 특성을 바꾸며 이름 편집·저장·불러오기가 자동 변환을 일으키지 않는다.

정상 상한은 계속 작동 가능한 교육용 범위, 파손 하한은 연출용 가정이다. 온도·방열·시간·항복 전류를 새로 계산하지 않는다. 특성값과 근거 및 경계 수용 검사는 설계를 따른다.
