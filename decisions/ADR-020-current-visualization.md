# ADR-020: 전류의 물리량과 표시용 움직임 분리

- 상태: accepted
- 결정일: 2026-09-29
- 관련 요구사항: VIS-006, VIS-004, MEA-002, QLT-001

## 결정 배경

사용자가 전류 화살표를 2D·3D의 일관된 흐름 표현으로 교체하도록 승인했다. 2D 좌표의 이동량을 3D 경사에 그대로 대응시키면 저항 경사에서 빨라 보이는 문제가 있다. 화면의 점을 고정 전하 묶음으로 취급하면 향후 축전기 틈을 전하가 통과하거나, 표시 이동 시간이 과도 응답 지연으로 오인될 위험도 있다.

## 결정

1. `visualization.buildCurrentModel`은 measurement의 공개 `probeCurrent`를 사용해 부품·도선별 부호 있는 전류와 기준 단자, `known`/`undefined`/`unavailable` 상태를 만든다. 같은 net 전체에 하나의 전류를 배정하지 않는다. 물리 모델에는 좌표·카메라·시계가 없다.
2. `buildCurrentPaths`는 별도의 기하 어댑터다. ID와 부품별 명시적 경로 정책을 따르며 전류를 재계산하지 않는다. 도선의 2D 비연결 교차는 공통 기호의 bridge 경로를 공유한다. 3D는 전위 모델의 높이를 사용하고 높이 미정 구간을 생략한다.
3. `current-view.createCurrentOverlay`는 CSS 픽셀 경로를 받는 공통 SVG 표시 계층이다. 2D SVG 변환과 Three.js 투영 어댑터가 같은 표시기를 사용한다. 투영 **이후**의 호 길이를 사용해 모든 구간에서 30 CSS px/s를 유지한다. 무늬는 실제 캐리어 궤적이나 신호 전파가 아니다.
4. 사용자 수정 요청을 반영해 고정 축척·축척 맞춤을 자동 축척과 두께 배율로 교체했다. `scaleAmperes`는 매번 최대 전류이고 `widthScale`은 문서 밖 UI 상태다. 띠 색상은 기존 전위 팔레트를 유지하고 색상 토글을 따른다. 띠 너비는 전류에 비례한다. 2026-10-07 사용자 요청에 따라 2D에서는 모든 도선을 1.25 CSS px·불투명도 14%의 옅은 중립색 기본선으로 남기고 소자 기호의 진하기는 유지한다. 기본선은 전류값·전위색·호버·선택과 무관하게 동일하며 전류 보기를 끄면 원래 표시로 복원한다. 3D 튜브는 기존처럼 숨긴다. 투명한 히트 영역으로 선택 기능은 유지한다. 3D 바닥 회로도의 도선은 전류 모드와 무관하게 유지하며, 전류 토글로 바닥 텍스처를 재생성하지 않는다.
5. 무늬 간격은 `34 × I_max / |I|` CSS px로 정한다. `visualization.buildCurrentTracks`는 단자 ID 기준 1입력·1출력 구간의 같은 전류를 하나의 경로로 합쳐 도선·부품 경계에서 연속 이동시킨다. 분기점에서는 가지별 밀도를 사용한다. 닫힌 회로는 경로 길이/간격을 정수 개수(최소 1개)로 반올림해 이음새를 없앤다. 이산 무늬의 밀도는 근사치이며 실제 전하는 무늬 개수로 적분하지 않는다.
6. 0 A에는 띠·무늬를 만들지 않는다. 미정·실패는 0으로 치환하지 않고 정적인 점선으로 표시하며 상세 설정에서 수치를 구분한다. 열린 스위치·전압계·미지원 소자에 전도 경로를 만들지 않는다.
7. 상단 설명 밴드와 범례를 제거하고 화면 내부 왼쪽 상단에 일시 정지/재생 버튼만 둔다. 두께 배율·선택 전류 수치는 기존 상세 설정에서 제공한다. 일시 정지·움직임 감소·문서 숨김·뷰 해제·WebGL 실패에는 RAF를 중단한다. Three.js는 기존처럼 카메라·데이터 변경 시만 렌더링한다. 개별 무늬의 2D·3D 위치 동일성은 계약이 아니다.
8. 카메라 이동 시 매 프레임 SVG와 점 열을 새로 만들지 않는다. 도선 ID·연속 경로 ID별 DOM을 유지하고 점을 풀링한다. 기존 점 열의 기준 경로에서 선분·선분 내 위치를 구해 현재 투영에 대응시킨다. 시점 변경이 140 ms 멈춘 뒤 한 번만 화면상 간격을 재설정하고 220 ms 교차 전환한다. 이동 중 점 개수 재계산으로 생기는 점프를 막고, 정지 후에는 다시 화면상 등속·전류별 간격을 유지한다. 정지/움직임 감소에서는 재투영만 수행하며 별도 프레임을 시작하지 않는다.

9. 분기·합류는 알려진 비영 전류 경로의 단자 ID별 유입·유출 차수로 판정한다. 가지별 점 열의 위상은 강제로 맞추지 않는다. 접점 중심 3.5 CSS px 안에서는 무늬를 숨기고 그 바깥 8 CSS px에서 smoothstep으로 불투명도를 전환한다. 거리는 각 경로의 투영된 호 길이로 계산하므로 비연결 교차에 페이드가 전파되지 않는다. 접점은 기존 전위색의 작은 원으로 표시한다. 위치·간격·속도·물리 전류는 바꾸지 않으며, 개별 점의 분배·합류 일대일 대응은 보장하지 않는다. 직렬 경계와 닫힌 경로에는 적용하지 않는다. 2D·3D가 같은 순수 페이드 함수와 DOM 표시기를 사용한다.

## 소자 확장 경계

현재 선형 DC 계산 범위는 유지한다. 축전기·다이오드 해석이나 실제 전하 추적을 이번 변경에 추가하지 않는다. 향후 과도 해석은 같은 물리 시각의 전류·전압·소자 저장 상태를 전달해야 하며 표시용 RAF가 전기 상태를 적분하지 않는다.

- 축전기: 단자 전류와 `q_a=C(V_a−V_b)`, `q_b=−q_a`, `i_a=dq_a/dt`를 해석기에서 일관되게 산출한다. 전하 표식이 유전체 틈을 건너가지 않는다. 변위전류는 필요한 경우 별도 설명·표현을 제공한다.
- 다이오드: 선택한 I–V/저장 모델의 결과를 표시한다. 0.7 V 임계값, 누설·항복·회복을 표시 코드에 가정하지 않는다. 단자 전위의 보간 경사를 접합 내부 장벽이나 캐리어 궤적으로 해석하지 않는다.
- 통과 전하 학습: 필요 시 단면의 `∫ I dt`를 별도 물리량으로 계산한다. 방향 무늬 개수로 전하·에너지·시간을 계산하지 않는다.

## 영향과 검증

요구사항 스키마의 물리 규칙 참조는 기존 PV와 새 CV 접두어를 허용한다. 기존 요구사항·fixture와 호환되며 회로 저장 형식과 무관하다.

`CircuitDocument`와 `SimulationResult` 저장·계산 계약은 바뀌지 않는다. 마이그레이션은 없다. `CircuitCanvas.currentArrows`는 `currentDisplay`로 교체하고 `Potential3DProps.currentDisplay`를 추가한다. 공통 표시 계층은 React·Three.js를 의존하지 않으며 브라우저 DOM 수명만 소유한다.

fixture 전류·KCL, 부호와 전원 단자 순서, 열린 스위치·미정·미세 전류, 배치/높이 불변식, 실제 3D 투영 후 등속, 자동 축척·두께 배율·역비례 간격·직렬 경계 연속성·닫힌 경로, 표시기 프레임 수명, 브라우저 전환·선택·높이 변경을 검증한다.

## 연속 값 갱신 (2026-10-02)

가변저항 조절은 [ADR-023](ADR-023-live-parameters.md)을 따른다. 범위 양 끝의 최대 전류를 고정 기준으로 사용한다. 전류·축척 변경 또는 조절 시작 시 전체 점열을 160 ms 동안 페이드아웃한다. 사라지는 동안 기존 간격과 이동을 유지하며, 첫 점을 기준으로 나머지 점을 재배치하지 않는다. 띠 두께·전위 색·측정값은 실제 계산값으로 즉시 갱신한다.

수동 조절 종료와 마지막 전류·축척 변경 후 300 ms 동안 안정되면 투명한 상태에서 최신 경로·간격으로 재설정하고 160 ms 페이드인한다. 자동 왕복 실행 중에는 끝점의 650 ms 정지 구간이나 조절창 숨김과 무관하게 점열을 숨긴다. 여러 부품 중 하나라도 조절 중이면 숨김을 유지한다. 점 간격의 단계화나 전류 전달 지연은 만들지 않는다.

`CurrentDisplay.changing`은 조절기의 실행 상태를 전달하는 선택적 표시 속성이다. app이 부품별 조절 상태를 모아 2D·3D에 같은 표시 계약으로 전달하고, current-view의 mark-visibility가 대기·페이드·타이머 정리를 소유한다. 계산 결과와 회로 저장 형식에는 추가하지 않는다. 공통 표시기는 전류·기준 축척의 변경도 직접 감지하며 카메라 좌표·색상 변경은 그 감지에 포함하지 않는다.

점열이 완전히 숨겨지면 점 그리기와 표시용 RAF를 중단한다. 일시 정지·움직임 감소에서는 페이드를 생략하고 안정된 점열만 정적으로 복원한다. 새 뷰가 자동 조절 중 생성되어도 처음부터 숨겨 점이 번쩍이지 않게 한다. 카메라만 이동할 때의 지연 재배치·분기 페이드·등속 표현은 기존 정책을 유지한다.

## 다이오드 확장 계약 (2026-10-05)

[ADR-026](ADR-026-diode-boundary-analysis.md)이 이 절과 겹치는 이전 범위를 확장한다. 다이오드의 A→K 전류와 OFF 0 A를 명시한다. 다이오드 조절 회로에는 선형 회로의 양 끝 극값 보장을 적용하지 않고 현재 검증값으로 범위를 확장한다. 파손 이후 현재 전류·전위 표현은 중단한다. 무늬 시간은 부품 위험과 독립이다.
