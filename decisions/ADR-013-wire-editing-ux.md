# ADR-013: 도선 삽입과 교차 연결의 명시적 편집

- 상태: accepted
- 결정일: 2026-09-23
- 관련: EDT-001/002/003/004/006, SIM-001, TCH-003, ADR-001/002/008

## 결정

사용자의 UX 제안서 기반 구현 요청에 따라 새 부품의 직렬 삽입, 교차 연결·분리, 공통 브리지 표시를 구현한다. 배선 명령 자체는 저장 필드를 추가하지 않는다. 현재 저장 형식 v2와 v1 호환 변환은 ADR-012를 따른다. 새 필드·Net 저장·좌표 기반 자동 전기 연결은 도입하지 않는다.

`InsertComponentOnWire`, `ConnectCrossing`, `DisconnectCrossing`, `ConnectToWire`는 editor 공개 Command에 추가한다. 기존 `previewCommand`의 권한 검사·변환·문서 검증을 통과한 결과만 `executeCommand`가 한 개의 이력으로 저장한다. 미리보기·취소는 문서에 영향을 주지 않는다. 정책은 새 명령 이름을 명시적으로 허용해야 하며 기존 AddComponent 허용만으로 삽입을 우회하지 않는다.

- 삽입: 도선의 직선 구간을 두 도선으로 나누고 부품의 서로 다른 단자를 참조한다. 주변 경로와 기존 바깥쪽 연결은 보존한다. 기호는 가로 0° / 세로 90°로 맞추고 극성을 보여 준다. 단자 반간격 44에 여유 12를 더한 56 회로 단위가 양쪽에 필요하다. 교차가 부품 영역에 있거나 꺾임·단자와 너무 가까우면 거절한다. 가까운 후보가 여럿이면 선택 후 확정한다.
- 라이브러리의 새 두 단자 전원·저항·부하·스위치·전류계를 지원한다. 전압계와 사용자 지정 단자 좌표는 자동 삽입하지 않는다. 이미 연결된 부품의 이동은 기존 정책을 유지한다.
- 연결: 두 직교 도선의 내부 교차 한 곳을 네 도선과 공통 Junction으로 변환한다. 여러 도선이 겹치는 모호한 지점은 거절한다.
- 분리: 정확히 네 갈래인 상·하·좌·우 경로를 서로 반대 방향끼리 연결한다. T자·겹침·다중 경로는 임의로 쌍을 고르지 않는다. 해당 Junction을 기준점이나 주석이 참조하면 먼저 다른 단자로 재지정하도록 안내하고 거절한다. 성공하면 다른 교차와 참조는 유지한다.
- 터치 배선: 시작 단자 → 끝 단자 또는 도선 탭. 끝 도선을 누르면 경로를 보존하며 분기점을 만들고 연결한다. Escape와 화면의 취소 버튼으로 시작 상태를 버린다.

`component-library`의 `wireCrossings`/`wirePath`는 공통 기하 표시 계약이다. 가로 도선이 반원으로 넘어가며 색상이나 불투명 흰 마스크에 의존하지 않는다. 좁은 교차 간격에서는 반지름을 줄인다. editor가 사용하는 좌표는 명시적 명령의 대상을 정하기 위한 것이며 connectivity의 net 판정은 계속 ID만 사용한다. 다른 위치의 우회 연결 때문에 같은 net인 두 도선도 이 교차에서 접속하지 않으면 브리지를 표시한다. 아치는 저항·전압 강하·3D 높이가 아니다.

## UI와 저장 영향

값 입력창·후보·교차 미리보기·패널 열림은 React 일시 상태다. 측정 모드의 편집 차단은 유지한다. 부품값은 SI 값으로 명령을 통해 저장하며 부정확한 입력은 이전 값을 유지한다. 부품 기호 자체는 기존 한국 교육용 지그재그 정의를 그대로 사용한다.

자동 저장과 JSON은 회로 문서만 포함한다. 측정 기록은 메모리/CSV 정책을 유지하고 화면에 알린다. 스키마 변경이 없어 마이그레이션은 필요하지 않으며 새 연결 결과의 JSON 왕복을 검증한다.

## 근거와 검증

### 후속 결정: 문맥에 따른 배선 UI

사용자가 승인한 후속 제안에 따라 분기점·교차 연결을 기본 선택 동작에 통합한다. 호버는 클릭 대상과 다음 행동만 미리 보여 주며 회로를 변경하지 않는다. 최신 사용자 지시에 따라 일반 단자·분기점은 배선 시작으로 유지하되, 전환 가능한 네 갈래 교차점은 클릭 자체로 연결·해제를 토글한다. 배선 진행 중에는 연결점을 도착점으로 사용한다. 교차 버블은 연결·비연결의 현재 상태만 표시하고 클릭을 가로채지 않는다. 새 교차는 여전히 비연결이며 생성 직후 안내와 재호버 안내를 제공한다. 해제 가능한지 여부는 기존 DisconnectCrossing 미리보기 결과를 사용한다.

도선 분기 시작은 임시 상태로 유지하고 도착 확정 시 분할·연결을 원자적으로 저장한다. 일반 배선의 설명 버블·하단 안내는 제거한다. 분기 후보에는 원형 표시와 포인터 방향의 희미한 가지 도선을 함께 보여 준다. 터치는 도선 후보를 탭으로 선택하고 체크 아이콘 또는 같은 후보 재탭으로 확정한다. 겹친 단자는 원래 위치에 선으로 대응하는 원형 아이콘으로 선택하며 접근성 이름에 방향을 제공한다. 선택하지 않은 부품 또는 빈 화면의 한 손가락 드래그는 화면 이동이며 두 손가락 동작은 진행 중 부품 드래그를 취소한다. 편집기 명령·스키마·물리 모델 경계는 유지한다.

`tests/context-wiring.test.ts`와 Canvas 포인터 이벤트 검사는 권한 실패 시 부분 분기점 미저장, 양 끝이 같은 도선인 분기, 취소·한 번의 undo/redo, 터치 확정, 교차 동작 구분과 모드 전환 취소를 검증한다.

`fixtures/ux/wire-editing.json`은 9 V·3 Ω 회로의 삽입·교차 연습용 문서다. `tests/wire-editing.test.ts`에서 6 Ω 삽입 시 3 A → 1 A, 명시적 단자 연결, 미리보기 일치, 실패 시 원본 보존, 실행 취소/다시 실행, 저장 왕복, 다중 교차 한 곳만 변경, 우회 경로 보존, 흑백·투명 SVG를 검증한다. Canvas 이벤트 테스트는 인라인 입력 실패·적용·취소와 실제 기호 미리보기를 다룬다. PNG와 작은 화면은 브라우저에서 확인한다.
