# ADR-007: 로컬 우선 저장

- 상태: accepted
- 결정일: 2026-09-23

## 배경

학교 환경에서 계정, 네트워크, 개인정보 의존성을 줄이고 핵심 기능을 정적 웹 배포로 제공해야 한다.

## 결정

핵심 편집·시뮬레이션·출력은 로컬에서 동작한다. 브라우저 자동 저장과 JSON 파일을 기본 저장 경로로 사용한다.

## 결과

- 로그인 없이 시작한다.
- 서버 장애가 기본 편집을 막지 않는다.
- 저장 파일에 스키마 버전과 마이그레이션이 필요하다.
- 실시간 공동 편집과 대규모 클라우드 저장은 MVP에서 제외한다.
- PWA는 후속 기능으로 검토하되 핵심 자산이 서버 API에 종속되지 않게 한다.

## 다이오드 확장 계약 (2026-10-05)

[ADR-026](ADR-026-diode-boundary-analysis.md)에 따라 현재 지원 저장은 회로 v6·측정 기록 v5이며 지원 밖 입력은 변환 없이 거부한다. 과거 결정의 마이그레이션 필요 문구보다 사용자 지시와 ADR-024/026의 현재 형식 전용 계약이 우선한다. 부품 프로필과 고정 특성 차이는 원본에 보존하고 분석 사건·파손 상태는 포함하지 않는다.
