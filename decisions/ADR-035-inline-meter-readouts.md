# ADR-035: 회로 위 계기값의 독립적인 펼침·축소

- 상태: accepted
- 결정일: 2026-10-08
- 요구사항: MEA-001/002, VIS-004

## 결정

분석 모드의 전류계·전압계 기호 우측 상단에 반투명한 원 안의 더하기(⊕) 버튼을 둔다. 누르면 기존 측정 도구의 연녹색 LCD와 숫자·단위 표현을 재사용한 작은 표시창을 연다. 제목·기록·도구 선택 행은 넣지 않고 값과 단위만 표시한다. 같은 위치의 원 안의 빼기 버튼으로 해당 창만 접는다. 보이는 아이콘은 작게 유지하되 조작 영역은 44 CSS px로 둔다.

각 계기는 독립적으로 열며 다른 위치 선택·측정 도구 사용·화면 이동·2D/3D 전환으로 접히지 않는다. 전체 전위 숫자의 표시 여부와도 독립적이다. 만들기·출력에서는 숨기며 분석으로 돌아오면 유지한다. 새 회로·파일/예제 불러오기에서는 초기화하고 삭제된 계기 ID는 정리한다. 펼침 상태와 측정 결과를 CircuitDocument에 저장하지 않는다.

표시값은 현재 공통 분석 결과에 `probeCurrent` 또는 `probeVoltage`를 적용해 얻는다. 전류·전압의 부호는 기존 단자 순서 기준을 유지하고 단자 방향은 툴팁으로 안내한다. 물리 모델·정확/근사 품질과 부품별 수치 표시 설정을 유지한다. 계산 불능, 독립 기준 사이의 전압, 전원 분리 중인 등가저항 측정, 파손 후 중단에는 이전 값을 남기거나 0으로 대체하지 않고 `—`와 단위를 표시한다. 정상적인 0과 실제 작은 전류는 그대로 표시한다.

## 구현 경계

- `app/MeasurementDisplay`가 기존 측정 도구와 작은 계기창의 LCD·값/단위 타이포그래피를 공유한다.
- `app/MeterReadouts`는 표시와 배치를 담당한다. App이 계기별 열림 상태와 측정 중단 조건을 전달한다. 모달·바깥 클릭 닫기 동작이 있는 FloatingPanel은 사용하지 않는다.
- `ComponentLabelLayout.symbolAnchors`는 선택적 화면 좌표다. 2D는 계기 원의 우측 상단, 3D는 기존 부품 중심 투영에 붙은 우측 상단 위치를 제공하며 라벨 숨김과 독립적이다. 연결/계산에는 사용하지 않는다.
- 기존 렌더러 콜백으로 위치를 갱신하고 별도 애니메이션 루프나 프레임별 React 상태를 추가하지 않는다. 화면 밖으로 나간 계기는 잠시 숨겨도 열림 상태는 유지한다. 표시창을 화면 안으로 제한하고 서로 겹치면 가까운 위·아래 위치를 우선 탐색한다.
- 계산 모델·계기 단자·기록 기능·문제지 출력 계약과 회로 v6·측정 기록 v5는 바꾸지 않는다.

## 검증

여러 계기 동시 표시·개별 축소·다른 위치 선택 후 유지, 스위치/값 변경에 따른 실시간 갱신, 숫자 숨김·측정 도구·2D/3D 전환, 전원 분리/오류/독립 기준에서의 미확정 표기, 문서 교체·삭제 시 상태 정리, 기존 측정 LCD 회귀를 확인한다. 브라우저에서 두 종류의 표시 크기와 작은 화면의 배치를 확인한다.
