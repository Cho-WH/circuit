# ADR-024: 선형 직류 회로의 정확 유리수 연산

- 상태: accepted
- 결정일: 2026-10-02
- 요구사항: SIM-002~006, SIM-008, EDT-004/008, MEA-001~004, VIS-006, DAT-001~003
- 구현 상태: 정확 엔진·회로 v5·측정 기록 v4 및 비용 검증 완료. [ADR-025](ADR-025-bounded-approximate-dc.md)의 계산 예산·명시적 근사 경로를 구현했다.

2026-10-02 추가 결정: 아래 정확값 보장은 정확 해석 경로에 적용한다. 모든 입력의 근사 전환을 금지하던 범위는 ADR-025로 개정하며, 정확한 입력 원본과 일반 수업 회로의 정확 해석을 유지한다.

## 배경

휘트스톤 브리지 FIX-09의 균형점에서 중앙 저항 전류는 0 A이지만, 도선 전류의 부동소수점 KCL 합산에 약 1.39×10⁻¹⁷ A가 남아 흐름 무늬가 나타났다. 행렬 풀이만 정밀하게 바꾸고 측정에서 다시 number를 합산하면 같은 문제가 재발한다. 작은 전류를 일괄적으로 0으로 처리하면 실제 작은 전류도 사라진다.

현재 지원하는 이상적인 선형 직류 저항 회로는 입력이 유리수이고 유일 해가 존재할 때 해도 유리수다. 이 범위에서 입력한 모델의 계산 반올림 오차를 제거한다.

## 결정

1. 입력과 정확 경로의 물리값은 정규화한 BigInt 분자·분모로 연산한다. 입력부터 저장, 연결망 컴파일, MNA, 도선 KCL, 측정·등가저항·전력·기록까지 정확값을 유지한다. 계산 예산 초과 시 ADR-025의 품질을 명시한 근사 경로를 적용한다.
2. 0·부호·동일 전위·전원 제약의 일치·행렬 계수의 판정은 정확 연산으로 한다. 0과 작은 비영 값을 허용오차로 합치지 않는다.
3. 기존 연결망과 MNA 구성, SimulationEngine 및 측정 모듈의 책임을 재사용한다. 공통 유리수 연산은 순수 모듈로 분리하고 행렬 알고리즘은 simulation 내부에 둔다.
4. 회로 물리값의 저장 원본은 정수 문자열 쌍으로 직렬화한 유리수 한 개다. 정확 경로의 number는 화면용 파생값이며 근사 경로의 계산값은 품질을 구분한다. 현재 회로 v5·정확/근사 품질을 보존하는 측정 기록 v4만 지원하며 이전 형식의 변환·호환은 제공하지 않는다. 관리하는 예제와 fixture는 현재 형식으로 갱신한다.
5. 숫자 표시는 정확값에서 반올림하고, 색·높이·두께·점열에는 정규화한 표시용 근삿값을 전달한다. 물리 판정은 변환 전에 끝내며 화면 근삿값을 계산에 되돌리지 않는다.
6. 정확 경로는 결정론적 소거법을 사용한다. ADR-025의 4,096비트·GCD 내부 반복 1,000,000회 계산 예산을 넘으면 명시적 근사 경로로 전환한다. 결과 품질을 숨기거나 계산 실패를 근사 성공으로 대체하지 않는다. 분수 없는 소거 등 내부 최적화는 별도로 검토할 수 있다.

상세 데이터 표현·계산 절차·실패 조건·저장 기준은 [정확 직류 연산 명세](../docs/physics/exact-dc-arithmetic.md)를 따른다.

## 기존 결정과의 관계

- ADR-004의 자체 조밀 행렬·엔진 내부 경계는 유지한다. number 행 정규화·`1e-13` 피벗·허용오차 잔차로 해를 판정하는 정책은 이 결정으로 대체한다.
- ADR-009의 자체 MNA·선형 직류 범위는 유지한다.
- ADR-010의 문서 원본·결정론·구조화 진단·검증 경계는 유지하고 물리 수치의 타입은 정확값으로 전환한다.
- ADR-019의 quantity/notation 분리·입력 문법·표시 선택은 유지한다. 계산 전 binary64 변환과 number를 물리값 원본으로 삼는 정책을 대체한다.
- ADR-023의 조절 UX·정상 상태 계산·시야 보존을 유지한다. 연속 조절의 물리 입력은 명세의 정수 단계 또는 확정 소수값으로 생성한다.

## 범위와 비용

정확성은 정확 경로에서 입력된 이상적 모델에 대한 보장이다. 실제 부품의 오차나 화면 픽셀, 향후 비선형·과도 해석까지 정확 유리수 해를 보장하지 않는다. 비용 검증에서 큰 분모의 수 초 지연이 확인되어 ADR-025를 채택했다. 현재 구현은 결정론적 첫 비영 피벗의 유리수 가우스 소거를 사용한다. 원래 식의 잔차가 정확히 0이 아니면 `EXACT_SOLVE_FAILED`로 결과를 거부한다. 물리 허용오차 옵션은 제거했으며 명시적 근사 경로는 ADR-025의 별도 수용 정책을 따른다.

2026-10-02 사용자의 추가 지시로 기존 자료의 순차 이행 계획을 철회했다. DAT-003, 저장 지침과 관련 ADR도 현재 형식만 지원하는 계약으로 맞춘다.

## 다이오드 확장 계약 (2026-10-05)

[ADR-026](ADR-026-diode-boundary-analysis.md)이 이 절과 겹치는 이전 범위를 확장한다. 현재 지원 저장은 회로 v6·측정 기록 v5다. 7/10 V 교과서 다이오드와 양의 도통 기울기를 가진 부품 모델도 같은 정확 유리수 계약을 따른다. 부품 모델의 물리적 근사와 수치 해법의 근사를 구별하며 내부 모델 요소·위험 결과를 제작 문서에 추가하지 않는다.
