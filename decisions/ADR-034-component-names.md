# ADR-034: 부품 이름의 공통 자동 생성

- 상태: accepted
- 결정일: 2026-10-08
- 관련: EDT-001/005/007, ADR-001/032

## 결정

내부 ID 발급과 표시 이름 생성을 분리한다. 새 배치(마우스·터치·도선 삽입)와 복사본은 `component-library.createComponentLabelAllocator(existingLabels)`를 사용한다. 부품 정의의 `short`를 받아 `접두어_양의정수`로 이름을 만들며 현재 사용하지 않은 가장 작은 번호를 고른다. 별도 종류별 분기나 전역 이름 카운터를 두지 않는다.

- 같은 접두어를 쓰는 종류는 번호를 공유한다. 일반·전환 스위치는 모두 S, 가변저항은 VR이다.
- 회로 전체의 실제 이름을 검사한다. `R1`, `R_1`, `R_{1}`, `R₁`과 앞자리 0이 있는 번호는 중복 검사에서 같은 이름으로 취급한다. 대소문자는 구분한다. 기존 이름의 저장값은 정규화하거나 변경하지 않는다.
- 복사는 원본 문서 순서로 이름을 배정하고 같은 묶음에서 이미 배정한 이름도 예약한다. 사용자 지정 이름을 가진 원본도 그대로 유지하되 복사본은 종류별 새 이름을 받는다. 값·특성·연결·상대 위치 보존은 ADR-032를 유지한다.
- 취소·배치 실패는 표시 번호를 소비하지 않는다. 삭제·실행 취소로 비게 된 번호는 다시 사용할 수 있다. 다시 실행은 저장된 이름을 그대로 복원한다.
- 수동 이름 편집과 기존 파일의 중복 이름은 계속 허용한다. 자동 생성 이름의 중복 회피를 문서 전체의 유일성 제약으로 확장하지 않는다.

## 경계와 확장

`componentDefinitions`가 접두어의 유일한 등록 위치다. 새 부품은 `short`에 수업용 문자 접두어를 지정하고 기존 배치·복사 경로를 사용한다. `componentDefinition(component)`가 변형까지 해석한다. 생성기는 `{ short }`만 읽는 순수 함수이며 ID·좌표·전기 모델·브라우저 상태를 참조하지 않는다. 기본 드래그 드롭도 같은 부품 정의로 허용 종류를 검사해 별도 목록 갱신을 요구하지 않는다.

`createComponent(kind, id, position, label?)`는 기호·모델 템플릿 생성기다. 실제 배치에서는 공통 생성기로 정한 label을 명시한다. 팔레트·기하 미리보기 등 이름을 표시하지 않는 템플릿은 생략할 수 있으며 이때 ID를 임시 이름으로 쓴다. 개별 종류에만 적용하던 이름 변환은 제거한다.

예제는 교육용으로 작성된 이름을 유지한다. 불러오기·기존 문서·수동 편집 이름을 재번호화하지 않으며 회로 v6·측정 기록 v5와 저장 스키마는 변경하지 않는다. 이름은 기존 label 필드에만 저장하고 별도 카운터·자동 이름 여부를 문서에 추가하지 않는다.

## 검증

혼합 종류 배치, 같은 접두어의 변형, 기존 표기·수동 이름과의 충돌, 번호의 빈자리, 묶음 복사·취소·원본 보존, 도선 삽입, Undo/Redo와 현재 저장 형식 왕복을 확인한다. 새 접두어도 생성기 수정 없이 동작해야 한다.
