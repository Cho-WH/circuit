# ADR-011: 등가저항의 포트와 외부 시험 전원

- 상태: accepted
- 결정일: 2026-09-23

## 배경

FIX-01~04·09·10은 전원 단자에서 바라본 **부하**의 등가저항을 기대한다. 해당 전원을 그대로 0 V로 치환하면 포트가 단락되어 0 Ω이 되므로, 물리 문서의 독립원 비활성화 규칙과 fixture 사이에 측정 대상의 구분이 필요하다.

## 결정

공개 함수는 제외할 외부 여자 전원 ID 목록을 명시적으로 받는다. 제외 목록이 없으면 회로 전체의 독립 전압원을 0 V로 만든다. 외부 여자 전원을 제외한 경우에는 그 전원을 먼저 회로에서 분리한 뒤 **나머지** 독립 전압원을 0 V로 만든다. 이후 포트에 1 V 시험 전원을 연결하고 시험 전류로 저항을 구한다.

UI는 `부하 등가저항 — 포트 전원 분리`와 `전체 회로 — 전원 0 V 치환`을 구분한다. 부하 모드에서 선택 포트에 직접 걸린 전원들을 제외하며 제외된 ID를 표시한다. 원본 문서는 수정하지 않는다. fixture의 기존 기대값은 부하 모드로 검증한다.

0 Ω 경로는 단락, 포트 간 경로 없음은 개방으로 반환하며 무한대나 미정 값을 유한 숫자로 표시하지 않는다. 관련 요구사항은 SIM-005와 MEA-001이다. 저장 형식 변경과 마이그레이션은 없다.

## 검증 계획

FIX-01~04·09·10의 부하 기대값, 동일 포트의 전체 회로 0 Ω, 다른 내부 전압원 비활성화, 1 V 시험 전원, 개방·단락·원본 불변성을 단계 4에서 검증한다.
