# ADR-011: 등가저항의 포트와 외부 시험 전원

- 상태: accepted
- 결정일: 2026-09-23
- 갱신일: 2026-09-24

## 배경

FIX-01~04·09·10은 전원 단자에서 바라본 **부하**의 등가저항을 기대한다. 해당 전원을 그대로 0 V로 치환하면 포트가 단락되어 0 Ω이 되므로, 물리 문서의 독립원 비활성화 규칙과 fixture 사이에 측정 대상의 구분이 필요하다.

화면에서 탐침 양단에 직접 연결된 전원만 제외하면 같은 직렬 회로에서도 저항 양단은 2 Ω, 전원 양단은 9 Ω으로 서로 다른 측정 조건이 적용된다. 학생용 저항 측정은 전원을 분리한 회로를 일관되게 대상으로 해야 한다.

## 결정

공개 함수는 제외할 외부 여자 전원 ID 목록을 명시적으로 받는다. 제외 목록이 없으면 회로 전체의 독립 전압원을 0 V로 만든다. 외부 여자 전원을 제외한 경우에는 그 전원을 먼저 회로에서 분리한 뒤 **나머지** 독립 전압원을 0 V로 만든다. 이후 포트에 1 V 시험 전원을 연결하고 시험 전류로 저항을 구한다.

저항 측정 UI는 모든 직류 전원 ID를 `excludeSourceIds`로 전달한다. 탐침 위치나 전압값에 관계없이 전원을 개방하고, 전원 포함/제외 선택은 제공하지 않는다. 모든 나머지 수동 경로는 유지한다. 전원 기호·이름·값을 흐리게 표시하고 양쪽 리드에 간격을 두되, 탐침용 회로 단자는 유지한다. 원본 문서를 수정하지 않고 다른 모드에서 정상 표시한다. 기록에는 분리 조건과 전원 이름을 남긴다. 안내 아이콘의 툴팁은 “실제 저항계는 전원을 분리한 회로에 작은 시험 신호를 보내 저항을 측정해요.”로 실제 원리를 설명한다.

0 Ω 경로는 단락, 포트 간 경로 없음은 개방으로 반환하며 무한대나 미정 값을 유한 숫자로 표시하지 않는다. 관련 요구사항은 SIM-005와 MEA-001이다. 저장 형식 변경과 마이그레이션은 없다.

## 검증 계획

기존 FIX-01~04·09·10 부하 기대값과 공개 API의 독립원 비활성화·1 V 시험 전원·개방·단락 검증을 유지한다. `resistance-mode.test.ts`는 UI의 직렬 3 Ω·6 Ω·전체 9 Ω, 병렬 2 Ω, 다중 전원과 0 V 전원 분리, 탐침 반전, 원본 불변·전압 모드 복귀, 전원 표시·툴팁·기록을 검증한다.
