# ADR-023: 가변저항 조절과 연속 갱신

- 상태: accepted
- 결정일: 2026-10-01
- 요구사항: EDT-008, VIS-004/006/007, MEA-003, DAT-001/002

## 사용자 경험

회로 만들기에서 가변저항의 회로 위 값 편집과 부품 상세 설정은 현재 저항값과 최솟값·최댓값을 함께 편집한다. 회로 위 이름·현재값·범위는 적용 버튼으로 함께 확정하고 취소 시 초안을 버린다. 두 진입점은 범위 입력·단위 해석·현재값 제한 로직을 공유한다. 분석하기의 왼쪽 측정 영역 아래에 이름, 현재값 입력, 선형 슬라이더, 양 끝 범위를 둔다. 여러 가변저항은 하나씩 선택한다. 탐침·기록·보기 설정은 유지한다. 슬라이더 아래 저항 자동 조절 재생 버튼은 실행 중 일시 정지 버튼으로 바뀐다. 자동 왕복은 편도 8초, 양 끝 650ms 정지로 시작하며 직접 조절·멈춤·분석 종료·문서 교체·숨겨진 탭에서 멈춘다. 별도 설명 밴드는 추가하지 않는다.

입력 중인 수치는 Enter/포커스 이동으로 확정하고 Escape로 취소한다. 슬라이더와 자동 왕복은 최신 입력을 화면 프레임마다 최대 한 번 적용한다. 놓을 때 마지막 값을 반영한다. 한 번의 슬라이더 조작 또는 자동 실행 구간은 한 번의 실행 취소 단위다. 기존 명령의 활동 권한·문서 검증을 매번 거친다.

## 조절창 표시와 실행 상태 (2026-10-01)

데스크톱 분석 패널은 가변저항 유무와 관계없이 도구 3열·탐침 가로 배치의 압축 스타일을 사용한다. 회로에서 선택한 가변저항의 조절창만 표시하며 드롭다운은 사용하지 않는다. 2D 측정 중 부품 몸체와 3D 전압 측정 중 부품 선택도 같은 선택 상태를 사용한다. 탐침 위치는 유지한다.

조절창의 가시성과 실행 수명은 구분한다. 분석 중 각 가변저항의 기존 ParameterControl을 유지하고 선택하지 않은 조절창은 hidden으로 숨긴다. 선택 해제와 다른 부품 선택은 자동 왕복을 멈추지 않는다. 다시 선택하면 진행 중인 값과 일시 정지 버튼을 표시한다. 분석 종료·문서 교체·부품 제거·브라우저 탭 숨김과 직접 입력·일시 정지의 기존 중단 동작은 유지한다. 비교 축척은 마지막으로 선택한 가변저항을 기준으로 창이 닫혀도 유지하며, 다른 부품 값 변경 시 다시 계산하는 기존 규칙을 따른다.

## 데이터와 물리

정확값 계약은 [ADR-024](ADR-024-exact-dc-arithmetic.md)로 구현했다. 범위·현재값은 v5의 정수 문자열 쌍이며 슬라이더·자동 왕복의 0~1000 정수 위치를 공통 parameterValueAt으로 정확히 변환한다. 직접 입력은 확정 소수·분수를 그대로 보존하고 슬라이더 이동 전에는 단계에 맞추지 않는다. 조절 UX·정상 상태 모델은 유지하며 연산 부하 검증은 후속이다.

두 단자 `resistive-load`의 기존 `resistanceOhm`에 선택적 `resistanceMinOhm`, `resistanceMaxOhm` 속성을 추가한다. 새 부품은 10 Ω, 범위 1~100 Ω이다. 명시된 범위는 `0 < min < max`, `min ≤ value ≤ max`를 만족한다. 범위만 축소할 때 현재값을 새 범위로 제한하고 같은 명령으로 확정한다. 현재값을 직접 입력했으면 새 범위 안인지 확인하고, 범위 밖 입력은 안내 후 수정을 기다린다. 회로 위에서 값과 범위를 함께 바꿀 때는 하나의 속성 변경 명령으로 적용한다. 수치만 바꾸면 기존 분수 원문을 지우는 규칙을 재사용한다.

현재 회로 v5만 지원하고 이전 형식의 변환은 제공하지 않는다. 범위가 생략된 현재 문서에는 현재 양수 값을 포함하는 기본 범위를 사용한다. 0 Ω을 표현한 문서도 계산 모델에서는 유지하며 조절을 시작할 때 양수 범위를 적용한다. 자동 실행·입력 초안·축척 기준은 문서 밖에 둔다.

각 프레임은 기존 직류 해석의 정확한 정상 상태다. 표시값 사이 보간이나 과도 응답을 추가하지 않는다. 한 양수 저항을 변화시키는 선형 회로의 전압·전류는 저항에 대한 분수 일차 함수이므로, 나머지 회로를 고정하면 범위 양 끝에서 극값을 구할 수 있다. app이 양 끝을 계산하고 최대 전류(도선 포함)·전위 범위를 공유한다. 전위 색·3D 높이와 눈금·전류 너비와 간격의 기준을 조절 중 유지한다. 다른 부품·범위·접지·조절 대상이 바뀌면 다시 구한다. 사용자 색 범위와 높이·두께 배율은 유지한다.

측정·기록은 동일한 실제 계산값을 사용한다. 기존 기록 스냅샷과 조건 묶기가 당시 가변저항값을 이미 보존하므로 기록 형식을 늘리지 않는다.

## 경계와 재사용

- component-library의 `adjustableParameter`는 부품의 조절 속성·범위·단위·이름을 제공한다. 향후 조절 가능한 직류 전원장치는 이 정의를 추가하고 같은 조절기를 사용할 수 있다. 이번에는 가변저항만 등록한다.
- app/parameters는 단위 입력·슬라이더·자동 왕복·프레임 갱신과 비교 축척을 담당한다. 계산은 기존 analyze/SimulationEngine 경로를 사용한다.
- useCircuitSession은 연속 조작 토큰으로 이력을 묶으며 다른 명령·실행 취소가 그룹을 끊는다. 회로 교체 세대를 별도로 전달해 같은 회로의 값 수정이 WebGL 재마운트로 이어지지 않게 한다.
- potential-3d/primitives는 기존 선·튜브·점의 GPU 자원을 유지하고 좌표·색상·크기만 갱신한다. 범용 렌더링 프레임워크를 추가하지 않는다. 카메라·진입·표시기는 기존 구현을 사용한다.
- 3D 바닥은 공통 SVG 출력으로 생성하되 조절 부품의 값은 바닥에서 생략하고 높이 지도 부품 이름 옆에 표시한다. 숫자 갱신마다 바닥 텍스처를 다시 만들지 않으며 바닥 도선은 유지한다.
- 조절기는 수동 조절·자동 실행 상태를 app에 전달하며, app은 여러 부품의 상태를 CurrentDisplay.changing으로 모은다. current-view는 조절 중 점열을 페이드아웃하고 값이 안정된 뒤 새 간격으로 페이드인한다. 자동 왕복 끝점과 조절창 숨김에서도 숨김을 유지한다. 띠·측정은 계속 갱신하며 화면 속도·분기 페이드·카메라 재투영 정책과 표시 시간은 ADR-020을 따른다.

## 검증

기존 계산·측정·저장 검증을 재사용한다. 변경 위험인 범위 검사·명령 권한·저장 왕복, 프레임별 최신 값과 마지막 값, 실행 취소 묶기, 자동 실행 중단, 측정 조건 기록, 3D 자원·시점·축척 유지에 집중한다. 실제 브라우저로 패널 배치와 조절 흐름을 확인하고 실기기 성능·교실 사용성은 구분해 기록한다.
