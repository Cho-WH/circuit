# ADR-017: 부품 삭제 시 도선 연결 유지

- 상태: accepted
- 결정일: 2026-09-24
- 관련: EDT-001/002/005, SIM-001, ADR-002/008/013/016

## 배경

DeleteElements는 부품의 단자를 참조하는 도선을 모두 지웠다. 사용자는 부품을 삭제한 자리가 도선으로 이어지고 기존 회로 경로는 유지되기를 요청했다. 이후 단순 직렬 구간에 남은 두 분기점을 제거하도록 보완했다. 부품 삭제의 연결 정책과 도선의 중간 연결점 정리를 분리한다.

## 결정

후속 [ADR-018](ADR-018-junction-lifecycle.md)은 6번 정리를 삭제로 영향을 받은 기존 분기점에도 확대하고 구현 책임을 `editor/wire-topology.ts`로 옮긴다. 또한 노드 수동 삭제를 폐지하여 아래 명시적 분기점 삭제 규칙을 대체한다. DeleteElements는 노드 ID를 거절하고 연결된 도선을 연쇄 삭제하지 않는다.

1. 명시적으로 선택한 도선·분기점을 먼저 제거한다. 선택한 분기점에 연결된 도선도 기존 규칙대로 제거한다.
2. 삭제할 두 단자 부품에 남아 있는 도선이 하나라도 있으면, 두 단자의 실제 위치에 각각 임시 Junction을 만들고 그 사이에 Wire 하나를 추가한다. 단자에 붙은 모든 도선은 해당 Junction으로 참조를 옮긴다. 이는 문서 명령 내부 중간 상태이며 정리 후 결과만 발행한다.
3. 연결이 없는 부품은 흔적 없이 삭제한다. 한쪽만 연결된 부품도 같은 규칙을 적용하므로 반대쪽에 열린 도선 끝이 남는다. 함께 삭제하도록 선택한 도선을 복원하지 않는다.
4. 복수 부품은 원본의 연결 상태를 기준으로 한 명령에서 처리한다. 선택 ID 순서와 중복에 따라 결과가 달라지지 않는다. 같은 좌표의 다른 단자·분기점과는 합치지 않는다.
5. 바뀐 단자를 가리키는 기준점·주석도 동일한 참조 변환으로 위치를 보존한다. 대체되지 않고 제거되는 단자·분기점의 기준점은 null로, 해당 주석은 삭제한다. 명시적으로 선택한 주석은 항상 삭제한다.
6. 이번 삭제로 만든 연결점 중 도선 끝이 정확히 두 개 만나고 기준점·주석이 없는 점은 두 경로를 이어 하나의 도선으로 합친다. 중복·같은 방향의 일직선 점만 정리하여 굴곡·되접힘을 보존한다. 문서 순서상 앞선 도선의 ID와 방향을 유지한다. 열린 끝, 실제 분기, 기준점·주석이 있는 점은 남기며 기존 문서의 다른 분기점은 건드리지 않는다. 폐곡선만 남으면 현재 저장 모델상 양 끝을 참조할 연결점 하나는 필요하므로 유지한다.

현재 지원하는 전원·저항·가변저항·스위치·전류계·전압계에 같은 두 단자 규칙을 적용한다. 삭제는 해당 부품을 이상적인 도선으로 바꾸는 편집이며, 전압계·열린 스위치도 두 쪽이 연결되므로 회로의 계산 결과가 바뀔 수 있다. 해석기는 새 문서를 그대로 재계산하며 기존 단락 진단을 유지한다. 스키마가 허용하는 미지원 다단자 입력은 각 단자별 외부 연결만 보존하고 서로 다른 단자를 연결하지 않는다. 같은 단자에 도선 두 개만 붙어 있었다면 6번 규칙으로 합칠 수 있다. 향후 트랜지스터·브리지 정류기 등에도 내부 핀 연결을 추측하지 않는 이 원칙을 유지하며, 부품 모델·지원 범위를 추가하는 작업은 이번 변경에 포함하지 않는다.

## 모듈 경계와 저장

- `editor/delete-elements.ts`: 명시적 삭제, 부품의 도선 대체, 단자 참조 변환을 소유한다. editor 내부 구현이며 공개 API는 기존 DeleteElements 그대로다. 명령 실행기가 권한·검증·복제·한 번의 이력을 책임지고 UI는 삭제 명령만 전달한다.
- `editor/wire-edits.ts`의 `dissolveWireJunctions`: 전달받은 연결점 ID만 대상으로 도선 끝 수와 앵커 참조를 검사하고 경로를 합친다. 부품 종류·삭제 정책·UI를 알지 않는다. 자동 전체 문서 정리나 새 공개 명령은 추가하지 않는다.
- `component-library.terminalPosition`: 회전과 localPosition을 반영한 실제 단자 좌표를 제공한다. `wire-geometry.orthogonalRoute`가 두 점 사이 경로를, `compactWirePoints`가 경로의 중복·일직선 정리를 담당한다. 기존 대각선 구간을 직각화하거나 다른 길로 재배선하지 않는다.
- `domain.createDocumentIdAllocator`: 문서 전체 ID를 예약한 결정론적 할당 함수다. 문맥 배선과 삭제 대체가 공유한다. 삭제 대상으로 예약된 ID도 같은 명령에서 재사용하지 않는다. 외부 시간·난수·전역 카운터에 의존하지 않는다.
- 삭제 대체에 필요한 Junction/Wire는 DeleteElements의 원자적 의미다. 별도 AddJunction/ConnectWire 권한을 요구하지 않으며 DeleteElements 권한 검사를 우회하지 않는다.
- 기존 v4의 Junction·Wire·EndpointRef만 사용하므로 저장 필드와 마이그레이션은 바뀌지 않는다. 실행 취소는 원래 부품·단자·도선·주석·기준점을 함께 복원한다.

## 검증

`component-deletion.test.ts`에서 기존 경로·분기 보존, 전 부품 종류와 회전, 한쪽 연결, 명시적 혼합 삭제, 전체 삭제, 인접 부품 동시 삭제, 같은 좌표의 비연결, 사용자 단자 좌표, ID 충돌, 권한 실패, 미리보기/확정 일치, 저장 왕복, undo/redo를 확인한다. 기존 wire-editing fixture에 직렬 저항을 삽입한 뒤 삭제하면 원래 전류가 회복되는지도 확인한다. `workspace-ui.test.ts`는 삭제 버튼과 Delete 키가 같은 결과를 내고 한 번의 실행 취소로 복원됨을 검증한다.
