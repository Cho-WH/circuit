# ADR-046: 플랫폼 설정과 무관한 학습 동작과 화면 전환

- 상태: accepted
- 결정일: 2026-11-06
- 관련: P-09, QLT-001, VIS-004/006/008, SIM-009, ADR-006/018/020/044/045
- 근거: 사용자가 모든 기능을 동작 줄이기 설정과 무관하게 동일하게 동작시키고 설계 원칙·AGENTS.md에 명시하도록 요청했다.

## 문제와 결정

전류 재생 버튼은 재생 상태인데 운영체제의 동작 줄이기 설정 때문에 실제 동그라미가 멈출 수 있었다. 학습 동작이 외부 설정에 따라 달라지고 사용자가 앱에서 원인을 확인하거나 해제할 수 없었다.

주요 기능과 일반 UI의 재생·전환·표시는 운영체제·브라우저의 `prefers-reduced-motion`과 무관하게 동일하게 제공한다. 설정을 처음부터 켜거나 사용 도중 변경해도 전류 이동·간격 재배치, 3D 진입·시점 전환, RC 재생·최종 평형 전환, 과부하·파손 효과, 선택·배치 피드백, 패널·알림·진행 표시의 동작과 시간을 바꾸지 않는다. 이 결정은 이전 ADR의 동작 줄이기 관련 정지·생략 규칙을 대체한다.

## 구현 경계

- JS의 모션 선호 조회·변경 구독과 해당 CSS 미디어 쿼리를 제거한다. 전역 animation/transition 차단과 예외용 덮어쓰기도 제거한다.
- RcSession은 모션 선호를 입력받지 않는다. 정상 종료·넘기기는 같은 settling 단계를 거쳐 정확한 평형으로 전환한다.
- 사용자 일시정지·재개·배속·넘기기, 카메라 직접 조작에 의한 전환 중단은 유지한다. 숨겨진 탭·뷰 해제·오류에 따른 중지도 유지한다.
- 물리 계산, 진단, 단자 연결, 저장 형식은 변경하지 않는다. 새 환경 설정이나 문서 저장 필드를 도입하지 않는다.
- 키보드·터치·초점·텍스트 안내와 기존 명시적 재생 제어는 유지한다. 새 기능에서도 플랫폼 모션 설정에 따른 묵시적 정지·즉시 완료 분기를 만들지 않는다.

## 수용 기준

동작 줄이기 켜짐/꺼짐에서 전류 좌표의 실제 진행, 카메라 프리셋의 시작·완료, RC 충방전 진행·settling·정확한 평형, 파손 중→완료 및 조작 잠금이 동일하다. 사용 중 모션 설정 변경은 전류를 멈추지 않는다. 명시적 일시정지와 숨겨진 화면·뷰 해제의 중지는 기존 검증으로 보호한다. 일반 UI에는 모션 선호에 따라 효과를 제거하는 CSS 분기가 남지 않아야 한다.
