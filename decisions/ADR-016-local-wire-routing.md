# ADR-016: 국소적인 직각 도선 편집

- 상태: accepted
- 결정일: 2026-09-24
- 관련: EDT-001/002/003/005, SIM-001, ADR-002/013

## 배경

연결된 부품을 움직이면 도선의 모든 waypoints를 지우던 정책은 사용자가 만든 외곽 경로를 잃게 한다. 경유점을 직접 배치할 수도 없었다. 사용자가 승인한 개선은 단순한 공통 규칙, 명확한 책임 분리, 미리보기와 확정의 일치가 우선이다.

## 결정과 경계

- `wire-geometry`: Point 배열과 좌표만 받는 순수 기하 모듈. domain의 Point 타입만 의존하고 문서·ID·React·포인터·렌더러·이력을 알지 않는다. 공개 index에 `orthogonalRoute`, `stretchWire`, `shiftWireSegment`, `orthogonalWirePoints`, `compactWirePoints`를 제공한다. 기존 component-library는 compactWirePoints를 재수출해 호출 호환성을 유지한다. 역방향으로 접힌 경로를 임의로 최적화하지 않는다. 모듈 경계 검사로 domain 외 모듈 의존을 차단한다.
- `editor/wire-edits.ts`와 명령 실행기: 단자 ID로 이전/새 좌표를 구해 기하 함수를 호출하고 waypoints만 변경한다. 권한·문서 검증·원자적 이력을 책임진다.
- `app/wiring`: 클릭별 미완성 구간·방향·호버·손잡이 표시를 소유한다. Canvas는 포인터·키보드와 기존 취소/핀치 수명에 연결하고 명령을 제출한다. UI에서 확정 문서를 직접 조립하지 않는다.
- 이동 미리보기는 시작 문서와 현재 변위로 `previewCommand`를 호출한다. 확정도 같은 명령을 사용한다. 이전 미리보기의 점 목록을 다음 입력으로 사용하지 않는다.

## 공통 기하 규칙

1. 새 배선은 마지막 확정점부터 가로→세로(HV) 또는 세로→가로(VH)로 그린다. 빈 곳 클릭/탭은 미확정 구간을 확정한다. 방향 전환은 마지막 구간만 바꾸고 단자/도선에서 완료하면 전체 연결을 한 번에 저장한다.
2. 부품 이동·회전은 기존 도선의 가장 가까운 코너 좌표 하나만 각 끝의 가로/세로 축에 맞춘다. 가운데 경로와 다른 가지는 보존하고 분기점을 끌고 가지 않는다. 양 끝 변위가 같으면 경로 전체를 평행 이동한다.
3. 직선의 두 끝이 어긋나면 원래 축을 유지하는 3구간 경로를 두 끝의 중간 좌표로 만든다. ㄴ자는 원래 축 순서의 교점 하나를 다시 계산한다. 연결 ID는 항상 유지한다.
4. 선분 이동은 그 선분의 수직 방향 좌표만 바꾼다. 인접 구간은 길이만 달라진다. 전기적 끝점에 붙은 구간은 끝점을 유지하도록 짧은 연결 구간을 추가한다.
5. 대각선이 있는 이전 문서는 읽을 때 바꾸지 않는다. 해당 도선을 이동/수정할 때만 VH로 직각화한 뒤 같은 규칙을 적용한다. 편집하지 않은 도선은 그대로 둔다.

경로의 코너는 영구 잠금점이 아니다. 클릭은 현재 모양을 확정하고, 부품에 가장 가까운 코너는 이후 이동 시 조정될 수 있다. 잠금 상태·자동/수동 코너 구별·장애물 탐색·다른 도선 밀어내기·좌표에 따른 자동 연결은 추가하지 않는다. 큰 이동으로 경로가 접히거나 부품에 겹치면 사용자가 선분을 수정한다.

## 공개 명령과 저장

- `MoveWireSegment { wireId, segment, offset }`: 원본 도선을 직각화·정리한 점 목록의 선분 번호와 수직 방향 변위. 잘못된 ID/번호/비유한 변위는 구조화된 진단으로 거절한다. 0 변위는 경로·이력을 바꾸지 않는다.
- `ConnectToWire`에 선택적 `waypoints`를 추가해 분기 도착에도 사용자가 그린 경로를 보존한다. 출발 도선 분할과 도착 연결은 기존 원자적 명령 묶음을 사용한다.
- 새 명령은 활동의 allowedCommands에 명시적으로 허용되어야 한다. 기존 MoveComponents 허용으로 우회하지 않는다.
- 문서 필드는 기존 `Wire.waypoints`만 사용한다. v4 스키마와 이전 fixture 해석은 유지하므로 마이그레이션이 필요하지 않다. 미완성 클릭 목록과 손잡이 상태는 저장하지 않는다.

## 조작과 검증

방향 전환 버튼과 `/`, 마지막 경유점 되돌리기 버튼과 Backspace, Esc 전체 취소를 제공한다. 배선 중 방향키로 커서를 이동하고 Enter로 점을 확정할 수 있다. 단자와 도선의 기존 Tab/Enter 연결도 유지한다. 선택 도선의 사각 선분 손잡이는 분기 후보와 구별하고 마우스·터치 드래그 및 방향키를 지원한다.

`tests/wire-routing.test.ts`는 직각성·끝점 일치·입력 불변·역방향 대칭·평행 이동·가운데 경로 보존·분기 경계·권한·저장 왕복·동일 계산 결과·undo/redo를 검증한다. 문맥 배선/Canvas 이벤트 테스트는 클릭별 되돌리기, 동일 경로 미리보기/확정, 다중 터치 취소, 키 입력 전파 차단, 원위치 복귀를 검증한다. 기존 `fixtures/ux/wire-editing.json`과 물리 fixture를 그대로 사용한다.
