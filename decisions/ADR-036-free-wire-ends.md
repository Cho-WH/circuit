# ADR-036: 빈 공간 배선 시작·열린 끝 확정과 전압계 삽입

- 상태: accepted
- 결정일: 2026-10-08
- 관련: EDT-001/002/005, SIM-001, MEA-002, ADR-013/016/018

## 결정

사용자가 배선 도구를 직접 선택한 경우 빈 공간의 격자 위치에서 도선을 시작할 수 있다. 빈 공간을 누르면 기존 직각 경로의 한 구간을 고정하며, 마지막 고정점을 같은 격자 위치에서 다시 누르면 그 지점까지 열린 끝 도선으로 확정한다. 시작점만 반복해서 누르는 동작은 길이 0인 도선이나 노드를 만들지 않는다. 기본 선택 모드의 빈 공간은 기존 선택 동작을 유지한다.

기존 단자·도선 도착, 터치 후보 확인, 경유점 되돌리기와 전체 취소를 재사용한다. 빈 공간 끝점은 초안에서만 좌표로 보관한다. 확정 시 기존 `AddJunction`, `ConnectWire`, `ConnectToWire` 명령을 `executeCommands` 한 트랜잭션으로 실행한다. 기존 도선 분할·경로 유지·권한 검사·실행 취소를 공유하며 거부·취소는 부분 변경이나 고립 노드를 남기지 않는다. 좌표가 지나가는 다른 도선과 자동으로 전기 연결하지 않는다.

전압계의 자동 직렬 삽입 제한을 해제한다. 기존 두 단자 삽입의 공간·교차·권한 검사, 미리보기, 터치 확인을 그대로 따른다. 이상적 전압계의 무한 저항 모델은 유지한다. 직렬 연결한 전압계로 회로가 개방되어 전류가 0 A가 되는 현상을 관찰할 수 있다.

## 경계와 검증

- 빈 공간 초안 타입은 app/wiring 내부에만 둔다. 기존 접지 배치용 `WireAnchor`와 기존 연결 대상 탐색을 확장하지 않는다.
- 저장 구조·공개 editor 명령·계산 모델은 바꾸지 않는다. 회로 v6·측정 기록 v5를 유지한다. 열린 끝은 기존 Junction 참조로 저장한다.
- 마우스·터치 시작/확정, 시작점 중복 클릭, 경유점 되돌림, 취소·모드 변경, 기존 단자/도선과의 양방향 연결, 권한 거부의 원자성, 저장 왕복·Undo/Redo를 검증한다.
- 전압계 삽입 후 우회선 부재, 전류 0 A·전압 9 V, 미리보기 일치, Undo·저장 왕복과 마우스·터치 삽입을 검증한다.
