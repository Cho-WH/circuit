# 기술 결정 기록

ADR은 기술 선택의 배경, 결정, 결과를 기록한다.

## 상태

- `proposed`: 검토 중
- `accepted`: 현재 적용
- `superseded`: 다른 ADR로 대체
- `rejected`: 채택하지 않음
