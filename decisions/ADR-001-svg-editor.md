# ADR-001: SVG 기반 2D 회로 편집기

- 상태: accepted
- 결정일: 2026-09-23

## 배경

회로 기호를 직접 조작하고 시험지용 벡터 출력을 같은 자원에서 생성해야 한다. 도선, 단자, 선택 영역, 인쇄 선 굵기를 정밀하게 제어해야 한다.

## 결정

2D 편집기는 자체 SVG 캔버스를 사용한다.

## 결과

- 회로 기호와 출력 기호가 같은 `SymbolDefinition`을 공유한다.
- 보이는 선과 넓은 클릭 영역을 분리할 수 있다.
- 직각 도선, 분기점, 교차선 판정을 직접 설계한다.
- 화면 렌더러와 인쇄 렌더러는 별도지만 같은 기호 정의를 사용한다.
- Canvas는 대규모 성능 문제가 확인될 때 특정 레이어에 제한적으로 검토한다.

## 가변저항 표기 보완 (2026-09-23)

가변저항은 기존 수업용 지그재그 저항에 대각선 조절 화살표를 더한다. 공공 교육 자료인 [강원소방학교 전기장치 기호표](https://gfsa.gwd.go.kr/egf/bp/board/article/download?fileSeq=1179676)의 가변저항 표기를 근거로 삼았다. 팔레트·편집·SVG·PNG는 같은 기호 정의를 사용한다.

사용자 요청에 따라 이름과 기호만 구별하며 두 단자와 resistanceOhm 계산은 일반 저항과 동일하다. 별도 조절 손잡이나 세 번째 단자는 추가하지 않는다. 기존 파일 호환을 위해 저장 타입 resistive-load를 유지한다. 화살표 높이는 공통 이름·값 배치에 반영한다.
